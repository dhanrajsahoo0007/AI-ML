# Origins AI Learn (web app)

Next.js (App Router) UI for **Origins AI Learn**: guided paths for ML, deep learning, GenAI, LLMs, and agentic AI; interview prep; ML system design notes; and `/api/v1/*` route handlers backed by **PostgreSQL** and **Redis**.

See the [repository README](../../README.md) for full-stack Docker, local development, and GitHub setup.

## Scripts

From the **monorepo root**:

```bash
npm run dev -w web
npm run build -w web
npm run lint -w web
```

Or from `apps/web` after `npm install` at the root:

```bash
npm run dev
```
