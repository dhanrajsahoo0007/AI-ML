## Outcomes

You will understand data splits, features, models, evaluation, and how to iterate safely on real problems.

1. **Data and labels** — tabular data, leakage, train/validation/test.
2. **Models** — linear models, trees, ensembles, and when each fits.
3. **Evaluation** — metrics that match the decision you care about.
