Given a positive integer N, list every N-digit positive integer whose digits are strictly
increasing from left to right (no leading zero in the N-digit number when N &gt; 1).

## Examples

````text
Example 1:
    Input: N = 1
    Output: [0,1,2,...,9] (every one-digit number vacuously has strictly increasing digits)

Example 2:
    Input: N = 2
    Output starts with 12,13,...,89 (36 numbers total)
````

## Constraints

````text
- 1 <= N <= 9
````

<PremiumBreak />

## Approach

**Pattern:** Backtracking with increasing constraint
Build digit lists; each new digit must exceed the previous; for N&gt;1 first digit is 1..9.

1. DFS appends digits d with d &gt; last (or any 1..9 when empty).
2. When length equals N, convert digit list to integer and append.
3. For N == 1, return 0..9; for N &gt; 1 the first digit is 1..9 so there is no leading zero.

## Complexity

**Time:** O(C(9, N)) - choose N distinct increasing digits from 1..9.

**Space:** O(N) - recursion depth excluding output.

## Solution

````python
from typing import List


class Solution:
    def increasingNumbers(self, n: int) -> List[int]:
        result: List[int] = []

        def backtrack(path: List[int]) -> None:
            if len(path) == n:
                value = 0
                for d in path:
                    value = value * 10 + d
                result.append(value)
                return
            start = (path[-1] + 1) if path else 1
            for d in range(start, 10):
                path.append(d)
                backtrack(path)
                path.pop()

        if n == 1:
            return list(range(10))
        backtrack([])
        return result
````
