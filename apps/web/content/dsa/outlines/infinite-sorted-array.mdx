Treat a very large sorted array as "infinite": find the index of target, or -1. Implementation uses
a finite list and exponential expansion of the search window followed by binary search.

## Examples

````text
Example 1:
Input: nums = [1, 2, 3, 4, 5, ...], target = 5
Output: 4
````

## Constraints

````text
- nums is sorted ascending (finite slice used in code)
- target may be absent
````
