Design a logger that receives (timestamp, message) and returns True the first time a message
is seen in a new 10-second window; repeat prints of the same message within 10 seconds of
the last print should return False (LeetCode 359 style rate limiter).

## Examples

````text
Example 1:
shouldPrint(1,'a') True; shouldPrint(2,'a') False; shouldPrint(11,'a') True.
````

## Constraints

````text
- Timestamps are monotonic non-decreasing integers; message strings arbitrary.
````

<PremiumBreak />

## Approach

**Pattern:** Hash map of last-print time per message
Compare current timestamp with stored last time for that key.

1. Keep dict message -&gt; last\_printed\_timestamp.
2. On call, if t &lt; last + 10 return False else update last to t and return True.

## Complexity

**Time:** O(1) per call.

**Space:** O(unique messages).

## Solution

````python
from typing import Dict


class Logger:
    def __init__(self) -> None:
        self._last: Dict[str, int] = {}

    def shouldPrintMessage(self, timestamp: int, message: str) -> bool:
        prev = self._last.get(message, -10_000_000)
        if timestamp < prev + 10:
            return False
        self._last[message] = timestamp
        return True
````
