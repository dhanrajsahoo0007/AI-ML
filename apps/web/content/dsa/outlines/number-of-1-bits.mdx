Return the number of '1' bits in the unsigned 32-bit binary representation of n.

## Examples

````text
Example 1:
    Input: n = 11
    Output: 3
Example 2:
    Input: n = 128
    Output: 1
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
````
