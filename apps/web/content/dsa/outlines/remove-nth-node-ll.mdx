Given the head of a linked list, remove the nth node from the end and return the new head.

## Examples

````text
Example 1:
Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
````

## Constraints

````text
- 1 <= n <= list length <= 30
- 0 <= Node.val <= 100
````
