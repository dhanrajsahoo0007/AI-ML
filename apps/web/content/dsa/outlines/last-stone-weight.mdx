You are given an array of integers stones where stones\[i\] is the weight of the ith stone.
On each turn, choose the two heaviest stones and smash them together.
If x == y, both are destroyed. If x != y, the stone of weight y-x remains.
Return the weight of the last remaining stone, or 0 if none left.

## Examples

````text
Example 1:
    Input: stones = [2,7,4,1,8,1]
    Output: 1
    Explanation: 7&8->1, 2&4->2, 2&1->1, 1&1->0, remaining: 1

Example 2:
    Input: stones = [1]
    Output: 1
````

## Constraints

````text
- 1 <= stones.length <= 30
- 1 <= stones[i] <= 1000
````
