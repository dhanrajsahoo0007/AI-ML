Given an integer array nums sorted in non-decreasing order, remove duplicates in-place so that
each unique element appears only once. Return k, the count of unique elements; the first k slots
of nums must hold the unique values in order.

## Examples

````text
Example 1:
    Input: nums = [1, 1, 2]
    Output: k = 2, nums = [1, 2, _]
Example 2:
    Input: nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
    Output: k = 5, nums = [0, 1, 2, 3, 4, _, _, _, _, _]
````

## Constraints

````text
- 1 <= len(nums) <= 3 * 10^4
- -100 <= nums[i] <= 100
- nums is sorted in non-decreasing order.
````

## Approach

**Pattern:** Slow / fast pointers
Keep a write index for the next unique value and scan forward, copying whenever a new value appears.

1. If nums is empty, return 0.
2. Maintain write index L starting at 1 (first element is always unique).
3. For each index R from 1 to end, if nums\[R\] != nums\[R - 1\], assign nums\[L\] = nums\[R\] and increment L.
4. Return L as the number of unique elements.

This function removes duplicates from the input array 'nums' which is sorted

Algorithm:
1. Use two pointers: L and R

- R iterates through the array

3. Iterate through the array starting from the second element (index 1)

- Increment L
5. After the loop, L represents the number of unique elements

Space Complexity: O(1), as we modify the array in-place

## Complexity

**Time:** O(n) - Single pass over the array.

**Space:** O(1) - Only a few indices are used besides the input array.

## Solution

````python
from typing import List


class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        write = 1
        for read in range(1, len(nums)):
            if nums[read] != nums[read - 1]:
                nums[write] = nums[read]
                write += 1
        return write
````
