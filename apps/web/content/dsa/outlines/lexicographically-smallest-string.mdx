Given a lowercase string s, form a palindrome by changing characters so that the
result is lexicographically smallest. At each mirrored pair, set both characters to
the smaller of the two.

## Examples

````text
Example 1:
    Input: s = "abcd"
    Output: "abba"

Example 2:
    Input: s = "abc"
    Output: "aba"

Example 3:
    Input: s = "leetcode"
    Output: "edeccede"
````

## Constraints

````text
- 1 <= len(s) <= 1000
- s consists of lowercase English letters.
````

## Approach

**Pattern:** Two pointers from both ends
Greedily equalize outer pairs using the smaller letter so the growing prefix stays minimal.

1. Convert s to a mutable list of characters.
2. While left &lt; right, if the two letters differ, replace both with the smaller letter.
3. Advance both pointers toward the center.
4. Join the list into the final palindrome string.

## Complexity

**Time:** O(n) - One linear pass from both ends.

**Space:** O(n) - Mutable copy of the string.

## Solution

````python
class Solution:
    def makeSmallestPalindrome(self, s: str) -> str:
        left = 0
        right = len(s) - 1
        chars = list(s)
        while left < right:
            if chars[left] != chars[right]:
                if chars[left] < chars[right]:
                    chars[right] = chars[left]
                else:
                    chars[left] = chars[right]
            left += 1
            right -= 1
        return "".join(chars)
````
