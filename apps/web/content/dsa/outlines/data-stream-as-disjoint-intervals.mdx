Implement a data structure that accepts integers and always represents the set of
distinct values as a sorted list of disjoint closed intervals. Support addNum to
insert a value (no effect if it already exists) and getIntervals to return the
current partition.

## Examples

````text
Example 1:
    Input: addNum(1), addNum(3), addNum(7), getIntervals()
    Output: [[1,1],[3,3],[7,7]]

Example 2:
    Input: addNum(2), getIntervals()
    Output: [[1,3],[7,7]]
````

## Constraints

````text
- At most 3 * 10^4 total calls to addNum and getIntervals combined
- 0 <= value <= 10^9
````
