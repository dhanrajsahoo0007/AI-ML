Given a circular integer array nums, return the maximum possible sum of a non-empty subarray.
The array is circular, so a subarray may wrap from the end to the beginning.

## Examples

````text
Example 1:
    Input: nums = [1,-2,3,-2]
    Output: 3

Example 2:
    Input: nums = [5,-3,5]
    Output: 10

Example 3:
    Input: nums = [-3,-2,-3]
    Output: -2
````

## Constraints

````text
- 1 <= nums.length <= 3 * 10^4
- -3 * 10^4 <= nums[i] <= 3 * 10^4
````
