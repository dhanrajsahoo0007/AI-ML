Given the head of a sorted singly linked list, delete duplicates so each value appears once.

## Examples

````text
Example 1:
    Input: head = [1,1,2]
    Output: [1,2]

Example 2:
    Input: head = [1,1,2,3,3]
    Output: [1,2,3]
````

## Constraints

````text
- 0 <= n <= 300
- -100 <= Node.val <= 100
- list is sorted in non-decreasing order
````
