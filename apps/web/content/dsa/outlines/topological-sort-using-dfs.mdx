Given a directed acyclic graph (DAG) with V vertices and directed edges \[u, v\], return any topological
ordering of vertices such that for every edge u -&gt; v, u appears before v. The graph may be disconnected.
Topological order exists only for a DAG; this implementation assumes no cycle.

## Examples

````text
Example 1:
    Input: V = 6, edges = [[5,2],[5,0],[4,0],[4,1],[2,3],[3,1]]
    Output: One valid order is [4,5,2,3,1,0] (any valid topological order is acceptable).
Example 2:
    Input: V = 3, edges = [[0,1],[0,2]]
    Output: [0,2,1] or [0,1,2] depending on DFS neighbor order.
````

## Constraints

````text
- 1 <= V, E <= 10^4
- Only defined on DAGs (no directed cycles).
````
