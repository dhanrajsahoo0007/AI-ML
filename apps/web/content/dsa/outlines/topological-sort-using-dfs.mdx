Given a directed acyclic graph (DAG) with V vertices and directed edges \[u, v\], return any topological
ordering of vertices such that for every edge u -&gt; v, u appears before v. The graph may be disconnected.
Topological order exists only for a DAG; this implementation assumes no cycle.

## Examples

````text
Example 1:
    Input: V = 6, edges = [[5,2],[5,0],[4,0],[4,1],[2,3],[3,1]]
    Output: One valid order is [4,5,2,3,1,0] (any valid topological order is acceptable).
Example 2:
    Input: V = 3, edges = [[0,1],[0,2]]
    Output: [0,2,1] or [0,1,2] depending on DFS neighbor order.
````

## Constraints

````text
- 1 <= V, E <= 10^4
- Only defined on DAGs (no directed cycles).
````

## Approach

**Pattern:** Topological sort via DFS finish times
Push vertices to a stack after visiting all descendants; reversing the stack yields a valid topological order.

1. Build adjacency lists for directed edges.
2. DFS each unvisited node; after exploring all outgoing edges, append the node to a stack.
3. Return stack reversed.

## Complexity

**Time:** O(V + E) — DFS visits each vertex and edge once.

**Space:** O(V + E) — graph storage plus O(V) for stack and recursion.

Notes: A topological order is a linear extension of the partial order defined by edges; it is not unique.
Kahn's BFS peel is an alternative when indegrees are known.

## Solution

````python
from typing import List


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
        return adj

    def topological_sort_dfs(self, V: int, adj: List[List[int]]) -> List[int]:
        visited = [False] * V
        stack: List[int] = []

        def dfs(u: int) -> None:
            visited[u] = True
            for v in adj[u]:
                if not visited[v]:
                    dfs(v)
            stack.append(u)

        for i in range(V):
            if not visited[i]:
                dfs(i)
        return stack[::-1]


def _is_valid_order(order: List[int], V: int, edges: List[List[int]]) -> bool:
    pos = {x: i for i, x in enumerate(order)}
    return all(pos[u] < pos[v] for u, v in edges)
````
