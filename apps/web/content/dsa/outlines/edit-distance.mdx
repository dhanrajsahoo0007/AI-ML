Given two strings word1 and word2, return the minimum number of operations to
convert word1 to word2 (insert, delete, or replace a character).

## Examples

````text
Example 1:
    Input: word1 = "horse", word2 = "ros"
    Output: 3
Example 2:
    Input: word1 = "intention", word2 = "execution"
    Output: 5
````

## Constraints

````text
- 0 <= len(word1), len(word2) <= 500
````

<PremiumBreak />

## Approach

**Pattern:** Levenshtein / 2D DP
dp\[i\]\[j\] = edit distance between first i chars of word1 and first j of word2.

1. Base rows/cols for empty prefixes.
2. If chars equal dp\[i-1\]\[j-1\]; else 1 + min(replace, delete, insert).

## Complexity

**Time:** O(m \* n).

**Space:** O(m \* n).

## Solution

````python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
        return dp[m][n]
````
