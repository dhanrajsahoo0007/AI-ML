Given a string of symbols T, F, &amp;, \|, ^ (operands at odd positions, operators at even
between them), count ways to parenthesize so the expression evaluates to True.
Return answer modulo 1003.

## Examples

````text
Example 1: s = "T|F" -> 1
Example 2: s = "F&T^T" -> 3 (per GFG small cases)
````

## Constraints

````text
- len(s) <= 100 and follows valid alternating pattern
````
