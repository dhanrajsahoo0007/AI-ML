Given a maze with '+', '.', and an entrance on an empty cell, find the nearest exit from the
entrance. An exit is any empty cell on the border that is not the entrance. Return the number
of steps in the shortest path, or -1 if none.

## Examples

````text
Example 1:
    Input: maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
    Output: 1
Example 2:
    Input: maze = [["+","+","+"],[".",".","."],["+","+","+"]], entrance = [1,0]
    Output: 2
````

## Constraints

````text
- 1 <= m, n <= 100
- maze[i][j] is '+', '.', or entrance is on '.'
````
