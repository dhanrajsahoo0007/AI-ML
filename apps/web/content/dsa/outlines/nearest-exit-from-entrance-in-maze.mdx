Given a maze with '+', '.', and an entrance on an empty cell, find the nearest exit from the
entrance. An exit is any empty cell on the border that is not the entrance. Return the number
of steps in the shortest path, or -1 if none.

## Examples

````text
Example 1:
    Input: maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
    Output: 1
Example 2:
    Input: maze = [["+","+","+"],[".",".","."],["+","+","+"]], entrance = [1,0]
    Output: 2
````

## Constraints

````text
- 1 <= m, n <= 100
- maze[i][j] is '+', '.', or entrance is on '.'
````

## Approach

**Pattern:** Graph - Multi-source / BFS on grid

1. BFS from entrance over '.' cells.
2. First time we dequeue a border empty cell that is not the entrance, return its distance.

## Complexity

**Time:** O(m \* n).

**Space:** O(m \* n).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        m, n = len(maze), len(maze[0])
        er, ec = entrance
        q = deque([(er, ec, 0)])
        vis = {(er, ec)}
        dirs = ((-1, 0), (1, 0), (0, -1), (0, 1))

        while q:
            r, c, d = q.popleft()
            if (r in (0, m - 1) or c in (0, n - 1)) and (r, c) != (er, ec):
                return d
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and maze[nr][nc] == "." and (nr, nc) not in vis:
                    vis.add((nr, nc))
                    q.append((nr, nc, d + 1))
        return -1
````
