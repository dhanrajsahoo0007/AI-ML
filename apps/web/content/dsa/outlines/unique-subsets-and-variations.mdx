Generate all unique subsequences of a string (set of strings, empty subsequence
included) using recursion with include/exclude branching.

## Examples

````text
Example 1:
    Input: "abc"
    Output sorted: ["", "a", "ab", "abc", "ac", "b", "bc", "c"]

Example 2:
    Input: "aa"
    Output sorted: ["", "a", "aa"]
````

## Constraints

````text
- Characters are lowercase letters in tests
````
