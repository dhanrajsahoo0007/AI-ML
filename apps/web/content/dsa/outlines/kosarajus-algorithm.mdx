Given a directed graph with V vertices (0 .. V-1) and a list of directed edges \[u, v\],
find all Strongly Connected Components (SCCs). Return a list of components; each
component is a sorted list of vertices (sorted for deterministic tests). Every vertex
appears in exactly one component.

## Examples

````text
Example 1:
    Input: V = 5, edges = [[1,0],[0,2],[2,1],[0,3],[3,4]]
    Output: [[0,1,2],[3],[4]]
    (cycle 0-2-1-0, then 3, then 4)
Example 2:
    Input: V = 3, edges = [[0,1],[1,2]]
    Output: [[0],[1],[2]]  (a DAG: each vertex its own SCC)
````

## Constraints

````text
- 1 <= V <= 10^4
- 0 <= len(edges) <= 10^5
````
