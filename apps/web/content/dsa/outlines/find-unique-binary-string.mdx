Given an array nums of n distinct binary strings each of length n, return any binary string of
length n that does not appear in nums.

## Examples

````text
Example 1:
    Input: nums = ["01", "10"]
    Output: "00" or "11" (any missing string is valid)
Example 2:
    Input: nums = ["00", "01"]
    Output: "10" or "11"
````

## Constraints

````text
- 1 <= n <= 16
- len(nums[i]) == n
- All strings in nums are distinct.
````

## Approach

**Pattern:** Diagonal / Cantor argument
Flip the i-th diagonal bit relative to nums\[i\] so the constructed string differs from every row.

1. For each index i from 0 to n - 1, set answer bit i to the opposite of nums\[i\]\[i\].
2. Join bits into a string of length n.

## Complexity

**Time:** O(n^2) - n rows, each row accessed at one index (still O(n) string indexing overall O(n^2) if building char by char - actually O(n) total characters read).

**Space:** O(n) - Output string.

## Solution

````python
from typing import List


class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        return "".join("1" if nums[i][i] == "0" else "0" for i in range(len(nums)))
````
