Given rental intervals (pickup, return) as half-open or closed intervals, find the minimum
fleet size (maximum number of simultaneous active rentals).

## Examples

````text
Example 1:
Input: [(1, 4), (2, 5), (7, 9)]
Output: 2
````

## Constraints

````text
- Times are integers; treat overlap if intervals share any positive-length intersection.
````
