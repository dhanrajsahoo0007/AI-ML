Given rental intervals (pickup, return) as half-open or closed intervals, find the minimum
fleet size (maximum number of simultaneous active rentals).

## Examples

````text
Example 1:
Input: [(1, 4), (2, 5), (7, 9)]
Output: 2
````

## Constraints

````text
- Times are integers; treat overlap if intervals share any positive-length intersection.
````

<PremiumBreak />

## Approach

**Pattern:** Sweep line / difference array
Event +1 at start, -1 after end for half-open \[start, end) or +1 start, -1 at end+epsilon.

1. Use events: at time t, add delta for start/end.
2. For closed \[s,e\], use +1 at s and -1 at e+1 (discrete sweep) or sort interval endpoints.
3. Track running sum maximum.

## Complexity

**Time:** O(n log n) for sorting events.

**Space:** O(n) for events.

## Solution

````python
from typing import List, Tuple


class CarFleetSystem:
    @staticmethod
    def min_cars_needed(logs: List[Tuple[int, int]]) -> int:
        """Closed intervals [s, e]; a car frees strictly after e, so the next rental may start at e+1."""
        events: List[Tuple[int, int]] = []
        for s, e in logs:
            events.append((s, 1))
            events.append((e + 1, -1))
        events.sort(key=lambda x: (x[0], -x[1]))
        cur = 0
        best = 0
        i = 0
        while i < len(events):
            t = events[i][0]
            while i < len(events) and events[i][0] == t:
                cur += events[i][1]
                i += 1
            best = max(best, cur)
        return best
````
