Given a string s, return any longest substring that appears at least twice in s.
If none exists, return the empty string.

## Examples

````text
Example 1:
    Input: s = "banana"
    Output: "ana"

Example 2:
    Input: s = "abcd"
    Output: ""
````

## Constraints

````text
- 2 <= len(s) <= 3 * 10^4
- s contains only lowercase English letters.
````
