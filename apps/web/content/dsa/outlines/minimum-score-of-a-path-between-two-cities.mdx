You are given n cities and undirected roads with distances. The score of a walk from
city 1 to city n is the minimum road distance appearing on that walk (revisiting cities and
roads is allowed). Return the minimum possible score among all such walks from 1 to n.

## Examples

````text
Example 1:
    Input: n = 4, roads = [[1,2,9],[2,3,6],[2,4,5],[1,4,10]]
    Output: 5
Example 2:
    Input: n = 4, roads = [[1,2,2],[1,3,4],[3,4,7]]
    Output: 2
````

## Constraints

````text
- 2 <= n <= 10^5
- 1 <= len(roads) <= 10^5
- There is a path between cities 1 and n
````

<PremiumBreak />

## Approach

**Pattern:** Graph - Connectivity + scan edges (component of city 1)

1. Build adjacency and collect all nodes reachable from city 1 (DFS/BFS).
2. Among all roads with both endpoints in that component, take the minimum road weight.
3. That value is the answer (you can route through the globally lightest edge in the 1-side
component while still reaching n).

## Complexity

**Time:** O(n + m).

**Space:** O(n + m).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        g = defaultdict(list)
        for a, b, w in roads:
            g[a].append(b)
            g[b].append(a)

        seen = {1}
        dq = deque([1])
        while dq:
            u = dq.popleft()
            for v in g[u]:
                if v not in seen:
                    seen.add(v)
                    dq.append(v)

        best = float("inf")
        for a, b, w in roads:
            if a in seen and b in seen:
                best = min(best, w)
        return int(best)
````
