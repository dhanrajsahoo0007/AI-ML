Given integers n and m, return the integer r such that r^n == m, or -1 if no such integer exists.

## Examples

````text
Example 1:
Input: n = 3, m = 27
Output: 3
````

## Constraints

````text
- 1 <= n <= 30
- 1 <= m <= 10^9
````
