Given an integer array nums of length n where every value is in \[1, n\], some
values appear twice and others once. Return two lists: values that appear twice
and values in \[1, n\] that never appear.

## Examples

````text
Example 1:
    Input: nums = [4,3,2,7,8,2,3,1]
    Output: ([2,3], [5,6])  # duplicates sorted, missing sorted
Example 2:
    Input: nums = [1,1]
    Output: ([1], [2])
````

## Constraints

````text
- 2 <= len(nums) <= 10^5
- 1 <= nums[i] <= n
````
