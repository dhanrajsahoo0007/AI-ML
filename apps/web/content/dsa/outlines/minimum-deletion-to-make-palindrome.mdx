Given string s, return the minimum deletions needed so the result is a palindrome.

## Examples

````text
Example 1:
    Input: s = "aebcbda"
    Output: 2
Example 2:
    Input: s = "a"
    Output: 0
````

## Constraints

````text
- 1 <= len(s) <= 1000
````
