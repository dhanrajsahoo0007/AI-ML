Implement a singly linked list supporting insert at beginning/end, insert and delete at index,
delete first node with a given value, length, and traversal (as values for testing).

## Examples

````text
Example 1:
Input: build [1,2,3], insert 0 at beginning, delete value 2
Output: list order [0,1,3], length 3
````

## Constraints

````text
- Values are integers; indices are 0-based; invalid index operations leave list unchanged.
````
