Infinite coins of each denomination in coins, but you may not mix denominations in one amount.
Return the k-th smallest positive amount in the multiset of all single-denomination multiples.

## Examples

````text
Example 1:
Input: coins = [3, 6, 9], k = 3
Output: 9
````

## Constraints

````text
- 1 <= len(coins) <= 15
- 1 <= k <= 2 * 10^9
````

## Approach

**Pattern:** Binary Search on Value + Inclusion–Exclusion
Count numbers &lt;= X divisible by at least one coin via IE over LCMs of nonempty subsets.

1. count(X) = union size of multiples &lt;= X.
2. Binary search smallest X with count(X) &gt;= k; expand hi until count(hi) &gt;= k.

## Complexity

**Time:** O(2^n \* n \* log U) - U is answer magnitude bound.

**Space:** O(1) - Subset iteration only.

You are given an integer array coins representing coins of different denominations and an integer k.

You have an infinite number of coins of each denomination. However, you are not allowed to combine coins of different denominations.

Return the kth smallest amount that can be made using these coins.

Explanation: The given coins can make the following amounts:
Coin 3 produces multiples of 3: 3, 6, 9, 12, 15, etc.
Coin 6 produces multiples of 6: 6, 12, 18, 24, etc.
Coin 9 produces multiples of 9: 9, 18, 27, 36, etc.
All of the coins combined produce: 3, 6, 9, 12, 15, etc.

Example 2:

Input: coins = \[5,2\], k = 7

Output: 12

Explanation: The given coins can make the following amounts:
Coin 5 produces multiples of 5: 5, 10, 15, 20, etc.
Coin 2 produces multiples of 2: 2, 4, 6, 8, 10, 12, etc.
All of the coins combined produce: 2, 4, 5, 6, 8, 10, 12, 14, 15, etc.

1 &lt;= coins.length &lt;= 15
1 &lt;= coins\[i\] &lt;= 25
1 &lt;= k &lt;= 2 \* 109
coins contains pairwise distinct integers.

## Solution

````python
from math import gcd
from typing import List


class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        n = len(coins)

        def count_leq(x: int) -> int:
            total = 0
            for mask in range(1, 1 << n):
                bits = bin(mask).count("1")
                l = 1
                for i in range(n):
                    if mask >> i & 1:
                        l = l * coins[i] // gcd(l, coins[i])
                c = x // l
                if bits % 2 == 1:
                    total += c
                else:
                    total -= c
            return total

        lo = min(coins)
        hi = lo
        while count_leq(hi) < k:
            hi *= 2
        while lo < hi:
            mid = (lo + hi) // 2
            if count_leq(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
````
