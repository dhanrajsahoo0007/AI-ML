Design a token manager with a fixed time-to-live (TTL). Support generating
tokens, renewing unexpired tokens (extending TTL from renewal time), and
counting how many tokens are still unexpired at a query time.

## Examples

````text
Example 1:
    TTL=10; generate('a',1); renew('a',5); count at 12 -> 1
Example 2:
    Renew only applies if the token exists and currentTime < expiry.
````

## Constraints

````text
- 1 <= timeToLive, currentTime <= 10^8
- tokenId are non-empty strings; at most 10^4 calls total
````
