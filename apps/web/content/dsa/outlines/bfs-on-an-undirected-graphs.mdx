Given V vertices (0..V-1) and undirected edges, build an adjacency list and return the breadth-first
traversal order starting from vertex 0.

## Examples

````text
Example 1:
    Input: V = 5, edges = [[0,1],[0,2],[0,3],[2,4]]
    Output: [0, 1, 2, 3, 4]
Example 2:
    Input: V = 4, edges = [[0,1],[0,3],[1,2]]
    Output: [0, 1, 3, 2]
````

## Constraints

````text
- 1 <= V <= 10^4
````

## Approach

**Pattern:** Breadth-first search on graph
Use a queue to visit vertices in increasing distance layers from the start.

1. Build undirected adjacency lists.
2. Initialize a queue with 0, mark 0 visited.
3. Repeatedly dequeue u, append u to the result, enqueue unvisited neighbors and mark them visited.

## Complexity

**Time:** O(V + E)

**Space:** O(V + E) for adjacency, O(V) for queue and visited.

## Solution

````python
from typing import List
from collections import deque


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        return adj

    def bfs_of_graph(self, V: int, adj: List[List[int]]) -> List[int]:
        visited = [False] * V
        result: List[int] = []
        q: deque[int] = deque([0])
        visited[0] = True
        while q:
            u = q.popleft()
            result.append(u)
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    q.append(v)
        return result
````
