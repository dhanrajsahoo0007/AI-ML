Given strings s, a, b and integer k, an index i is beautiful if a occurs in s at i
and some occurrence of b in s lies within distance k of i. Return all beautiful
indices in sorted order.

## Examples

````text
Example 1:
    Input: s = "isawsquirrelnearmysquirrelhouseohmy", a = "my", b = "squirrel", k = 15
    Output: [16, 33]

Example 2:
    Input: s = "abcd", a = "a", b = "a", k = 4
    Output: [0]
````

## Constraints

````text
- 1 <= k <= len(s) <= 10^5
- 1 <= len(a), len(b) <= 10
````
