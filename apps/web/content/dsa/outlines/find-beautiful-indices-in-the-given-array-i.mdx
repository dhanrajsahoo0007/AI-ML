Given strings s, a, b and integer k, an index i is beautiful if a occurs in s at i
and some occurrence of b in s lies within distance k of i. Return all beautiful
indices in sorted order.

## Examples

````text
Example 1:
    Input: s = "isawsquirrelnearmysquirrelhouseohmy", a = "my", b = "squirrel", k = 15
    Output: [16, 33]

Example 2:
    Input: s = "abcd", a = "a", b = "a", k = 4
    Output: [0]
````

## Constraints

````text
- 1 <= k <= len(s) <= 10^5
- 1 <= len(a), len(b) <= 10
````

<PremiumBreak />

## Approach

**Pattern:** KMP plus binary search
Find all match positions with KMP, then for each a-index check whether any b-index lies in \[i-k, i+k\] using bisect.

1. Build the prefix (pi) table for a pattern and run KMP on s to list a-positions and b-positions.
2. Sort b-positions (KMP already yields increasing order).
3. For each a-index i, use bisect\_left to find the first b-index &gt;= i-k; if it exists and &lt;= i+k, keep i.
4. Return collected indices.

## Complexity

**Time:** O(len(s) + len(a) + len(b) + A log B) with A, B match counts.

**Space:** O(A + B) - Occurrence lists plus pi arrays.

## Solution

````python
import bisect
from typing import List


class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        hits_a = self._kmp_find(s, a)
        hits_b = self._kmp_find(s, b)
        answer: List[int] = []
        for i in hits_a:
            lo = i - k
            hi = i + k
            idx = bisect.bisect_left(hits_b, lo)
            if idx < len(hits_b) and hits_b[idx] <= hi:
                answer.append(i)
        return answer

    def _kmp_find(self, text: str, pattern: str) -> List[int]:
        if not pattern:
            return []
        m = len(pattern)
        pi = [0] * m
        for i in range(1, m):
            j = pi[i - 1]
            while j and pattern[i] != pattern[j]:
                j = pi[j - 1]
            if pattern[i] == pattern[j]:
                j += 1
            pi[i] = j
        hits: List[int] = []
        j = 0
        for i, ch in enumerate(text):
            while j and ch != pattern[j]:
                j = pi[j - 1]
            if ch == pattern[j]:
                j += 1
            if j == m:
                hits.append(i - m + 1)
                j = pi[j - 1]
        return hits
````
