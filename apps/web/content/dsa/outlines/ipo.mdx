LeetCode is preparing for its IPO. The company can work on at most k distinct projects.
Each project has a capital requirement and a pure profit. Starting with capital w,
find the maximum capital after completing at most k projects.

## Examples

````text
Example 1:
    Input: k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
    Output: 4
    Explanation: Start with w=0, do project 0 (profit 1, w=1),
                 then project 2 (profit 3, w=4).

Example 2:
    Input: k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
    Output: 6
````

## Constraints

````text
- 1 <= k <= 10^5
- 0 <= w <= 10^9
- n == profits.length == capital.length
- 1 <= n <= 10^5
- 0 <= profits[i] <= 10^4
- 0 <= capital[i] <= 10^9
````

## Approach

**Pattern:** Two Heaps
We use a min-heap sorted by capital requirements and a max-heap for available profits.
This lets us efficiently find the most profitable affordable project at each step.

1. Sort projects by capital requirement (min-heap).
2. For each of k rounds:
a. Move all affordable projects to a max-heap of profits.
b. Pick the most profitable project and add its profit to capital.
3. Return final capital.

## Complexity

**Time:** O(N log N)
- Sorting: O(N log N). Each project pushed/popped once: O(N log N).

**Space:** O(N) for both heaps.

## Solution

````python
import heapq
from typing import List


class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: List[int], capital: List[int]) -> int:
        projects = sorted(zip(capital, profits))
        available_profits = []
        i = 0
        n = len(profits)

        for _ in range(k):
            while i < n and projects[i][0] <= w:
                heapq.heappush(available_profits, -projects[i][1])
                i += 1

            if not available_profits:
                break

            # Profit increases capital (undo negation from max-heap encoding).
            w -= heapq.heappop(available_profits)

        return w
````
