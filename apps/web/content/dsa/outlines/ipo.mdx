LeetCode is preparing for its IPO. The company can work on at most k distinct projects.
Each project has a capital requirement and a pure profit. Starting with capital w,
find the maximum capital after completing at most k projects.

## Examples

````text
Example 1:
    Input: k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
    Output: 4
    Explanation: Start with w=0, do project 0 (profit 1, w=1),
                 then project 2 (profit 3, w=4).

Example 2:
    Input: k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
    Output: 6
````

## Constraints

````text
- 1 <= k <= 10^5
- 0 <= w <= 10^9
- n == profits.length == capital.length
- 1 <= n <= 10^5
- 0 <= profits[i] <= 10^4
- 0 <= capital[i] <= 10^9
````
