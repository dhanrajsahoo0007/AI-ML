Implement full matching of a text s against a pattern p where '.' matches any
single character and '\*' matches zero or more of the preceding element.

## Examples

````text
Example 1:
    Input: s = "aa", p = "a*"
    Output: True

Example 2:
    Input: s = "ab", p = ".*"
    Output: True
````

## Constraints

````text
- 0 <= len(s), len(p) <= 20 in tests
````
