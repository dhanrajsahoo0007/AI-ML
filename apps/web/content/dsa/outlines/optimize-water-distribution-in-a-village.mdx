There are n houses in a village. Wells can be built at houses with cost wells\[i-1\] (0 if
no well). Pipes connect houses given as \[house1, house2, cost\]. Each house must get water
via a well or pipes. Return the minimum total cost.

## Examples

````text
Example 1:
    Input: n = 3, wells = [1,2,2], pipes = [[1,2,1],[2,3,1]]
    Output: 3
Example 2:
    Input: n = 2, wells = [1,1], pipes = [[1,2,1],[1,2,2]]
    Output: 2
````

## Constraints

````text
- 2 <= n <= 10^4
- wells.length == n
- 1 <= len(pipes) <= 10^4
````
