There are n houses in a village. Wells can be built at houses with cost wells\[i-1\] (0 if
no well). Pipes connect houses given as \[house1, house2, cost\]. Each house must get water
via a well or pipes. Return the minimum total cost.

## Examples

````text
Example 1:
    Input: n = 3, wells = [1,2,2], pipes = [[1,2,1],[2,3,1]]
    Output: 3
Example 2:
    Input: n = 2, wells = [1,1], pipes = [[1,2,1],[1,2,2]]
    Output: 2
````

## Constraints

````text
- 2 <= n <= 10^4
- wells.length == n
- 1 <= len(pipes) <= 10^4
````

## Approach

**Pattern:** Graph - MST (Kruskal) with virtual well node

1. Add node 0 connected to each house i with edge weight wells\[i-1\].
2. Run Kruskal MST on all edges (virtual well edges + pipes); sum chosen weights.

## Complexity

**Time:** O(E log E) sorting edges.

**Space:** O(n + E) for DSU and edges.

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def minCostToSupplyWater(self, n: int, wells: List[int], pipes: List[List[int]]) -> int:
        edges = []
        for i, w in enumerate(wells, start=1):
            edges.append((w, 0, i))
        for a, b, c in pipes:
            edges.append((c, a, b))
        edges.sort()
        parent = list(range(n + 1))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> bool:
            ra, rb = find(a), find(b)
            if ra == rb:
                return False
            parent[rb] = ra
            return True

        total = 0
        for w, a, b in edges:
            if union(a, b):
                total += w
        return total
````
