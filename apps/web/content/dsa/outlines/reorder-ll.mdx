Reorder L0...Ln to L0 -&gt; Ln -&gt; L1 -&gt; Ln-1 -&gt; ... without changing stored values except by rewiring.

## Examples

````text
Example 1:
Input: head = [1,2,3,4]
Output: [1,4,2,3]
````

## Constraints

````text
- 1 <= n <= 5 * 10^4
- 1 <= Node.val <= 1000
````
