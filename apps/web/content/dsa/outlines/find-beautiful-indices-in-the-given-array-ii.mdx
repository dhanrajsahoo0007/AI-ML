Same as part I: indices i where pattern a occurs in s at i and some occurrence of b
lies within k positions. Constraints are larger, so use the same KMP plus bisect
approach for linear-time matching.

## Examples

````text
Example 1:
    Input: s = "isawsquirrelnearmysquirrelhouseohmy", a = "my", b = "squirrel", k = 15
    Output: [16, 33]

Example 2:
    Input: s = "abcd", a = "a", b = "a", k = 4
    Output: [0]
````

## Constraints

````text
- 1 <= len(s), len(a), len(b) <= 5 * 10^5
- 1 <= k <= len(s)
````
