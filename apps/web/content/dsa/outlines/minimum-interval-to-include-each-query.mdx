You are given a list of closed intervals \[left\_i, right\_i\] and an array of queries.
For each query q, find the smallest interval (by number of integers it contains) that
still contains q. If no interval contains q, use -1 for that answer.

## Examples

````text
Example 1:
    Input: intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]
    Output: [3,3,1,4]

Example 2:
    Input: intervals = [[2,3],[2,5],[1,8],[20,25]], queries = [2,19,25,22,30]
    Output: [2,-1,6,6,-1]
````

## Constraints

````text
- 1 <= len(intervals) <= 10^5
- 1 <= len(queries) <= 10^5
- intervals[i].length == 2 and 1 <= left_i <= right_i <= 10^7
````

## Approach

**Pattern:** Sweep intervals with hash map per query
Grouping queries by value and scanning sorted unique interval endpoints lets each query
inherit the best active interval size in amortized linear time over all events.

1. Build a map from each query value to its list of indices.
2. Collect every distinct endpoint (interval starts, ends, query values) and sort.
3. Sweep endpoints, activating intervals on their starts and deactivating on ends+1.
4. Track the minimum width among active intervals covering the current coordinate and
assign answers when reaching each query key.

## Complexity

**Time:** O((n + m + u) log u) for n intervals, m queries, u unique endpoints.

**Space:** O(n + m) for bookkeeping structures.

## Solution

````python
from collections import defaultdict
from typing import List


class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        index_map: dict[int, List[int]] = defaultdict(list)
        for idx, value in enumerate(queries):
            index_map[value].append(idx)

        events: List[tuple[int, str, int, int]] = []
        for left, right in intervals:
            width = right - left + 1
            events.append((left, "start", width, right))
            events.append((right + 1, "end", width, right))

        for value in index_map:
            events.append((value, "query", 0, 0))

        events.sort(key=lambda item: (item[0], 0 if item[1] == "start" else 1 if item[1] == "end" else 2))

        active: dict[int, int] = {}
        answers = [-1] * len(queries)

        for pos, kind, width, right in events:
            if kind == "start":
                active[right] = width
            elif kind == "end":
                if active.get(right) == width:
                    active.pop(right, None)
            else:
                if not active:
                    best = -1
                else:
                    best = min(active.values())
                for q_index in index_map[pos]:
                    answers[q_index] = best

        return answers
````
