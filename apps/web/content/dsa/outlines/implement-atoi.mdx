Implement atoi: convert a string to a 32-bit signed integer by trimming leading
whitespace, optional sign, then reading digits until a non-digit or end of string.
Clamp the result to \[-2^31, 2^31 - 1\]. Return 0 if no valid conversion.

## Examples

````text
Example 1:
    Input: s = "42"
    Output: 42

Example 2:
    Input: s = "   -042"
    Output: -42

Example 3:
    Input: s = "1337c0d3"
    Output: 1337

Example 4:
    Input: s = "words and 987"
    Output: 0
````

## Constraints

````text
- 0 <= len(s) <= 200
- s consists of English letters, digits, ' ', '+', '-', and '.'.
````

## Approach

**Pattern:** State machine / parsing
Walk the string in phases: skip spaces, read sign, accumulate digits with overflow check.

1. Strip leading whitespace by advancing an index.
2. Read optional '+' or '-' to set sign.
3. While digits remain, update value as value \* 10 + digit with clamping against INT32 bounds.
4. Return signed value clamped to 32-bit range.

## Complexity

**Time:** O(n) - Single pass over s.

**Space:** O(1) - Only a few integer variables.

## Solution

````python
class Solution:
    def myAtoi(self, s: str) -> int:
        INT_MAX = 2**31 - 1
        INT_MIN = -2**31
        n = len(s)
        i = 0
        while i < n and s[i] == " ":
            i += 1
        if i == n:
            return 0
        sign = 1
        if s[i] in "+-":
            sign = -1 if s[i] == "-" else 1
            i += 1
        result = 0
        while i < n and s[i].isdigit():
            digit = ord(s[i]) - ord("0")
            if result > (INT_MAX - digit) // 10:
                return INT_MAX if sign == 1 else INT_MIN
            result = result * 10 + digit
            i += 1
        return sign * result
````
