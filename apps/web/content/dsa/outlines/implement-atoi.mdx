Implement atoi: convert a string to a 32-bit signed integer by trimming leading
whitespace, optional sign, then reading digits until a non-digit or end of string.
Clamp the result to \[-2^31, 2^31 - 1\]. Return 0 if no valid conversion.

## Examples

````text
Example 1:
    Input: s = "42"
    Output: 42

Example 2:
    Input: s = "   -042"
    Output: -42

Example 3:
    Input: s = "1337c0d3"
    Output: 1337

Example 4:
    Input: s = "words and 987"
    Output: 0
````

## Constraints

````text
- 0 <= len(s) <= 200
- s consists of English letters, digits, ' ', '+', '-', and '.'.
````
