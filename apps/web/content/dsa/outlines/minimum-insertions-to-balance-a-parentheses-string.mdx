A string is balanced if it is empty, concatenation of balanced strings, or of the form (A)) where
A is balanced. Return the minimum insertions needed to balance the given parentheses string.

## Examples

````text
Example 1:
Input: "(()))"
Output: 1
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s consists of '(' and ')' only
````
