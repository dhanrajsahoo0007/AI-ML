Given a binary tree, find the minimum depth: the number of nodes along the shortest path from the root
down to the nearest leaf (a node with no children).

## Examples

````text
Example 1:
    Input: root = [3,9,20,None,None,15,7]
    Output: 2
Example 2:
    Input: root = [2,None,3,None,4,None,5,None,6]
    Output: 5
````

## Constraints

````text
- The number of nodes is in the range [0, 10^5].
- Node values fit in 32-bit signed integers.
````
