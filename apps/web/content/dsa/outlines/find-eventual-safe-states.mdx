You have a directed graph of n nodes labeled 0..n-1. graph\[i\] lists nodes j such that an edge i -&gt; j exists.
A terminal node has no outgoing edges. A node is safe if every path starting from it eventually reaches a terminal node.
Return all safe nodes in ascending order. Nodes on cycles or leading into cycles are unsafe.

## Examples

````text
Example 1:
    Input: graph = [[1,2],[2,3],[5],[0],[5],[],[]]
    Output: [2,4,5,6]
Example 2:
    Input: graph = [[1,2,3,4],[1,2],[3,4],[0,4],[]]
    Output: [4]
````

## Constraints

````text
- n == len(graph)
- 1 <= n <= 10^4
- 0 <= len(graph[i]) <= n
````

<PremiumBreak />

## Approach

**Pattern:** DFS state labeling (tri-color) / cycle detection
Mark nodes as visiting, then safe after all successors are safe; revisiting a visiting node implies a cycle.

1. For each node, run DFS with states: 0 unvisited, 1 visiting, 2 safe.
2. If DFS hits state 1 on a successor, not safe; on success set state 2.
3. Collect all nodes with state 2.

## Complexity

**Time:** O(n + e) where e is total edges.

**Space:** O(n + e) for graph implicit in input plus O(n) for state and recursion.

## Solution

````python
from typing import List


class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        state = [0] * n

        def dfs(u: int) -> bool:
            if state[u] == 1:
                return False
            if state[u] == 2:
                return True
            state[u] = 1
            for v in graph[u]:
                if not dfs(v):
                    return False
            state[u] = 2
            return True

        for i in range(n):
            dfs(i)
        return [i for i in range(n) if state[i] == 2]
````

### Approach

**Pattern:** Reverse graph + Kahn's peel (topological trimming)
Start from terminal nodes (zero out-degree in original), work backwards removing edges; remaining unsafe.

1. Build reverse adjacency; indegree\[u\] counts outgoing edges from u in the original graph.
2. Queue all u with indegree\[u\]==0; mark safe; decrement indegrees of predecessors via reverse edges.
3. Return sorted list of safe flags.

### Complexity

**Time:** O(n + e)

**Space:** O(n + e)

### Solution

````python
from typing import List
from collections import deque


class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        rev: List[List[int]] = [[] for _ in range(n)]
        indegree = [0] * n
        for u, nbrs in enumerate(graph):
            indegree[u] = len(nbrs)
            for v in nbrs:
                rev[v].append(u)
        q: deque[int] = deque(i for i in range(n) if indegree[i] == 0)
        safe = [False] * n
        while q:
            u = q.popleft()
            safe[u] = True
            for v in rev[u]:
                indegree[v] -= 1
                if indegree[v] == 0:
                    q.append(v)
        return [i for i in range(n) if safe[i]]
````
