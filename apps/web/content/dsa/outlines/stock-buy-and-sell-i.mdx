At most one buy and one sell; maximize profit from prices.

<PremiumBreak />

## Approach

**Pattern:** Track minimum price so far.

## Complexity

**Time:** O(n). Space: O(1).

## Solution

````python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        best = 0
        lo = 10**9
        for p in prices:
            lo = min(lo, p)
            best = max(best, p - lo)
        return best
````
