Given the head of a linked list and an integer val, remove every node whose value equals val.

## Examples

````text
Example 1:
    Input: head = [1,2,6,3,4,5,6], val = 6
    Output: [1,2,3,4,5]

Example 2:
    Input: head = [], val = 1
    Output: []
````

## Constraints

````text
- 0 <= list length <= 10^4
- 1 <= Node.val <= 10^6
- 0 <= val <= 10^6
````
