Given meeting intervals \[start\_i, end\_i\], return the minimum number of conference rooms
required so that no two overlapping meetings share a room. Meetings that only touch
at an endpoint do not overlap.

## Examples

````text
Example 1:
    Input: intervals = [[0,40],[5,10],[15,20]]
    Output: 2

Example 2:
    Input: intervals = [[4,9]]
    Output: 1
````

## Constraints

````text
- 0 <= len(intervals) <= 500
- 0 <= start_i < end_i <= 10^6
````

## Approach

**Pattern:** Min-heap on end times (chronological simulation)
Sort meetings by start and sweep forward, freeing rooms whose meetings ended before
the current start; the heap size is the concurrent room usage at each step.

1. Sort intervals by start time.
2. Keep a min-heap of active meeting end times.
3. For each meeting, pop every end time not strictly greater than the current start.
4. Push the current meeting's end and track the maximum heap size.
5. Return that maximum.

## Complexity

**Time:** O(n log n) - each interval is pushed and popped at most once from the heap.

**Space:** O(n) - heap holds all active meetings in the worst case.

## Original notes

````text
Alternate sweep (from original notes — chronological two-pointer):
1. Sort all start times and all end times separately.
2. Walk starts with pointer `s` and ends with pointer `e`.
3. If the next start happens before the next end, a new meeting begins → increment the
   active count; otherwise a meeting finished → decrement the active count.
4. Track the maximum active meetings seen — that peak equals `minMeetingRooms`.
````

## Solution

````python
import heapq
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0

        intervals.sort(key=lambda x: x[0])
        heap: List[int] = []
        max_rooms = 0

        for start, end in intervals:
            while heap and heap[0] <= start:
                heapq.heappop(heap)
            heapq.heappush(heap, end)
            max_rooms = max(max_rooms, len(heap))

        return max_rooms


class MeetingRoomsTwoPointer:
    """Second implementation from the user's original file — kept for pedagogy."""

    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0

        starts = sorted(i[0] for i in intervals)
        ends = sorted(i[1] for i in intervals)
        active = 0
        peak = 0
        s = e = 0
        while s < len(intervals):
            if starts[s] < ends[e]:
                active += 1
                peak = max(peak, active)
                s += 1
            else:
                active -= 1
                e += 1
        return peak
````

## Another version

From 02. Prefix Sum/08. Interval Problems.

### Approach

**Pattern:** Chronological Ordering / Prefix Events
Sort starts and ends; sweep time increasing rooms in use when a start precedes the next end.

1. Sort all start times and all end times.
2. Two-pointer: if next start is before next end, occupy a room; otherwise release one.
3. Track the peak simultaneous meetings.

### Complexity

**Time:** O(n log n) for sorting.

**Space:** O(n) for the sorted copies.

### Solution

````python
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        starts = sorted(s for s, _ in intervals)
        ends = sorted(e for _, e in intervals)
        n = len(intervals)
        i = j = 0
        cur = 0
        best = 0
        while i < n:
            if starts[i] < ends[j]:
                cur += 1
                best = max(best, cur)
                i += 1
            else:
                cur -= 1
                j += 1
        return best
````
