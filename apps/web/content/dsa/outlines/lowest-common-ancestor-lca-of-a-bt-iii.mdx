Each TreeNode has a parent pointer. Given two nodes p and q in the same tree, return their LCA.

## Examples

````text
Example 1:
    Classic tree [3,5,1,6,2,0,8,None,None,7,4], p node 5 and q node 1 -> 3
Example 2:
    p=5, q=4 -> 5
Example 3:
    Chain 1-2, p=1, q=2 -> 1
````

## Constraints

````text
- 2 <= n <= 10^5, unique values, p != q.
````

## Approach

**Pattern:** Two-pointer on parent chains (like linked list intersection)
Walk p and q upward; when one hits null, jump to the other start; they meet at LCA.

1. Set a, b to p, q.
2. While a != b: move a to a.parent if a else q; move b to b.parent if b else p.
3. Return a (or b).

## Complexity

**Time:** O(h)

**Space:** O(1)
Restored (original notes, diagrams, and walkthrough):
Problem: Lowest Common Ancestor of a Binary Tree III

Given two nodes of a binary tree p and q, return their lowest common ancestor (LCA).
Each node will have a reference to its parent node.

Example 1:
3
/      5   1
/ \\ /    6  2 0  8
/     7   4

Input: p = 5, q = 1
Output: 3
Explanation: The LCA of nodes 5 and 1 is 3.

Example 2:
3
/      5   1
/ \\ /    6  2 0  8
/     7   4

Input: p = 5, q = 4
Output: 5
Explanation: The LCA of nodes 5 and 4 is 5, since a node can be a descendant of itself.

Example 3:
1
/
2
Input: p = 1, q = 2
Output: 1

Constraints:
\* The number of nodes in the tree is in the range \[2, 10^5\].
\* -10^9 &lt;= Node.val &lt;= 10^9
\* All Node.val are unique.
\* p != q
\* p and q exist in the tree.

Time Complexity: O(h), where h is the height of the tree.
In the worst case, we might need to traverse from a leaf to the root.

Space Complexity: O(h), where h is the height of the tree.
We use a set to store seen, which in the worst case could contain all nodes from a leaf to the root.

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(
        self,
        val: int = 0,
        left: Optional["TreeNode"] = None,
        right: Optional["TreeNode"] = None,
        parent: Optional["TreeNode"] = None,
    ):
        self.val = val
        self.left = left
        self.right = right
        self.parent = parent


def build_leetcode_tree_with_parents() -> List[TreeNode]:
    """Builds nodes for values [3,5,1,6,2,0,8,7,4] in standard LeetCode layout."""
    nodes = {v: TreeNode(v) for v in [3, 5, 1, 6, 2, 0, 8, 7, 4]}
    n = nodes
    n[3].left, n[3].right = n[5], n[1]
    n[5].left, n[5].right = n[6], n[2]
    n[2].left, n[2].right = n[7], n[4]
    n[1].left, n[1].right = n[0], n[8]
    for v, node in n.items():
        if node.left:
            node.left.parent = node
        if node.right:
            node.right.parent = node
    return list(n.values())


class Solution:
    def lowestCommonAncestor(self, p: TreeNode, q: TreeNode) -> TreeNode:
        a: Optional[TreeNode] = p
        b: Optional[TreeNode] = q
        while a != b:
            a = a.parent if a else q
            b = b.parent if b else p
        return a
````
