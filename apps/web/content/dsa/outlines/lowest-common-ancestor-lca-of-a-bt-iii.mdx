Each TreeNode has a parent pointer. Given two nodes p and q in the same tree, return their LCA.

## Examples

````text
Example 1:
    Classic tree [3,5,1,6,2,0,8,None,None,7,4], p node 5 and q node 1 -> 3
Example 2:
    p=5, q=4 -> 5
Example 3:
    Chain 1-2, p=1, q=2 -> 1
````

## Constraints

````text
- 2 <= n <= 10^5, unique values, p != q.
````
