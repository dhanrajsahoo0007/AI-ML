Given a string s, return the length of the longest substring that contains no
repeated characters.

## Examples

````text
Example 1:
    Input: s = "abcabcbb"
    Output: 3
Example 2:
    Input: s = "bbbbb"
    Output: 1
Example 3:
    Input: s = "pwwkew"
    Output: 3
````

## Constraints

````text
- 0 <= len(s) <= 5 * 10^4 in typical online judge statements.
````

## Approach

**Pattern:** Variable-size sliding window with last-seen indices
Expand the right end while characters are unique; when a repeat appears inside the window, move the left bound past its previous index.

1. Track the last index of each character (or use a set with two pointers).
2. Advance the right pointer; if s\[right\] was seen at or after left, set left to last\_index + 1.
3. Update the last index and maximize the window length.

## Complexity

**Time:** O(n) - Each index is visited by the right pointer once; left only moves forward.

**Space:** O(alphabet) - Storage for character positions is bounded by the alphabet size.

## Solution

````python
from typing import List


class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last: List[int] = [-1] * 256
        left = 0
        best = 0

        for right, ch in enumerate(s):
            code = ord(ch)
            if last[code] >= left:
                left = last[code] + 1
            last[code] = right
            best = max(best, right - left + 1)

        return best
````
