Given a string s, return the length of the longest substring that contains no
repeated characters.

## Examples

````text
Example 1:
    Input: s = "abcabcbb"
    Output: 3
Example 2:
    Input: s = "bbbbb"
    Output: 1
Example 3:
    Input: s = "pwwkew"
    Output: 3
````

## Constraints

````text
- 0 <= len(s) <= 5 * 10^4 in typical online judge statements.
````
