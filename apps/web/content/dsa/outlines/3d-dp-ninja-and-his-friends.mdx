On an n x n grid of non-negative cherries, two robots start at (0,0) and (0,n-1).
Each step both move down one row, each moving to an adjacent column offset in
&#123;-1,0,1&#125;. They collect cherries on visited cells (a cell once even if both
land there). Maximize cherries until both reach (n-1,n-1).

## Examples

````text
Example 1:
Input: grid = [[3, 1], [2, 5]]
Output: 9
````

## Constraints

````text
- 1 <= n <= 50
- 0 <= grid[i][j]
````

<PremiumBreak />

## Approach

**Pattern:** 3D DP on row and two columns
State f\[r\]\[c1\]\[c2\] after processing row r at columns c1 and c2.

1. Initialize f\[0\]\[0\]\[n-1\].
2. For each row transition, add cherries on the two landing cells (dedupe same cell).
3. Answer f\[n-1\]\[n-1\]\[n-1\].

## Complexity

**Time:** O(n^3).

**Space:** O(n^3) (can compress to O(n^2) per row).

## Solution

````python
from typing import List


class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        n = len(grid)
        if n == 1:
            return max(0, grid[0][0])
        neg = -10**9
        f = [[[neg] * n for _ in range(n)] for _ in range(n)]
        f[0][0][n - 1] = grid[0][0] + grid[0][n - 1]
        for r in range(n - 1):
            for a in range(n):
                for b in range(n):
                    if f[r][a][b] <= neg // 2:
                        continue
                    for da in (-1, 0, 1):
                        for db in (-1, 0, 1):
                            na, nb = a + da, b + db
                            if 0 <= na < n and 0 <= nb < n:
                                add = grid[r + 1][na] + (grid[r + 1][nb] if na != nb else 0)
                                f[r + 1][na][nb] = max(f[r + 1][na][nb], f[r][a][b] + add)
        return max(0, f[n - 1][n - 1][n - 1])
````
