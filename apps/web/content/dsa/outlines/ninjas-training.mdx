A ninja trains for \`days\` days and each day has three activities with given
merits. He cannot pick the same activity on two consecutive days. Maximize total merit.

## Examples

````text
Example 1:
Input: days=3, points=[[1,2,5],[3,1,1],[3,3,3]]
Output: 11
````

## Constraints

````text
- 1 <= days <= 10^5
- len(points[i]) == 3
````

<PremiumBreak />

## Approach

**Pattern:** 2D DP small state
dp\[d\]\[a\] best up to day d ending with activity a.

1. Initialize day 0 with points\[0\].
2. For each next day, dp\[d\]\[a\]=points\[d\]\[a\]+max(dp\[d-1\]\[b\] for b!=a).

## Complexity

**Time:** O(days \* 9) = O(days).

**Space:** O(1) with two rows of size 3.

## Solution

````python
from typing import List


class Solution:
    def maximumPoints(self, points: List[List[int]]) -> int:
        a, b, c = points[0]
        for i in range(1, len(points)):
            x, y, z = points[i]
            na = x + max(b, c)
            nb = y + max(a, c)
            nc = z + max(a, b)
            a, b, c = na, nb, nc
        return max(a, b, c)
````
