Partition a linked list around value x so that all nodes with value &lt; x appear before nodes &gt;= x,
preserving relative order inside each partition.

## Examples

````text
Example 1:
Input: head = [1,4,3,2,5,2], x = 3
Output: [1,2,2,4,3,5]
````

## Constraints

````text
- 0 <= n <= 200
- -100 <= Node.val <= 100
- -200 <= x <= 200
````
