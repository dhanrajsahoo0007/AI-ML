Given an integer array, for each index return the nearest element to the right that is strictly
greater than the current value. If none exists, use -1.

## Examples

````text
Example 1:
Input: [4, 5, 2, 25, 7, 8]
Output: [5, 25, 25, -1, 8, -1]
````

## Constraints

````text
- 1 <= len(arr) <= 10^5 (typical stack problem; values fit in normal int range)
````
