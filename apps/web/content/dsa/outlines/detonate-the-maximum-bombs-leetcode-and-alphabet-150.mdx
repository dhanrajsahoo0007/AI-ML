Bombs are circles (x, y, r). Detonating bomb i detonates every bomb j whose
center lies inside or on the circle of i. Return the maximum number of bombs
that can be detonated if you may start by detonating exactly one bomb.

## Examples

````text
Example 1:
    Input: bombs = [[2,1,3],[6,1,4]]
    Output: 2
Example 2:
    Input: bombs = [[1,1,5],[10,10,5]]
    Output: 1
````

## Constraints

````text
- 1 <= len(bombs) <= 100
- 1 <= xi, yi, ri <= 10^5
````

## Approach

**Pattern:** Graph DFS / BFS
Build directed edges i -&gt; j when j lies in i's blast radius; answer is the
largest reachable set from any start node.

1. For each pair (i, j), add edge i -&gt; j if squared distance &lt;= r\_i^2.
2. From each start node, DFS or BFS to count reachable nodes.
3. Return the maximum count.

## Complexity

**Time:** O(n^3) worst for DFS from each start on dense graph

**Space:** O(n^2) - adjacency list

## Solution

````python
from collections import deque
from typing import List


class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        g: List[List[int]] = [[] for _ in range(n)]

        def in_range(i: int, j: int) -> bool:
            x1, y1, _ = bombs[i]
            x2, y2, _ = bombs[j]
            dx, dy = x1 - x2, y1 - y2
            r = bombs[i][2]
            return dx * dx + dy * dy <= r * r

        for i in range(n):
            for j in range(n):
                if i != j and in_range(i, j):
                    g[i].append(j)

        def bfs(start: int) -> int:
            seen = {start}
            q = deque([start])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if v not in seen:
                        seen.add(v)
                        q.append(v)
            return len(seen)

        return max(bfs(s) for s in range(n))
````
