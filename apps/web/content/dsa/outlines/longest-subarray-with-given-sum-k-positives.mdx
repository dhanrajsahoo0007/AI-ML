Given an array nums of positive integers and an integer k, return the length of the longest
contiguous subarray whose sum equals k. If none exists, return 0.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 4, 5], k = 9
    Output: 3  # subarray [2, 3, 4]
Example 2:
    Input: nums = [1, 1, 1], k = 3
    Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- 1 <= nums[i] <= 1000
- 1 <= k <= 10^8
````
