Asteroids move in a line; positives go right, negatives go left. When opposite directions meet,
the smaller mass explodes; equal masses destroy each other. Return surviving asteroids left to right.

## Examples

````text
Example 1:
Input: [5, 10, -5]
Output: [5, 10]
````

## Constraints

````text
- 2 <= len(asteroids) <= 10^4
- asteroids[i] != 0
````
