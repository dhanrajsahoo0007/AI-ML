Given an integer array height of length n, choose two lines together with the x-axis to form a container.
Return the maximum amount of water the container can store. You may not slant the container.

## Examples

````text
Example 1:
    Input: height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
    Output: 49
Example 2:
    Input: height = [1, 1]
    Output: 1
````

## Constraints

````text
- n == len(height)
- 2 <= n <= 10^5
- 0 <= height[i] <= 10^4
````
