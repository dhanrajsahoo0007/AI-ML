Given an array of integers and a positive integer k, for every contiguous subarray
of length k, return the first negative number in that window, or 0 if there is none.

## Examples

````text
Example 1:
    Input: arr = [12, -1, -7, 8, -15, 30, 16, 28], k = 3
    Output: [-1, -1, -7, -15, -15, 0]
Example 2:
    Input: arr = [1, 2, 3], k = 2
    Output: [0, 0]
````

## Constraints

````text
- Array length and k are positive; k <= len(arr).
````
