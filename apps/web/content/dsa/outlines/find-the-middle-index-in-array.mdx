Return the smallest index i such that the sum of elements before i equals the sum
of elements after i. If none, return -1.

## Examples

````text
Example 1:
Input: nums = [2, 3, -1, 8, 4]
Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 100
- -1000 <= nums[i] <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Prefix-Suffix Balance
Same as pivot-style balance: compare prefix before i with suffix after i.

1. total = sum(nums).
2. For each i, left = sum(nums\[0:i\]), right = total - left - nums\[i\].
3. Return first i with left == right, else -1.

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
from typing import List


class Solution:
    def findMiddleIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0
        for i, x in enumerate(nums):
            right = total - left - x
            if left == right:
                return i
            left += x
        return -1
````
