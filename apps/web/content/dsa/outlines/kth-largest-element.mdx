Given an unsorted array of integers, find the kth largest element in the array.
Note: It is the kth largest element in sorted order, not the kth distinct element.

## Examples

````text
Example 1:
    Input: nums = [3,2,1,5,6,4], k = 2
    Output: 5

Example 2:
    Input: nums = [3,2,3,1,2,4,5,5,6], k = 4
    Output: 4
````

## Constraints

````text
- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Top-K
We maintain a min-heap of size k. The root of this heap is always the kth largest
element seen so far. Any element smaller than the root is ignored.

1. Build a min-heap from the first k elements of the array.
2. For each remaining element, if it is larger than the heap root, replace the root.
3. After processing all elements, the root of the heap is the kth largest element.

## Complexity

**Time:** O(n log k), where n is the length of the array
- We iterate through all n elements once.
- For each element, we might perform a heap operation which takes O(log k) time.

**Space:** O(k) - We maintain a heap of at most k elements.

## Original notes

````text
Original notes (restored):
The kth largest in sorted order is tracked with a min-heap of size k: the root is the
smallest among those k, i.e. the kth largest overall. This is especially attractive when
k << n because memory stays O(k). The original write-up used `heapreplace` for the same
"pop smallest then push candidate" step as `heapq.heapreplace` here.
````

## Solution

````python
import heapq
from typing import List


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        min_heap = nums[:k]
        heapq.heapify(min_heap)

        for i in range(k, len(nums)):
            # Anything smaller than the k-th-so-far can be ignored.
            if nums[i] > min_heap[0]:
                heapq.heapreplace(min_heap, nums[i])

        return min_heap[0]
````
