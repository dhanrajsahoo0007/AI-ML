Implement a Disjoint Set Union (DSU) with \`find\` (with path compression) and \`union\` (union by rank)
on elements 0..n-1. After unions, \`find\` returns the representative of each set.

## Examples

````text
Example 1:
Input: n = 5, unions = [[0, 1], [1, 2], [3, 4]]
After unions: find(0) == find(2), find(3) == find(4), find(0) != find(3).
````

## Constraints

````text
- 1 <= n <= 10^5 (typical competitive programming bounds)
````
