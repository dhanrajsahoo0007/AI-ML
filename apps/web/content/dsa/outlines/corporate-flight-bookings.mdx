There are n flights labeled 1..n. Each booking bookings\[i\] = \[first, last, seats\]
reserves seats seats for every flight in \[first, last\] inclusive. Return an array
of length n where the i-th value is total seats reserved on flight i + 1.

## Examples

````text
Example 1:
Input: bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]], n = 5
Output: [10, 55, 45, 25, 25]
````

## Constraints

````text
- 1 <= n <= 2 * 10^5
- 1 <= len(bookings) <= 2 * 10^4
- bookings[i].length == 3
````
