Given a string of letters and digits, return every string you can make by choosing
lowercase or uppercase independently for each letter; digits stay fixed.

## Examples

````text
Example 1:
    Input: "a1"
    Output sorted: ["a1", "A1"]

Example 2:
    Input: "3z4"
    Output includes "3z4" and "3Z4"
````

## Constraints

````text
- Length modest for exponential branching in tests
````
