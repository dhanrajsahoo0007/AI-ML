Undirected tree rooted at 0 with gate rewards/costs at nodes. Alice starts at 0 moving toward
a leaf; Bob starts at bob moving toward 0 each second along the unique path. Gates already
opened give nothing; if Alice and Bob open together they split the value equally. Return the
maximum net income Alice can achieve choosing a leaf path.

## Examples

````text
Example 1:
    Input: edges = [[0,1],[1,2],[1,3],[3,4]], bob = 3, amount = [-2,4,2,-4,6]
    Output: 6
Example 2:
    Input: edges = [[0,1]], bob = 1, amount = [-7280,2350]
    Output: -7280
````

## Constraints

````text
- 2 <= n <= 10^5
- amount[i] is even in [-10^4, 10^4]
````

## Approach

**Pattern:** Graph - Tree DFS + timing (Alice vs Bob on fixed Bob route)

1. Record parent from root 0; mark Bob arrival times along bob -&gt; ... -&gt; 0.
2. DFS Alice paths accumulating gate value using depth vs bob\_time rules.
3. Maximize total profit at leaves.

## Complexity

**Time:** O(n).

**Space:** O(n).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def mostProfitablePath(self, edges: List[List[int]], bob: int, amount: List[int]) -> int:
        n = len(amount)
        g = defaultdict(list)
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)

        parent = [-1] * n

        def dfs_parent(u: int, p: int) -> None:
            parent[u] = p
            for v in g[u]:
                if v != p:
                    dfs_parent(v, u)

        dfs_parent(0, -1)

        bob_time = {}
        t = 0
        cur = bob
        while True:
            bob_time[cur] = t
            if cur == 0:
                break
            cur = parent[cur]
            t += 1

        self.best = -10**18

        def dfs(u: int, p: int, depth: int, profit: int) -> None:
            bt = bob_time.get(u)
            if bt is None:
                gain = amount[u]
            elif depth < bt:
                gain = amount[u]
            elif depth > bt:
                gain = 0
            else:
                gain = amount[u] // 2
            profit += gain
            kids = [v for v in g[u] if v != p]
            if not kids:
                self.best = max(self.best, profit)
            else:
                for v in kids:
                    dfs(v, u, depth + 1, profit)

        dfs(0, -1, 0, 0)
        return self.best
````
