Given a string s of '\*' and '\|', answer queries \[left, right\]: count plates '\*'
that lie strictly between the nearest candles '\|' bounding the interval.

## Examples

````text
Example 1:
Input: s = "**|**|***|", queries = [[2, 5], [5, 9]]
Output: [2, 3]
````

## Constraints

````text
- 3 <= len(s) <= 10^5
- 1 <= len(queries) <= 10^5
````
