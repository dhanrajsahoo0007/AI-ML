Balloons on a wall are given as points\[i\] = \[x\_start, x\_end\], meaning a horizontal
diameter covers every x with x\_start &lt;= x &lt;= x\_end. An arrow shot vertically at x
bursts every balloon whose interval contains x. Return the minimum arrows needed to
burst every balloon.

## Examples

````text
Example 1:
    Input: points = [[10,16],[2,8],[1,6],[7,12]]
    Output: 2

Example 2:
    Input: points = [[1,2],[3,4],[5,6],[7,8]]
    Output: 4
````

## Constraints

````text
- 1 <= len(points) <= 10^5
- -2^31 <= x_start < x_end <= 2^31 - 1
````
