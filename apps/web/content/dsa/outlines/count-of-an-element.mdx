Given a sorted array and a target, return how many times target appears.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 3, 3, 3, 5], target = 3
    Output: 4

Example 2:
    Input: nums = [1, 2, 3, 4, 5], target = 6
    Output: 0
````

## Constraints

````text
- nums is sorted in non-decreasing order
- 0 <= len(nums) <= 10^5
````
