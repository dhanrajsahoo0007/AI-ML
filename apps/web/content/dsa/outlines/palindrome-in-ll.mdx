Return whether values of a singly linked list form a palindrome.

## Examples

````text
Example 1:
    Input: head = [1,2,2,1]
    Output: True

Example 2:
    Input: head = [1,2]
    Output: False
````

## Constraints

````text
- 0 <= n <= 10^5
- 0 <= Node.val <= 9
````
