Same course model as Course Schedule I. Return any valid order to take all numCourses courses.
If impossible due to a cycle, return an empty list.

## Examples

````text
Example 1:
    Input: numCourses = 2, prerequisites = [[1,0]]
    Output: [0,1]
Example 2:
    Input: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
    Output: [0,1,2,3] or [0,2,1,3]
````

## Constraints

````text
- 1 <= numCourses <= 2000
- 0 <= len(prerequisites) <= 5000
````

## Approach

**Pattern:** Kahn's topological sort
Emit nodes as their indegree drops to zero; incomplete traversal implies a cycle.

1. Build adjacency list b -&gt; a and indegrees.
2. Append nodes to the answer in Kahn order.
3. If answer length equals numCourses, return it; else \[\].

## Complexity

**Time:** O(V + E)

**Space:** O(V + E)

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        adj = defaultdict(list)
        indegree = [0] * numCourses
        for a, b in prerequisites:
            adj[b].append(a)
            indegree[a] += 1
        q: deque[int] = deque(i for i in range(numCourses) if indegree[i] == 0)
        order: List[int] = []
        while q:
            u = q.popleft()
            order.append(u)
            for v in adj[u]:
                indegree[v] -= 1
                if indegree[v] == 0:
                    q.append(v)
        return order if len(order) == numCourses else []
````
