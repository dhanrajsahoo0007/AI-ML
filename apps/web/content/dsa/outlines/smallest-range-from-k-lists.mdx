You have k lists of sorted integers in non-decreasing order. Find the smallest
range that includes at least one number from each of the k lists.

## Examples

````text
Example 1:
    Input: nums = [[4,10,15,24,26],[0,9,12,20],[5,18,22,30]]
    Output: [20,24]

Example 2:
    Input: nums = [[1,2,3],[1,2,3],[1,2,3]]
    Output: [1,1]
````

## Constraints

````text
- nums.length == k
- 1 <= k <= 3500
- 1 <= nums[i].length <= 50
- -10^5 <= nums[i][j] <= 10^5
- nums[i] is sorted in non-decreasing order.
````

<PremiumBreak />

## Approach

**Pattern:** K-Way Merge
We maintain a min-heap with one element from each list. The range is
\[heap\_min, current\_max\]. We shrink the range by advancing the minimum.

1. Push the first element of each list into a min-heap, tracking the max.
2. Record the initial range \[min, max\].
3. Pop the minimum, push the next element from the same list.
4. Update max and range if the new range is smaller.
5. Stop when any list is exhausted (can't cover all k lists anymore).

## Complexity

**Time:** O(N log k), where N is total elements

**Space:** O(k) for the heap

## Original notes

````text
Original notes (restored):
LC 632 style: the heap always stores one "finger" per list; `current_max` tracks the largest
head value. Popping the smallest head shrinks the window start; advancing that list may raise
the end. Compare span `(end - start)` and keep the lexicographically smallest range on ties.
Loop invariant: every list still contributes at least one value inside `[min_heap[0][0], current_max]`
until some list is exhausted — then no range can cover all k lists anymore.
````

## Solution

````python
import heapq
from typing import List


class Solution:
    def smallestRange(self, nums: List[List[int]]) -> List[int]:
        min_heap = []
        current_max = float('-inf')

        for i in range(len(nums)):
            heapq.heappush(min_heap, (nums[i][0], i, 0))
            current_max = max(current_max, nums[i][0])

        result = [min_heap[0][0], current_max]

        while True:
            _, list_idx, elem_idx = heapq.heappop(min_heap)
            next_idx = elem_idx + 1

            if next_idx >= len(nums[list_idx]):
                break

            next_val = nums[list_idx][next_idx]
            heapq.heappush(min_heap, (next_val, list_idx, next_idx))
            current_max = max(current_max, next_val)

            current_min = min_heap[0][0]
            if current_max - current_min < result[1] - result[0]:
                result = [current_min, current_max]

        return result
````
