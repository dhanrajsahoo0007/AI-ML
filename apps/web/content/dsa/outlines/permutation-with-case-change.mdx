Given a string of letters and digits, enumerate every combination formed by
independently lowercasing or uppercasing each letter; digits are unchanged.

## Examples

````text
Example 1:
    Input: "ab"
    Output sorted: ["AB", "Ab", "aB", "ab"]

Example 2:
    Input: "a1b2"
    Output length: 2^2 = 4 letter branches
````

## Constraints

````text
- Letters are alphabetic ASCII in tests
````
