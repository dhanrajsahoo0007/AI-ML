Given a string s, partition s such that every substring of the partition is a
palindrome. Return the minimum cuts needed so that every piece is a palindrome.

## Examples

````text
Example 1:
    Input: s = "aab"
    Output: 1
Example 2:
    Input: s = "a"
    Output: 0
````

## Constraints

````text
- 1 <= len(s) <= 2000
- s contains only lowercase English letters
````

<PremiumBreak />

## Approach

**Pattern:** 1D DP with palindrome preprocessing
Precompute is\_pal\[i\]\[j\], then dp\[i\] = min cuts for prefix ending at i.

1. Build palindrome table is\_pal\[i\]\[j\] expanding centers.
2. dp\[i\] = min over j&lt;=i with is\_pal\[j\]\[i\] of (dp\[j-1\]+1) or 0 if j==0.
3. Return dp\[n-1\]-1 (cuts = pieces-1) or compute cuts directly.

## Complexity

**Time:** O(n^2) for palindrome table and DP.

**Space:** O(n^2) for is\_pal (can optimize to O(n)).

## Solution

````python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 2 or is_pal[i + 1][j - 1]):
                    is_pal[i][j] = True

        dp = [0] * n
        for i in range(n):
            if is_pal[0][i]:
                dp[i] = 0
                continue
            best = i
            for j in range(1, i + 1):
                if is_pal[j][i]:
                    best = min(best, dp[j - 1] + 1)
            dp[i] = best
        return dp[n - 1]
````
