Design a succession order for a monarchy: the king is root; births append a child under a
parent; deaths mark a person as deceased (they stay in the family tree but are omitted from
the order). Return inheritance order as preorder DFS skipping dead names.

## Examples

````text
Example 1:
king = "king", births = [("king","andy"),("king","bob"),("andy","matthew"),("bob","alex"),("bob","asha")],
deaths = ["bob"]
Output: ["king","andy","matthew","alex","asha"]
````

## Constraints

````text
- 1 <= len(names) <= 10^5
- Names are unique strings of lowercase letters
````

<PremiumBreak />

## Approach

**Pattern:** Graph - Tree preorder traversal with skip set

1. Maintain adjacency children list in birth order for each parent.
2. DFS from king; append name if not dead; recurse children left-to-right.

## Complexity

**Time:** O(n) per getInheritanceOrder over all people.

**Space:** O(n) for tree and recursion stack.

## Solution

````python
from typing import Dict, List, Set
from collections import defaultdict, deque


class Solution:
    def inheritanceOrder(self, king: str, children: Dict[str, List[str]], dead: Set[str]) -> List[str]:
        order: List[str] = []

        def dfs(name: str) -> None:
            if name not in dead:
                order.append(name)
            for ch in children.get(name, []):
                dfs(ch)

        dfs(king)
        return order
````
