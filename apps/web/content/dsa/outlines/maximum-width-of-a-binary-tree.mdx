Given the root of a binary tree, return the maximum width among all levels.
Width counts the span between leftmost and rightmost non-null nodes in the level-order layout
(null nodes between ends count).

## Examples

````text
Example 1:
    Input: root = [1,3,2,5,3,None,9]
    Output: 4
Example 2:
    Input: root = [1,3,2,5,None,None,9,6,None,7]
    Output: 7
````

## Constraints

````text
- The number of nodes is in the range [1, 3000].
- Node values fit in 32-bit signed integers.
````
