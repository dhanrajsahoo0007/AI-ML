Given an integer array nums and an integer target, return indices i and j with i &lt; j such that
nums\[i\] + nums\[j\] == target. Exactly one valid answer exists.

## Examples

````text
Example 1:
    Input: nums = [3, 4, 5, 6], target = 7
    Output: [0, 1]
Example 2:
    Input: nums = [4, 5, 6], target = 10
    Output: [0, 2]
````

## Constraints

````text
- 2 <= len(nums) <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- Exactly one solution exists; you may not use the same element twice.
````
