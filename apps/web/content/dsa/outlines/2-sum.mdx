Given an integer array nums and an integer target, return indices i and j with i &lt; j such that
nums\[i\] + nums\[j\] == target. Exactly one valid answer exists.

## Examples

````text
Example 1:
    Input: nums = [3, 4, 5, 6], target = 7
    Output: [0, 1]
Example 2:
    Input: nums = [4, 5, 6], target = 10
    Output: [0, 2]
````

## Constraints

````text
- 2 <= len(nums) <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- Exactly one solution exists; you may not use the same element twice.
````

<PremiumBreak />

## Approach

**Pattern:** Hash map (one pass)
Store each value's index; for each element, check whether target - nums\[i\] was seen.

1. Maintain a map from value to index for elements seen so far.
2. For each index i and value num, if complement = target - num is in the map, return \[map\[complement\], i\].
3. Otherwise record num -&gt; i and continue.

## Complexity

**Time:** O(n) - Single left-to-right pass.

**Space:** O(n) - Hash map holds up to n entries in the worst case.

## Solution

````python
from typing import List


class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_map: dict[int, int] = {}  # value -> index for everything seen so far
        for i, num in enumerate(nums):
            complement = target - num
            if complement in num_map:
                return [num_map[complement], i]  # earlier index first, then current
            num_map[num] = i
        return []  # problem guarantees one solution; this is a safe fallback
````
