Design an in-memory file system that supports creating directories, listing paths,
appending file content, and reading file content. Paths are absolute strings like "/a/b/c".

## Examples

````text
Example 1:
Input: mkdir("/a/b/c"), addContentToFile("/a/b/c/d", "hello"), readContentFromFile("/a/b/c/d"), ls("/")
Output: read returns "hello"; ls("/") lists top-level names (e.g. "a").
````

## Constraints

````text
- Path names are non-empty, start with '/', and contain lowercase letters and '/'.
- File content is appended as strings; same path may receive multiple appends.
````
