Given an unsorted array of integers, find the kth smallest element in the array.

## Examples

````text
Example 1:
    Input: nums = [7, 10, 4, 3, 20, 15], k = 3
    Output: 7

Example 2:
    Input: nums = [7, 10, 4, 3, 20, 15], k = 4
    Output: 10
````

## Constraints

````text
- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
````
