Given a sorted array of integers and a target, return an element of the array whose absolute
difference with target is minimum (prefer the smaller element on ties per common convention).

## Examples

````text
Example 1:
    Input: nums = [1, 3, 8, 10, 15], target = 12
    Output: 10

Example 2:
    Input: nums = [2, 4, 6, 8, 10], target = 5
    Output: 4
````

## Constraints

````text
- nums is sorted in non-decreasing order
- 1 <= len(nums) in typical use; handle small n
````

## Approach

**Pattern:** Floor / Ceiling by Index
Nearest value lies between the greatest value &lt;= target and the smallest value &gt;= target.

1. If target is outside the array range, return the nearest endpoint.
2. Binary search for floor index (last &lt;= target) and ceiling index (first &gt;= target).
3. Compare distances and return the closer element (smaller on tie).

## Complexity

**Time:** O(log n) - Two binary searches or one combined logic.

**Space:** O(1) - Constant extra space.
Restored (original notes, diagrams, and walkthrough):
Problem Statement: Minimum Difference Element in a Sorted Array

Given a sorted array of integers and a target integer, find the element in the array that has the minimum difference with the target.

Examples:

1. Input: arr = \[1, 3, 8, 10, 15\], target = 12
Output: 10
Explanation: 10 has the minimum difference with 12 (\|10-12\| = 2).

2. Input: arr = \[2, 5, 10, 12, 15\], target = 6
Output: 5
Explanation: 5 has the minimum difference with 6 (\|5-6\| = 1).

3. Input: arr = \[2, 4, 6, 8, 10\], target = 5
Output: 4 or 6
Explanation: Both 4 and 6 have the same minimum difference with 5 (\|4-5\| = \|6-5\| = 1).

The approach uses ceiling and floor operations to find the element with the minimum difference.

Explanation of the approach:

1. Floor and Ceiling Functions:
- find\_floor: Finds the largest element in the array that is less than or equal to the target.
- find\_ceiling: Finds the smallest element in the array that is greater than or equal to the target.

2. Minimum Difference Element:
- Use floor and ceiling functions to find the two elements closest to the target.
- Compare the differences of these two elements with the target and return the one with the smaller difference.

3. Edge Cases:
- If the target is less than or equal to the first element, return the first element.
- If the target is greater than or equal to the last element, return the last element.

## Solution

````python
from typing import List


class Solution:
    def findClosestElement(self, nums: List[int], target: int) -> int:
        if not nums:
            raise ValueError("nums must be non-empty")
        if target <= nums[0]:
            return nums[0]
        if target >= nums[-1]:
            return nums[-1]

        def floor_index() -> int:
            left, right = 0, len(nums) - 1
            fl = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    return mid
                if nums[mid] < target:
                    fl = mid
                    left = mid + 1
                else:
                    right = mid - 1
            return fl

        def ceiling_index() -> int:
            left, right = 0, len(nums) - 1
            ce = len(nums)
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    return mid
                if nums[mid] < target:
                    left = mid + 1
                else:
                    ce = mid
                    right = mid - 1
            return ce

        fi = floor_index()
        ci = ceiling_index()
        if fi == ci:
            return nums[fi]
        if target - nums[fi] <= nums[ci] - target:
            return nums[fi]
        return nums[ci]
````
