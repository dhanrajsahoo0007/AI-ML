Given an integer array arr, return the sum of min(b) over every non-empty contiguous subarray b.
Return the result modulo 10^9 + 7.

## Examples

````text
Example 1:
Input: [3, 1, 2, 4]
Output: 17
````

## Constraints

````text
- 1 <= len(arr) <= 3 * 10^4
- 1 <= arr[i] <= 3 * 10^4
````
