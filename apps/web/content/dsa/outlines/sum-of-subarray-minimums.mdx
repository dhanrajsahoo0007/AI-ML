Given an integer array arr, return the sum of min(b) over every non-empty contiguous subarray b.
Return the result modulo 10^9 + 7.

## Examples

````text
Example 1:
Input: [3, 1, 2, 4]
Output: 17
````

## Constraints

````text
- 1 <= len(arr) <= 3 * 10^4
- 1 <= arr[i] <= 3 * 10^4
````

## Approach

**Pattern:** Monotonic Stack + Contribution Counting
Count how many subarrays treat each index as the minimum using next-smaller boundaries.

1. Build arrays for previous strictly smaller index and next smaller-or-equal index.
2. For each index i, multiply arr\[i\] by left span times right span of subarrays where it wins.
3. Accumulate modulo 1\_000\_000\_007.

Problem Statement:
Given an array of integers arr, find the sum of min(b), where b ranges over every (contiguous) subarray of arr.
Since the answer may be large, return the answer modulo 10^9 + 7.

Time Complexity:
Approach 1 (Brute Force): O(n^2)
Approach 2 (Monotonic Stack): O(n)

Space Complexity:
Approach 1: O(1)
Approach 2: O(n)

\# Approach 1: Simple Brute Force (May result in TLE for large inputs)
Explanation for Approach 1 (Brute Force):
1. We use two nested loops to generate all possible subarrays.
2. For each subarray, we keep track of the minimum element.
3. We add the minimum element of each subarray to the result.
4. The final result is the sum of all these minimums, modulo 10^9 + 7.

Time Complexity: O(n^2) due to the nested loops.
Space Complexity: O(1) as we only use a constant amount of extra space.

## Complexity

**Time:** O(n) - Two monotonic passes plus one accumulation.

**Space:** O(n) - Boundary arrays and stack storage.

## Solution

````python
from typing import List


class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        mod = 10**9 + 7
        n = len(arr)
        prev_smaller = [-1] * n
        stack: List[int] = []
        for i in range(n):
            while stack and arr[stack[-1]] > arr[i]:
                stack.pop()
            prev_smaller[i] = stack[-1] if stack else -1
            stack.append(i)

        next_smaller = [n] * n
        stack.clear()
        for i in range(n - 1, -1, -1):
            while stack and arr[stack[-1]] >= arr[i]:
                stack.pop()
            next_smaller[i] = stack[-1] if stack else n
            stack.append(i)

        total = 0
        for i in range(n):
            left = i - prev_smaller[i]
            right = next_smaller[i] - i
            total = (total + arr[i] * left * right) % mod
        return total
````
