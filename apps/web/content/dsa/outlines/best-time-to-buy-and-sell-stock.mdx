You are given daily stock prices. Choose one day to buy and a later day to sell to
maximize profit. Return that maximum profit, or 0 if no gain is possible.

## Examples

````text
Example 1:
    Input: prices = [7, 1, 5, 3, 6, 4]
    Output: 5
Example 2:
    Input: prices = [7, 6, 4, 3, 1]
    Output: 0
````

## Constraints

````text
- 1 <= len(prices) <= 10^5
- 0 <= prices[i] <= 10^4
````
