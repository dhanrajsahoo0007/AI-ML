You are given a sorted unique integer array nums. Return the smallest sorted list of
ranges that cover all the numbers in the array exactly. Each element of nums must be
covered by exactly one range, and there is no integer x such that x is in one of the
ranges but not in nums. A range is formatted as "a" if a == b or "a-&gt;b" if a &lt; b.

## Examples

````text
Example 1:
    Input: nums = [0,1,2,4,5,7]
    Output: ["0->2","4->5","7"]

Example 2:
    Input: nums = [0,2,3,4,6,8,9]
    Output: ["0","2->4","6","8->9"]
````

## Constraints

````text
- 0 <= len(nums) <= 20
- -2^31 <= nums[i] <= 2^31 - 1
- All values in nums are unique and nums is sorted ascending
````
