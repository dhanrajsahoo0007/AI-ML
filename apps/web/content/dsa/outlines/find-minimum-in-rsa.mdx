Given a sorted array rotated at an unknown pivot, return the minimum element.

## Examples

````text
Example 1:
    Input: nums = [4, 5, 6, 7, 0, 1, 2]
    Output: 0

Example 2:
    Input: nums = [11, 13, 15, 17]
    Output: 11
````

## Constraints

````text
- 1 <= len(nums) <= 5000
- -5000 <= nums[i] <= 5000
- All integers unique (typical rotated-sorted setting)
````
