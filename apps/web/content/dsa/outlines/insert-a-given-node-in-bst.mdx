Given the root of a binary search tree and a value to insert, insert the value and return
the root of the updated BST. Duplicates are typically ignored (do not insert again).

## Examples

````text
Example 1:
    Input: root = [4,2,7,1,3], val = 5
    Output: BST containing 5 in the correct position under 7

Example 2:
    Input: root = None, val = 1
    Output: single-node tree with val 1
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
- Values fit in 32-bit signed integers.
````
