String t is formed by shuffling string s and adding exactly one extra letter.
Return that added letter.

## Examples

````text
Example 1:
    Input: s = "abcd", t = "abcde"
    Output: "e"
Example 2:
    Input: s = "", t = "y"
    Output: "y"
````

## Constraints

````text
- 0 <= len(s) <= 1000
- len(t) == len(s) + 1
- Letters are lowercase English
````
