Given four points in the plane, determine whether they form a valid square.

## Examples

````text
Example 1:
    Input: p1=[0,0], p2=[1,1], p3=[1,0], p4=[0,1]
    Output: True
Example 2:
    Input: p1=[0,0], p2=[1,1], p3=[1,0], p4=[0,12]
    Output: False
````

## Constraints

````text
- All coordinates are integers with absolute value <= 2000
````

## Approach

**Pattern:** Compare six squared distances
A square has four equal non-zero side lengths and two equal longer diagonals
with diagonal^2 = 2 \* side^2.

1. Compute squared distances between all six unordered pairs.
2. Sort them; require d\[0..3\] equal, d\[4\]==d\[5\], d\[0\] &gt; 0, and d\[4\] == 2\*d\[0\].

## Complexity

**Time:** O(1) - six pairwise checks

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def validSquare(
        self, p1: List[int], p2: List[int], p3: List[int], p4: List[int]
    ) -> bool:
        pts = [p1, p2, p3, p4]
        dists: List[int] = []
        for i in range(4):
            for j in range(i + 1, 4):
                dx = pts[i][0] - pts[j][0]
                dy = pts[i][1] - pts[j][1]
                dists.append(dx * dx + dy * dy)
        dists.sort()
        return (
            dists[0] > 0
            and dists[0] == dists[1] == dists[2] == dists[3]
            and dists[4] == dists[5]
            and dists[4] == 2 * dists[0]
        )
````
