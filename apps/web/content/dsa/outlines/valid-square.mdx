Given four points in the plane, determine whether they form a valid square.

## Examples

````text
Example 1:
    Input: p1=[0,0], p2=[1,1], p3=[1,0], p4=[0,1]
    Output: True
Example 2:
    Input: p1=[0,0], p2=[1,1], p3=[1,0], p4=[0,12]
    Output: False
````

## Constraints

````text
- All coordinates are integers with absolute value <= 2000
````
