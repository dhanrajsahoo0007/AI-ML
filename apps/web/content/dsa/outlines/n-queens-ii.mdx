Return the number of distinct solutions to the n-queens puzzle (boards modulo labeling).

## Examples

````text
Example 1:
    Input: n = 4
    Output: 2

Example 2:
    Input: n = 1
    Output: 1
````

## Constraints

````text
- 1 <= n <= 9
````

<PremiumBreak />

## Approach

**Pattern:** Row-wise queen placement counting
Same backtracking as enumerate-all, but increment a counter instead of storing boards.

1. Track column and diagonal conflicts while assigning one queen per row.
2. Increment answer when a full placement reaches row n.

## Complexity

**Time:** O(n!) worst case.

**Space:** O(n) for conflict structures and recursion.

## Solution

````python
class Solution:
    def totalNQueens(self, n: int) -> int:
        cols = set()
        pos_diag = set()
        neg_diag = set()
        count = 0

        def backtrack(row: int) -> None:
            nonlocal count
            if row == n:
                count += 1
                return
            for col in range(n):
                if col in cols or (row + col) in pos_diag or (row - col) in neg_diag:
                    continue
                cols.add(col)
                pos_diag.add(row + col)
                neg_diag.add(row - col)
                backtrack(row + 1)
                cols.remove(col)
                pos_diag.remove(row + col)
                neg_diag.remove(row - col)

        backtrack(0)
        return count
````
