Sort a list of non-negative integers using least-significant-digit (LSD)
radix sort and return the sorted list.

## Examples

````text
Example 1:
    Input: nums = [170, 45, 75, 90, 2, 802, 24, 66]
    Output: sorted ascending
Example 2:
    Input: nums = [5, 1, 3]
    Output: [1, 3, 5]
````

## Constraints

````text
- 0 <= nums[i] <= 10^6 typical
- len(nums) <= 10^5
````
