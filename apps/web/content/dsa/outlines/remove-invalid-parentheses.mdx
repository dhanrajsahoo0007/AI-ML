Remove the minimum number of parentheses so the string becomes valid; return every possible
resulting string (letters stay). Parentheses are valid when balanced and properly nested.

## Examples

````text
Example 1:
Input: s = "()())()"
Output: ["()()()", "(())()"] (order may vary)
````

## Constraints

````text
- 1 <= len(s) <= 25 in exhaustive tests
````

<PremiumBreak />

## Approach

**Pattern:** Level-order search on removal states
Repeatedly delete one parenthesis from frontier strings until some valid strings appear; that
entire frontier is an optimal set.

1. Start with &#123;s&#125;; if any member is valid, return all valid members in the set.
2. Otherwise build the next frontier by removing one parenthesis from each string at each index.
3. Deduplicate with a set and continue until valid strings exist.

## Complexity

**Time:** Exponential in worst case; fine for typical interview sizes.

**Space:** Exponential frontier size in worst case.

## Solution

````python
from typing import List


class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        def is_valid(st: str) -> bool:
            balance = 0
            for ch in st:
                if ch == "(":
                    balance += 1
                elif ch == ")":
                    balance -= 1
                    if balance < 0:
                        return False
            return balance == 0

        frontier = {s}
        while True:
            valid = [x for x in frontier if is_valid(x)]
            if valid:
                return valid
            nxt: set[str] = set()
            for word in frontier:
                for i, ch in enumerate(word):
                    if ch not in "()":
                        continue
                    nxt.add(word[:i] + word[i + 1 :])
            frontier = nxt
````

if __name__ == "__main__":
    sol = Solution()

        return sorted(vals)
