Return every integer of length n whose digits differ by exactly k between every pair of
adjacent digits. Numbers may not have a leading zero unless n == 1.

## Examples

````text
Example 1:
    Input: n = 3, k = 7
    Output: [181,292,707,818,929]

Example 2:
    Input: n = 2, k = 1
    Output: [10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]
````

## Constraints

````text
- 2 <= n <= 9
- 0 <= k <= 9
````

## Approach

**Pattern:** Digit DFS / BFS
Extend the number from each valid first digit 1..9 (or 0..9 when n==1) by appending prev +/- k.

1. DFS on (value\_so\_far, remaining\_length).
2. When remaining hits 0, record the integer.
3. Branch to last\_digit + k and last\_digit - k when in range 0..9.

## Complexity

**Time:** O(2^n) branches worst case.

**Space:** O(n) recursion depth.

## Solution

````python
from typing import List


class Solution:
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        result: List[int] = []

        def dfs(value: int, length: int) -> None:
            if length == n:
                result.append(value)
                return
            last = value % 10
            if last + k <= 9:
                dfs(value * 10 + last + k, length + 1)
            if last - k >= 0 and k != 0:
                dfs(value * 10 + last - k, length + 1)

        if n == 1:
            return list(range(10))
        for d in range(1, 10):
            dfs(d, 1)
        return result
````
