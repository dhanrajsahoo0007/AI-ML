Given the root of a binary search tree, return any balanced BST that contains exactly the same
values. A balanced tree has left and right subtree heights differing by at most one at every node.

## Examples

````text
Example 1:
    Input: skewed BST with values 1..5
    Output: balanced BST with the same multiset of values

Example 2:
    Input: None
    Output: None
````

## Constraints

````text
- The number of nodes is in the range [1, 10^4].
````
