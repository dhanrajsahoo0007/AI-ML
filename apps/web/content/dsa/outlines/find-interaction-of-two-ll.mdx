Given heads of two singly linked lists, return the node where they intersect, or None if disjoint.
Intersection means the lists share the same tail from some node (same reference), not merely equal values.

## Examples

````text
Example 1:
Input: listA ends in 8->4->5, listB merges into that tail
Output: node with value 8
````

## Constraints

````text
- 0 <= m, n <= 3 * 10^4
- 1 <= Node.val <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Two pointers (path switching)
Switch each pointer to the other list's head at end; equal travel distance lets them meet at merge or None.

1. ptrA, ptrB start at heads.
2. On reaching end, jump to opposite head; repeat until ptrA == ptrB.
3. Return ptrA (intersection or both None).

## Complexity

**Time:** O(m + n).

**Space:** O(1).

## Solution

````python
from __future__ import annotations

from typing import List, Optional


class ListNode:
    def __init__(self, val: int = 0, next: Optional[ListNode] = None):
        self.val = val
        self.next = next


def list_to_linked_list(values: List[int]) -> Optional[ListNode]:
    dummy = ListNode(0)
    cur = dummy
    for v in values:
        cur.next = ListNode(v)
        cur = cur.next
    return dummy.next


class Solution:
    def getIntersectionNode(self, headA: Optional[ListNode], headB: Optional[ListNode]) -> Optional[ListNode]:
        if not headA or not headB:
            return None
        a, b = headA, headB
        while a != b:
            a = headB if a is None else a.next
            b = headA if b is None else b.next
        return a
````

## Tests from the notes

````python
if __name__ == "__main__":
    sol = Solution()

    list_a = list_to_linked_list([4, 1])
    list_b = list_to_linked_list([5, 6])
    tail = list_to_linked_list([8, 4, 5])
    list_a.next.next = tail
    list_b.next.next = tail
    node = sol.getIntersectionNode(list_a, list_b)
    assert node is not None and node.val == 8

    h1 = list_to_linked_list([1, 2, 3])
    h2 = list_to_linked_list([4, 5, 6])
    assert sol.getIntersectionNode(h1, h2) is None

    single = list_to_linked_list([9])
    assert sol.getIntersectionNode(single, single).val == 9

    a2 = list_to_linked_list([2, 6, 4])
    b2 = list_to_linked_list([1, 5])
    shared = list_to_linked_list([3, 7])
    a2.next.next.next = shared
    b2.next.next = shared
    assert sol.getIntersectionNode(a2, b2).val == 3

    assert sol.getIntersectionNode(None, list_to_linked_list([1])) is None

    print("\nAll test cases passed!")
````
