Solve Tower of Hanoi for n disks on three pegs labeled A (source), B (auxiliary),
and C (target). Return the sequence of moves, each move transferring the top disk
from one peg to another following the rules: only one disk at a time, never place
a larger disk on a smaller one.

## Examples

````text
Example 1:
    Input: n = 1
    Output: ["A->C"]

Example 2:
    Input: n = 2
    Output: ["A->B", "A->C", "B->C"]
````

## Constraints

````text
- 1 <= n <= 10 for tests (exponential number of moves)
````
