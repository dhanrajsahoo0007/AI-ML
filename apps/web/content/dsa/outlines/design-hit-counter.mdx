Count hits in the last 300 seconds relative to each query timestamp. Calls arrive in non-decreasing
timestamp order; at most 300 hits and queries total.

## Examples

````text
Example 1:
Input: hit(1), hit(2), hit(3), getHits(4) -> 3
Next: hit(300), getHits(300) -> 4, getHits(301) -> 3
````

## Constraints

````text
- 1 <= timestamp <= 2 * 10^9
- Chronological order guaranteed
````
