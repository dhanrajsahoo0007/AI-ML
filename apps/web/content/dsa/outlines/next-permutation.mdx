Given an array of integers nums, reorder it to the lexicographically next greater permutation.
If no such ordering exists, rearrange to the lowest possible order (sorted ascending). Must use
O(1) extra memory besides modifying nums in place.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3]
    Output: [1, 3, 2]
Example 2:
    Input: nums = [3, 2, 1]
    Output: [1, 2, 3]
````

## Constraints

````text
- 1 <= len(nums) <= 100
- 0 <= nums[i] <= 100
````
