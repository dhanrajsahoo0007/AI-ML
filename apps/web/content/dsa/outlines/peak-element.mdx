Return any index of a peak element: strictly greater than both neighbors (boundary -inf outside).
In a bitonic array (increase then decrease), that peak is the unique maximum.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 1]
    Output: 2

Example 2:
    Input: nums = [1, 2, 1, 3, 5, 6, 4]
    Output: 1 or 5 (any valid peak index)
````

## Constraints

````text
- 1 <= len(nums) <= 1000
- nums[i] != nums[i + 1] for valid peaks in the classic formulation
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search by Slope
Move toward the side where nums\[mid\] &lt; nums\[mid+1\] (uphill) to reach a peak.

1. Handle n == 1 and boundary peaks at 0 and n-1.
2. Binary search on interior: if nums\[mid-1\] &lt; nums\[mid\] &gt; nums\[mid+1\], return mid.
3. If ascending at mid, search right; else search left.

## Complexity

**Time:** O(log n) - Halving interior range.

**Space:** O(1) - Constant indices only.

## Solution

````python
from typing import List


class Solution:
    def findPeakElement(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return 0
        if nums[0] > nums[1]:
            return 0
        if nums[n - 1] > nums[n - 2]:
            return n - 1
        lo, hi = 1, n - 2
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid - 1] < nums[mid] > nums[mid + 1]:
                return mid
            if nums[mid] < nums[mid + 1]:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo
````

    for arr in ([1, 2, 3, 1], [1, 2, 1, 3, 5, 6, 4], [1], [1, 2], [2, 1], [1, 2, 3]):
