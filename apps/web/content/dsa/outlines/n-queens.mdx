Place n queens on an n x n chessboard so none attack; return all distinct boards as lists
of strings using 'Q' and '.'.

## Examples

````text
Example 1:
Input: n = 4
Output: two board layouts (see tests)
````

## Constraints

````text
- 1 <= n <= 9
````

<PremiumBreak />

## Approach

**Pattern:** Row-wise queen placement with diagonal sets
Track occupied columns and both diagonals; place one queen per row then recurse.

1. For each row try each column not attacked by column or diagonal sets.
2. Place queen, update sets, recurse next row, then undo.
3. When row == n, snapshot the board.

## Complexity

**Time:** O(n!) worst-case search tree.

**Space:** O(n) for sets and recursion excluding outputs.

## Solution

````python
from typing import List


class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        cols = set()
        pos_diag = set()
        neg_diag = set()
        board = [["."] * n for _ in range(n)]
        result: List[List[str]] = []

        def backtrack(row: int) -> None:
            if row == n:
                result.append(["".join(r) for r in board])
                return
            for col in range(n):
                if col in cols or (row + col) in pos_diag or (row - col) in neg_diag:
                    continue
                cols.add(col)
                pos_diag.add(row + col)
                neg_diag.add(row - col)
                board[row][col] = "Q"
                backtrack(row + 1)
                board[row][col] = "."
                cols.remove(col)
                pos_diag.remove(row + col)
                neg_diag.remove(row - col)

        backtrack(0)
        return result
````
