Exactly two nodes in a BST were swapped by mistake. Recover the tree to a valid BST by
swapping their values back (do not change the tree shape).

## Examples

````text
Example 1:
    Input: [3,1,4,null,null,2] (values out of order)
    Output: inorder becomes sorted

Example 2:
    Input: [1,3,null,2] (adjacent swap pattern)
    Output: valid BST inorder
````

## Constraints

````text
- The number of nodes is in the range [2, 1000].
````
