Given n x n matrix, choose a falling path (start any column, each step go to
adjacent column index +/-1 or same) minimizing total sum.

## Examples

````text
Example 1: matrix=[[2,1,3],[6,5,4],[7,8,9]] -> 13
````

## Constraints

````text
- n <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Row-wise DP with 3 predecessors
dp\[i\]\[j\]=matrix\[i\]\[j\]+min(dp\[i-1\]\[k\]) for k in &#123;j-1,j,j+1&#125;.

## Complexity

**Time:** O(n^2). Space: O(n).

## Solution

````python
from typing import List


class Solution:
    def minFallingPathSum(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        prev = matrix[0][:]
        for i in range(1, n):
            cur = [0] * n
            for j in range(n):
                best = prev[j]
                if j:
                    best = min(best, prev[j - 1])
                if j + 1 < n:
                    best = min(best, prev[j + 1])
                cur[j] = matrix[i][j] + best
            prev = cur
        return min(prev)
````
