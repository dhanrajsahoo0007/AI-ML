Row 1 of a grammar table is "0". Each next row replaces every 0 with "01" and every
1 with "10". Answer two tasks: (1) return the k-th symbol (1-indexed) in row n as 0
or 1; (2) build row n as a string using the same replacement rule.

## Examples

````text
Example 1:
    Input: n = 4, k = 3
    Output: 1 (row 4 is 01101001)

Example 2:
    Input: n = 3
    Output: "0110" for the full third row
````

## Constraints

````text
- 1 <= n <= 30 for row materialization tests; k fits grammar definitions (1-indexed)
````
