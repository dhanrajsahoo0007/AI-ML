Given an array of integers nums, sort the array in increasing order based on the
frequency of the values. If multiple values have the same frequency, sort them
in decreasing order. Return the sorted array.

## Examples

````text
Example 1:
    Input: nums = [1,1,2,2,2,3]
    Output: [3,1,1,2,2,2]
    Explanation: '3' has frequency 1, '1' has frequency 2, '2' has frequency 3.

Example 2:
    Input: nums = [2,3,1,3,2]
    Output: [1,3,3,2,2]
    Explanation: '2' and '3' both have frequency 2, sorted in decreasing order.
````

## Constraints

````text
- 1 <= nums.length <= 100
- -100 <= nums[i] <= 100
````

## Approach

**Pattern:** Top-K
We use a min-heap with (frequency, -num) tuples. This sorts by increasing
frequency first, then by decreasing value for tie-breaking.

1. Count frequencies using Counter.
2. Push (freq, -num) tuples into a min-heap.
3. Pop elements from the heap and extend the result by freq copies of num.

## Complexity

**Time:** O(n log k) where k is the number of unique elements

**Space:** O(n)

## Original notes

````text
Original notes (restored):
LeetCode 1636-style sort: primary key = ascending frequency, tie-breaker = descending numeric value.
Push `(freq, -num)` so among equal frequencies larger `num` pops first, which yields smaller values
earlier in the output when expanded (`result.extend` repeats `num` `freq` times).
Original examples:
    [1,1,2,2,2,3] -> [3,1,1,2,2,2]; [2,3,1,3,2] -> [1,3,3,2,2].
````

## Solution

````python
import heapq
from collections import Counter
from typing import List


class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        counter = Counter(nums)
        min_heap = []
        result = []

        for num, freq in counter.items():
            # -num breaks ties: higher value first when frequencies match.
            heapq.heappush(min_heap, (freq, -num))

        while min_heap:
            freq, neg_num = heapq.heappop(min_heap)
            result.extend([-neg_num] * freq)

        return result
````
