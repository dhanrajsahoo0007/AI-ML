Use recursion to build the sequence from 1 to n and from n down to 1 without using loops.

## Examples

````text
Example 1:
    Input: n = 5 (ascending)
    Output: [1, 2, 3, 4, 5]

Example 2:
    Input: n = 4 (descending)
    Output: [4, 3, 2, 1]
````

## Constraints

````text
- 0 <= n <= 2000 (keep n modest for recursion depth in CPython)
````

<PremiumBreak />

## Approach

**Pattern:** Recursion with deferred / immediate work
Ascending order recurses first then appends the current value; descending prints
the current value before recursing so larger indices unwind in reverse.

1. For ascending: if n == 0 return \[\]; else return one\_to\_n(n-1) + \[n\].
2. For descending: if n == 0 return \[\]; else return \[n\] + n\_to\_one(n-1).

## Complexity

**Time:** O(n) - one recursive call per integer

**Space:** O(n) - output size plus O(n) call stack depth

## Solution

````python
from typing import List


class Solution:
    def one_to_n(self, n: int) -> List[int]:
        if n <= 0:
            return []
        return self.one_to_n(n - 1) + [n]

    def n_to_one(self, n: int) -> List[int]:
        if n <= 0:
            return []
        return [n] + self.n_to_one(n - 1)
````
