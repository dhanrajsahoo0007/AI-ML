You are given an integer array cost where cost\[i\] is the cost of step i on a
staircase. Once you pay, you may climb one or two steps. Indices 0 and 1 are
valid starting points. Return the minimum cost to reach the top (index n,
beyond the last paid step).

## Examples

````text
Example 1:
    Input: cost = [10, 15, 20]
    Output: 15
Example 2:
    Input: cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]
    Output: 6
````

## Constraints

````text
- 2 <= len(cost) <= 1000
- 0 <= cost[i] <= 999
````
