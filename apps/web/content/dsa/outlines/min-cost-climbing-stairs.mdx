You are given an integer array cost where cost\[i\] is the cost of step i on a
staircase. Once you pay, you may climb one or two steps. Indices 0 and 1 are
valid starting points. Return the minimum cost to reach the top (index n,
beyond the last paid step).

## Examples

````text
Example 1:
    Input: cost = [10, 15, 20]
    Output: 15
Example 2:
    Input: cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]
    Output: 6
````

## Constraints

````text
- 2 <= len(cost) <= 1000
- 0 <= cost[i] <= 999
````

<PremiumBreak />

## Approach

**Pattern:** 1D Dynamic Programming
Minimum to stand on i is cost\[i\] plus min cost to reach i-1 or i-2.

1. Let dp\[i\] be min cost to land on step i (after paying cost\[i\] when stepping on it).
2. Alternatively compute min to reach beyond last: iterate i with two previous totals.
3. Answer = min(last two cumulative costs to finish).

## Complexity

**Time:** O(n).

**Space:** O(1) with two variables.

## Solution

````python
from typing import List


class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        a = cost[0]
        b = cost[1]
        for i in range(2, len(cost)):
            a, b = b, cost[i] + min(a, b)
        return min(a, b)
````
