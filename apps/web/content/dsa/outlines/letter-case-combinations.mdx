Return all strings obtainable by toggling any subset of letter positions to upper
or lower case while leaving digits untouched.

## Examples

````text
Example 1:
    Input: "Jw"
    Output sorted includes "JW", "Jw", "jW", "jw"

Example 2:
    Input: ""
    Output: [""]
````

## Constraints

````text
- Input length small enough for 2^k combinations in tests
````
