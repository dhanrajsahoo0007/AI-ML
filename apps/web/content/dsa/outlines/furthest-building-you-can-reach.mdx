Given building heights, bricks, and ladders, find the furthest building index
you can reach using them optimally. Use bricks for small climbs, ladders for large ones.

## Examples

````text
Example 1:
    Input: heights = [4,2,7,6,9,14,12], bricks = 5, ladders = 1
    Output: 4

Example 2:
    Input: heights = [4,12,2,7,3,18,20,3,19], bricks = 10, ladders = 2
    Output: 7
````

## Constraints

````text
- 1 <= heights.length <= 10^5
- 1 <= heights[i] <= 10^6
- 0 <= bricks <= 10^9
- 0 <= ladders <= heights.length
````

## Approach

**Pattern:** Greedy with Heap
Use ladders for the largest climbs and bricks for smaller ones.
A min-heap of size equal to ladders tracks the ladder-assigned climbs.

1. For each upward climb, push the climb height into a min-heap.
2. If heap size &gt; ladders, pop the smallest climb and use bricks for it.
3. If bricks run out, return the current index.
4. If we process all buildings, return the last index.

## Complexity

**Time:** O(n log L) where L is the number of ladders

**Space:** O(L) for the heap

## Original notes

````text
Original notes (restored):
Treat ladders as "wildcards" for the largest climbs: push each positive climb into a min-heap;
once size exceeds `ladders`, pay bricks for the smallest climb seen so far (exchange ladder for bricks).
If bricks cannot cover that smallest forced climb, stop before crossing that edge.
````

## Solution

````python
import heapq
from typing import List


class Solution:
    def furthestBuilding(self, heights: List[int], bricks: int, ladders: int) -> int:
        climb_heap = []

        for i in range(len(heights) - 1):
            climb = heights[i + 1] - heights[i]
            if climb <= 0:
                continue

            heapq.heappush(climb_heap, climb)

            if len(climb_heap) > ladders:
                smallest_climb = heapq.heappop(climb_heap)
                if bricks < smallest_climb:
                    return i
                bricks -= smallest_climb

        return len(heights) - 1
````
