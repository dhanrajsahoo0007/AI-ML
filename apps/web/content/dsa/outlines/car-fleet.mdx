Cars start at positions with speeds toward a shared target. Faster cars cannot pass slower ones and
form fleets moving at the slowest member's speed. Count fleets arriving at target.

## Examples

````text
Example 1:
Input: target = 12, position = [10, 8, 0, 5, 3], speed = [2, 4, 1, 1, 3]
Output: 3
````

## Constraints

````text
- n == len(position) == len(speed)
- 1 <= n <= 10^5
````
