Given n pairs of parentheses, generate every well-formed (balanced) combination.

## Examples

````text
Example 1:
    Input: n = 1
    Output: ["()"]

Example 2:
    Input: n = 3
    Output length: 5th Catalan number = 5 strings
````

## Constraints

````text
- 1 <= n <= 4 in tests (output grows quickly)
````
