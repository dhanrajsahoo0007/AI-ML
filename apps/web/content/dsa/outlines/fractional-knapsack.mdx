Given item values and weights and a knapsack capacity W, choose fractions of items to maximize
total value. You may take any fraction of an item; value scales linearly with the fraction taken.

## Examples

````text
Example 1:
    Input: W = 50, values = [100, 60, 120], weights = [20, 10, 30]
    Output: 240.0

Example 2:
    Input: W = 10, values = [10], weights = [5]
    Output: 10.0

Example 3:
    Input: W = 15, values = [5, 10], weights = [10, 30]
    Output: 6.666... (take all of first, 5/30 of second)
````

## Constraints

````text
- weights[i] > 0 for all i
- W >= 0
````

## Approach

**Pattern:** Greedy by Density
Repeatedly consume as much as possible of the remaining highest value-per-weight item.

1. Build tuples of (value/weight, value, weight) and sort descending by ratio.
2. Greedily take whole items while capacity allows; then take a fractional tail of the next item.
3. Return accumulated value as a float.

## Complexity

**Time:** O(n log n) - Sorting dominates.

**Space:** O(n) - List of item tuples.

## Solution

````python
from typing import List


class Solution:
    def fractionalKnapsack(self, W: int, values: List[int], weights: List[int]) -> float:
        # Tuple layout mirrors the teaching notes: (density, value, weight).
        items = [(v / w, v, w) for v, w in zip(values, weights)]
        items.sort(reverse=True)
        total_value = 0.0
        capacity = W
        for ratio, value, weight in items:
            if capacity >= weight:
                capacity -= weight
                total_value += value
            else:
                total_value += ratio * capacity
                break
        return total_value


class Item:
    """Lightweight container used in the alternate OOP version from the original notes."""

    def __init__(self, value: int, weight: int) -> None:
        self.value = value
        self.weight = weight


class SolutionWithItems:
    """Same greedy policy, but operates on a list of `Item` objects (historical second solution)."""

    def fractionalKnapsack(self, W: int, arr: List[Item]) -> float:
        arr.sort(key=lambda x: x.value / x.weight, reverse=True)
        cur_weight = 0
        final_value = 0.0
        for it in arr:
            if cur_weight + it.weight <= W:
                cur_weight += it.weight
                final_value += it.value
            else:
                remain = W - cur_weight
                final_value += it.value / it.weight * remain
                break
        return final_value
````
