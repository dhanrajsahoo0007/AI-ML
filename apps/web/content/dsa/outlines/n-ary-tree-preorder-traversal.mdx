Given the root of an n-ary tree, return its preorder traversal using an explicit stack (iterative).

## Examples

````text
Example 1:
Root with val 1 and three children ordered 3,2,4 (each may have subtrees) -> preorder lists nodes depth-first.
````

## Constraints

````text
- Number of nodes in [0, 10^4].
- 0 <= Node.val <= 10^4.
````
