Given the root of an n-ary tree, return its preorder traversal using an explicit stack (iterative).

## Examples

````text
Example 1:
Root with val 1 and three children ordered 3,2,4 (each may have subtrees) -> preorder lists nodes depth-first.
````

## Constraints

````text
- Number of nodes in [0, 10^4].
- 0 <= Node.val <= 10^4.
````

<PremiumBreak />

## Approach

**Pattern:** DFS with stack
Push root; repeatedly pop, record value, push children in reverse so the first child is processed next.

1. If root is None, return \[\].
2. Stack starts with root; while stack: pop node, append val, extend stack with children reversed.

## Complexity

**Time:** O(n)

**Space:** O(n) for the stack in a star tree.

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, children: Optional[List["TreeNode"]] = None):
        self.val = val
        self.children = children if children is not None else []


class Solution:
    def preorder(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        out: List[int] = []
        stack: List[TreeNode] = [root]
        while stack:
            node = stack.pop()
            out.append(node.val)
            for child in reversed(node.children):
                stack.append(child)
        return out


def build_sample_tree() -> TreeNode:
    n5 = TreeNode(5)
    n6 = TreeNode(6)
    n3 = TreeNode(3, [n5, n6])
    n2 = TreeNode(2)
    n4 = TreeNode(4)
    return TreeNode(1, [n3, n2, n4])
````
