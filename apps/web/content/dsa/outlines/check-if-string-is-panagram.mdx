Given a string sentence of lowercase English letters, return True if every letter
of the alphabet appears at least once (pangram), otherwise False.

## Examples

````text
Example 1:
    Input: sentence = "thequickbrownfoxjumpsoverthelazydog"
    Output: True

Example 2:
    Input: sentence = "leetcode"
    Output: False
````

## Constraints

````text
- 1 <= len(sentence) <= 1000
- sentence consists of lowercase English letters.
````
