Given the root of a binary search tree, return the minimum and maximum values stored in the tree.
For an empty tree, both results are undefined and represented as None.

## Examples

````text
Example 1:
    Input: BST with values [5,3,7,1,4,6,8]
    Output: min = 1, max = 8

Example 2:
    Input: single node with val 10
    Output: min = 10, max = 10
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
````
