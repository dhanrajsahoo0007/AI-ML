Given a string s, return all distinct permutations of its characters (orderings that use
every character exactly once).

## Examples

````text
Example 1:
    Input: s = "abc"
    Output: ["abc","acb","bac","bca","cab","cba"] (order may vary)

Example 2:
    Input: s = "aab"
    Output: ["aab","aba","baa"] (order may vary)
````

## Constraints

````text
- 1 <= len(s) <= 7
- s contains lowercase English letters.
````
