Given an array of strings strs, return the longest common prefix shared by all
strings. If none, return an empty string.

## Examples

````text
Example 1:
Input: strs = ["flower", "flow", "flight"]
Output: "fl"
````

## Constraints

````text
- 1 <= len(strs) <= 200
- 0 <= len(strs[i]) <= 200
- strs[i] contains only lowercase English letters
````

<PremiumBreak />

## Approach

**Pattern:** Horizontal Scan / Prefix
Compare characters column-wise until any string mismatches or ends.

1. Use the first string as the candidate prefix.
2. For each character index, compare across all strings.
3. Stop at first mismatch or length limit; return the accepted slice.

## Complexity

**Time:** O(S) where S is the sum of lengths of all strings.

**Space:** O(1) beyond the output slice reference.

## Solution

````python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        base = strs[0]
        for i, ch in enumerate(base):
            for s in strs[1:]:
                if i == len(s) or s[i] != ch:
                    return base[:i]
        return base
````
