nums\[i\] can be changed by 1 at cost cost\[i\] per unit. Choose a final common value t to minimize total
cost to make all nums equal.

## Examples

````text
Example 1:
Input: nums = [1, 3, 5, 2], cost = [2, 3, 1, 14]
Output: 8
````

## Constraints

````text
- len(nums) == len(cost) <= 10^5
- 1 <= nums[i], cost[i] <= 10^6
````

<PremiumBreak />

## Approach

**Pattern:** Weighted Median
Cost(t) = sum cost\[i\] \* abs(nums\[i\] - t) is convex; minimizer is any weighted median of pairs (nums\[i\], cost\[i\]).

1. Sort pairs by nums.
2. Accumulate cost until running sum &gt;= total\_cost / 2; that nums value is optimal t.
3. Evaluate cost at t.

## Complexity

**Time:** O(n log n) - Sort dominates.

**Space:** O(n) - Pairs array.

## Solution

````python
from typing import List


class Solution:
    def minCost(self, nums: List[int], cost: List[int]) -> int:
        pairs = sorted(zip(nums, cost), key=lambda x: x[0])
        total_w = sum(c for _, c in pairs)
        half = (total_w + 1) // 2
        run = 0
        target = pairs[0][0]
        for x, w in pairs:
            run += w
            if run >= half:
                target = x
                break
        return sum(c * abs(x - target) for x, c in zip(nums, cost))
````
