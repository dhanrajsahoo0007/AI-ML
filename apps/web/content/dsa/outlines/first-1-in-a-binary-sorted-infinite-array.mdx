In an infinite sorted binary array (0s then 1s), find the index of the first 1. Use a finite array
in code; return -1 if no 1 exists.

## Examples

````text
Example 1:
    Input: nums = [0, 0, 0, 0, 0, 1, 1, ...]
    Output: 5

Example 2:
    Input: nums = [1, 1, 1, ...]
    Output: 0
````

## Constraints

````text
- nums contains only 0 and 1, sorted (all zeros before ones)
````
