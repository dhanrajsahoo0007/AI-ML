Customers pay with $5, $10, or $20 bills for a $5 lemonade. Starting with no change,
process each bill in order and return whether you can make correct change for everyone.

## Examples

````text
Example 1:
    Input: bills = [5, 5, 5, 10, 20]
    Output: True

Example 2:
    Input: bills = [5, 5, 10, 10, 20]
    Output: False

Example 3:
    Input: bills = [5, 5, 10]
    Output: True
````

## Constraints

````text
- 1 <= bills.length <= 10^5
- bills[i] is 5, 10, or 20
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Simulation
Prefer giving one $10 + one $5 for a $20 before using three $5s when possible to preserve flexibility.

1. Keep counts of $5 and $10 bills on hand.
2. For each payment, update inventory; for $10 require one $5; for $20 prefer $10+$5 else three $5s.
3. If any step fails, return False; otherwise return True.

## Complexity

**Time:** O(n) - One pass over bills.

**Space:** O(1) - Two counters.

## Solution

````python
from typing import List


class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five = ten = 0
        for bill in bills:
            if bill == 5:
                five += 1
            elif bill == 10:
                if not five:
                    return False
                five -= 1
                ten += 1
            else:  # $20 bill → need $15 of change
                if ten and five:
                    # Greedy preference: spend a $10 before burning three $5s.
                    ten -= 1
                    five -= 1
                elif five >= 3:
                    five -= 3
                else:
                    return False
        return True
````
