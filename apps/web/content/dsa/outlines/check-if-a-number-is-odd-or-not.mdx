Given an integer n, return True if n is odd.

## Examples

````text
Example 1:
    Input: n = 3
    Output: True
Example 2:
    Input: n = 4
    Output: False
````

## Constraints

````text
- n fits in 32-bit signed range
````

<PremiumBreak />

## Approach

**Pattern:** Lowest bit test
Odd numbers have the least significant bit equal to 1.

1. Return (n &amp; 1) == 1.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def isOdd(self, n: int) -> bool:
        return (n & 1) == 1
````
