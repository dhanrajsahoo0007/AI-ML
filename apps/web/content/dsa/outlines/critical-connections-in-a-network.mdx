Given an undirected connected graph of servers as edges, return all critical connections
(bridges): edges whose removal increases the number of connected components.

## Examples

````text
Example 1:
    Input: n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
    Output: [[1,3]]
Example 2:
    Input: n = 2, connections = [[0,1]]
    Output: [[0,1]]
````

## Constraints

````text
- 2 <= n <= 10^5
- len(connections) == n - 1 (tree) or general undirected graph
````

<PremiumBreak />

## Approach

**Pattern:** Graph - Tarjan bridge finding (low-link DFS)

1. Run a DFS recording discovery time and low-link values.
2. For tree edge u-&gt;v, if low\[v\] &gt; disc\[u\], then (u,v) is a bridge.

## Complexity

**Time:** O(V + E).

**Space:** O(V + E).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        g = defaultdict(list)
        for u, v in connections:
            g[u].append(v)
            g[v].append(u)

        disc = [-1] * n
        low = [-1] * n
        t = 0
        bridges: List[List[int]] = []

        def dfs(u: int, p: int) -> None:
            nonlocal t
            disc[u] = low[u] = t
            t += 1
            for v in g[u]:
                if v == p:
                    continue
                if disc[v] == -1:
                    dfs(v, u)
                    low[u] = min(low[u], low[v])
                    if low[v] > disc[u]:
                        bridges.append([u, v])
                else:
                    low[u] = min(low[u], disc[v])

        dfs(0, -1)
        return bridges
````
