Start from an all-zero array equal in length to target. In one operation pick any subarray and add
1 to every element. Return the minimum operations to reach target.

## Examples

````text
Example 1:
Input: [1, 2, 3, 2, 1]
Output: 3
````

## Constraints

````text
- 1 <= len(target) <= 10^5
- 1 <= target[i] <= 10^5
````
