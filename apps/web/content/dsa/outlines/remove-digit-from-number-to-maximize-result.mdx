Given a string number representing a non-negative integer and a digit character digit that appears
in number, remove exactly one occurrence of digit from number so that the resulting string is
maximized in numeric value (no leading zeros except the single zero).

## Examples

````text
Example 1:
    Input: number = "5511", digit = "5"
    Output: "511"

Example 2:
    Input: number = "133235", digit = "3"
    Output: "13325"

Example 3:
    Input: number = "10", digit = "1"
    Output: "0"
````

## Constraints

````text
- 2 <= len(number) <= 10^5
- number consists of digits from '0' to '9'
- digit is a digit occurring in number
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Leftmost Lift
Remove the leftmost chosen digit where the next digit is larger; if none, remove the rightmost occurrence.

1. Scan indices except the last; when number\[i\] == digit and number\[i\] &lt; number\[i+1\], return slice removing i.
2. If no such index, remove the last occurrence of digit with rfind.

## Complexity

**Time:** O(n) - Linear scan and string concatenation cost O(n) in Python.

**Space:** O(n) - New string for the result.

## Solution

````python
class Solution:
    def removeDigit(self, number: str, digit: str) -> str:
        n = len(number)
        for i in range(n - 1):
            if number[i] == digit and number[i] < number[i + 1]:
                return number[:i] + number[i + 1 :]
        j = number.rfind(digit)
        return number[:j] + number[j + 1 :]
````
