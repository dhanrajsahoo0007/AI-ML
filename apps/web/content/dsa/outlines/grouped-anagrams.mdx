Given an array of strings strs, group anagrams together. The answer may be in any order.

## Examples

````text
Example 1:
    Input: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
    Output: [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]] (order of groups and within groups may vary)
Example 2:
    Input: strs = [""]
    Output: [[""]]
````

## Constraints

````text
- 1 <= len(strs) <= 10^4
- 0 <= len(strs[i]) <= 100
- strs[i] consists of lowercase English letters.
````
