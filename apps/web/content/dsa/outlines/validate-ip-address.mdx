Given a string queryIP, return "IPv4" if it is a valid IPv4 address, "IPv6" if it
is a valid IPv6 address, or "Neither" otherwise.

## Examples

````text
Example 1:
    Input: queryIP = "172.16.254.1"
    Output: "IPv4"

Example 2:
    Input: queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
    Output: "IPv6"

Example 3:
    Input: queryIP = "256.256.256.256"
    Output: "Neither"
````

## Constraints

````text
- queryIP consists only of digits, letters, and the characters '.' and ':'.
````
