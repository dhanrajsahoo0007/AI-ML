Given a list of strings of lowercase letters, group all strings that belong to the same shifting
sequence. Two strings are shifts of each other if lengths match and corresponding letters differ
by the same offset modulo 26 between all positions.

## Examples

````text
Example 1:
Input: strings = ["abc", "bcd", "acef", "xyz", "az", "ba", "a", "z"]
Output: [["acef"], ["a", "z"], ["abc", "bcd", "xyz"], ["az", "ba"]] (group order may vary)
````

## Constraints

````text
- 1 <= len(strings) <= 200
- 1 <= len(strings[i]) <= 50
- strings[i] consists of lowercase English letters.
````
