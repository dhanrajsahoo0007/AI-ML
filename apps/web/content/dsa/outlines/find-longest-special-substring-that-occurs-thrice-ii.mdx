A special substring uses one repeated letter. Return the maximum length L such that some special
substring of length L appears at least three times in s (possibly overlapping). Return -1 if none.

## Examples

````text
Example 1:
    Input: s = "aaaa"
    Output: 2

Example 2:
    Input: s = "abcdef"
    Output: -1
````

## Constraints

````text
- 3 <= len(s) <= 5 * 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Length + Run-Length Counting
Compress s into runs; for letter c and length L, occurrences equal sum over runs of max(0, run\_len - L + 1).

1. Build runs (char, length).
2. Binary search L; feasible if any character's total occurrence count of length-L specials is &gt;= 3.

## Complexity

**Time:** O(n log n) - At most log n lengths, each check O(number of runs) &lt;= O(n).

**Space:** O(n) - Run list in worst case per character alternation.

You are given a string s that consists of lowercase English letters.

A string is called special if it is made up of only a single character. For example, the string "abc" is not special, whereas the strings "ddd", "zz", and "f" are special.

Return the length of the longest special substring of s which occurs at least thrice, or -1 if no special substring occurs at least thrice.

A substring is a contiguous non-empty sequence of characters within a string.

Example 1:

Input: s = "aaaa"
Output: 2
Explanation: The longest special substring which occurs thrice is "aa": substrings "aaaa", "aaaa", and "aaaa".
It can be shown that the maximum length achievable is 2.
Example 2:

Input: s = "abcdef"
Output: -1
Explanation: There exists no special substring which occurs at least thrice. Hence return -1.
Example 3:

Input: s = "abcaba"
Output: 1
Explanation: The longest special substring which occurs thrice is "a": substrings "abcaba", "abcaba", and "abcaba".
It can be shown that the maximum length achievable is 1.

## Solution

````python
from itertools import groupby
from typing import List, Tuple


class Solution:
    def maximumLength(self, s: str) -> int:
        runs: List[Tuple[str, int]] = [(ch, len(list(g))) for ch, g in groupby(s)]

        def count_for_letter(ch: str, length: int) -> int:
            total = 0
            for c, ln in runs:
                if c == ch and ln >= length:
                    total += ln - length + 1
            return total

        def ok(length: int) -> bool:
            if length <= 0:
                return False
            for ch in set(s):
                if count_for_letter(ch, length) >= 3:
                    return True
            return False

        lo, hi = 1, len(s)
        ans = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if ok(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
````
