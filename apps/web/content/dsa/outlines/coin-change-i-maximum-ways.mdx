Given coins of distinct positive denominations and an amount, count the number
of combinations that sum to amount (order of coins does not matter; unlimited
supply of each coin).

## Examples

````text
Example 1:
    Input: amount = 5, coins = [1, 2, 5]
    Output: 4
Example 2:
    Input: amount = 3, coins = [2]
    Output: 0
````

## Constraints

````text
- 1 <= len(coins) <= 300
- 1 <= coins[i] <= 5000
- 0 <= amount <= 5000
````

<PremiumBreak />

## Approach

**Pattern:** Unbounded knapsack counting
Iterate coins outer loop to avoid permutations; inner loop on amount ascending.

1. dp\[0\] = 1; dp\[v\] = sum of dp\[v-c\] over coins c &lt;= v processed so far.
2. Return dp\[amount\].

## Complexity

**Time:** O(amount \* len(coins)).

**Space:** O(amount).

## Solution

````python
from typing import List


class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        dp = [0] * (amount + 1)
        dp[0] = 1
        for c in coins:
            for v in range(c, amount + 1):
                dp[v] += dp[v - c]
        return dp[amount]
````
