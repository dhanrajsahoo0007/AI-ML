Given coins of distinct positive denominations and an amount, count the number
of combinations that sum to amount (order of coins does not matter; unlimited
supply of each coin).

## Examples

````text
Example 1:
    Input: amount = 5, coins = [1, 2, 5]
    Output: 4
Example 2:
    Input: amount = 3, coins = [2]
    Output: 0
````

## Constraints

````text
- 1 <= len(coins) <= 300
- 1 <= coins[i] <= 5000
- 0 <= amount <= 5000
````
