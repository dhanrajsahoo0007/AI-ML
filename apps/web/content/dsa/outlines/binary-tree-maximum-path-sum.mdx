Given the root of a binary tree, return the maximum path sum of any non-empty path where a path
is a sequence of connected parent-child edges (a node appears at most once).

## Examples

````text
Example 1:
    Input: [1,2,3]
    Output: 6

Example 2:
    Input: [-10,9,20,null,null,15,7]
    Output: 42
````

## Constraints

````text
- The number of nodes is in the range [1, 3 * 10^4].
- Node values may be negative.
````
