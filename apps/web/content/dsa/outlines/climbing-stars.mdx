You are climbing a staircase; it takes n steps to reach the top. Each move you
can climb 1 or 2 steps. Return the number of distinct ways to reach the top.

## Examples

````text
Example 1:
    Input: n = 3
    Output: 3
Example 2:
    Input: n = 5
    Output: 8
````

## Constraints

````text
- 1 <= n <= 45
````
