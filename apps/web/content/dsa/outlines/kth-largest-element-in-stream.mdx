Design a class to find the kth largest element in a stream.
KthLargest(int k, int\[\] nums) initializes with k and initial stream.
int add(int val) appends val and returns the kth largest element.

## Examples

````text
Example 1:
Input: k=3, nums=[4,5,8,2], add(3)=4, add(5)=5, add(10)=5, add(9)=8
````

## Constraints

````text
- 1 <= k <= 10^4
- 0 <= nums.length <= 10^4
- -10^4 <= nums[i], val <= 10^4
- At most 10^4 calls to add.
- At least k elements when add is called.
````
