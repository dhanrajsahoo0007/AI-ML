An array original becomes changed by appending twice every element of original, then shuffling.
Given changed, reconstruct any valid original, or return \[\] if none exists.

## Examples

````text
Example 1:
    Input: changed = [1, 3, 4, 2, 6, 8]
    Output: [1, 3, 4] (or any permutation such as [4, 3, 1])
Example 2:
    Input: changed = [6, 3, 0, 1]
    Output: []
Example 3:
    Input: changed = [1]
    Output: []
````

## Constraints

````text
- 1 <= len(changed) <= 10^5
- 0 <= changed[i] <= 10^5
````

## Approach

**Pattern:** Greedy with frequency map
Process values in sorted order; each unused smallest x must pair with 2x before larger numbers consume doubles.

1. If len(changed) is odd, return \[\] (doubled array has even length).
2. Count frequencies with a multiset (Counter).
3. For x in sorted unique keys, while count\[x\] &gt; 0, decrement x and 2x; if 2x missing, return \[\]; else append x to answer.
4. Return answer when all elements are paired away.

## Complexity

**Time:** O(n log n) - Sorting distinct keys; processing each element a constant number of times.

**Space:** O(n) - Frequency map and output list.

## Original notes

````text
Reconstruction intuition (from original statement):
If ``changed`` is a doubled array, every smallest unused value x must still have its partner 2x
available; otherwise no valid ``original`` exists. Example: ``[1,3,4,2,6,8]`` can come from
``[1,3,4]`` because 2, 6, and 8 are exactly twice those values (order after shuffle can vary).
Odd length or impossible pairings (e.g. missing double) mean return ``[]``.
````

## Solution

````python
import collections
from typing import List


class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2 == 1:
            return []
        freq = collections.Counter(changed)
        result: List[int] = []
        for x in sorted(freq.keys()):
            while freq[x] > 0:
                # Greedy: consume x with its double 2x while both counts allow it.
                if freq[x * 2] <= 0:
                    return []
                freq[x] -= 1
                freq[x * 2] -= 1
                result.append(x)
        return result


def _multiset_equal(a: List[int], b: List[int]) -> bool:
    return collections.Counter(a) == collections.Counter(b)
````
