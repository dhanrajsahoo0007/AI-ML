Given the root of a non-empty binary tree, return the maximum path sum where a path is any sequence of connected nodes
(parent-child edges); the path need not pass through the root.

## Examples

````text
Example 1:
    Input: root = [1,2,3]
    Output: 6
Example 2:
    Input: root = [-10,9,20,None,None,15,7]
    Output: 42
````

## Constraints

````text
- The number of nodes is in the range [1, 3 * 10^4].
- Node values in [-1000, 1000].
````
