Given the root of a non-empty binary tree, return the maximum path sum where a path is any sequence of connected nodes
(parent-child edges); the path need not pass through the root.

## Examples

````text
Example 1:
    Input: root = [1,2,3]
    Output: 6
Example 2:
    Input: root = [-10,9,20,None,None,15,7]
    Output: 42
````

## Constraints

````text
- The number of nodes is in the range [1, 3 * 10^4].
- Node values in [-1000, 1000].
````

<PremiumBreak />

## Approach

**Pattern:** Post-order with contribution to parent
Track global best as node.val + max(0, left\_gain) + max(0, right\_gain); return upward gain with one side only.

1. DFS returns max single-path sum from this node down to any descendant (may be 0 if negative).
2. Update answer with node.val + max(0, l) + max(0, r).
3. Return node.val + max(0, max(l, r)).

## Complexity

**Time:** O(n)

**Space:** O(h) recursion.

Restored (original notes, diagrams, and walkthrough):
Inline commentary from the original solution:

- Recursively compute the best "gain" from the left and right subtrees; ignore negative gains
(\`max(..., 0)\`) because we are allowed to drop a branch entirely.
- A candidate path through the current node uses both sides: \`node.val + left\_gain + right\_gain\`.
Compare that "price" against the global best on every visit.
- The value returned to the parent must extend along only one child (\`node.val + max(left, right)\`),
since a valid upward path cannot fork twice.

## Solution

````python
from typing import Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.best = -10**15

        def gain(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            left = max(gain(node.left), 0)
            right = max(gain(node.right), 0)
            self.best = max(self.best, node.val + left + right)
            return node.val + max(left, right)

        gain(root)
        return self.best


def build_tree_from_level_order(values):
    if not values or values[0] is None:
        return None
    from collections import deque

    root = TreeNode(values[0])
    q = deque([root])
    i = 1
    while q and i < len(values):
        node = q.popleft()
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            q.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            q.append(node.right)
        i += 1
    return root
````
