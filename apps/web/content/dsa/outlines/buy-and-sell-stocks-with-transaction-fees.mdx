Pay fee per sell; unlimited transactions.

<PremiumBreak />

## Approach

**Pattern:** Two-state DP.

## Complexity

**Time:** O(n).

## Solution

````python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        hold = -10**9
        cash = 0
        for p in prices:
            hold = max(hold, cash - p)
            cash = max(cash, hold + p - fee)
        return cash
````
