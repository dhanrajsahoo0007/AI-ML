An integer array changed is formed by taking an unknown array original, concatenating doubled copies
of each original value, then shuffling. Reconstruct any valid original if possible, else return \[\].

## Examples

````text
Example 1:
    Input: changed = [1,3,4,2,6,8]
    Output: [1,3,4] (or any valid original)

Example 2:
    Input: changed = [6,3,0,1]
    Output: []

Example 3:
    Input: changed = [0]
    Output: []
````

## Constraints

````text
- 1 <= len(changed) <= 10^5
- 0 <= changed[i] <= 10^5
````

## Approach

**Pattern:** Greedy Frequency Matching
Process values in ascending order and pair each count with its double before larger numbers consume it.

1. Count frequencies; if length is odd, impossible.
2. For sorted keys, handle zero separately using even count pairing.
3. For x &gt; 0, require count\[2x\] &gt;= count\[x\]; emit x that many times and decrement doubles accordingly.

## Complexity

**Time:** O(n log n) for sorting keys.

**Space:** O(n) for counter and output.

## Solution

````python
from collections import Counter
from typing import List


class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2:
            return []
        cnt = Counter(changed)
        out: List[int] = []
        for x in sorted(cnt):
            if cnt[x] == 0:
                continue
            if x == 0:
                if cnt[x] % 2:
                    return []
                out.extend([0] * (cnt[x] // 2))
                cnt[x] = 0
                continue
            y = 2 * x
            if cnt[y] < cnt[x]:
                return []
            out.extend([x] * cnt[x])
            cnt[y] -= cnt[x]
            cnt[x] = 0
        return out if len(out) == len(changed) // 2 else []
````
