Given two strings str1 and str2, return the shortest string that has both str1
and str2 as subsequences. If multiple answers exist, any valid one is fine.

## Examples

````text
Example 1:
Input: str1 = "abac", str2 = "cab"
Output: length 5 (e.g. "cabac" or "cabac" variant)
````

## Constraints

````text
- 1 <= len(str1), len(str2) <= 1000
````
