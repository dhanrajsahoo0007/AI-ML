You have n courses labeled 1..n. relations\[i\] = \[xi, yi\] means course xi must be completed before yi.
time\[i\] is the number of months to complete course i+1. You may take any number of courses in parallel
if prerequisites are satisfied. Return the minimum months to complete all courses.

## Examples

````text
Example 1:
    Input: n = 3, relations = [[1,3],[2,3]], time = [3,2,5]
    Output: 8
Example 2:
    Input: n = 4, relations = [[1,2],[2,3],[3,4]], time = [1,2,3,4]
    Output: 10
````

## Constraints

````text
- 1 <= n <= 5 * 10^4
- 0 <= len(relations) <= 5 * 10^4
- relations[i].length == 2
- 1 <= xi, yi <= n
- xi != yi
- 1 <= time[i] <= 10^4
````

## Approach

**Pattern:** Longest path in weighted DAG (critical path)
For each course, finish time is its own duration plus the maximum finish time among prerequisites.

1. Build adjacency list and indegree counts.
2. Initialize queue with courses having no prerequisites; set dp\[i\] = time\[i-1\].
3. Relax edges in topological order: dp\[v\] = max(dp\[v\], dp\[u\] + time\[v-1\]).
4. Return max(dp\[1:\]).

## Complexity

**Time:** O(n + m)

**Space:** O(n + m).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def minimumTime(self, n: int, relations: List[List[int]], time: List[int]) -> int:
        g = defaultdict(list)
        indeg = [0] * (n + 1)
        for x, y in relations:
            g[x].append(y)
            indeg[y] += 1
        q: deque[int] = deque()
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            if indeg[i] == 0:
                q.append(i)
                dp[i] = time[i - 1]
        while q:
            u = q.popleft()
            for v in g[u]:
                dp[v] = max(dp[v], dp[u] + time[v - 1])
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
        return max(dp[1:])
````
