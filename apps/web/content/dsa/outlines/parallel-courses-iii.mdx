You have n courses labeled 1..n. relations\[i\] = \[xi, yi\] means course xi must be completed before yi.
time\[i\] is the number of months to complete course i+1. You may take any number of courses in parallel
if prerequisites are satisfied. Return the minimum months to complete all courses.

## Examples

````text
Example 1:
    Input: n = 3, relations = [[1,3],[2,3]], time = [3,2,5]
    Output: 8
Example 2:
    Input: n = 4, relations = [[1,2],[2,3],[3,4]], time = [1,2,3,4]
    Output: 10
````

## Constraints

````text
- 1 <= n <= 5 * 10^4
- 0 <= len(relations) <= 5 * 10^4
- relations[i].length == 2
- 1 <= xi, yi <= n
- xi != yi
- 1 <= time[i] <= 10^4
````
