Given the root of a binary tree, return the left-side view and the right-side view.
The left view is the first node at each depth; the right view is the last node at each depth.

## Examples

````text
Example 1:
Input: root = [1,2,3,None,5,None,4]
Output: left [1,2,5], right [1,3,4]
````

## Constraints

````text
- The number of nodes is in the range [0, 100].
- Node values fit in 32-bit signed integers.
````

<PremiumBreak />

## Approach

**Pattern:** BFS with level indexing
Track the first seen index per level for left view; overwrite per level for right view.

1. Use a queue of (node, depth) starting from (root, 0).
2. For left view, when depth equals len(result), append the node's value.
3. For right view, append on new depth else assign result\[depth\] = val.

## Complexity

**Time:** O(n) - each node processed once.

**Space:** O(w) - queue width plus O(h) for result lists.

## Solution

````python
from collections import deque
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_from_level_order(values: List[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    q: deque[TreeNode] = deque([root])
    i = 1
    while q and i < len(values):
        node = q.popleft()
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            q.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            q.append(node.right)
        i += 1
    return root


class Solution:
    def leftSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        result: List[int] = []
        queue: deque[tuple[TreeNode, int]] = deque([(root, 0)])
        while queue:
            node, level = queue.popleft()
            if level == len(result):
                result.append(node.val)
            if node.left:
                queue.append((node.left, level + 1))
            if node.right:
                queue.append((node.right, level + 1))
        return result

    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        result: List[int] = []
        queue: deque[tuple[TreeNode, int]] = deque([(root, 0)])
        while queue:
            node, level = queue.popleft()
            if level == len(result):
                result.append(node.val)
            else:
                result[level] = node.val
            if node.left:
                queue.append((node.left, level + 1))
            if node.right:
                queue.append((node.right, level + 1))
        return result
````
