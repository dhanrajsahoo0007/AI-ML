Given a non-negative integer n and a zero-based bit index i, return True if the
i-th bit of n is 1.

## Examples

````text
Example 1:
    Input: n = 5, i = 0
    Output: True
Example 2:
    Input: n = 5, i = 1
    Output: False
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
- 0 <= i <= 31
````

<PremiumBreak />

## Approach

**Pattern:** Bit mask with AND
Shift 1 left by i positions and AND with n; non-zero means the bit is set.

1. Compute (n &gt;&gt; i) &amp; 1.
2. Return whether the result equals 1.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def isBitSet(self, n: int, i: int) -> bool:
        return ((n >> i) & 1) == 1
````
