Given a non-negative integer n and a zero-based bit index i, return True if the
i-th bit of n is 1.

## Examples

````text
Example 1:
    Input: n = 5, i = 0
    Output: True
Example 2:
    Input: n = 5, i = 1
    Output: False
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
- 0 <= i <= 31
````
