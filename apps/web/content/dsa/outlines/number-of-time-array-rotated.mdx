Given a sorted array of distinct integers that was rotated clockwise some number of times, return
how many rotations were applied. Equivalently, return the index of the minimum element (0 if not rotated).

## Examples

````text
Example 1:
    Input: nums = [4, 5, 6, 7, 0, 1, 2]
    Output: 4

Example 2:
    Input: nums = [1, 2, 3, 4, 5]
    Output: 0
````

## Constraints

````text
- All values are distinct
- nums was sorted ascending before rotation
````
