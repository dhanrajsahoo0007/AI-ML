Given a sorted array of distinct integers that was rotated clockwise some number of times, return
how many rotations were applied. Equivalently, return the index of the minimum element (0 if not rotated).

## Examples

````text
Example 1:
    Input: nums = [4, 5, 6, 7, 0, 1, 2]
    Output: 4

Example 2:
    Input: nums = [1, 2, 3, 4, 5]
    Output: 0
````

## Constraints

````text
- All values are distinct
- nums was sorted ascending before rotation
````

## Approach

**Pattern:** Binary Search for Pivot
The minimum is the only place where the next and previous neighbors are both greater or equal in the cyclic sense.

1. If nums\[0\] &lt;= nums\[-1\], the array is not rotated; return 0.
2. Binary search: detect the minimum using comparisons with neighbors (mod n).
3. If the right segment nums\[mid..right\] is sorted, search left; if left segment sorted, search right.

## Complexity

**Time:** O(log n) - Halving search space each step.

**Space:** O(1) - Constant extra variables.

## Solution

````python
from typing import List


class Solution:
    def findRotateSteps(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1 or nums[0] <= nums[-1]:
            return 0
        left, right = 0, n - 1
        while left <= right:
            if nums[left] <= nums[right]:
                return left
            mid = (left + right) // 2
            nxt = (mid + 1) % n
            prev = (mid - 1 + n) % n
            if nums[mid] <= nums[nxt] and nums[mid] <= nums[prev]:
                return mid
            if nums[mid] <= nums[right]:
                right = mid - 1
            elif nums[left] <= nums[mid]:
                left = mid + 1
        return 0
````
