You are given positive weights w. Implement pickIndex that returns a random index
i with probability w\[i\] / sum(w). Calls use a uniform random integer generator.

## Examples

````text
Example 1:
Input: w = [1, 3]
Repeated picks yield index 0 about 25% and index 1 about 75% of the time.
````

## Constraints

````text
- 1 <= len(w) <= 10^4
- 1 <= w[i] <= 10^5
````

**Also in the notes under:** [08. Binary Search/10. Maths](/dsa/problems/random-pick-with-weight).

## Approach

**Pattern:** Prefix Sum + Binary Search
Build cumulative weights and map a uniform draw in \[1, total\] to the first bucket.

1. Store prefix sums of w.
2. Draw target uniformly from 1..total inclusive.
3. Return bisect\_left(prefix, target).

## Complexity

**Time:** O(n) preprocessing, O(log n) per pick.

**Space:** O(n) for prefix sums.

## Solution

````python
import bisect
import random
from typing import List


class Solution:
    def __init__(self, w: List[int]) -> None:
        self._prefix: List[int] = []
        s = 0
        for x in w:
            s += x
            self._prefix.append(s)

    def index_for_target(self, target: int) -> int:
        return bisect.bisect_left(self._prefix, target)

    def pickIndex(self) -> int:
        return self.index_for_target(random.randint(1, self._prefix[-1]))
````
