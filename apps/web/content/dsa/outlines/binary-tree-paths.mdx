Given the root of a binary tree, return all root-to-leaf paths as strings "a-&gt;b-&gt;c".

## Examples

````text
Example 1:
    Input: root = [1,2,3,5]
    Output: ["1->2->5","1->3"]
Example 2:
    Input: root = [1]
    Output: ["1"]
````

## Constraints

````text
- The number of nodes is in the range [1, 100].
- Node values are in [-100, 100].
````
