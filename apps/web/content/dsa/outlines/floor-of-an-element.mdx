Given a sorted array and a target, return the floor: the largest value in the array that is
less than or equal to target. If none exists, return -1.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 4, 6, 10, 12, 14], target = 7
    Output: 6

Example 2:
    Input: nums = [1, 2, 4, 6, 10, 12, 14], target = 0
    Output: -1
````

## Constraints

````text
- nums is sorted in non-decreasing order
- 0 <= len(nums) <= 10^5
````
