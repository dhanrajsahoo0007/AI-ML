Implement MRUQueue(n) backed by \[1..n\] and fetch(k) that moves the kth element (1-indexed) to the
end and returns its value.

## Examples

````text
Example 1:
Input: MRUQueue(8), fetch(3), fetch(5), fetch(2), fetch(8)
Output: [3, 6, 2, 2]
````

## Constraints

````text
- 1 <= n <= 2000
- 1 <= k <= current length
````
