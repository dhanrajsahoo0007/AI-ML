Given an integer array nums and a positive integer k, return the number of good
subarrays. A subarray is good if it is non-empty and contains exactly k distinct integers.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 1, 2, 3], k = 2
    Output: 7
Example 2:
    Input: nums = [1, 2, 1, 3, 4], k = 3
    Output: 3
Example 3:
    Input: nums = [1, 1, 1, 1], k = 1
    Output: 10
````

## Constraints

````text
- 1 <= len(nums) <= 20000
- 1 <= nums[i], k <= len(nums)
````
