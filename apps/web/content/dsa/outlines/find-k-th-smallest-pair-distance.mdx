Given an integer array nums and an integer k, return the k-th smallest absolute
difference among all unordered pairs (i, j) with i &lt; j.

## Examples

````text
Example 1:
    Input: nums = [1,3,1], k = 1
    Output: 0
Example 2:
    Input: nums = [1,1,1], k = 2
    Output: 0
````

## Constraints

````text
- 2 <= len(nums) <= 10^4
- 0 <= nums[i] <= 10^6
- 1 <= k <= n*(n-1)//2
````

## Approach

**Pattern:** Binary search on answer + two pointers count
Sort nums; count pairs with distance &lt;= mid in linear time; binary search the
smallest distance with at least k pairs.

1. Sort nums.
2. Binary search D in \[0, max-min\]; count pairs with diff &lt;= D using two pointers.
3. Return minimal D with count &gt;= k.

## Complexity

**Time:** O(n log W) with W value range after sorting O(n log n) once

**Space:** O(1) extra besides sorting buffer

## Solution

````python
from typing import List


class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)

        def count_leq(limit: int) -> int:
            cnt = 0
            j = 0
            for i in range(n):
                while j < n and nums[j] - nums[i] <= limit:
                    j += 1
                cnt += j - i - 1
            return cnt

        lo, hi = 0, nums[-1] - nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if count_leq(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
````
