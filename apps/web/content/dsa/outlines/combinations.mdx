Given integers n and k, return all combinations of k numbers chosen from 1..n.

## Examples

````text
Example 1:
Input: n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
````

## Constraints

````text
- 1 <= k <= n <= 20
````

<PremiumBreak />

## Approach

**Pattern:** Combination backtracking
Choose the next value from an increasing start index so each combination appears once.

1. When len(path) == k, append a copy.
2. Loop i from start to n, push i, recurse with start = i + 1, pop.

## Complexity

**Time:** O(k \* C(n, k)).

**Space:** O(k) auxiliary stack/path.

````text
Problem Statement:
    Given two integers n and k, return all possible combinations of k numbers chosen from the range [1, n].

    - We store all C(n,k) combinations, each of size k
    - The recursion stack can go up to depth k

Example:
    Input: n = 4, k = 2
    Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
    Explanation: There are 6 possible combinations of 2 numbers from the range [1, 4].
````

## Solution

````python
from typing import List


class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        result: List[List[int]] = []

        def backtrack(start: int, path: List[int]) -> None:
            if len(path) == k:
                result.append(path[:])
                return
            for i in range(start, n + 1):
                path.append(i)
                backtrack(i + 1, path)
                path.pop()

        backtrack(1, [])
        return result
````
