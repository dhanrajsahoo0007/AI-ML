Given integers n and k, return all combinations of k numbers chosen from 1..n.

## Examples

````text
Example 1:
Input: n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
````

## Constraints

````text
- 1 <= k <= n <= 20
````
