Design a structure that is given an integer array nums once and can answer
many queries sum(nums\[left..right\]) inclusive in O(1) time per query.

## Examples

````text
Example 1:
Input: nums = [-2, 0, 3, -5, 2, -1]
After construction, sumRange(0, 2) -> 1, sumRange(2, 5) -> -1, sumRange(0, 5) -> -3
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -10^5 <= nums[i] <= 10^5
- 0 <= left <= right < len(nums)
- At most 10^4 calls to sumRange
````
