Each element in the array is at most k positions away from where it would appear in the fully
sorted array. Search for a target and return its index, or -1.

## Examples

````text
Example 1:
Input: nums = [2, 3, 10, 4, 40], k = 2, target = 4
Output: 3
````

## Constraints

````text
- k >= 0; typical use has small k relative to n
- Array length can be zero
````
