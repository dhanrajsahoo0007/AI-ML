Given a string s, return the length of its longest palindromic subsequence.

## Examples

````text
Example 1:
    Input: s = "bbbab"
    Output: 4
Example 2:
    Input: s = "cbbd"
    Output: 2
````

## Constraints

````text
- 1 <= len(s) <= 1000
````
