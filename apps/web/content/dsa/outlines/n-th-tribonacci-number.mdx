The Tribonacci sequence T(n) is defined as T(0)=0, T(1)=1, T(2)=1, and for n&gt;=3,
T(n)=T(n-1)+T(n-2)+T(n-3). Given n, return T(n).

## Examples

````text
Example 1:
    Input: n = 4
    Output: 4
Example 2:
    Input: n = 25
    Output: 1389537
````

## Constraints

````text
- 0 <= n <= 37
````
