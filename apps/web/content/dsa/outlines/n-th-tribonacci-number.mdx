The Tribonacci sequence T(n) is defined as T(0)=0, T(1)=1, T(2)=1, and for n&gt;=3,
T(n)=T(n-1)+T(n-2)+T(n-3). Given n, return T(n).

## Examples

````text
Example 1:
    Input: n = 4
    Output: 4
Example 2:
    Input: n = 25
    Output: 1389537
````

## Constraints

````text
- 0 <= n <= 37
````

<PremiumBreak />

## Approach

**Pattern:** 1D Dynamic Programming
Each term depends on the previous three values; iterate forward.

1. Handle n == 0, 1, 2 explicitly.
2. Maintain three rolling values and update for i in 3..n.

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
class Solution:
    def tribonacci(self, n: int) -> int:
        if n == 0:
            return 0
        if n <= 2:
            return 1
        a, b, c = 0, 1, 1
        for _ in range(3, n + 1):
            a, b, c = b, c, a + b + c
        return c
````
