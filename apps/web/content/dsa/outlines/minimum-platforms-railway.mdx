Given arrival and departure times of trains at a station (same length arrays), find the minimum
number of platforms required so that no train waits (all arrivals and departures in chronological order per train).

## Examples

````text
Example 1:
    Input: arr = [900, 940, 950, 1100, 1500, 1800], dep = [910, 1200, 1120, 1130, 1900, 2000]
    Output: 3

Example 2:
    Input: arr = [10, 200], dep = [50, 250]
    Output: 1

Example 3:
    Input: arr = [10, 12], dep = [20, 25]
    Output: 2
````

## Constraints

````text
- 1 <= n <= 10^5
- 0 <= arr[i], dep[i] <= 2359
- dep[i] > arr[i] for each train in typical formulations
````
