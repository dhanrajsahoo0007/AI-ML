Given an m x n grid: 0 empty, 1 fresh orange, 2 rotten. Each minute, any fresh orange 4-adjacent to a rotten
one becomes rotten. Return minutes until no fresh orange remains, or -1 if impossible.

## Examples

````text
Example 1:
    Input: grid = [[2,1,1],[1,1,0],[0,1,1]]
    Output: 4
Example 2:
    Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
    Output: -1
Example 3:
    Input: grid = [[0,2]]
    Output: 0
````

## Constraints

````text
- 1 <= m, n <= 10
- grid[i][j] in {0, 1, 2}
````

## Approach

**Pattern:** Multi-source BFS on a grid

1. Enqueue all rotten cells with time 0; count fresh oranges.
2. If no fresh at start, return 0.
3. BFS expanding to adjacent fresh cells, rotting them and tracking elapsed minutes; if fresh remain, -1.

## Complexity

**Time:** O(m \* n)

**Space:** O(m \* n) for the queue.

Original LeetCode-style problem statement (994) is summarized above; prior debug print removed in favor of tests.

## Solution

````python
from typing import List
from collections import deque


class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        if not grid:
            return 0

        rows, cols = len(grid), len(grid[0])
        q: deque[tuple[int, int, int]] = deque()
        fresh = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    q.append((r, c, 0))
                elif grid[r][c] == 1:
                    fresh += 1
        if fresh == 0:
            return 0
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        minutes = 0
        while q:
            r, c, t = q.popleft()
            minutes = max(minutes, t)
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    q.append((nr, nc, t + 1))
        return -1 if fresh else minutes
````
