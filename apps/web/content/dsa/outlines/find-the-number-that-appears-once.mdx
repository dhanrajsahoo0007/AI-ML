Given a non-empty array where every element appears twice except for one, find that single element.

## Examples

````text
Example 1:
    Input: nums = [2, 2, 1]
    Output: 1
Example 2:
    Input: nums = [4, 1, 2, 1, 2]
    Output: 4
````

## Constraints

````text
- 1 <= len(nums) <= 3 * 10^4
- Each element appears twice except one which appears once.
- -3 * 10^4 <= nums[i] <= 3 * 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Bit manipulation (XOR)
XORing a value with itself is zero; XORing all numbers leaves the unique one.

1. Initialize ans to 0.
2. XOR every element of nums into ans.
3. Return ans.

## Complexity

**Time:** O(n) - Single pass.

**Space:** O(1) - One integer accumulator.

## Solution

````python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for x in nums:
            ans ^= x
        return ans
````
