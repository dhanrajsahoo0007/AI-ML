Given a K-sorted (nearly sorted) array where each element is at most K positions
away from its position in the sorted array, sort the array efficiently.

## Examples

````text
Example 1:
    Input: arr = [6, 5, 3, 2, 8, 10, 9], k = 3
    Output: [2, 3, 5, 6, 8, 9, 10]

Example 2:
    Input: arr = [10, 9, 8, 7, 4, 70, 60, 50], k = 4
    Output: [4, 7, 8, 9, 10, 50, 60, 70]
````

## Constraints

````text
- 1 <= arr.length <= 10^5
- 0 <= k <= arr.length
- Each element is at most k positions from its sorted position.
````
