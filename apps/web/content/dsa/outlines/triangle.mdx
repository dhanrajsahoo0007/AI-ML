Given a triangle array, return the minimum path sum from top to bottom moving
to an adjacent index on the next row.

## Examples

````text
Example 1:
Input: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11
````

## Constraints

````text
- 1 <= len(triangle) <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Bottom-up DP on triangle
Collapse row from bottom using min of two children.

1. Start from last row; for each row above, add current cell to min of two below.

## Complexity

**Time:** O(n^2).

**Space:** O(n).

## Solution

````python
from typing import List


class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        cur = triangle[-1][:]
        for i in range(len(triangle) - 2, -1, -1):
            cur = [triangle[i][j] + min(cur[j], cur[j + 1]) for j in range(len(triangle[i]))]
        return cur[0]
````
