Given a binary string of 'a' and 'b', delete characters so no 'b' appears before an 'a'. Return the
minimum deletions.

## Examples

````text
Example 1:
Input: "aababbab"
Output: 2
````

## Constraints

````text
- 1 <= len(s) <= 10^5
````
