Given an integer array nums and an integer k, return the number of contiguous non-empty
subarrays whose sum equals k.

## Examples

````text
Example 1:
    Input: nums = [1, 1, 1], k = 2
    Output: 2
Example 2:
    Input: nums = [1, 2, 3], k = 3
    Output: 2
````

## Constraints

````text
- nums may contain negative numbers and zeros.
````
