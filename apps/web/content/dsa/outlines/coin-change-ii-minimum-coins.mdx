Given coins (distinct positive integers) and amount, find the fewest coins to
make amount with unlimited supply of each coin. Return -1 if impossible.

## Examples

````text
Example 1:
    Input: coins = [1, 2, 5], amount = 11
    Output: 3
Example 2:
    Input: coins = [2], amount = 3
    Output: -1
````

## Constraints

````text
- 1 <= len(coins) <= 12
- 1 <= coins[i] <= 2^31 - 1
- 0 <= amount <= 10^4
````
