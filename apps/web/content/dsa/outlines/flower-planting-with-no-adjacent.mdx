There are n gardens in a row and some bidirectional paths. Plant type 1..4 in each garden so
no garden has the same type as an adjacent garden. Return any valid answer length n.

## Examples

````text
Example 1:
    Input: n = 3, paths = [[1,2],[2,3],[3,1]]
    Output: [1,2,3] (any valid coloring)
Example 2:
    Input: n = 4, paths = [[1,2],[3,4]]
    Output: four valid colors
````

## Constraints

````text
- 1 <= n <= 10^4
- 0 <= len(paths) <= 2 * 10^4
````

## Approach

**Pattern:** Graph - Greedy graph coloring (bounded degree &lt;=3 in this construction)

1. Build adjacency with 0-based indices.
2. For each garden in order, pick the smallest color in &#123;1,2,3,4&#125; not used by neighbors
already colored.

## Complexity

**Time:** O(n + m).

**Space:** O(n + m).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        g = defaultdict(list)
        for x, y in paths:
            a, b = x - 1, y - 1
            g[a].append(b)
            g[b].append(a)
        res = [0] * n
        for i in range(n):
            used = {res[j] for j in g[i] if res[j]}
            for c in range(1, 5):
                if c not in used:
                    res[i] = c
                    break
        return res
````
