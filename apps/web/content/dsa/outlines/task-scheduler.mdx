Given an array of CPU tasks labeled A-Z and a cooldown interval n, find the
minimum number of CPU intervals required to complete all tasks. There must be
a gap of at least n intervals between two tasks with the same label.

## Examples

````text
Example 1:
    Input: tasks = ["A","A","A","B","B","B"], n = 2
    Output: 8
    Explanation: A -> B -> idle -> A -> B -> idle -> A -> B

Example 2:
    Input: tasks = ["A","C","A","B","D","B"], n = 1
    Output: 6

Example 3:
    Input: tasks = ["A","A","A","B","B","B"], n = 3
    Output: 10
````

## Constraints

````text
- 1 <= tasks.length <= 10^4
- tasks[i] is an uppercase English letter.
- 0 <= n <= 100
````
