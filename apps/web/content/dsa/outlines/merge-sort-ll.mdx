Sort a singly linked list in ascending order and return its head.

## Examples

````text
Example 1:
Input: head = [4,2,1,3]
Output: [1,2,3,4]
````

## Constraints

````text
- 0 <= n <= 5 * 10^4
- -10^5 <= Node.val <= 10^5
````
