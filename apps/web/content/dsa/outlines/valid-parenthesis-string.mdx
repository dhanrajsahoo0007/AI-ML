Given a string s containing '(', ')', and '\*', where '\*' can match empty string, '(' or ')',
determine whether s can be a valid parentheses string by choosing a replacement for each '\*'.

## Examples

````text
Example 1:
    Input: s = "()"
    Output: True

Example 2:
    Input: s = "(*)"
    Output: True

Example 3:
    Input: s = "(*))"
    Output: True
````

## Constraints

````text
- 1 <= len(s) <= 100
- s[i] is '(', ')', or '*'
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Balance Range
Track the minimum and maximum possible unmatched '(' count after each character; feasibility holds if the range ever stays valid.

1. Maintain low and high bounds for how many unmatched '(' could exist.
2. On '(', increase both; on ')', decrease both; on '\*', decrease low, increase high (all interpretations).
3. Clamp low at zero; if high &lt; 0, impossible; at end require low == 0.

## Complexity

**Time:** O(n) - Single pass.

**Space:** O(1) - Two integers.

## Solution

````python
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = high = 0
        for ch in s:
            if ch == "(":
                low += 1
                high += 1
            elif ch == ")":
                low -= 1
                high -= 1
            else:
                low -= 1
                high += 1
            low = max(low, 0)
            if high < 0:
                return False
        return low == 0
````
