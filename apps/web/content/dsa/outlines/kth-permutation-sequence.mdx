The set \[1, 2, ..., n\] has n! permutations ordered lexicographically. Given n and k, return the
k-th permutation sequence as a string (1-indexed k).

## Examples

````text
Example 1:
    Input: n = 3, k = 3
    Output: "213"
Example 2:
    Input: n = 4, k = 9
    Output: "2314"
````

## Constraints

````text
- 1 <= n <= 9
- 1 <= k <= n!
````

<PremiumBreak />

## Approach

**Pattern:** Factorial number system / unranking
At each step, (len-1)! fits into k determine which remaining digit to place next.

1. Keep an ordered list of available digits as strings "1".."n".
2. Convert k to zero-based.
3. While digits remain, let fact = (len-1)!, choose index = k // fact, pop that digit, set k %= fact.
4. Join popped digits.

## Complexity

**Time:** O(n^2) - Each pop is O(n); n &lt;= 9.

**Space:** O(n) - Remaining digit list and output.

## Solution

````python
import math
from typing import List


class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        nums: List[str] = [str(i) for i in range(1, n + 1)]
        k -= 1
        result: List[str] = []
        while nums:
            fact = math.factorial(len(nums) - 1)
            idx, k = divmod(k, fact)
            result.append(nums.pop(idx))
        return "".join(result)
````
