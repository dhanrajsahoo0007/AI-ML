Given a text string and a pattern string, count how many contiguous substrings of
text have the same length as pattern and are anagrams of pattern (same multiset of letters).

## Examples

````text
Example 1:
    Input: text = "forxxorfxdofr", pattern = "for"
    Output: 3
Example 2:
    Input: text = "aabaabaa", pattern = "aaba"
    Output: 4
````

## Constraints

````text
- pattern is non-empty and no longer than text when counting is meaningful.
````
