For nums, consider all unordered pairs i &lt; j. Return the k-th smallest absolute difference.

## Examples

````text
Example 1:
Input: nums = [1, 3, 1], k = 1
Output: 0
````

## Constraints

````text
- 2 <= len(nums) <= 10^4
- 1 <= k <= n * (n - 1) // 2
````

## Approach

**Pattern:** Binary Search on Distance + Two Pointers Count
Sort nums; count pairs with difference &lt;= D in O(n) with sliding left pointer.

1. Sort nums.
2. Binary search D in \[0, max-min\]; count pairs with diff &lt;= D.
3. Smallest D with count &gt;= k.

## Complexity

**Time:** O(n log W) - W = value spread.

**Space:** O(1) - Aside from sorting buffer.

The distance of a pair of integers a and b is defined as the absolute difference between a and b.

Given an integer array nums and an integer k, return the kth smallest distance among all the pairs nums\[i\] and nums\[j\] where 0 &lt;= i &lt; j &lt; nums.length.

Example 1:

Input: nums = \[1,3,1\], k = 1
Output: 0
Explanation: Here are all the pairs:
(1,3) -&gt; 2
(1,1) -&gt; 0
(3,1) -&gt; 2
Then the 1st smallest distance pair is (1,1), and its distance is 0.
Example 2:

Input: nums = \[1,1,1\], k = 2
Output: 0
Example 3:

Input: nums = \[1,6,1\], k = 3
Output: 5

Constraints:

n == nums.length
2 &lt;= n &lt;= 104
0 &lt;= nums\[i\] &lt;= 106
1 &lt;= k &lt;= n \* (n - 1) / 2

## Solution

````python
from typing import List


class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        nums.sort()

        def count_leq(d: int) -> int:
            c = left = 0
            for right in range(len(nums)):
                while nums[right] - nums[left] > d:
                    left += 1
                c += right - left
            return c

        lo, hi = 0, nums[-1] - nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if count_leq(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
````
