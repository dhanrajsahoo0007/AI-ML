For nums, consider all unordered pairs i &lt; j. Return the k-th smallest absolute difference.

## Examples

````text
Example 1:
Input: nums = [1, 3, 1], k = 1
Output: 0
````

## Constraints

````text
- 2 <= len(nums) <= 10^4
- 1 <= k <= n * (n - 1) // 2
````
