Repeatedly delete every occurrence of part from s until none remain, returning the final string.

## Examples

````text
Example 1:
Input: s = "daabcbaabcbc", part = "abc"
Output: "dab"
````

## Constraints

````text
- 1 <= len(s), len(part) <= 1000
- Strings use lowercase English letters
````

<PremiumBreak />

## Approach

**Pattern:** Streaming Stack Match
Append characters and slice the tail whenever it matches part.

1. Maintain a list as a stack of characters.
2. After each push, compare the tail window to part; pop m letters on a match.
3. Join the survivors.

## Complexity

**Time:** O(n \* m) - Tail checks cost O(m) per character in worst case.

**Space:** O(n) - Stack holds the current rebuilt string.

## Solution

````python
class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        m = len(part)
        stack: list[str] = []
        for ch in s:
            stack.append(ch)
            if len(stack) >= m and "".join(stack[-m:]) == part:
                del stack[-m:]
        return "".join(stack)
````
