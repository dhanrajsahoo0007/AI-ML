Given the root of a binary search tree (BST) and an integer key, return the node whose
value equals key, or None if no such node exists.

## Examples

````text
Example 1:
    Input: BST root with values [4,2,7,1,3], key = 3
    Output: node with val 3

Example 2:
    Input: same tree, key = 9
    Output: None
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
- Node values and key fit in 32-bit signed integers.
````

## Approach

**Pattern:** BST search
Compare key with the current node and move left or right using the BST ordering property.

1. Start at the root.
2. If the current node is None or its value equals the key, return the current node.
3. If key is smaller, continue in the left subtree; otherwise continue in the right subtree.
4. Optionally implement the same logic iteratively with O(1) extra space.

## Complexity

**Time:** O(h) - At most one path from root to a leaf; h is tree height (O(log n) balanced, O(n) skewed).

**Space:** O(h) - Recursion stack depth for the recursive version; O(1) for the iterative version.
Restored (original notes, diagrams, and walkthrough):
Problem Statement:
Implement a function to search for a value in a Binary Search Tree (BST).
A BST is a binary tree where for each node, all values in its left subtree
are less than the node's value, and all values in its right subtree are greater.

Time Complexity: O(h), where h is the height of the tree.
- In the worst case (skewed tree), h = n, where n is the number of nodes.
- In the best case (balanced tree), h = log(n).

Space Complexity: O(h) for the recursive approach due to the call stack.
- O(1) for the iterative approach.

## Solution

````python
from typing import List, Optional

class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_bst_insert(values: List[int]) -> Optional[TreeNode]:
    root: Optional[TreeNode] = None
    for v in values:
        if root is None:
            root = TreeNode(v)
            continue
        cur = root
        while True:
            if v < cur.val:
                if cur.left is None:
                    cur.left = TreeNode(v)
                    break
                cur = cur.left
            elif v > cur.val:
                if cur.right is None:
                    cur.right = TreeNode(v)
                    break
                cur = cur.right
            else:
                break
    return root


class Solution:
    def searchBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if root is None or root.val == val:
            return root
        if val < root.val:
            return self.searchBST(root.left, val)
        return self.searchBST(root.right, val)

    def searchBSTIterative(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        cur = root
        while cur:
            if cur.val == val:
                return cur
            cur = cur.left if val < cur.val else cur.right
        return None
````
