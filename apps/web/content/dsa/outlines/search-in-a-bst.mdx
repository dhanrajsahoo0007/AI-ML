Given the root of a binary search tree (BST) and an integer key, return the node whose
value equals key, or None if no such node exists.

## Examples

````text
Example 1:
    Input: BST root with values [4,2,7,1,3], key = 3
    Output: node with val 3

Example 2:
    Input: same tree, key = 9
    Output: None
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
- Node values and key fit in 32-bit signed integers.
````
