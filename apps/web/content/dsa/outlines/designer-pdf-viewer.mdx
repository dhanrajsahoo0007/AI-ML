Given a list h of 26 integers (heights 0-7 mm for letters 'a' through 'z') and a word
of lowercase letters, compute the area of the rectangle that highlights the word when
each letter is 1 mm wide and the highlight height is the maximum letter height in the word.

## Examples

````text
Example 1:
Input: h = [1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 3, 1, 1, 1, 1, 1, 1, 1], word = "abc"
Output: 9
Explanation: max height among a,b,c is 3; width is 3; area = 9.
````

## Constraints

````text
- len(h) == 26, values in a valid range for the problem (typically 1-7).
- word uses lowercase English letters.
````
