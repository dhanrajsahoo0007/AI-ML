Given an array nums containing n distinct numbers taken from the range \[0, n\], return the only
number in that range missing from the array.

## Examples

````text
Example 1:
    Input: nums = [3, 0, 1]
    Output: 2
Example 2:
    Input: nums = [0, 1]
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- 0 <= nums[i] <= len(nums)
- All values in nums are unique.
````

<PremiumBreak />

## Approach

**Pattern:** XOR / Gauss sum
XOR indices 0..n with values cancels present numbers and leaves the missing one.

1. Initialize result to n (covers the missing index/value pairing for length n).
2. For each index i, XOR result with i and with nums\[i\].
3. Return result.

## Complexity

**Time:** O(n) - One pass.

**Space:** O(1) - Only the accumulator.

## Solution

````python
from typing import List


class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        result = len(nums)
        for i, v in enumerate(nums):
            result ^= i ^ v
        return result
````

### Approach

**Pattern:** XOR / arithmetic sum
XOR all indices and numbers; the missing index remains.

1. x starts at n (the length), then XOR each index and value.

### Complexity

**Time:** O(n)

**Space:** O(1)

### Solution

````python
from typing import List


class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        x = len(nums)
        for i, v in enumerate(nums):
            x ^= i ^ v
        return x
````
