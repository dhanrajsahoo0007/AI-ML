Given nums and an integer k, return True if nums has a continuous subarray of
length at least two whose sum is a multiple of k.

## Examples

````text
Example 1:
Input: nums = [23, 2, 4, 6, 7], k = 6
Output: True
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- 0 <= nums[i] <= 10^9
- 0 <= k <= 10^9
````

**Also in the notes under:** [01. Array/05. Subarray Problem](/dsa/problems/continuous-subarray-sum).

## Approach

**Pattern:** Prefix Sum + Modulo Map
Equal remainders at indices at least two apart imply a divisible middle segment.

1. Track running sum mod k (treat k==0 as special: need consecutive zero sum pair).
2. Store first index per remainder; if same remainder seen with index gap &gt;= 2, True.
3. For k==0, look for consecutive zeros or any valid length-2+ multiple pattern.

## Complexity

**Time:** O(n).

**Space:** O(min(n, k)) for remainder map (bounded by k when k&gt;0).

## Solution

````python
from typing import List


class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        first_mod: dict[int, int] = {0: -1}
        total = 0
        for i, x in enumerate(nums):
            total += x
            if k != 0:
                r = total % k
            else:
                r = total
            if r in first_mod:
                if i - first_mod[r] >= 2:
                    return True
            else:
                first_mod[r] = i
        return False
````
