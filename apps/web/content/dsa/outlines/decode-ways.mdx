Given a string s of digits, count how many ways it can be decoded to letters
'A'..'Z' mapped from '1'..'26'. Leading zeros and invalid groups are not allowed.

## Examples

````text
Example 1:
    Input: s = "12"
    Output: 2
Example 2:
    Input: s = "226"
    Output: 3
````

## Constraints

````text
- 1 <= len(s) <= 100
- s contains only digits
````
