Given two axis-aligned rectangles on a plane, return the total area covered
by both rectangles (union area).

## Examples

````text
Example 1:
    Input: ax1=-3, ay1=0, ax2=3, ay2=4, bx1=0, by1=-1, bx2=9, by2=2
    Output: 45
Example 2:
    Input: ax1=-2, ay1=-2, ax2=2, ay2=2, bx1=-2, by1=-2, bx2=2, by2=2
    Output: 16
````

## Constraints

````text
- -10^4 <= coordinates <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Inclusion–exclusion
Union area equals sum of individual areas minus overlap area.

1. Compute width and height of each rectangle from corners.
2. Overlap width is max(0, min(ax2,bx2) - max(ax1,bx1)); same for height.
3. Return areaA + areaB - overlap.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def computeArea(
        self,
        ax1: int,
        ay1: int,
        ax2: int,
        ay2: int,
        bx1: int,
        by1: int,
        bx2: int,
        by2: int,
    ) -> int:
        a = (ax2 - ax1) * (ay2 - ay1)
        b = (bx2 - bx1) * (by2 - by1)
        ox = max(0, min(ax2, bx2) - max(ax1, bx1))
        oy = max(0, min(ay2, by2) - max(ay1, by1))
        return a + b - ox * oy
````
