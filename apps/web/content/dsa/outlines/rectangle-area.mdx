Given two axis-aligned rectangles on a plane, return the total area covered
by both rectangles (union area).

## Examples

````text
Example 1:
    Input: ax1=-3, ay1=0, ax2=3, ay2=4, bx1=0, by1=-1, bx2=9, by2=2
    Output: 45
Example 2:
    Input: ax1=-2, ay1=-2, ax2=2, ay2=2, bx1=-2, by1=-2, bx2=2, by2=2
    Output: 16
````

## Constraints

````text
- -10^4 <= coordinates <= 10^4
````
