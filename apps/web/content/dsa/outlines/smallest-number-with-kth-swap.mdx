Given a digit string num\_str and an integer k, perform at most k adjacent-position swaps
(any pair of indices, counted as one swap each operation in this formulation: swap two
positions) to obtain the smallest possible numeric string.

## Examples

````text
Example 1:
    Input: num_str = "4321", k = 1
    Output: "1324" (swap the leading digit with the rightmost smallest digit)

Example 2:
    Input: num_str = "7654321", k = 1
    Output: "1654327"
````

## Constraints

````text
- 1 <= len(num_str) <= 10 for exhaustive search
- Digits are '0'..'9'
````

<PremiumBreak />

## Approach

**Pattern:** Backtracking with greedy minimum digit
At each index, if a smaller digit exists to the right, swap with the rightmost minimum to
preserve options, decrease k, recurse; also try skipping a swap.

1. Track the minimum string found.
2. From \`index\`, find the minimum digit in digits\[index:\]; if it equals digits\[index\], only recurse forward with same k.
3. Otherwise swap with each index holding that minimum (try all), recurse with k-1, backtrack.

## Complexity

**Time:** Exponential in worst case; bounded for small inputs.

**Space:** O(n) - recursion depth.

## Solution

````python
from typing import List


class Solution:
    def findSmallestNum(self, num_str: str, k: int) -> str:
        digits: List[str] = list(num_str)
        best = [num_str]

        def swap(i: int, j: int) -> None:
            digits[i], digits[j] = digits[j], digits[i]

        def dfs(index: int, swaps: int) -> None:
            cur = "".join(digits)
            if cur < best[0]:
                best[0] = cur
            if swaps == 0 or index == len(digits):
                return
            min_digit = min(digits[index:])
            if digits[index] != min_digit:
                for j in range(len(digits) - 1, index, -1):
                    if digits[j] == min_digit:
                        swap(index, j)
                        dfs(index + 1, swaps - 1)
                        swap(index, j)
            dfs(index + 1, swaps)

        dfs(0, k)
        return best[0]
````
