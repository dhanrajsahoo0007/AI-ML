Implement a doubly linked list with insert at beginning/end, delete by value, length,
forward and backward traversal (values collected for tests), and reverse.

## Examples

````text
Example 1:
Input: insert end 1,2; insert beginning 0; insert end 3; delete 2
Output: forward values [0,1,3], length 3
````

## Constraints

````text
- Keys are integers; delete removes first match only.
````
