Given a string s, rearrange characters so no two adjacent characters are the same.
Return any valid rearrangement or "" if not possible.

## Examples

````text
Example 1:
    Input: s = "aab"
    Output: "aba"

Example 2:
    Input: s = "aaab"
    Output: ""
````

## Constraints

````text
- 1 <= s.length <= 500
- s consists of lowercase English letters.
````
