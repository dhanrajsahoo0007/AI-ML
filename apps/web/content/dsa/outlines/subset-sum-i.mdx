Given an integer array nums of unique elements, return all subsets (the power set).

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3]
    Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]] (order may vary)

Example 2:
    Input: nums = [0]
    Output: [[],[0]]
````

## Constraints

````text
- All elements in nums are unique.
- 1 <= len(nums) <= 10
````

<PremiumBreak />

## Approach

**Pattern:** Subset backtracking
Record every prefix along the DFS; extend by choosing the next element from a sliding start index.

1. Append path snapshot at each recursive entry.
2. For i in \[start, n), push nums\[i\], recurse with i + 1, pop.

## Complexity

**Time:** O(n \* 2^n) - number of subsets times copy cost.

**Space:** O(n) - depth and current path excluding output.

## Solution

````python
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result: List[List[int]] = []

        def backtrack(start: int, path: List[int]) -> None:
            result.append(path[:])
            for i in range(start, len(nums)):
                path.append(nums[i])
                backtrack(i + 1, path)
                path.pop()

        backtrack(0, [])
        return result
````
