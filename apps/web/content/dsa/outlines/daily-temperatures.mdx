For each day in a temperature list, return how many days you must wait until a warmer temperature;
use 0 if none exists.

## Examples

````text
Example 1:
Input: [73, 74, 75, 71, 69, 72, 76, 73]
Output: [1, 1, 4, 2, 1, 1, 0, 0]
````

## Constraints

````text
- 1 <= len(temperatures) <= 10^5
- 30 <= temperatures[i] <= 100
````
