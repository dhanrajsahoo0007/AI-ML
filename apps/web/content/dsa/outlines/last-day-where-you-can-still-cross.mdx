Start from all land. On day i (1-based), cells\[i-1\] floods. Return the last day you can still walk
from any top cell to any bottom cell using 4-direction moves on land.

## Examples

````text
Example 1:
Input: row = 2, col = 2, cells = [[1,1],[2,1],[1,2],[2,2]]
Output: 2
````

## Constraints

````text
- 2 <= row, col; 4 <= row * col <= 2 * 10^4
- len(cells) == row * col, all distinct 1-based coordinates
````

## Approach

**Pattern:** Binary Search on Day + BFS Reachability
After d floods, blocked set is the first d cells; check top-bottom connectivity.

1. Binary search largest d in \[0, len(cells)\] with path possible when blocking cells\[:d\].
2. BFS from every dry top cell.

## Complexity

**Time:** O(R C log(R C)) - Each BFS O(RC), log steps.

**Space:** O(R C) - Visited set and queue.

There is a 1-based binary matrix where 0 represents land and 1 represents water. You are given integers row and col representing the number of rows and columns in the matrix, respectively.

Return the last day where it is possible to walk from the top to the bottom by only walking on land cells.

## Solution

````python
from collections import deque
from typing import List, Set, Tuple


class Solution:
    def latestDayToCross(self, row: int, col: int, cells: List[List[int]]) -> int:
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def can_cross(mid: int) -> bool:
            blocked: Set[Tuple[int, int]] = {(cells[i][0] - 1, cells[i][1] - 1) for i in range(mid)}
            q = deque()
            seen: Set[Tuple[int, int]] = set()
            for c in range(col):
                if (0, c) not in blocked:
                    q.append((0, c))
                    seen.add((0, c))
            while q:
                r, c = q.popleft()
                if r == row - 1:
                    return True
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < row and 0 <= nc < col and (nr, nc) not in blocked and (nr, nc) not in seen:
                        seen.add((nr, nc))
                        q.append((nr, nc))
            return False

        lo, hi = 0, len(cells)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if can_cross(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
````
