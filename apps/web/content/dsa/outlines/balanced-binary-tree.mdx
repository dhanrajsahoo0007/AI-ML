Given a binary tree, determine if it is height-balanced: for every node, the left and right subtree heights
differ by at most one.

## Examples

````text
Example 1:
    Input: root = [3,9,20,None,None,15,7]
    Output: True
Example 2:
    Input: root = [1,2,2,3,3,None,None,4,4]
    Output: False
````

## Constraints

````text
- The number of nodes is in the range [0, 5000].
- Node values fit in 32-bit signed integers.
````
