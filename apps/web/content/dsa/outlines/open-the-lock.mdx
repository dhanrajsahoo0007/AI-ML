Wheels show four digits 0000-9999; each move changes one wheel by +/-1 with wrap.
Given deadends and a target, return minimum moves from 0000 avoiding deadends, or -1.

## Examples

````text
Example 1:
    Input: deadends = ["0201","0101","0102","1212","2002"], target = "0202"
    Output: 6
Example 2:
    Input: deadends = ["8888"], target = "0009"
    Output: 1
````

## Constraints

````text
- 1 <= len(deadends) <= 500
- deadends[i] length 4
- target length 4
````
