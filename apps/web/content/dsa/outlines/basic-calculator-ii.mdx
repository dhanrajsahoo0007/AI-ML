Evaluate a valid expression of non-negative integers with + - \* / operators and spaces, without parentheses.

## Examples

````text
Example 1:
Input: "3+2*2"
Output: 7
````

## Constraints

````text
- 1 <= len(s) <= 3 * 10^5
- Division truncates toward zero; expression is always valid
````
