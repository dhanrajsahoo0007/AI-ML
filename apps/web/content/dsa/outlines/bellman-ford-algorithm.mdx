Given V vertices (0..V-1), a list of directed weighted edges \[u, v, w\], and a source S, compute shortest
distances from S to every vertex. Negative edges are allowed; if a reachable negative cycle exists,
return \[-1\]. Unreachable vertices are reported as -1 in the distance list.

## Examples

````text
Example 1:
    Input: V = 5, edges = [[0,1,5],[1,2,3],[2,3,1],[0,3,10],[1,3,2],[2,4,2],[3,4,6]], S = 0
    Output: [0,5,8,7,10]
Example 2:
    Input: V = 3, edges = [[0,1,5],[1,2,-3],[2,0,-4]], S = 0
    Output: [-1] (negative cycle)
````

## Constraints

````text
- 1 <= V <= 500
- 1 <= len(edges) <= 10^4
````
