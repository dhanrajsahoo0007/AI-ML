Given a rotated sorted array that may contain duplicates, return whether target exists.

## Examples

````text
Example 1:
    Input: nums = [3, 3, 1, 2, 3, 3], target = 1
    Output: True

Example 2:
    Input: nums = [1, 2, 3, 4, 5], target = 6
    Output: False
````

## Constraints

````text
- 1 <= len(nums) <= 5000
- Worst-case time can degrade when many duplicates obscure which side is sorted
````
