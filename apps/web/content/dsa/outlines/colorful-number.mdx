A positive integer is colorful if the products of every consecutive sequence
of digits are all distinct. Given an integer A, return 1 if it is colorful, else 0.

## Examples

````text
Example 1:
    Input: A = 23
    Output: 1
Example 2:
    Input: A = 236
    Output: 0
````

## Constraints

````text
- 1 <= A <= 10^6 (typical interview constraints)
- Treat digits without leading zeros in the decimal string
````
