Given an array nums and two arrays l and r of equal length, for each query i consider the
subarray nums\[l\[i\] : r\[i\] + 1\]. Return a list of booleans indicating whether each subarray forms
an arithmetic sequence when sorted.

## Examples

````text
Example 1:
Input: nums = [4, 6, 5, 9, 3, 7], l = [0, 3, 4], r = [2, 5, 5]
Output: [True, False, True]  # middle slice [9, 3, 7] is not arithmetic when sorted
````

## Constraints

````text
- n == len(nums)
- m == len(l) == len(r)
- 2 <= n <= 500
- 1 <= m <= 500
- 0 <= l[i] < r[i] < n
````
