Given a sorted array of integers and a target, return the indices of the first and last position
of target. If target is not in the array, return \[-1, -1\].

## Examples

````text
Example 1:
    Input: nums = [1, 3, 3, 3, 5, 5, 5, 7, 8, 9], target = 5
    Output: [4, 6]

Example 2:
    Input: nums = [1, 2, 3, 4, 5, 6], target = 7
    Output: [-1, -1]
````

## Constraints

````text
- 0 <= len(nums) <= 10^5
- nums is sorted in non-decreasing order
````
