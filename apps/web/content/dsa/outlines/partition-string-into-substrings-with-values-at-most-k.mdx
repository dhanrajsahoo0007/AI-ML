Given a binary string s (bits interpreted as a binary integer per substring) and an integer k,
partition s into a minimum number of contiguous substrings such that each substring's numeric value
is at most k. Split greedily whenever appending the next bit would exceed k.

## Examples

````text
Example 1:
    Input: s = "101110001", k = 5
    Output: 3

Example 2:
    Input: s = "101110001", k = 10
    Output: 3

Example 3:
    Input: s = "101110001", k = 1000000000
    Output: 1
````

## Constraints

````text
- 1 <= len(s) <= 1000
- s[i] is '0' or '1'
- 1 <= k <= 10^9
````
