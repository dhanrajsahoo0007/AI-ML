Basket positions are distinct integers. Place m balls into baskets to maximize the minimum absolute
distance between any two balls.

## Examples

````text
Example 1:
Input: position = [1, 2, 3, 4, 7], m = 3
Output: 3
````

## Constraints

````text
- 2 <= m <= len(position) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Answer (maximize minimum gap)
Same greedy feasibility as aggressive cows after sorting positions.

1. Sort positions.
2. Binary search minimum force F; greedily place balls starting from the smallest index.

## Complexity

**Time:** O(n log W) - W = spread of positions.

**Space:** O(1) - Greedy placement only.

## Solution

````python
from typing import List


class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()

        def can(force: int) -> bool:
            prev = position[0]
            cnt = 1
            for x in position[1:]:
                if x - prev >= force:
                    cnt += 1
                    prev = x
                if cnt == m:
                    return True
            return False

        lo, hi = 1, position[-1] - position[0]
        best = 0
        while lo <= hi:
            mid = lo + (hi - lo) // 2
            if can(mid):
                best = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return best
````
