Given an integer array nums and an integer k, return the median array for each
sliding window of size k moving from left to right.

## Examples

````text
Example 1:
    Input: nums = [1,3,-1,-3,5,3,6,7], k = 3
    Output: [1.0,-1.0,-1.0,3.0,5.0,6.0]

Example 2:
    Input: nums = [1,2,3,4,2,3,1,4,2], k = 3
    Output: [2.0,3.0,3.0,3.0,2.0,3.0,2.0]
````

## Constraints

````text
- 1 <= k <= nums.length <= 10^5
- -2^31 <= nums[i] <= 2^31 - 1
````
