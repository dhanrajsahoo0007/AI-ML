Given a directed graph with V vertices and a list of directed edges, determine whether the graph
contains a cycle (including self-loops as cycles).

## Examples

````text
Example 1:
    Input: V = 4, edges = [[0,1],[1,2],[2,3],[3,1]]
    Output: True
Example 2:
    Input: V = 4, edges = [[0,1],[1,2],[2,3]]
    Output: False
````

## Constraints

````text
- 1 <= V, edges <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** DFS with recursion stack (three-color / path set)
A back edge to a vertex still on the current DFS path indicates a directed cycle.

1. Build directed adjacency lists.
2. Track visited and in\_recursion; on DFS, if neighbor is in\_recursion, cycle found.
3. Clear in\_recursion when unwinding from u.

## Complexity

**Time:** O(V + E)

**Space:** O(V) for arrays and recursion depth.

## Solution

````python
from typing import List


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
        return adj

    def has_cycle(self, V: int, adj: List[List[int]]) -> bool:
        visited = [False] * V
        in_recursion = [False] * V

        def dfs(u: int) -> bool:
            visited[u] = True
            in_recursion[u] = True
            for v in adj[u]:
                if not visited[v]:
                    if dfs(v):
                        return True
                elif in_recursion[v]:
                    return True
            in_recursion[u] = False
            return False

        for i in range(V):
            if not visited[i] and dfs(i):
                return True
        return False
````
