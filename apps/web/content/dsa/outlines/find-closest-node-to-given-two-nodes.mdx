You are given a directed graph of n nodes labeled 0..n-1 where each node has at most one outgoing edge.
edges\[i\] is the destination of the edge from i, or -1 if none. Given node1 and node2, return the
smallest index of a node reachable from both starts such that the maximum of the two distances
(from node1 and from node2) is minimized. If multiple nodes tie, return the smallest index.

## Examples

````text
Example 1:
    Input: edges = [2,2,3,-1], node1 = 0, node2 = 1
    Output: 2
Example 2:
    Input: edges = [1,2,-1], node1 = 0, node2 = 2
    Output: 2
````

## Constraints

````text
- 2 <= n <= 10^5
- edges.length == n
- -1 <= edges[i] < n
- edges[i] != i
- 0 <= node1, node2 < n
````
