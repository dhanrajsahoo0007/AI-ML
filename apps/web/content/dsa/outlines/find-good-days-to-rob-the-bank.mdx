security\[i\] is guards on day i. For integer time, day i is good if there are at
least time days before and after i, and the guard counts satisfy the required
monotonicity on both sides (as defined in the original problem). Return all good
days in increasing order.

## Examples

````text
Example 1:
Input: security = [5, 3, 3, 3, 5, 6, 2], time = 2
Output: [2, 3]
````

## Constraints

````text
- 1 <= len(security), time <= 10^5
- 0 <= security[i] <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Prefix Arrays on Monotonic Runs
Precompute how far monotonicity holds from each direction, then filter valid indices.

1. Build before\[i\] counting a consecutive &lt;= relation with the previous day.
2. Build after\[i\] similarly toward the end.
3. Collect i in \[time, n - time) where before\[i\] &gt;= time and after\[i\] &gt;= time.

## Complexity

**Time:** O(n).

**Space:** O(n) for the auxiliary arrays.

## Solution

````python
from typing import List


class Solution:
    def goodDaysToRobBank(self, security: List[int], time: int) -> List[int]:
        n = len(security)
        if time == 0:
            return list(range(n))
        before = [0] * n
        for i in range(1, n):
            if security[i] <= security[i - 1]:
                before[i] = before[i - 1] + 1
        after = [0] * n
        for i in range(n - 2, -1, -1):
            if security[i] <= security[i + 1]:
                after[i] = after[i + 1] + 1
        out: List[int] = []
        for i in range(time, n - time):
            if before[i] >= time and after[i] >= time:
                out.append(i)
        return out
````
