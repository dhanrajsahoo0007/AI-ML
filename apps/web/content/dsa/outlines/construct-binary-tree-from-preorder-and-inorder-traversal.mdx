Given two integer arrays preorder and inorder where preorder is the preorder traversal of a
binary tree and inorder is the inorder traversal of the same tree, construct and return the root
of that tree (values are unique).

## Examples

````text
Example 1:
    Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
    Output: tree whose preorder matches input

Example 2:
    Input: preorder = [-1], inorder = [-1]
    Output: single node -1
````

## Constraints

````text
- 1 <= preorder.length == inorder.length <= 3000
- Values are unique.
````

## Approach

**Pattern:** Divide and conquer with hash map
The first preorder value is the subtree root; split inorder at that value to size left and right parts.

1. Map each inorder value to its index for O(1) lookup.
2. Read the next preorder value as root, find its inorder index mid.
3. Recursively build left on inorder\[lo:mid-1\] and right on inorder\[mid+1:hi\].
4. Advance a preorder pointer across recursive calls.

## Complexity

**Time:** O(n) - Each node is built once; index lookups are O(1) with the hash map.

**Space:** O(n) - Map storage plus O(n) recursion stack in the worst skewed case.

Problem: Construct Binary Tree from Inorder and Postorder Traversal

Given two integer arrays inorder and postorder where inorder is the inorder traversal of a binary tree

Time Complexity: O(n^2) in the worst case, where n is the number of nodes.
Space Complexity: O(n) due to the recursion stack.

## Solution

````python
from typing import Dict, List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def inorder_list(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    return inorder_list(root.left) + [root.val] + inorder_list(root.right)


class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        idx: Dict[int, int] = {v: i for i, v in enumerate(inorder)}
        self.pre_idx = 0

        def build(lo: int, hi: int) -> Optional[TreeNode]:
            if lo > hi:
                return None
            val = preorder[self.pre_idx]
            self.pre_idx += 1
            mid = idx[val]
            node = TreeNode(val)
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node

        return build(0, len(inorder) - 1)
````
