Given two integer arrays preorder and inorder where preorder is the preorder traversal of a
binary tree and inorder is the inorder traversal of the same tree, construct and return the root
of that tree (values are unique).

## Examples

````text
Example 1:
    Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
    Output: tree whose preorder matches input

Example 2:
    Input: preorder = [-1], inorder = [-1]
    Output: single node -1
````

## Constraints

````text
- 1 <= preorder.length == inorder.length <= 3000
- Values are unique.
````
