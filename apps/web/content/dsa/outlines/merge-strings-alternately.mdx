Given two strings word1 and word2, merge them by adding letters in alternating order,
starting with word1. If one string is longer, append its remaining characters to the end.

## Examples

````text
Example 1:
    Input: word1 = "abc", word2 = "pqr"
    Output: "apbqcr"
Example 2:
    Input: word1 = "ab", word2 = "pqrs"
    Output: "apbqrs"
````

## Constraints

````text
- 1 <= len(word1), len(word2) <= 100
- word1 and word2 consist of lowercase English letters.
````

## Approach

**Pattern:** Two pointers
Advance separate indices through each string and interleave characters until one string is exhausted.

1. Use indices i and j starting at 0 for word1 and word2.
2. While both indices are in range, append word1\[i\] then word2\[j\] and increment both.
3. Append any remaining suffix of word1 or word2 to the result.
4. Join collected characters into a single string.

Problem: Merge Strings Alternately

You are given two strings word1 and word2. Merge the strings by adding letters in alternating order, starting with word1.
If a string is longer than the other, append the additional letters onto the end of the merged string.

Return the merged string.

Example 1:
Input: word1 = "abc", word2 = "pqr"
Output: "apbqcr"
Explanation: The merged string will be merged as so:
word1:  a   b   c
word2:    p   q   r
merged: a p b q c r

## Complexity

**Time:** O(m + n) - Each character from both strings is visited at most once.

**Space:** O(m + n) - The output holds every character from both inputs.

## Solution

````python
from typing import List


class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        i = j = 0
        res: List[str] = []
        while i < len(word1) and j < len(word2):
            res.append(word1[i])
            res.append(word2[j])
            i += 1
            j += 1
        res.extend(word1[i:])
        res.extend(word2[j:])
        return "".join(res)
````
