Given the head of a linked list and integer k (1-indexed), swap the values of the kth node
from the start and the kth node from the end.

## Examples

````text
Example 1:
Input: head = [1,2,3,4,5], k = 2
Output: [1,4,3,2,5]
````

## Constraints

````text
- 1 <= k <= n <= 10^5
- 0 <= Node.val <= 100
````
