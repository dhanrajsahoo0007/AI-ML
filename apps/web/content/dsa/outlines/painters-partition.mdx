Boards have lengths; k painters each paint contiguous sections in order. Each painter works in parallel
at rate one unit length per unit time. Minimize the time when the slowest painter finishes (the
maximum workload among painters).

## Examples

````text
Example 1:
Input: boards = [10, 10, 10, 10], k = 2
Output: 20
````

## Constraints

````text
- 1 <= k <= len(boards) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Answer (minimize maximum partition sum)
Identical feasibility structure to book allocation and shipping capacity.

1. Search max segment sum in \[max(boards), sum(boards)\].
2. Greedy count painters needed for a trial cap; compare to k.

## Complexity

**Time:** O(n log S) - S = total board length.

**Space:** O(1) - Greedy counting only.

## Solution

````python
from typing import List


class Solution:
    def minTime(self, boards: List[int], k: int) -> int:
        def painters_needed(cap: int) -> int:
            p = 1
            cur = 0
            for b in boards:
                if b > cap:
                    return k + 1
                if cur + b > cap:
                    p += 1
                    cur = b
                else:
                    cur += b
                if p > k:
                    return p
            return p

        lo, hi = max(boards), sum(boards)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if painters_needed(mid) <= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
````
