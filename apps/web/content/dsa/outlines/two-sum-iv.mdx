Given the root of a binary search tree and an integer k, return True if there exist two
different nodes whose values sum to k.

## Examples

````text
Example 1:
    Input: BST [5,3,6,2,4,null,7], k = 9
    Output: True (3 + 6)

Example 2:
    Input: same tree, k = 28
    Output: False
````

## Constraints

````text
- The number of nodes is in the range [1, 10^4].
- Node values and k fit in 32-bit signed integers.
````

## Approach

**Pattern:** Two pointers on sorted order
Use a forward iterator (smallest to largest) and a reverse iterator (largest to smallest).

1. Initialize two stacks: one for inorder, one for reverse inorder.
2. Pop smallest as left and largest as right; compare their sum to k.
3. If sum is too small, advance the small iterator; if too large, advance the large iterator.
4. Stop when pointers cross.

## Complexity

**Time:** O(n) - Each node is pushed and popped a constant number of times overall.

**Space:** O(h) - Two stacks of height at most h.
Restored (original notes, diagrams, and walkthrough):
Problem Statement:
Given the root of a Binary Search Tree and a target number k, return true if there exist
two elements in the BST such that their sum is equal to the given target.

Time Complexity: O(n), where n is the number of nodes in the BST
Space Complexity: O(h), where h is the height of the tree (for the stack in the iterator)

Approach:
We use a bidirectional BST iterator to traverse the tree from both ends simultaneously.
This allows us to perform a two-pointer technique similar to the one used in a sorted array.

Example:
Input: root = \[5,3,6,2,4,null,7\], k = 9
Output: true
Explanation:
5
/        3   6
/ \\        2   4   7
There exist two elements 3 and 6 such that 3 + 6 = 9

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_level_order(values: List[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    queue: List[TreeNode] = [root]
    i = 1
    while queue and i < len(values):
        node = queue.pop(0)
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            queue.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            queue.append(node.right)
        i += 1
    return root


class BSTIterator:
    def __init__(self, root: Optional[TreeNode], reverse: bool):
        self.stack: List[TreeNode] = []
        self.reverse = reverse
        self._push_all(root)

    def _push_all(self, node: Optional[TreeNode]) -> None:
        while node:
            self.stack.append(node)
            node = node.right if self.reverse else node.left

    def next(self) -> int:
        node = self.stack.pop()
        self._push_all(node.left if self.reverse else node.right)
        return node.val

    def has_next(self) -> bool:
        return len(self.stack) > 0


class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        if root is None:
            return False
        forward = BSTIterator(root, False)
        reverse = BSTIterator(root, True)
        left = forward.next()
        right = reverse.next()
        while left < right:
            s = left + right
            if s == k:
                return True
            if s < k:
                left = forward.next()
            else:
                right = reverse.next()
        return False
````
