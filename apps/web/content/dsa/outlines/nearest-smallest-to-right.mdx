Given an integer array, for each index return the nearest element to the right that is strictly
smaller than the current value. If none exists, use -1.

## Examples

````text
Example 1:
Input: [4, 5, 2, 10, 8]
Output: [2, 2, -1, 8, -1]
````

## Constraints

````text
- 1 <= len(arr) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Monotonic Increasing Stack
Traverse from the right while maintaining increasing values to expose the next smaller.

1. Initialize result with -1 and an empty stack.
2. Iterate from n-1 to 0, popping while stack top &gt;= arr\[i\].
3. If stack remains, result\[i\] is stack\[-1\]; push arr\[i\].
4. Return result.

## Complexity

**Time:** O(n) - Each element enters and leaves the stack once.

**Space:** O(n) - Auxiliary stack and output.

## Solution

````python
from typing import List


class Solution:
    def nearestSmallestToRight(self, arr: List[int]) -> List[int]:
        n = len(arr)
        result = [-1] * n
        stack: List[int] = []
        for i in range(n - 1, -1, -1):
            while stack and stack[-1] >= arr[i]:
                stack.pop()
            if stack:
                result[i] = stack[-1]
            stack.append(arr[i])
        return result
````
