Given a Roman numeral string s, convert it to an integer. Subtractive pairs such as
IV and CM are valid and must be interpreted correctly.

## Examples

````text
Example 1:
    Input: s = "III"
    Output: 3

Example 2:
    Input: s = "LVIII"
    Output: 58

Example 3:
    Input: s = "MCMXCIV"
    Output: 1994
````

## Constraints

````text
- 1 <= len(s) <= 15
- s is a valid Roman numeral in the range [1, 3999].
````

## Approach

**Pattern:** Left-to-right parsing with lookahead
Prefer two-character values when they map to a subtractive form; otherwise add one symbol.

1. Build a map for single symbols and valid two-symbol subtractive forms.
2. Scan with index i; if s\[i:i+2\] is in the map, add its value and advance by two.
3. Otherwise add the single-symbol value and advance by one.
4. Return the accumulated sum.

## Complexity

**Time:** O(n) - Each character is examined at most twice.

**Space:** O(1) - Map size is constant.

## Solution

````python
class Solution:
    def romanToInt(self, s: str) -> int:
        val = {
            "I": 1,
            "V": 5,
            "X": 10,
            "L": 50,
            "C": 100,
            "D": 500,
            "M": 1000,
            "IV": 4,
            "IX": 9,
            "XL": 40,
            "XC": 90,
            "CD": 400,
            "CM": 900,
        }
        amount = 0
        i = 0
        n = len(s)
        while i < n:
            # Peek two chars when possible so IV/IX/... map before single-letter fallback.
            if i < n - 1 and s[i : i + 2] in val:
                amount += val[s[i : i + 2]]
                i += 2
            else:
                amount += val[s[i]]
                i += 1
        return amount
````
