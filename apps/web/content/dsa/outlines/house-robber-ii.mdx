Houses are arranged in a circle (first and last are neighbors). You cannot rob
two adjacent houses. Return the maximum money robbable.

## Examples

````text
Example 1:
    Input: nums = [2, 3, 2]
    Output: 3
Example 2:
    Input: nums = [1, 2, 3, 1]
    Output: 4
````

## Constraints

````text
- 1 <= nums.length <= 100
- 0 <= nums[i] <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** 1D Dynamic Programming + case split
Break the cycle by solving House Robber I on nums\[:-1\] and on nums\[1:\], then take the max.

1. If one house, return nums\[0\].
2. Helper linear\_rob on a slice: classic O(1) space DP.
3. Return max(linear\_rob(nums\[:-1\]), linear\_rob(nums\[1:\])).

## Complexity

**Time:** O(n) - two linear passes.

**Space:** O(1) besides the input slice views (copy avoided by index ranges in helper).

Pattern note: Slicing creates copies O(n); for clarity we use index ranges below.

## Solution

````python
from typing import List


class Solution:
    def _rob_range(self, nums: List[int], lo: int, hi: int) -> int:
        if lo > hi:
            return 0
        if lo == hi:
            return nums[lo]
        prev2 = nums[lo]
        prev1 = max(nums[lo], nums[lo + 1])
        for i in range(lo + 2, hi + 1):
            prev2, prev1 = prev1, max(prev1, prev2 + nums[i])
        return prev1

    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]
        return max(self._rob_range(nums, 0, n - 2), self._rob_range(nums, 1, n - 1))
````
