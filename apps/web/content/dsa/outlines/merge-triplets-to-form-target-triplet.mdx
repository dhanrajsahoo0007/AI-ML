You are given triplets of integers and a target triplet. You may merge any triplet by taking the
element-wise maximum with an accumulator that starts at \[0,0,0\]. A triplet is unusable if any
coordinate exceeds target. Return whether target can be reached.

## Examples

````text
Example 1:
    Input: triplets = [[2,5,3],[1,8,4],[1,7,5]], target = [2,7,5]
    Output: True

Example 2:
    Input: triplets = [[3,4,5],[4,5,6]], target = [2,5,8]
    Output: False

Example 3:
    Input: triplets = [[2,5,3],[2,3,4],[1,2,5],[5,2,3]], target = [5,5,5]
    Output: True
````

## Constraints

````text
- 1 <= triplets.length <= 10^5
- triplets[i].length == target.length == 3
- 0 <= triplets[i][j], target[j] <= 1000
````
