Given the root of a binary search tree and a target (floating point), return the node value
whose absolute distance to target is minimum; break ties by choosing the smaller value.

## Examples

````text
Example 1:
    Input: BST [4,2,5,1,3], target = 3.714286
    Output: 4

Example 2:
    Input: BST [1], target = 4.428571
    Output: 1
````

## Constraints

````text
- The tree is non-empty in typical tests; handle single-node trees.
````
