Given an integer n, return True if n is a positive integer power of two.

## Examples

````text
Example 1:
    Input: n = 16
    Output: True
Example 2:
    Input: n = 3
    Output: False
````

## Constraints

````text
- -2^31 <= n <= 2^31 - 1
````
