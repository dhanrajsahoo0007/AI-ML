Given a lowercase string s, choose any non-empty substring and replace every letter
in it with the previous letter in the alphabet ('b' -&gt; 'a', 'a' -&gt; 'z'). Return the
lexicographically smallest string obtainable with one such operation.

## Examples

````text
Example 1:
    Input: s = "cbabc"
    Output: "baabc"

Example 2:
    Input: s = "aa"
    Output: "az"

Example 3:
    Input: s = "acbbc"
    Output: "abaab"

Example 4:
    Input: s = "leetcode"
    Output: "kddsbncd"
````

## Constraints

````text
- 1 <= len(s) <= 3 * 10^5
- s consists of lowercase English letters.
````

## Approach

**Pattern:** Greedy leftmost improvement
Skip leading 'a' characters; decrement the first non-'a' run; if the string is all
'a's, decrement only the last character to 'z'.

1. Scan from the left while characters are 'a'.
2. If the whole string is 'a', change the last character to 'z' and return.
3. Otherwise decrement characters from the first non-'a' until the next 'a' or end.
4. Return the joined list.

## Complexity

**Time:** O(n) - At most one full pass.

**Space:** O(n) - Mutable list of characters.

## Solution

````python
class Solution:
    def smallestString(self, s: str) -> str:
        chars = list(s)
        n = len(chars)
        i = 0
        while i < n and chars[i] == "a":
            i += 1  # skip prefix already at smallest letter
        if i == n:
            chars[-1] = "z"  # e.g. "aa" -> "az"
        else:
            while i < n and chars[i] != "a":
                chars[i] = chr(ord(chars[i]) - 1)  # apply the allowed -1 map once per char
                i += 1
        return "".join(chars)
````
