Given a lowercase string s, choose any non-empty substring and replace every letter
in it with the previous letter in the alphabet ('b' -&gt; 'a', 'a' -&gt; 'z'). Return the
lexicographically smallest string obtainable with one such operation.

## Examples

````text
Example 1:
    Input: s = "cbabc"
    Output: "baabc"

Example 2:
    Input: s = "aa"
    Output: "az"

Example 3:
    Input: s = "acbbc"
    Output: "abaab"

Example 4:
    Input: s = "leetcode"
    Output: "kddsbncd"
````

## Constraints

````text
- 1 <= len(s) <= 3 * 10^5
- s consists of lowercase English letters.
````
