Given a non-negative integer n, set its rightmost 0 bit to 1. If every bit in
the working representation is already 1, return n unchanged.

## Examples

````text
Example 1:
    Input: n = 6 (binary 110)
    Output: 7 (111)
Example 2:
    Input: n = 5 (101)
    Output: 7 (111)
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
````

<PremiumBreak />

## Approach

**Pattern:** Isolate lowest clear bit
The mask (\~n) &amp; (n + 1) isolates the lowest zero as a single 1; OR it into n.

1. Return n \| ((\~n) &amp; (n + 1)).

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def setRightmostUnsetBit(self, n: int) -> int:
        return n | ((~n) & (n + 1))
````
