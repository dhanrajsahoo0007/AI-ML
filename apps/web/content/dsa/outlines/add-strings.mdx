Given two non-negative integers represented as strings num1 and num2, return their
sum as a string without using built-in big integers for the full conversion.

## Examples

````text
Example 1:
    Input: num1 = "11", num2 = "123"
    Output: "134"

Example 2:
    Input: num1 = "4567", num2 = "7890"
    Output: "12457"
````

## Constraints

````text
- 1 <= len(num1), len(num2) <= 10^4
- num1 and num2 contain only digits and have no leading zeros except the single "0".
````

## Approach

**Pattern:** Schoolbook addition with carry
Add digits from least significant to most significant while propagating carry.

1. Point indices at the ends of both strings and initialize carry to 0.
2. While either string has digits or carry remains, add the two digits and carry.
3. Append (sum % 10) to the result and set carry to sum // 10.
4. Reverse the collected digits and return as a string.

## Complexity

**Time:** O(max(m, n)) - One pass over the longer operand.

**Space:** O(max(m, n)) - Output length is at most max(m, n) + 1.

## Solution

````python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i = len(num1) - 1
        j = len(num2) - 1
        carry = 0
        out: list[str] = []
        while i >= 0 or j >= 0 or carry:
            d1 = ord(num1[i]) - ord("0") if i >= 0 else 0
            d2 = ord(num2[j]) - ord("0") if j >= 0 else 0
            total = d1 + d2 + carry
            out.append(str(total % 10))
            carry = total // 10
            i -= 1
            j -= 1
        return "".join(reversed(out))
````
