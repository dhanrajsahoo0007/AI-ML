Given two non-negative integers represented as strings num1 and num2, return their
sum as a string without using built-in big integers for the full conversion.

## Examples

````text
Example 1:
    Input: num1 = "11", num2 = "123"
    Output: "134"

Example 2:
    Input: num1 = "4567", num2 = "7890"
    Output: "12457"
````

## Constraints

````text
- 1 <= len(num1), len(num2) <= 10^4
- num1 and num2 contain only digits and have no leading zeros except the single "0".
````
