Every element appears twice except one; find the element that appears once.

## Examples

````text
Example 1:
    Input: nums = [2,2,1]
    Output: 1
Example 2:
    Input: nums = [4,1,2,1,2]
    Output: 4
````

## Constraints

````text
- 1 <= len(nums) <= 3 * 10^4
- Each element appears twice except one
````
