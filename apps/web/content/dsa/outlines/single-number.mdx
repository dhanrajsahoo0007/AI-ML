Every element appears twice except one; find the element that appears once.

## Examples

````text
Example 1:
    Input: nums = [2,2,1]
    Output: 1
Example 2:
    Input: nums = [4,1,2,1,2]
    Output: 4
````

## Constraints

````text
- 1 <= len(nums) <= 3 * 10^4
- Each element appears twice except one
````

<PremiumBreak />

## Approach

**Pattern:** XOR cancellation
x XOR x == 0, so XOR of the whole array leaves the unique element.

1. Initialize acc = 0.
2. XOR every value into acc and return acc.

## Complexity

**Time:** O(n)

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        x = 0
        for v in nums:
            x ^= v
        return x
````
