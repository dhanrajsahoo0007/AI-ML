Same as part I: each second remove the first k characters of word and append any k
characters to the end; return the minimum positive time to restore the original
string. Constraints are larger, so the solution must stay linear.

## Examples

````text
Example 1:
    Input: word = "abacaba", k = 2
    Output: 2

Example 2:
    Input: word = "abcd", k = 2
    Output: 2

Example 3:
    Input: word = "aa", k = 2
    Output: 1
````

## Constraints

````text
- 1 <= len(word) <= 10^6
- 1 <= k <= len(word)
````
