There are numCourses courses labeled 0..numCourses-1. prerequisites\[i\] = \[a, b\] means course b must be
completed before course a. Return true if every course can be finished; false if the prerequisite graph
has a cycle.

## Examples

````text
Example 1:
    Input: numCourses = 2, prerequisites = [[1, 0]]
    Output: True
Example 2:
    Input: numCourses = 2, prerequisites = [[1, 0], [0, 1]]
    Output: False
````

## Constraints

````text
- 1 <= numCourses <= 2000
- 0 <= len(prerequisites) <= 5000
- prerequisites[i].length == 2
````
