Given integer array prices of chocolate costs and an integer money, buy exactly two distinct
chocolates so the total cost does not exceed money and leftover money is minimized (or impossible).
Return leftover money after buying the two cheapest valid pair; if no valid pair exists, return money.

## Examples

````text
Example 1:
    Input: prices = [1,2,2], money = 3
    Output: 0

Example 2:
    Input: prices = [3,2,3], money = 3
    Output: 3

Example 3:
    Input: prices = [1,1,2,3], money = 4
    Output: 2
````

## Constraints

````text
- 2 <= prices.length <= 50
- 1 <= prices[i] <= 100
- 1 <= money <= 200
````
