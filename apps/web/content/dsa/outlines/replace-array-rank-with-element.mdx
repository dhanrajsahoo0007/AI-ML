Given an integer array arr, replace each element with its rank. The rank of an element is
one more than the number of distinct values strictly smaller than that element in the entire array.

## Examples

````text
Example 1:
    Input: arr = [100, 2, 70, 2, 8, 70, 100]
    Output: [4, 1, 3, 1, 2, 3, 4]
Example 2:
    Input: arr = [5, 5, 5, 5]
    Output: [1, 1, 1, 1]
````

## Constraints

````text
- 0 <= len(arr) <= 10^5
- -10^9 <= arr[i] <= 10^9
````
