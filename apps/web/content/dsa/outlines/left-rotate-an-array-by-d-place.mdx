Rotate an integer array to the left by k positions in place. After a left rotation by k,
the element that was at index k becomes the first element, preserving relative order of all parts.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 4, 5], k = 2
    Output: [3, 4, 5, 1, 2]
Example 2:
    Input: nums = [1], k = 5
    Output: [1]
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- -10^9 <= nums[i] <= 10^9
- 0 <= k (effective rotation uses k mod len(nums))
````
