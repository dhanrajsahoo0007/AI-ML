Given an undirected weighted graph (n vertices, edges as \[u, v, weight\]), return the total
weight of a Minimum Spanning Tree using Kruskal's algorithm. If disconnected, return -1.

## Examples

````text
Example 1:
    Input: n = 4, edges = [[0,1,1],[1,2,2],[0,2,3],[2,3,4]]
    Output: 7
Example 2:
    Input: n = 3, edges = [[0,1,4]]
    Output: -1
````

## Constraints

````text
- 1 <= n <= 10^4
- 0 <= len(edges) <= 10^5
- Edge weights are positive integers.
````

<PremiumBreak />

## Approach

**Pattern:** Minimum Spanning Tree — Kruskal + Disjoint Set Union (Union-Find)

1. Sort all edges by non-decreasing weight.
2. Initialize DSU with n singleton sets.
3. Greedily add an edge if it connects two different components (union by rank/size).
4. Stop when n-1 edges are taken or edges are exhausted; verify one component covers all.

## Complexity

**Time:** O(E log E) for sorting + O(E \* alpha(V)) for DSU traversals.

**Space:** O(V + E) for parent/rank arrays and the edge list.

## Solution

````python
from typing import List


class Solution:
    # --- Original teaching notes (Kruskal + DSU mental model) ---
    # Sort edges:  (0)--1--(1)--2--(2)--4--(3)
    #                \         /
    #                 `--3---'
    # Try lightest first: (0,1,1) take, (1,2,2) take, skip (0,2,3) (cycle), take (2,3,4).
    # DSU rejects any edge whose endpoints already share a root — that edge would close a cycle.
    #
    #    Components merge like droplets:   {0} {1}  ->  {0,1}  ->  {0,1,2}  ->  {0,1,2,3}
    # --- end visualization ---

    class _DSU:
        __slots__ = ("parent", "rank", "components")

        def __init__(self, n: int) -> None:
            self.parent = list(range(n))
            self.rank = [0] * n
            self.components = n

        def find(self, x: int) -> int:
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a: int, b: int) -> bool:
            ra, rb = self.find(a), self.find(b)
            if ra == rb:
                return False
            if self.rank[ra] < self.rank[rb]:
                ra, rb = rb, ra
            self.parent[rb] = ra
            if self.rank[ra] == self.rank[rb]:
                self.rank[ra] += 1
            self.components -= 1
            return True

    def kruskal_mst_total_weight(self, n: int, edges: List[List[int]]) -> int:
        if n == 1:
            return 0

        edges_sorted = sorted(edges, key=lambda e: e[2])
        dsu = self._DSU(n)
        total = 0
        edges_used = 0

        for u, v, w in edges_sorted:
            if dsu.union(u, v):
                total += w
                edges_used += 1
                if edges_used == n - 1:
                    break

        return total if edges_used == n - 1 else -1
````
