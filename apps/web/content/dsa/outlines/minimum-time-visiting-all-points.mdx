You start at points\[0\]. In one second you may move one unit vertically,
horizontally, or diagonally. Return minimum time to visit all points in order.

## Examples

````text
Example 1:
    Input: points = [[1,1],[3,4],[-1,0]]
    Output: 7
Example 2:
    Input: points = [[3,2],[-2,2]]
    Output: 5
````

## Constraints

````text
- len(points) <= 100
- |coordinates| <= 10^3
````
