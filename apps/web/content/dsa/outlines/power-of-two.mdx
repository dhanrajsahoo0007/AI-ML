Return True if n is a power of two (LeetCode 231 semantics: n must be &gt; 0).

## Examples

````text
Example 1:
    Input: n = 1
    Output: True
Example 2:
    Input: n = 16
    Output: True
Example 3:
    Input: n = 3
    Output: False
````

## Constraints

````text
- -2^31 <= n <= 2^31 - 1
````

<PremiumBreak />

## Approach

**Pattern:** Clear lowest set bit
Positive powers of two have a single 1 bit.

1. Return n &gt; 0 and (n &amp; (n - 1)) == 0.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & (n - 1)) == 0
````
