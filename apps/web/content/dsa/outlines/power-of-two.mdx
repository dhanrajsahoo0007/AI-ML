Return True if n is a power of two (LeetCode 231 semantics: n must be &gt; 0).

## Examples

````text
Example 1:
    Input: n = 1
    Output: True
Example 2:
    Input: n = 16
    Output: True
Example 3:
    Input: n = 3
    Output: False
````

## Constraints

````text
- -2^31 <= n <= 2^31 - 1
````
