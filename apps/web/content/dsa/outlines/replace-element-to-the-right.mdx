Given an array arr, replace every element arr\[i\] with the greatest element among indices
strictly to its right. Replace the last element with -1.

## Examples

````text
Example 1:
    Input: arr = [17, 18, 5, 4, 6, 1]
    Output: [18, 6, 6, 6, 1, -1]
Example 2:
    Input: arr = [400]
    Output: [-1]
````

## Constraints

````text
- 1 <= len(arr) <= 10^4
- 1 <= arr[i] <= 10^5
````
