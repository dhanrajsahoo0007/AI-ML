Given an integer n, return how many structurally unique BSTs store values 1..n.

## Examples

````text
Example 1:
    Input: n = 3
    Output: 5
Example 2:
    Input: n = 1
    Output: 1
````

## Constraints

````text
- 1 <= n <= 19
````
