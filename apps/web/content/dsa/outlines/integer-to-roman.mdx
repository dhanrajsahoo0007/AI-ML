Given an integer num in the range \[1, 3999\], convert it to a Roman numeral using the
standard subtractive notation (IV, IX, XL, XC, CD, CM).

## Examples

````text
Example 1:
    Input: num = 3
    Output: "III"

Example 2:
    Input: num = 58
    Output: "LVIII"

Example 3:
    Input: num = 1994
    Output: "MCMXCIV"
````

## Constraints

````text
- 1 <= num <= 3999
````

## Approach

**Pattern:** Greedy / lookup table
Repeatedly subtract the largest representable value and append its symbol.

1. Define ordered (value, numeral) pairs from largest to smallest.
2. For each pair, append the numeral floor(num / value) times and reduce num.
3. Stop when num becomes zero and return the built string.

## Complexity

**Time:** O(1) - Bounded by a fixed table of thirteen symbols.

**Space:** O(1) - Output length is bounded by a small constant for num &lt;= 3999.

## Solution

````python
from typing import List


class Solution:
    def intToRoman(self, num: int) -> str:
        digits = [
            (1000, "M"),
            (900, "CM"),
            (500, "D"),
            (400, "CD"),
            (100, "C"),
            (90, "XC"),
            (50, "L"),
            (40, "XL"),
            (10, "X"),
            (9, "IX"),
            (5, "V"),
            (4, "IV"),
            (1, "I"),
        ]
        roman_parts: List[str] = []
        for value, symbol in digits:
            if num == 0:
                break
            count = num // value  # how many times this symbol fits
            num -= count * value
            roman_parts.append(symbol * count)  # append that many copies
        return "".join(roman_parts)
````
