Given intervals\[i\] = \[l\_i, r\_i\] representing \[l\_i, r\_i) on the number line, remove
every interval that is covered by another interval in the list. Interval \[a, b) is
covered by \[c, d) if and only if c &lt;= a and b &lt;= d. Return how many intervals remain.

## Examples

````text
Example 1:
    Input: intervals = [[1,4],[3,6],[2,8]]
    Output: 2

Example 2:
    Input: intervals = [[1,4],[2,3]]
    Output: 1
````

## Constraints

````text
- 1 <= len(intervals) <= 1000
- 0 <= l_i < r_i <= 10^5
````

## Approach

**Pattern:** Sort by left endpoint with greedy sweep
Sorting by increasing left and decreasing right lets earlier intervals dominate in
coverage checks so each candidate is compared only against the last surviving interval.

1. Sort by (left ascending, right descending) so wider intervals appear first for the same left.
2. Walk the sorted list, keeping a stack-like list of survivors.
3. If the current interval is covered by the last survivor, skip it; otherwise append it.
4. Return the survivor count.

## Complexity

**Time:** O(n log n) - sorting dominates.

**Space:** O(n) - the survivor list in the worst case.

## Original notes

````text
(preamble)
Half-open vs closed reminder:

Why sort by decreasing right for ties on the same left:
Among intervals sharing the same start, the longer one covers the shorter ones. Visiting
the longest first ensures the stack top is always the widest guard for future intervals.

The LeetCode statement uses half-open intervals `[l, r)`; the coverage test is
`prev_left <= left and prev_right >= right`. The same greedy ordering works once the
dominance rule matches the problem's definition of "covered".
````

## Solution

````python
from typing import List


class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        intervals.sort(key=lambda i: (i[0], -i[1]))
        survivors: List[List[int]] = [intervals[0]]

        for left, right in intervals[1:]:
            prev_left, prev_right = survivors[-1]
            if prev_left <= left and prev_right >= right:
                continue
            survivors.append([left, right])

        return len(survivors)
````
