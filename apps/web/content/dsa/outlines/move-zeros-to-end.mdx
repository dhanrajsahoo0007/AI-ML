Given an integer array nums, move all zeros to the end while keeping the relative order of
non-zero elements. Modify the array in place.

## Examples

````text
Example 1:
    Input: nums = [0, 1, 0, 3, 12]
    Output: [1, 3, 12, 0, 0]
Example 2:
    Input: nums = [0]
    Output: [0]
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1
````
