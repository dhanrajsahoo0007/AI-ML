Given an integer array nums, move all zeros to the end while keeping the relative order of
non-zero elements. Modify the array in place.

## Examples

````text
Example 1:
    Input: nums = [0, 1, 0, 3, 12]
    Output: [1, 3, 12, 0, 0]
Example 2:
    Input: nums = [0]
    Output: [0]
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1
````

<PremiumBreak />

## Approach

**Pattern:** Two pointers (partitioning)
Maintain a write index for non-zero values; swap non-zeros forward as you scan.

1. Initialize write = 0.
2. For each read index, if nums\[read\] != 0, swap nums\[write\] and nums\[read\], increment write.
3. Return nums.

## Complexity

**Time:** O(n) - Single pass.

**Space:** O(1) - In-place swaps only.

## Solution

````python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> List[int]:
        write = 0
        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write], nums[read] = nums[read], nums[write]
                write += 1
        return nums
````
