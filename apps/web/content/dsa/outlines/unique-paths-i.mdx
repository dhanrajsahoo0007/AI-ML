Count paths from top-left to bottom-right in an m x n grid moving only right or down.

## Examples

````text
Example 1: m=3, n=7 -> 28
Example 2: m=3, n=2 -> 3
````

## Constraints

````text
- 1 <= m, n <= 100
````

<PremiumBreak />

## Approach

**Pattern:** 2D grid DP
Number of ways equals sum of ways from top and left.

1. One-row DP: row\[j\] += row\[j-1\].

## Complexity

**Time:** O(m\*n). Space: O(n).

## Solution

````python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        row = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                row[j] += row[j - 1]
        return row[-1]
````
