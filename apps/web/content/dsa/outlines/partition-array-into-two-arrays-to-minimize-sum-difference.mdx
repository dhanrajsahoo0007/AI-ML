Given an integer array nums containing 2 \* n values, split nums into two arrays of length n each so that
the absolute difference between their sums is minimized, and return that minimum difference.

## Examples

````text
Example 1:
    Input: nums = [3, 9, 7, 3]
    Output: 2
Example 2:
    Input: nums = [-36, 36]
    Output: 72
Example 3:
    Input: nums = [2, -1, 0, 4, -2, -9]
    Output: 0
````

## Constraints

````text
- 1 <= n <= 15 where len(nums) == 2 * n
- -10^7 <= nums[i] <= 10^7
````

## Approach

**Pattern:** Meet-in-the-middle with binary search
Enumerate subset sums for each half grouped by size, then pair complementary sizes to approach half the total.

1. Split nums into two halves of length n and compute all subset sums grouped by subset cardinality.
2. Sort each list of sums from the right half for binary search.
3. For every left subset of size k, binary search the right subset of size n - k whose sum makes the overall subset sum closest to total / 2.
4. Track the minimum absolute difference between total and twice the best combined sum.

## Complexity

**Time:** O(C(n, n/2) \* log C(n, n/2)) in the balanced case; overall exponential but feasible for n &lt;= 15.

**Space:** O(2^n) - Stores subset sums for each half in grouped lists.

## Solution

````python
import bisect
import itertools
from collections import defaultdict
from typing import List


class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 2
        total = sum(nums)
        first = nums[:n]
        second = nums[n:]

        def subset_sums_by_size(arr: List[int]) -> dict[int, list[int]]:
            groups: dict[int, list[int]] = defaultdict(list)
            for k in range(n + 1):
                for combo in itertools.combinations(arr, k):
                    groups[k].append(sum(combo))
            return groups

        left_groups = subset_sums_by_size(first)
        right_groups = subset_sums_by_size(second)
        for values in right_groups.values():
            values.sort()

        min_diff = float("inf")
        goal = total // 2

        for left_count, left_sums in left_groups.items():
            right_count = n - left_count
            if right_count not in right_groups:
                continue
            right_vals = right_groups[right_count]
            for left_sum in left_sums:
                idx = bisect.bisect_left(right_vals, goal - left_sum)
                for j in (idx - 1, idx):
                    if 0 <= j < len(right_vals):
                        combined = left_sum + right_vals[j]
                        min_diff = min(min_diff, abs(total - 2 * combined))
        return int(min_diff)
````
