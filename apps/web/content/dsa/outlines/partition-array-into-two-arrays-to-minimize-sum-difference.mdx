Given an integer array nums containing 2 \* n values, split nums into two arrays of length n each so that
the absolute difference between their sums is minimized, and return that minimum difference.

## Examples

````text
Example 1:
    Input: nums = [3, 9, 7, 3]
    Output: 2
Example 2:
    Input: nums = [-36, 36]
    Output: 72
Example 3:
    Input: nums = [2, -1, 0, 4, -2, -9]
    Output: 0
````

## Constraints

````text
- 1 <= n <= 15 where len(nums) == 2 * n
- -10^7 <= nums[i] <= 10^7
````
