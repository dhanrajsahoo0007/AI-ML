Given a 1-indexed array of integers numbers sorted in non-decreasing order, find two distinct indices
such that numbers\[index1\] + numbers\[index2\] equals target. Return \[index1, index2\] using 1-based indexing.

## Examples

````text
Example 1:
    Input: numbers = [2, 7, 11, 15], target = 9
    Output: [1, 2]
Example 2:
    Input: numbers = [2, 3, 4], target = 6
    Output: [1, 3]
````

## Constraints

````text
- 2 <= len(numbers) <= 3 * 10^4
- -1000 <= numbers[i] <= 1000
- numbers is sorted in non-decreasing order.
- -1000 <= target <= 1000
- Exactly one valid answer exists.
````
