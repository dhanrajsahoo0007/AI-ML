Given a 1-indexed array of integers numbers sorted in non-decreasing order, find two distinct indices
such that numbers\[index1\] + numbers\[index2\] equals target. Return \[index1, index2\] using 1-based indexing.

## Examples

````text
Example 1:
    Input: numbers = [2, 7, 11, 15], target = 9
    Output: [1, 2]
Example 2:
    Input: numbers = [2, 3, 4], target = 6
    Output: [1, 3]
````

## Constraints

````text
- 2 <= len(numbers) <= 3 * 10^4
- -1000 <= numbers[i] <= 1000
- numbers is sorted in non-decreasing order.
- -1000 <= target <= 1000
- Exactly one valid answer exists.
````

## Approach

**Pattern:** Two pointers on sorted data
Start with the widest pair; shrink the sum by moving the larger end left or the smaller end right.

1. Initialize i at 0 and j at len(numbers) - 1.
2. Compare numbers\[i\] + numbers\[j\] with target.
3. If equal, return \[i + 1, j + 1\]; if smaller, increment i; otherwise decrement j.
4. Repeat until a pair is found (guaranteed by problem constraints).

## Complexity

**Time:** O(n) - Pointers move monotonically across the array.

**Space:** O(1) - Only two indices are tracked.

## Solution

````python
from typing import List


class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        i, j = 0, len(numbers) - 1
        while i < j:
            current = numbers[i] + numbers[j]
            if current == target:
                return [i + 1, j + 1]
            if current < target:
                i += 1
            else:
                j -= 1
        return []
````
