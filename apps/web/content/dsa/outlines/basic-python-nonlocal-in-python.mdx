In Python, assigning to a name inside a nested function makes that name local
to the inner function unless declared otherwise. Incrementing an outer
variable from an inner function therefore requires the \`nonlocal\` keyword;
without it, reading then assigning the same name raises UnboundLocalError.

## Examples

````text
Example 1:
    With nonlocal: outer `count` starts at 0, inner increments it once →
    outer returns 1.

Example 2:
    Without nonlocal: `count += 1` in inner treats `count` as local but it is
    read before assignment → UnboundLocalError when inner runs.
````

## Constraints

````text
- Illustration only; no input size constraints.
````

<PremiumBreak />

## Approach

**Pattern:** Closure and lexical scoping
Nested functions close over outer bindings; \`nonlocal\` opts an enclosing
name into the assignment scope so updates affect the outer frame.

1. Define an outer counter initialized to zero.
2. Define an inner function that increments that counter.
3. Declare \`nonlocal count\` before incrementing so the outer binding updates.
4. Call inner from outer and return the updated counter.

## Complexity

**Time:** O(1) — fixed number of operations.

**Space:** O(1) — only integer state and nested function objects.

## Solution

````python
class Solution:
    def count_after_nested_increment(self) -> int:
        count = 0

        def inner() -> None:
            nonlocal count
            count += 1

        inner()
        return count

    def attempt_increment_without_nonlocal(self) -> None:
        count = 0

        def inner() -> None:
            count += 1

        inner()
````
