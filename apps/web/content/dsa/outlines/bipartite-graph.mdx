There is an undirected graph with n nodes numbered 0..n-1. You are given graph as an adjacency list:
graph\[u\] contains distinct neighbors v (undirected edges u—v). There are no self-loops or parallel edges.
The graph may be disconnected.

A graph is bipartite if nodes can be partitioned into two independent sets A and B such that every edge
connects a node in A to a node in B. Return true if and only if the graph is bipartite.

## Examples

````text
Example 1:
    Input: graph = [[1, 2, 3], [0, 2], [0, 1, 3], [0, 2]]
    Output: False
Example 2:
    Input: graph = [[1, 3], [0, 2], [1, 3], [0, 2]]
    Output: True
````

## Constraints

````text
- graph.length == n
- 1 <= n <= 100
- 0 <= graph[u].length < n
- graph[u] does not contain u; values are unique; if v in graph[u] then u in graph[v]
````
