Implement a Min Heap data structure from scratch that supports the following operations:
- heapify: Convert an array into a valid min heap
- insert: Add a new element to the heap
- remove: Remove and return the minimum element
- peek: Return the minimum element without removing it
- sift\_down: Move an element down to its correct position
- sift\_up: Move an element up to its correct position

## Examples

````text
Example 1:
    Input: array = [5, 3, 8, 1, 2]
    After heapify: [1, 2, 8, 5, 3] (or any valid min heap arrangement)

Example 2:
    heap.insert(4) -> heap maintains min heap property
    heap.remove() -> returns minimum element
    heap.peek() -> returns minimum without removing
````

## Constraints

````text
- Elements must be comparable (support < operator)
- Heap is stored as a contiguous array
````
