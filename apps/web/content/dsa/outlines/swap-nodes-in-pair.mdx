Swap every two adjacent nodes in a linked list and return the head. Do not only swap values;
rewire nodes.

## Examples

````text
Example 1:
    Input: head = [1,2,3,4]
    Output: [2,1,4,3]

Example 2:
    Input: head = []
    Output: []
````

## Constraints

````text
- 0 <= n <= 100
- 0 <= Node.val <= 100
````
