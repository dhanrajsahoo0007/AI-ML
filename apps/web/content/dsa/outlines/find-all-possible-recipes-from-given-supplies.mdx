You have supplies of ingredients and recipes each requiring specific ingredients. A recipe can
be made only when all its ingredients are available (initial supplies or previously made recipes).
Return all recipes that can eventually be made.

## Examples

````text
Example 1:
Input: recipes = ["bread"], ingredients = [["yeast", "flour"]], supplies = ["yeast", "flour", "corn"]
Output: ["bread"]
````

## Constraints

````text
- 1 <= len(recipes) <= 100
- ingredients[i] contains distinct strings, same length as recipes list.
- 1 <= len(ingredients[i]), len(supplies) <= 100
- Each string is lowercase English letters of length 1 to 10.
````
