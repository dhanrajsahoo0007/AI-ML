Given distinct positive integers nums and a target, count how many ordered sequences of
numbers from nums sum to target (different orderings count separately).

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3], target = 4
    Output: 7

Example 2:
    Input: nums = [9], target = 3
    Output: 0
````

## Constraints

````text
- nums elements are unique positive integers.
- 1 <= target <= 1000 for the DP implementation below.
````

<PremiumBreak />

## Approach

**Pattern:** Ordered composition counting (DP)
Let dp\[s\] be ways to form sum s; transition tries every coin as the last step.

1. dp\[0\] = 1.
2. For s from 1 to target, dp\[s\] += dp\[s - x\] for each x in nums if s &gt;= x.
3. Return dp\[target\].

## Complexity

**Time:** O(target \* len(nums)).

**Space:** O(target).

## Solution

````python
from typing import List


class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        dp = [0] * (target + 1)
        dp[0] = 1
        for s in range(1, target + 1):
            for x in nums:
                if x <= s:
                    dp[s] += dp[s - x]
        return dp[target]
````
