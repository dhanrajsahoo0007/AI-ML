Count the number of contiguous subarrays whose elements sum to k.

## Examples

````text
Example 1:
Input: nums = [1, 1, 1], k = 2
Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 2 * 10^4
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7
````

**Also in the notes under:** [07. Sliding Window/03. Variable size](/dsa/problems/subarray-sum-equals-k).

<PremiumBreak />

## Approach

**Pattern:** Prefix Sum + Hash Map
If prefix\[j\] - prefix\[i\] = k, count prior prefix sums equal to current - k.

1. Walk nums while tracking cumulative sum cur.
2. ans += freq\[cur - k\]; increment freq\[cur\].
3. Return ans.

## Complexity

**Time:** O(n).

**Space:** O(n) - frequency map of prefix sums.

## Solution

````python
from collections import defaultdict
from typing import List


class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        freq: defaultdict[int, int] = defaultdict(int)
        freq[0] = 1
        cur = 0
        ans = 0
        for x in nums:
            cur += x
            ans += freq[cur - k]
            freq[cur] += 1
        return ans
````
