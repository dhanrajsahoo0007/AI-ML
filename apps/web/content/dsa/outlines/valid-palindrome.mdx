Given a string s, return true if it is a palindrome after considering only alphanumeric
characters and ignoring case.

## Examples

````text
Example 1:
    Input: s = "A man, a plan, a canal: Panama"
    Output: true
Example 2:
    Input: s = "race a car"
    Output: false
````

## Constraints

````text
- 1 <= len(s) <= 2 * 10^5
- s consists only of printable ASCII characters.
````
