n machines each count words in one document via async futures countWords(machine\_id, doc\_id)
returning CWFuture with Join() (blocking result) and IsDone(). Implement totalWordsCount to sum all counts.

## Examples

````text
Example 1:
n = 1 with document word count 500 -> total 500.
````

## Constraints

````text
- Handle partial failures with retries or propagate errors based on policy.
- Utilize all machines concurrently where possible.
````

<PremiumBreak />

## Approach

**Pattern:** Thread pool / futures aggregation
Launch one async job per (machine, document), wait with Join or poll IsDone, sum successes.

1. For each machine i, create CWFuture for document i (mocked mapping).
2. Use a thread pool to simulate async Join without blocking the main thread sequentially... or call Join in threads.
3. Sum integer results; on failure after retries, re-raise or return partial per design.

## Complexity

**Time:** O(n) wall-clock with parallelism vs O(n) sequential Joins.

**Space:** O(n) for futures and thread overhead.

## Solution

````python
from __future__ import annotations

import threading
import time
from concurrent.futures import ThreadPoolExecutor, as_completed
from typing import Callable, Dict, List, Optional


class CWFuture:
    """Minimal future: async result becomes available after a short delay."""

    def __init__(self, value: int, fail: bool = False, delay: float = 0.01) -> None:
        self._value = value
        self._fail = fail
        self._delay = delay
        self._done = threading.Event()
        self._lock = threading.Lock()
        threading.Thread(target=self._complete, daemon=True).start()

    def _complete(self) -> None:
        time.sleep(self._delay)
        with self._lock:
            self._done.set()

    def IsDone(self) -> bool:
        return self._done.is_set()

    def Join(self) -> int:
        self._done.wait()
        if self._fail:
            raise RuntimeError("simulated network failure")
        return self._value


# Global test hooks (hidden in real system)
_DOC_COUNTS: Dict[int, int] = {}
_MACHINE_FAIL: Dict[int, bool] = {}


def countWords(machine_id: int, doc_id: int) -> CWFuture:
    """Simulated remote call: machine_id processes doc_id."""
    cnt = _DOC_COUNTS.get(doc_id, 0)
    return CWFuture(cnt, fail=_MACHINE_FAIL.get(machine_id, False))


def totalWordsCount(n: int, retries: int = 2) -> int:
    """Sum word counts for documents 0..n-1 using machines 0..n-1."""

    def work(mid: int) -> int:
        last_err: Optional[BaseException] = None
        for _ in range(retries + 1):
            fut = countWords(mid, mid)
            try:
                return fut.Join()
            except RuntimeError as e:
                last_err = e
                time.sleep(0.005)
        assert last_err is not None
        raise last_err

    with ThreadPoolExecutor(max_workers=max(1, n)) as ex:
        futures = [ex.submit(work, i) for i in range(n)]
        return sum(f.result() for f in as_completed(futures))
````
