Given a string s, sort it in decreasing order based on character frequency.
Return the sorted string.

## Examples

````text
Example 1:
    Input: s = "tree"
    Output: "eert"

Example 2:
    Input: s = "cccaaa"
    Output: "aaaccc" or "cccaaa"

Example 3:
    Input: s = "Aabb"
    Output: "bbAa"
````

## Constraints

````text
- 1 <= s.length <= 5 * 10^5
- s consists of uppercase/lowercase English letters and digits.
````
