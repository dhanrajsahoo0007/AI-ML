Given strings word1 and word2, return the minimum number of steps required to
make word1 equal word2. Each step is either delete a character from word1 or
insert a character into word1.

## Examples

````text
Example 1:
    Input: word1 = "sea", word2 = "eat"
    Output: 2
Example 2:
    Input: word1 = "leetcode", word2 = "etco"
    Output: 4
````

## Constraints

````text
- 0 <= len(word1), len(word2) <= 500
````
