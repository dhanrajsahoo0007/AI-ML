Given intervals\[i\] = \[start\_i, end\_i\], return the minimum number of intervals to
remove so that the remaining intervals are pairwise non-overlapping. Two intervals
overlap if they share any positive-length time in common (touching at a point is
allowed).

## Examples

````text
Example 1:
    Input: intervals = [[1,2],[2,3],[3,4],[1,3]]
    Output: 1

Example 2:
    Input: intervals = [[1,2],[1,2],[1,2]]
    Output: 2
````

## Constraints

````text
- 1 <= len(intervals) <= 10^5
- -5 * 10^4 <= start_i < end_i <= 5 * 10^4
````
