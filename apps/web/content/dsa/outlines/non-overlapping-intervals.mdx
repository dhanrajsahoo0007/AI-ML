Given intervals\[i\] = \[start\_i, end\_i\], return the minimum number of intervals to
remove so that the remaining intervals are pairwise non-overlapping. Two intervals
overlap if they share any positive-length time in common (touching at a point is
allowed).

## Examples

````text
Example 1:
    Input: intervals = [[1,2],[2,3],[3,4],[1,3]]
    Output: 1

Example 2:
    Input: intervals = [[1,2],[1,2],[1,2]]
    Output: 2
````

## Constraints

````text
- 1 <= len(intervals) <= 10^5
- -5 * 10^4 <= start_i < end_i <= 5 * 10^4
````

## Approach

**Pattern:** Greedy interval scheduling by end time
After sorting by start, when two intervals clash, discarding the one that ends later
preserves more room for future intervals, minimizing removals.

1. Sort intervals by start time ascending.
2. Track the end time of the last kept interval.
3. For each next interval, if it starts at or after that end, keep it and update end.
4. Otherwise increment removals and shrink the effective end to the earlier finishing
of the two overlapping intervals.
5. Return the removal count.

## Complexity

**Time:** O(n log n) - sorting dominates.

**Space:** O(1) - only a few scalars besides the sorted input list.

## Solution

````python
from typing import List


class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        intervals.sort()
        removals = 0
        prev_end = intervals[0][1]

        for start, end in intervals[1:]:
            if start >= prev_end:
                prev_end = end
            else:
                removals += 1
                # Prefer the interval that frees the timeline sooner.
                prev_end = min(end, prev_end)

        return removals
````
