Given distinct integer points in the plane, return the minimum area of any
rectangle formed by four points (not necessarily axis-aligned). If none, 0.

## Examples

````text
Example 1:
    Input: points = [[1,2],[2,1],[1,0],[0,1]]
    Output: 2.0
Example 2:
    Input: points = [[0,1],[2,1],[1,1],[1,0],[2,0]]
    Output: 1.0
````

## Constraints

````text
- 1 <= len(points) <= 50
- Coordinates are integers with |coord| <= 4 * 10^4
````

## Approach

**Pattern:** Enumerate right angles
Fix one corner and two adjacent sides with perpendicular vectors; verify the
fourth vertex exists in the point set.

1. Store points in a set for O(1) lookup.
2. Triple loop distinct i, j, k; treat i as corner, edges to j and k.
3. Require dot product zero for perpendicular adjacent sides; compute the
fourth corner j + k - i; if present, area is product of edge lengths.

## Complexity

**Time:** O(n^3)

**Space:** O(n) - hash set of points

## Solution

````python
import math
from typing import List, Set, Tuple


class Solution:
    def minAreaFreeRect(self, points: List[List[int]]) -> float:
        pset: Set[Tuple[int, int]] = {(x, y) for x, y in points}
        n = len(points)
        best = float("inf")
        for i in range(n):
            x1, y1 = points[i]
            for j in range(n):
                if i == j:
                    continue
                x2, y2 = points[j]
                dx1, dy1 = x2 - x1, y2 - y1
                for k in range(n):
                    if k in (i, j):
                        continue
                    x3, y3 = points[k]
                    dx2, dy2 = x3 - x1, y3 - y1
                    if dx1 * dx2 + dy1 * dy2 != 0:
                        continue
                    x4, y4 = x2 + x3 - x1, y2 + y3 - y1
                    if (x4, y4) in pset:
                        area = math.hypot(dx1, dy1) * math.hypot(dx2, dy2)
                        best = min(best, area)
        return 0.0 if best == float("inf") else best
````
