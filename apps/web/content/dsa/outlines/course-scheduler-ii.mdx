Same setup as Course Scheduler I, but return any valid order of all numCourses courses. If no order
exists (cycle), return an empty list.

## Examples

````text
Example 1:
    Input: numCourses = 2, prerequisites = [[1, 0]]
    Output: [0, 1]
Example 2:
    Input: numCourses = 4, prerequisites = [[1, 0], [2, 0], [3, 1], [3, 2]]
    Output: [0, 2, 1, 3] (or [0, 1, 2, 3])
````

## Constraints

````text
- 1 <= numCourses <= 2000
- 0 <= len(prerequisites) <= 5000
````
