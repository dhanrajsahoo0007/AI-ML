Same setup as Course Scheduler I, but return any valid order of all numCourses courses. If no order
exists (cycle), return an empty list.

## Examples

````text
Example 1:
    Input: numCourses = 2, prerequisites = [[1, 0]]
    Output: [0, 1]
Example 2:
    Input: numCourses = 4, prerequisites = [[1, 0], [2, 0], [3, 1], [3, 2]]
    Output: [0, 2, 1, 3] (or [0, 1, 2, 3])
````

## Constraints

````text
- 1 <= numCourses <= 2000
- 0 <= len(prerequisites) <= 5000
````

**Also in the notes under:** [17. Graphs/05. Topological Sort](/dsa/problems/course-scheduler-ii-topological-sort).

## Approach

**Pattern:** Topological sort via DFS (postorder reversal)
Edges b -&gt; a; append node to order after finishing DFS; reverse gives a topological order.

1. Build adjacency list b -&gt; a.
2. DFS with visiting/done flags; on back-edge to visiting node, set impossible flag.
3. Push node to stack after exploring neighbors; reverse stack if acyclic.

## Complexity

**Time:** O(V + E)

**Space:** O(V + E)

## Solution

````python
from typing import List
from collections import defaultdict


class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        adj = defaultdict(list)
        for a, b in prerequisites:
            adj[b].append(a)

        state = [0] * numCourses  # 0 unvisited, 1 visiting, 2 done
        order: List[int] = []
        impossible = False

        def dfs(u: int) -> None:
            nonlocal impossible
            state[u] = 1
            for v in adj[u]:
                if state[v] == 1:
                    impossible = True
                    return
                if state[v] == 0:
                    dfs(v)
                    if impossible:
                        return
            state[u] = 2
            order.append(u)

        for i in range(numCourses):
            if state[i] == 0:
                dfs(i)
                if impossible:
                    return []

        return order[::-1]
````

if __name__ == "__main__":
    sol = Solution()

    def is_valid_topo(n: int, prereq: List[List[int]], order: List[int]) -> bool:
        if len(order) != n:
            return False
        pos = {c: i for i, c in enumerate(order)}
        for a, b in prereq:
            if pos[b] > pos[a]:
                return False
        return True

    o1 = sol.findOrder(2, [[1, 0]])
