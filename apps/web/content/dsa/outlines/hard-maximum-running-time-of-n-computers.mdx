Run n computers simultaneously. batteries\[i\] minutes from battery i; swap batteries freely at
integer times. Return the maximum integer T such that all n computers can run together for T minutes.

## Examples

````text
Example 1:
Input: n = 2, batteries = [3, 3, 3]
Output: 4
````

## Constraints

````text
- 1 <= n <= len(batteries) <= 10^5
- 1 <= batteries[i] <= 10^9
````
