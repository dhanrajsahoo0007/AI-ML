Design a user activity logger that records timestamps per user and aggregates how
many activities fall into consecutive time buckets between start\_timestamp and
end\_timestamp (inclusive). Use 60-second buckets for frequency "minutes" and
3600-second buckets for "hours". The first bucket counts all activities in
\[start\_timestamp, min(start\_timestamp + width, end\_timestamp)\]; each following
bucket counts activities in (bucket\_start, next\_boundary\] clipped to end\_timestamp,
while the reported bucket still shows contiguous \[start + i\*width, ...\] windows.

## Examples

````text
Example 1:
Input: add_user_activity('user_1', t) for t in [10,12,17,18,60,65,90,121,150];
       calculate_activity('user_1', 5, 130, 'minutes')
Output: [
    {'start': 5, 'end': 65, 'count': 6},
    {'start': 65, 'end': 125, 'count': 2},
    {'start': 125, 'end': 130, 'count': 0},
]
````

## Constraints

````text
- Timestamps are non-negative integers (seconds)
- start_timestamp <= end_timestamp for queries
- frequency is either "minutes" or "hours"
````
