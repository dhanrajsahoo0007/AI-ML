Given a string s, return its longest proper prefix which is also a suffix (not
counting the full string as a prefix).

## Examples

````text
Example 1:
    Input: s = "level"
    Output: "l"

Example 2:
    Input: s = "ababab"
    Output: "abab"

Example 3:
    Input: s = "leetcodeleet"
    Output: "leet"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s contains only lowercase English letters.
````
