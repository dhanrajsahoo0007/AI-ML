Given row x col binary grid where 1 is land and 0 is water, there is exactly one island (connected 4-dir).
Return the perimeter of the island.

## Examples

````text
Example 1:
Input: grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]]
Output: 16
````

## Constraints

````text
- row == len(grid), col == len(grid[0])
- 1 <= row, col <= 100
````
