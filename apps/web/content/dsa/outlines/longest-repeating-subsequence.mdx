Given a string s, return the length of the longest subsequence of s that
appears at least twice (using two disjoint index sets with same relative order).

## Examples

````text
Example 1:
    Input: s = "aab"
    Output: 1
Example 2:
    Input: s = "axxax"
    Output: 2
````

## Constraints

````text
- 1 <= len(s) <= 2000
````

<PremiumBreak />

## Approach

**Pattern:** LCS of s with itself skipping diagonal
dp\[i\]\[j\] for i!=j: if s\[i-1\]==s\[j-1\] take 1+dp\[i-1\]\[j-1\] else max skips.

1. Same as LCS but require i != j when taking match (implemented by i&lt;j loop variant).
2. Classic: run LCS on s vs s with condition i!=j for equal indices.

## Complexity

**Time:** O(n^2).

**Space:** O(n^2).

## Solution

````python
class Solution:
    def longestRepeatingSubsequence(self, s: str) -> int:
        n = len(s)
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                if i != j and s[i - 1] == s[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[n][n]
````
