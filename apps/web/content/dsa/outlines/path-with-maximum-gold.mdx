In an m x n grid, each cell has gold amount or 0 (empty). From any cell with gold, walk
up/down/left/right without revisiting a cell or stepping on 0. Return the maximum gold sum.

## Examples

````text
Example 1:
Input: grid = [[0,6,0],[5,8,7],[0,9,0]]
Output: 24
````

## Constraints

````text
- 1 <= m, n <= 15
- 0 <= grid[i][j] <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Grid DFS with local visit marking
Temporarily zero out the current cell to mark visited, explore neighbors, then restore.

1. For each positive cell, start DFS that returns best continuation gold from there.
2. In DFS, save value, set cell to 0, sum value plus max of four DFS calls, restore value.
3. Take the maximum over all starts.

## Complexity

**Time:** O((mn)^2) worst case; each path touches limited cells in practice.

**Space:** O(mn) recursion depth in worst case.

````text
Problem Statement:
    In a gold mine grid of size m x n, each cell in this mine has an integer representing
    the amount of gold in that cell, 0 if it is empty. 
    Return the maximum amount of gold you can collect ,
    under the following conditions:
        - Every time you are located in a cell you will collect all the gold in that cell.
        - From your position, you can walk one step to the left, right, up, or down.
        - You can't visit the same cell more than once.
        - Never visit a cell with 0 gold.
        - You can start and stop collecting gold from any position in the grid that has some gold.

Returns:
    int: The maximum amount of gold that can be collected.

Time Complexity: O(4^k), where k is the number of cells with gold.
    - In the worst case, we explore 4 directions for each cell with gold.

Space Complexity: O(k), where k is the number of cells with gold.
    - This is due to the recursion stack in the worst case.

Example:
    Input: grid = [ [0,6,0],
                    [5,8,7],
                    [0,9,0]]
    Output: 24
    Explanation: Path to get the maximum gold, 9 -> 8 -> 7.
````

## Solution

````python
from typing import List


class Solution:
    def getMaximumGold(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = ((-1, 0), (1, 0), (0, 1), (0, -1))

        def dfs(i: int, j: int) -> int:
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == 0:
                return 0
            gold = grid[i][j]
            grid[i][j] = 0
            best = 0
            for di, dj in dirs:
                best = max(best, dfs(i + di, j + dj))
            grid[i][j] = gold
            return gold + best

        best_overall = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] != 0:
                    best_overall = max(best_overall, dfs(i, j))
        return best_overall
````
