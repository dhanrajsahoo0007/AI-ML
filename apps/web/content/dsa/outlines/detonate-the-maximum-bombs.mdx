You are given a list bombs where bombs\[i\] = \[xi, yi, ri\]. Bomb i detonates bombs j whose Euclidean
distance from (xi, yi) is at most ri (including j on the boundary). Detonations chain. Return the maximum
number of bombs that can be detonated if you may detonate exactly one starting bomb.

## Examples

````text
Example 1:
    Input: bombs = [[2,1,3],[6,1,4]]
    Output: 2
Example 2:
    Input: bombs = [[1,1,5],[10,10,5]]
    Output: 1
````

## Constraints

````text
- 1 <= len(bombs) <= 100
- bombs[i].length == 3
````

## Approach

**Pattern:** Directed graph + DFS
Draw edge i -&gt; j if bomb j lies in bomb i's blast radius; answer is the largest reachable set from any start.

1. For each pair (i, j), if in range, add directed edge i -&gt; j.
2. DFS from each node with a visited set; track component size.
3. Return the maximum size.

## Complexity

**Time:** O(n^3) for building edges plus O(n^2) per start in worst case.

**Space:** O(n^2) for the adjacency list.

## Solution

````python
from typing import List


class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        adj: List[List[int]] = [[] for _ in range(n)]

        def in_range(i: int, j: int) -> bool:
            x1, y1, r = bombs[i]
            x2, y2, _ = bombs[j]
            dx, dy = x1 - x2, y1 - y2
            return dx * dx + dy * dy <= r * r

        for i in range(n):
            for j in range(n):
                if i != j and in_range(i, j):
                    adj[i].append(j)

        def dfs(u: int, seen: List[bool]) -> int:
            seen[u] = True
            cnt = 1
            for v in adj[u]:
                if not seen[v]:
                    cnt += dfs(v, seen)
            return cnt

        best = 0
        for i in range(n):
            best = max(best, dfs(i, [False] * n))
        return best
````

## Another version

### Approach

**Pattern:** Graph DFS / BFS
Build directed edges i -&gt; j when j lies in i's blast radius; answer is the
largest reachable set from any start node.

1. For each pair (i, j), add edge i -&gt; j if squared distance &lt;= r\_i^2.
2. From each start node, DFS or BFS to count reachable nodes.
3. Return the maximum count.

### Complexity

**Time:** O(n^3) worst for DFS from each start on dense graph

**Space:** O(n^2) - adjacency list

### Solution

````python
from collections import deque
from typing import List


class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        g: List[List[int]] = [[] for _ in range(n)]

        def in_range(i: int, j: int) -> bool:
            x1, y1, _ = bombs[i]
            x2, y2, _ = bombs[j]
            dx, dy = x1 - x2, y1 - y2
            r = bombs[i][2]
            return dx * dx + dy * dy <= r * r

        for i in range(n):
            for j in range(n):
                if i != j and in_range(i, j):
                    g[i].append(j)

        def bfs(start: int) -> int:
            seen = {start}
            q = deque([start])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if v not in seen:
                        seen.add(v)
                        q.append(v)
            return len(seen)

        return max(bfs(s) for s in range(n))
````
