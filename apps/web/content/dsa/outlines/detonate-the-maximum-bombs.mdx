You are given a list bombs where bombs\[i\] = \[xi, yi, ri\]. Bomb i detonates bombs j whose Euclidean
distance from (xi, yi) is at most ri (including j on the boundary). Detonations chain. Return the maximum
number of bombs that can be detonated if you may detonate exactly one starting bomb.

## Examples

````text
Example 1:
    Input: bombs = [[2,1,3],[6,1,4]]
    Output: 2
Example 2:
    Input: bombs = [[1,1,5],[10,10,5]]
    Output: 1
````

## Constraints

````text
- 1 <= len(bombs) <= 100
- bombs[i].length == 3
````
