Given n tasks with \[enqueueTime, processingTime\], process them on a single-threaded CPU.
The CPU picks the shortest processing time task (ties broken by smallest index).
Return the order in which tasks are processed.

## Examples

````text
Example 1:
    Input: tasks = [[1,2],[2,4],[3,2],[4,1]]
    Output: [0,2,3,1]

Example 2:
    Input: tasks = [[7,10],[7,12],[7,5],[7,4],[7,2]]
    Output: [4,3,2,0,1]
````

## Constraints

````text
- tasks.length == n
- 1 <= n <= 10^5
- 1 <= enqueueTime_i, processingTime_i <= 10^9
````
