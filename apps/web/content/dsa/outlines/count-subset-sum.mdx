Count subsets of nums whose elements sum exactly to target (each element used
at most once; order of picking does not create new subsets).

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 3], target = 6
    Output: 3
Example 2:
    Input: nums = [1, 1, 1], target = 2
    Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 0 <= nums[i] <= 1000
- 0 <= target <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** 0-1 Knapsack counting
dp\[i\]\[j\] = number of ways to reach sum j with first i items.

1. dp\[i\]\[0\] = 1 for all i (empty subset for sum 0).
2. dp\[i\]\[j\] = dp\[i-1\]\[j\] + dp\[i-1\]\[j-nums\[i-1\]\] when j&gt;=nums\[i-1\].
3. Return dp\[n\]\[target\].

## Complexity

**Time:** O(n \* target).

**Space:** O(n \* target).

## Solution

````python
from typing import List


class Solution:
    def countSubsets(self, nums: List[int], target: int) -> int:
        n = len(nums)
        dp = [[0] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = 1
        for i in range(1, n + 1):
            for j in range(target + 1):
                dp[i][j] = dp[i - 1][j]
                if nums[i - 1] <= j:
                    dp[i][j] += dp[i - 1][j - nums[i - 1]]
        return dp[n][target]
````
