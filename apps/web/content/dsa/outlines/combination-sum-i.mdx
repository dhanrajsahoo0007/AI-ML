Given distinct positive integers candidates and a target, return every unique combination
where chosen numbers sum to target. The same candidate may be chosen unlimited times.

## Examples

````text
Example 1:
    Input: candidates = [2, 3, 6, 7], target = 7
    Output: [[2, 2, 3], [7]]

Example 2:
    Input: candidates = [2], target = 1
    Output: []
````

## Constraints

````text
- All elements of candidates are distinct.
- 2 <= len(candidates) <= 40
````

<PremiumBreak />

## Approach

**Pattern:** Unbounded combination backtracking
Sort for pruning; recurse with the same start index to allow reuse of the last pick.

1. DFS(start, remaining): if remaining == 0 store path; if &lt; 0 return.
2. For i from start to end, append candidates\[i\], recurse with i (reuse allowed), pop.

## Complexity

**Time:** O(n^(target / min)) in worst case.

**Space:** O(target / min) recursion depth.

## Solution

````python
from typing import List


class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        result: List[List[int]] = []

        def dfs(start: int, remaining: int, path: List[int]) -> None:
            if remaining == 0:
                result.append(path[:])
                return
            if remaining < 0:
                return
            for i in range(start, len(candidates)):
                val = candidates[i]
                if val > remaining:
                    break
                path.append(val)
                dfs(i, remaining - val, path)
                path.pop()

        dfs(0, target, [])
        return result
````
