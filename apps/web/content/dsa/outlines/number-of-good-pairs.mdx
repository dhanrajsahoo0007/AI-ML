Given an integer array nums, return the number of pairs (i, j) with i &lt; j such that nums\[i\] == nums\[j\].

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 1, 1, 3]
    Output: 4
Example 2:
    Input: nums = [1, 1, 1, 1]
    Output: 6
````

## Constraints

````text
- 1 <= len(nums) <= 100
- 1 <= nums[i] <= 100
````
