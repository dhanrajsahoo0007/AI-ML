Given a directed acyclic graph (DAG) of n nodes labeled 0..n-1, graph\[i\] lists nodes j with a directed
edge i -&gt; j. Return all paths from node 0 to node n-1 (in any order).

## Examples

````text
Example 1:
    Input: graph = [[1, 2], [3], [3], []]
    Output: [[0, 1, 3], [0, 2, 3]]
Example 2:
    Input: graph = [[1], []]
    Output: [[0, 1]]
Example 3:
    Input: graph = [[4, 3, 1], [3, 2, 4], [3], [4], []]
    Output: five paths ending at 4 (see LeetCode 797)
````

## Constraints

````text
- n == len(graph)
- 2 <= n <= 15
- The graph is a DAG; edges are unique; no self-loops
````
