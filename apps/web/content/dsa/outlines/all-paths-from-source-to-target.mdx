Given a directed acyclic graph (DAG) of n nodes labeled 0..n-1, graph\[i\] lists nodes j with a directed
edge i -&gt; j. Return all paths from node 0 to node n-1 (in any order).

## Examples

````text
Example 1:
    Input: graph = [[1, 2], [3], [3], []]
    Output: [[0, 1, 3], [0, 2, 3]]
Example 2:
    Input: graph = [[1], []]
    Output: [[0, 1]]
Example 3:
    Input: graph = [[4, 3, 1], [3, 2, 4], [3], [4], []]
    Output: five paths ending at 4 (see LeetCode 797)
````

## Constraints

````text
- n == len(graph)
- 2 <= n <= 15
- The graph is a DAG; edges are unique; no self-loops
````

## Approach

**Pattern:** Graph BFS (path enumeration with queue of partial paths)

1. Initialize a queue with the path \[0\].
2. Pop a path; if its last node is n-1, record it; else extend with each neighbor and enqueue copies.
3. Continue until the queue is empty.

## Complexity

**Time:** O(2^n \* n) worst case for path count and path copying.

**Space:** O(2^n \* n) for the queue and stored paths.

## Solution

````python
from typing import List
from collections import deque


class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        n = len(graph)
        target = n - 1
        result: List[List[int]] = []
        temp = [0]  # Initial path with just the source node

        que: deque[List[int]] = deque([temp])  # Initialize queue with the starting path [0]

        while que:
            currPath = que.popleft()
            lastNode = currPath[-1]

            if lastNode == target:
                result.append(currPath)
            else:
                for v in graph[lastNode]:
                    path = currPath.copy()  # Create a copy of the current path
                    path.append(v)  # Append the new node
                    que.append(path)

        return result
````

### Approach

**Pattern:** Backtracking / DFS on DAG
Explore every extension of the current path from 0; when the last node is n-1, record a copy of the path.

1. Start path \[0\] and DFS from node 0 toward target n-1.
2. For each neighbor, push, recurse, pop (backtrack).
3. When u == n-1, append path copy to results.

### Complexity

**Time:** O(2^n \* n) in worst-case exponential path count; each path length O(n).

**Space:** O(n) for recursion stack and current path (excluding output).

### Solution

````python
from typing import List


class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        target = len(graph) - 1
        result: List[List[int]] = []
        path: List[int] = [0]

        def dfs(u: int) -> None:
            if u == target:
                result.append(path.copy())
                return
            for v in graph[u]:
                path.append(v)
                dfs(v)
                path.pop()

        dfs(0)
        return result
````
