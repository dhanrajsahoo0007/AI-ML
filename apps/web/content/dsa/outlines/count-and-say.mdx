The count-and-say sequence starts with "1". Each subsequent term is generated by
reading the previous term aloud: consecutive equal digits are replaced by count
followed by digit. Return the nth term (1-indexed).

## Examples

````text
Example 1:
    Input: n = 1
    Output: "1"

Example 2:
    Input: n = 4
    Output: "1211"
````

## Constraints

````text
- 1 <= n <= 30
````
