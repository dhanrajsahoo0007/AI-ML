Given non-overlacing axis-aligned rectangles (x1,y1,x2,y2), find a vertical line x that
splits total area as evenly as possible (area strictly to the left of x vs strictly to the right).

## Examples

````text
Example 1:
    Input: [(1, 1, 4, 4)]
    Output: 2.5
Example 2:
    Input: [(1, 1, 3, 3), (4, 1, 6, 3)]
    Output: 3.5 (plateau of equal left-area between rectangles; midpoint is used)
Example 3:
    Input: [(1, 1, 3, 3), (3, 1, 6, 3)]  # total area 10, half is 5
    Output: 3.5 (vertical line where cumulative area from the left reaches 5)
````

## Constraints

````text
- Rectangles do not overlap; x2 > x1 and y2 > y1.
````

<PremiumBreak />

## Approach

**Pattern:** Binary search on monotone cumulative area
Area to the left of x grows with x; binary search for x where left area is half of total.

1. Compute total area and area\_left(x) using rectangle clamped width min(x,x2)-x1.
2. Binary search x in \[min\_x, max\_x\] to minimize \|area\_left(x) - total/2\| or find crossing.

## Complexity

**Time:** O(R \* log(range/eps)) for R rectangles.

**Space:** O(1) extra.

## Solution

````python
from typing import List, Tuple


class RectangleLineDivider:
    @staticmethod
    def area_left(rectangles: List[Tuple[int, int, int, int]], x: float) -> float:
        s = 0.0
        for x1, y1, x2, y2 in rectangles:
            w = max(0.0, min(x, float(x2)) - float(x1))
            s += w * (y2 - y1)
        return s

    @staticmethod
    def total_area(rectangles: List[Tuple[int, int, int, int]]) -> float:
        return sum((x2 - x1) * (y2 - y1) for x1, y1, x2, y2 in rectangles)

    @classmethod
    def find_dividing_line(cls, rectangles: List[Tuple[int, int, int, int]]) -> float:
        total = cls.total_area(rectangles)
        target = total / 2.0
        x_lo = float(min(r[0] for r in rectangles))
        x_hi = float(max(r[2] for r in rectangles))
        # Smallest x with area_left(x) >= target
        lo, hi = x_lo, x_hi
        for _ in range(80):
            mid = (lo + hi) / 2.0
            if cls.area_left(rectangles, mid) < target:
                lo = mid
            else:
                hi = mid
        left_bound = hi
        # Largest x with area_left(x) <= target (handles flat plateaus between rectangles)
        lo, hi = x_lo, x_hi
        for _ in range(80):
            mid = (lo + hi) / 2.0
            if cls.area_left(rectangles, mid) <= target:
                lo = mid
            else:
                hi = mid
        right_bound = lo
        return (left_bound + right_bound) / 2.0
````
