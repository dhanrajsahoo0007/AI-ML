Partition nums into two non-empty subsets to minimize absolute difference of
their sums. Return that minimum difference.

## Examples

````text
Example 1:
    Input: nums = [1, 5, 11, 5]
    Output: 0
Example 2:
    Input: nums = [1, 6, 11, 5]
    Output: 1
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 0 <= nums[i] <= 5000
````
