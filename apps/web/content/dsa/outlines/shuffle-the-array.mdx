Given an array nums of 2n integers in the form \[x1,...,xn,y1,...,yn\], return
the array \[x1,y1,x2,y2,...,xn,yn\].

## Examples

````text
Example 1:
    Input: nums = [2,5,1,3,4,7], n = 3
    Output: [2,3,5,4,1,7]
Example 2:
    Input: nums = [1,2,3,4,4,3,2,1], n = 4
    Output: [1,4,2,3,3,2,4,1]
````

## Constraints

````text
- 1 <= n <= 500
- len(nums) == 2n
````

## Approach

**Pattern:** Two-pointer interleaving
First half provides x\_i at even indices; second half provides y\_i at odds.

1. Build result by taking nums\[i\] and nums\[i + n\] for i in range(n).

## Complexity

**Time:** O(n)

**Space:** O(n) for the output list

## Solution

````python
from typing import List


class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        return [nums[i // 2] if i % 2 == 0 else nums[n + i // 2] for i in range(2 * n)]
````
