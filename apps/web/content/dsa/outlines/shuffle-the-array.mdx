Given an array nums of 2n integers in the form \[x1,...,xn,y1,...,yn\], return
the array \[x1,y1,x2,y2,...,xn,yn\].

## Examples

````text
Example 1:
    Input: nums = [2,5,1,3,4,7], n = 3
    Output: [2,3,5,4,1,7]
Example 2:
    Input: nums = [1,2,3,4,4,3,2,1], n = 4
    Output: [1,4,2,3,3,2,4,1]
````

## Constraints

````text
- 1 <= n <= 500
- len(nums) == 2n
````
