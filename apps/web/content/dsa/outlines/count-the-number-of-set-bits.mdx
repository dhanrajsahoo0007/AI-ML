Count how many bits are 1 in the binary representation of a non-negative n.

## Examples

````text
Example 1:
    Input: n = 11
    Output: 3
Example 2:
    Input: n = 128
    Output: 1
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
````
