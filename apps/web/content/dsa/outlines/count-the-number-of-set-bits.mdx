Count how many bits are 1 in the binary representation of a non-negative n.

## Examples

````text
Example 1:
    Input: n = 11
    Output: 3
Example 2:
    Input: n = 128
    Output: 1
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
````

<PremiumBreak />

## Approach

**Pattern:** Brian Kernighan bit clearing
Repeatedly clear the lowest set bit with n &amp;= n - 1 until n becomes 0.

1. Initialize count to 0.
2. While n &gt; 0: n &amp;= n - 1; increment count.
3. Return count.

## Complexity

**Time:** O(number of set bits)

**Space:** O(1)

## Solution

````python
class Solution:
    def countSetBits(self, n: int) -> int:
        c = 0
        while n:
            n &= n - 1
            c += 1
        return c
````
