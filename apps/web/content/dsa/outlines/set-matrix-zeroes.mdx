Given an m x n integer matrix, if an element is 0, set its entire row and column to 0.
You must do it in place.

## Examples

````text
Example 1:
    Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
    Output: [[1,0,1],[0,0,0],[1,0,1]]

Example 2:
    Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
    Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
````

## Constraints

````text
- m == len(matrix), n == len(matrix[0])
- 1 <= m, n <= 200
- -2^31 <= matrix[i][j] <= 2^31 - 1
````

## Approach

**Pattern:** Use matrix as its own marker set
Store which rows/cols need zeroing in the first row and first column, with two flags for those lines themselves.

1. Record whether the first row or first column originally contains a zero.
2. Scan the rest of the matrix; for each zero at (i, j), set matrix\[i\]\[0\] and matrix\[0\]\[j\] to 0 as markers.
3. Second pass: zero cells (i, j) for i,j &gt;= 1 if row i or column j is marked.
4. Finally zero the first row and/or first column if the initial flags say so.

## Complexity

**Time:** O(m \* n) - Constant passes over all cells.

**Space:** O(1) - Only a few booleans besides the modified matrix.

## Solution

````python
from typing import List


class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m = len(matrix)
        n = len(matrix[0])
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
````
