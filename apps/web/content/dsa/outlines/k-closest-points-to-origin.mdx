Given an array of points in a 2D plane, find the K closest points to the origin (0, 0).
The distance between two points is the Euclidean distance.
You may return the answer in any order.

## Examples

````text
Example 1:
    Input: points = [[1,3],[-2,2]], k = 1
    Output: [[-2,2]]
    Explanation: Distance of (1,3) = sqrt(10), Distance of (-2,2) = sqrt(8). [-2,2] is closer.

Example 2:
    Input: points = [[3,3],[5,-1],[-2,4]], k = 2
    Output: [[3,3],[-2,4]]
````

## Constraints

````text
- 1 <= k <= points.length <= 10^4
- -10^4 <= xi, yi <= 10^4
````

## Approach

**Pattern:** Top-K
We maintain a max-heap of size k based on squared distance from origin.
We use squared distance to avoid computing square roots.

1. For each point, calculate its squared distance from the origin.
2. Push to a max-heap (using negative distance) of size k.
3. If the heap exceeds size k, remove the farthest point.
4. Extract and return the k closest points.

## Complexity

**Time:** O(n log k), where n is the number of points

**Space:** O(k) for the heap

## Original notes

````text
Original notes (restored):
Use squared Euclidean distance `x*x + y*y` — ordering is identical to real distance and
avoids `sqrt`. Store `(-dist_sq, point)` so `heapq` (min-heap) acts as a max-heap on distance:
the farthest of the k closest sits at the top and gets evicted first when a closer point arrives.
````

## Solution

````python
import heapq
from typing import List


class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        max_heap = []

        for point in points:
            x, y = point
            # Negated squared distance → min-heap behaves like max-heap on closeness.
            dist = -(x * x + y * y)

            if len(max_heap) < k:
                heapq.heappush(max_heap, (dist, point))
            elif dist > max_heap[0][0]:
                heapq.heapreplace(max_heap, (dist, point))

        return [point for _, point in max_heap]
````

## Another version

From 21. Math &amp; Geometry/02. Leetcode and Alphabet 150.

### Approach

**Pattern:** Sorting / heap by squared distance
Compare squared distances to avoid floating sqrt; take k smallest.

1. Sort points by x\*x + y\*y ascending.
2. Return the first k points.

### Complexity

**Time:** O(n log n) - sorting

**Space:** O(n) - sorted copy (or O(k) with heap)

### Solution

````python
import heapq
from typing import List


class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        return heapq.nsmallest(k, points, key=lambda p: p[0] * p[0] + p[1] * p[1])
````
