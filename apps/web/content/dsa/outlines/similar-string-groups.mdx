Two strings are similar if you can swap two letters in one string to get the other, or they are equal.
Strings are in the same group if they are similar (transitively). Given an array of strings of equal
length, return the number of groups.

## Examples

````text
Example 1:
    Input: strs = ["tars","rats","arts","star"]
    Output: 2
Example 2:
    Input: strs = ["omv","ovm"]
    Output: 1
````

## Constraints

````text
- 1 <= len(strs) <= 300
- 1 <= len(strs[i]) <= 300
- strs[i] consist of lowercase letters only.
- All strings have the same length.
````
