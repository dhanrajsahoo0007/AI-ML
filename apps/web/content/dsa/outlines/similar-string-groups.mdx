Two strings are similar if you can swap two letters in one string to get the other, or they are equal.
Strings are in the same group if they are similar (transitively). Given an array of strings of equal
length, return the number of groups.

## Examples

````text
Example 1:
    Input: strs = ["tars","rats","arts","star"]
    Output: 2
Example 2:
    Input: strs = ["omv","ovm"]
    Output: 1
````

## Constraints

````text
- 1 <= len(strs) <= 300
- 1 <= len(strs[i]) <= 300
- strs[i] consist of lowercase letters only.
- All strings have the same length.
````

<PremiumBreak />

## Approach

**Pattern:** Union-Find on string indices
Connect indices whose strings are similar; count DSU components.

1. For each pair i &lt; j, check similarity (equal or exactly two differing positions with swapped chars).
2. Union similar indices.
3. Count distinct roots.

## Complexity

**Time:** O(n^2 \* L) for n strings of length L.

**Space:** O(n) for DSU.

## Solution

````python
from typing import List


class Solution:
    def numSimilarGroups(self, strs: List[str]) -> int:
        n = len(strs)

        def similar(a: str, b: str) -> bool:
            if len(a) != len(b):
                return False
            diff = [i for i in range(len(a)) if a[i] != b[i]]
            if not diff:
                return True
            if len(diff) != 2:
                return False
            i, j = diff
            return a[i] == b[j] and a[j] == b[i]

        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[rb] = ra

        for i in range(n):
            for j in range(i + 1, n):
                if similar(strs[i], strs[j]):
                    union(i, j)

        return len({find(i) for i in range(n)})
````
