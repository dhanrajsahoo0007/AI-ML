Parse a chemical formula with nested parentheses and multipliers, then return atom counts sorted
lexicographically with counts omitted when equal to 1.

## Examples

````text
Example 1:
Input: "H2O"
Output: "H2O"
````

## Constraints

````text
- 1 <= len(formula) <= 1000
- formula uses valid chemical notation with uppercase leaders and optional digits
````

<PremiumBreak />

## Approach

**Pattern:** Stack of Frequency Maps
Push a fresh counter map for each '(' and merge upward when ')' applies an outer multiplier.

1. Keep a stack of defaultdict counters; default outer map starts active.
2. On '(', push a new map; on ')', pop, read trailing multiplier, and add scaled counts upward.
3. Otherwise parse element name and optional count, updating the current map.
4. Sort atoms and format counts.

## Complexity

**Time:** O(n log k) - n scans the formula; k unique atoms for sorting.

**Space:** O(n) - Stack depth and counter storage.

## Solution

````python
from collections import defaultdict
from typing import Dict, List


class Solution:
    def countOfAtoms(self, formula: str) -> str:
        stack: List[Dict[str, int]] = [defaultdict(int)]
        i = 0
        n = len(formula)
        while i < n:
            ch = formula[i]
            if ch == "(":
                stack.append(defaultdict(int))
                i += 1
            elif ch == ")":
                top = stack.pop()
                i += 1
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                mult = int(formula[start:i] or 1)
                for name, val in top.items():
                    stack[-1][name] += val * mult
            else:
                start = i
                i += 1
                while i < n and formula[i].islower():
                    i += 1
                name = formula[start:i]
                start = i
                while i < n and formula[i].isdigit():
                    i += 1
                count = int(formula[start:i] or 1)
                stack[-1][name] += count
        parts: List[str] = []
        for name, cnt in sorted(stack[0].items()):
            parts.append(name)
            if cnt > 1:
                parts.append(str(cnt))
        return "".join(parts)
````
