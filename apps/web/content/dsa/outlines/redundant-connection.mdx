Given an undirected graph that started as a tree with n nodes labeled 1..n and one extra edge,
return an edge that can be removed so the result is a tree. If multiple, return the edge
that appears last in the input.

## Examples

````text
Example 1:
    Input: edges = [[1,2],[1,3],[2,3]]
    Output: [2,3]
Example 2:
    Input: edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]
    Output: [1,4]
````

## Constraints

````text
- n == len(edges)
- 3 <= n <= 1000
- edges[i].length == 2
````

## Approach

**Pattern:** Graph - Union Find (DSU)

1. Process edges in order; use DSU to detect first edge whose endpoints are already connected.
2. That edge is the redundant one (last such in input for the canonical problem).

## Complexity

**Time:** O(n \* alpha(n)) \~ O(n).

**Space:** O(n) for parent array.

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        n = len(edges)
        parent = list(range(n + 1))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> bool:
            ra, rb = find(a), find(b)
            if ra == rb:
                return False
            parent[rb] = ra
            return True

        for a, b in edges:
            if not union(a, b):
                return [a, b]
        return []
````
