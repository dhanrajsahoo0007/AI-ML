Same adjacency rules as Word Ladder I, but return all shortest transformation sequences from beginWord to
endWord. If none exist, return \[\]. Each sequence is a list of words from beginWord to endWord inclusive.

## Examples

````text
Example 1:
    Input: beginWord = "hit", endWord = "cog",
        wordList = ["hot","dot","dog","lot","log","cog"]
    Output: [["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]
Example 2:
    Input: beginWord = "hit", endWord = "cog",
        wordList = ["hot","dot","dog","lot","log"]
    Output: []
````

## Constraints

````text
- As in LeetCode 126; all words same length; beginWord != endWord
````
