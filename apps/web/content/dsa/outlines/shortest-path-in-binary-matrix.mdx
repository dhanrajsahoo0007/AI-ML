Given an n x n binary matrix grid, return the length of the shortest clear path from the
top-left cell (0, 0) to the bottom-right cell (n - 1, n - 1). If no clear path exists, return -1.
A clear path visits only cells with value 0; each step may move to one of the eight neighbors
(including diagonals). The path length is the number of cells visited.

## Examples

````text
Example 1:
    Input: grid = [[0,1],[1,0]]
    Output: 2
Example 2:
    Input: grid = [[0,0,0],[1,1,0],[1,1,0]]
    Output: 4
Example 3:
    Input: grid = [[1,0,0],[1,1,0],[1,1,0]]
    Output: -1
````

## Constraints

````text
- n == len(grid) == len(grid[i])
- 1 <= n <= 100
- grid[i][j] is 0 or 1
````
