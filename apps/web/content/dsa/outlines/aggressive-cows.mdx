Stall positions are given on a line. Place k cows in distinct stalls so that the minimum distance
between any two cows is as large as possible. Return that maximum achievable minimum distance.

## Examples

````text
Example 1:
Input: stalls = [0, 3, 4, 7, 10, 9], k = 4
Output: 3
````

## Constraints

````text
- 2 <= k <= len(stalls) <= 10^5
- Stall coordinates fit in 32-bit range
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Answer (maximize minimum)
Sort stalls; check if k cows can be placed with pairwise distance at least d using a greedy scan.

1. Sort stalls.
2. Binary search d in \[0, max - min\]; greedy place first cow at stalls\[0\], then next when gap &gt;= d.
3. Largest d with enough placements wins.

## Complexity

**Time:** O(n log W) - W = coordinate spread, plus O(n log n) sort once.

**Space:** O(1) - Aside from sorting in place.

## Solution

````python
from typing import List


class Solution:
    def aggressiveCows(self, stalls: List[int], k: int) -> int:
        stalls.sort()
        n = len(stalls)

        def can(min_dist: int) -> bool:
            placed = 1
            last = stalls[0]
            for i in range(1, n):
                if stalls[i] - last >= min_dist:
                    placed += 1
                    last = stalls[i]
                    if placed == k:
                        return True
            return False

        lo, hi = 0, stalls[-1] - stalls[0]
        best = 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if can(mid):
                best = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return best
````
