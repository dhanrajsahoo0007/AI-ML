You are given a tree of n nodes labeled from 0 to n - 1, and an integer array parent of
length n - 1 where parent\[i\] is the parent of node i + 1. You are also given a string s of
length n where s\[i\] is the character assigned to node i. Return the length of the longest
path in the tree such that no pair of adjacent nodes on the path have the same character.

## Examples

````text
Example 1:
    Input: parent = [-1,0,0,1,1,2], s = "abacbe"
    Output: 3
Example 2:
    Input: parent = [-1,0,0,2], s = "aeeb"
    Output: 4
````

## Constraints

````text
- n == len(parent) + 1 == len(s)
- 0 <= parent[i] < n for all i >= 0 (parent[0] == -1 for the root)
- s consists only of lowercase English letters
````
