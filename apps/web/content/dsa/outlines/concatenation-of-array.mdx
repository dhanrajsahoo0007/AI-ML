Given an integer array nums of length n, build an array ans of length 2n such that
ans\[i\] == nums\[i\] and ans\[i + n\] == nums\[i\] for every index i in \[0, n). In other words,
ans is nums concatenated with itself.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 1]
    Output: [1, 2, 1, 1, 2, 1]
Example 2:
    Input: nums = [1, 3, 2, 1]
    Output: [1, 3, 2, 1, 1, 3, 2, 1]
````

## Constraints

````text
- 1 <= len(nums) <= 1000
- 1 <= nums[i] <= 1000
````
