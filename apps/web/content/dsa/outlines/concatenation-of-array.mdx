Given an integer array nums of length n, build an array ans of length 2n such that
ans\[i\] == nums\[i\] and ans\[i + n\] == nums\[i\] for every index i in \[0, n). In other words,
ans is nums concatenated with itself.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 1]
    Output: [1, 2, 1, 1, 2, 1]
Example 2:
    Input: nums = [1, 3, 2, 1]
    Output: [1, 3, 2, 1, 1, 3, 2, 1]
````

## Constraints

````text
- 1 <= len(nums) <= 1000
- 1 <= nums[i] <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Array construction
Build the answer by repeating the input sequence once more.

1. Return a new list that is nums followed by nums (or equivalently nums repeated twice).
2. Do not mutate the caller's list in place.

## Complexity

**Time:** O(n) - Each of the n elements is copied twice into the result.

**Space:** O(n) - The output holds 2n integers; extra space beyond output is O(n) for the copy.

## Solution

````python
from typing import List


class Solution:
    def getConcatenation(self, nums: List[int]) -> List[int]:
        return nums + nums


class SolutionWithExtend:
    """Same answer by extending the list in place (mutates the caller's list)."""

    def getConcatenation(self, nums: List[int]) -> List[int]:
        nums.extend(nums)
        return nums


class SolutionWithRepeat:
    """Same answer using sequence repetition (new list)."""

    def getConcatenation(self, nums: List[int]) -> List[int]:
        return nums * 2
````
