Given a list of characters chars, compress it in place: for each maximal run of
the same character, write the character once, then decimal digits of the run length
if the length exceeds one. Return the new logical length of the prefix that holds
the compressed form.

## Examples

````text
Example 1:
    Input: chars = ["a","a","b","b","c","c","c"]
    Output: 6
    Explanation: Prefix becomes ["a","2","b","2","c","3"].

Example 2:
    Input: chars = ["a"]
    Output: 1

Example 3:
    Input: chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
    Output: 4
    Explanation: Prefix ["a","b","1","2"].
````

## Constraints

````text
- 1 <= len(chars) <= 2000
- chars[i] is a lowercase English letter, uppercase English letter, digit, or symbol.
````

## Approach

**Pattern:** Two pointers (read / write)
One pointer scans groups; another writes the compact encoding without extra arrays.

1. Walk i through chars, measuring each equal run length.
2. Write the character at write index, then write each digit of count as characters if count &gt; 1.
3. Advance i past the run and repeat until the string is exhausted.
4. Return the final write index.

## Complexity

**Time:** O(n) - Single pass over chars.

**Space:** O(1) - Only index variables besides the required in-place output.

## Solution

````python
from typing import List


class Solution:
    def compress(self, chars: List[str]) -> int:
        n = len(chars)
        write = 0  # next position to write in the compressed prefix
        i = 0  # read head
        while i < n:
            curr = chars[i]
            count = 0
            while i < n and chars[i] == curr:  # measure full run of ``curr``
                i += 1
                count += 1
            chars[write] = curr
            write += 1
            if count > 1:
                for ch in str(count):  # multi-digit counts split into separate slots
                    chars[write] = ch
                    write += 1
        return write
````
