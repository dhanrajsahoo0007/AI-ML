Given a valid parentheses string s that may contain digits and operators, return the maximum
nesting depth of parentheses in s (number of '(' opened before a matching ')' at deepest point).

## Examples

````text
Example 1:
    Input: s = "(1+(2*3)+((8)/4))+1"
    Output: 3

Example 2:
    Input: s = "(1)+((2))+(((3)))"
    Output: 3

Example 3:
    Input: s = "()(())((()()))"
    Output: 3
````

## Constraints

````text
- 1 <= len(s) <= 100
- s is a valid parentheses string with only digits, '+', '-', '*', '/', '(', and ')'
````
