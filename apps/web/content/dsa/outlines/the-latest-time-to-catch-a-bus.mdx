You are given integer arrays buses (departure times) and passengers (arrival times), and an integer
capacity per bus. Buses leave in sorted time order; each passenger with arrival time &lt;= departure
boards the earliest available bus until full. Choose the latest integer arrival time for you so
you still board, assuming you are not in passengers initially.

## Examples

````text
Example 1:
    Input: buses = [10,20], passengers = [2,17,18,19], capacity = 2
    Output: 16

Example 2:
    Input: buses = [20,30,10], passengers = [19,13,26,4,25,11,21], capacity = 2
    Output: 20

Example 3:
    Input: buses = [3], passengers = [2,4], capacity = 2
    Output: 3
````

## Constraints

````text
- 1 <= buses.length, passengers.length <= 10^5
- 2 <= capacity <= 10^9
- 1 <= buses[i], passengers[i] <= 10^9
````

## Approach

**Pattern:** Greedy Simulation + Backtrack
Simulate boarding in time order while tracking the latest gap before a passenger arrival; if a bus has space after loading, its departure time may be feasible.

1. Sort buses and passengers.
2. For each bus, fill with passengers arriving by that departure until capacity.
3. Track latest candidate time just before each boarded passenger when that slot is free.
4. If a bus is not full after boarding and its departure is not already taken, you may arrive exactly then.

## Complexity

**Time:** O(n log n + m log m) for sorting plus linear scan.

**Space:** O(1) extra beyond sorting buffers.

## Original notes

````text
Storyboard (merged from the original long comment):
- Buses depart at fixed times; passengers board in chronological order until a bus fills.
- Whenever passenger `p` boards, the timestamp `p - 1` is a candidate arrival for you
  **unless** another passenger already occupies that second (`prev` tracks the last
  filled timestamp to enforce uniqueness).
- If a bus still has free seats after loading everyone who arrived early enough, you
  might hop on exactly at `dep` — but not if someone already arrived at that same time,
  because you were not part of the original passenger list.
````

## Solution

````python
from typing import List


class Solution:
    def latestTimeCatchTheBus(self, buses: List[int], passengers: List[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        p = 0
        prev = -1  # last timestamp that is definitely occupied by an existing passenger
        ans = 0
        for dep in buses:
            taken = 0
            while p < len(passengers) and passengers[p] <= dep and taken < capacity:
                # Try to slip in one second before this passenger if that second is still free.
                if passengers[p] - 1 != prev:
                    ans = passengers[p] - 1
                prev = passengers[p]
                p += 1
                taken += 1
            if taken < capacity and prev != dep:
                # Bus not full → riding exactly at departure might still be possible.
                ans = dep
        return ans
````
