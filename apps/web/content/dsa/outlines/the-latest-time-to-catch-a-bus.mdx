You are given integer arrays buses (departure times) and passengers (arrival times), and an integer
capacity per bus. Buses leave in sorted time order; each passenger with arrival time &lt;= departure
boards the earliest available bus until full. Choose the latest integer arrival time for you so
you still board, assuming you are not in passengers initially.

## Examples

````text
Example 1:
    Input: buses = [10,20], passengers = [2,17,18,19], capacity = 2
    Output: 16

Example 2:
    Input: buses = [20,30,10], passengers = [19,13,26,4,25,11,21], capacity = 2
    Output: 20

Example 3:
    Input: buses = [3], passengers = [2,4], capacity = 2
    Output: 3
````

## Constraints

````text
- 1 <= buses.length, passengers.length <= 10^5
- 2 <= capacity <= 10^9
- 1 <= buses[i], passengers[i] <= 10^9
````
