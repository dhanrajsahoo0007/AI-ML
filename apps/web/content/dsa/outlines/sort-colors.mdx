Given an array nums with n objects colored red, white, or blue, sort them in-place so that objects of the
same color are adjacent with the order red, then white, then blue. Use integers 0, 1, and 2 to represent
each color and do not use the library sort function.

## Examples

````text
Example 1:
    Input: nums = [2, 0, 2, 1, 1, 0]
    Output: [0, 0, 1, 1, 2, 2]
Example 2:
    Input: nums = [2, 0, 1]
    Output: [0, 1, 2]
````

## Constraints

````text
- n == len(nums)
- 1 <= n <= 300
- nums[i] is 0, 1, or 2.
````
