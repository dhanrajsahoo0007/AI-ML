Given two sorted arrays nums1 and nums2, return the median of the combined multiset (O(log(m+n)) target).

## Examples

````text
Example 1:
Input: nums1 = [1, 3], nums2 = [2]
Output: 2.0
````

## Constraints

````text
- 1 <= len(nums1) + len(nums2) <= 2000
````

## Approach

**Pattern:** Binary Partition (two sorted arrays)
Partition the shorter array so left halves contain half the total elements and max(left) &lt;= min(right).

1. Binary search partition on the shorter array.
2. Derive complementary partition on the other array; adjust until boundary values interleave.

## Complexity

**Time:** O(log(min(m, n))) - Search on shorter array only.

**Space:** O(1) - A few scalars and comparisons.

Given two sorted arrays nums1 and nums2 of size m and n respectively, return the median of the two sorted arrays.

The overall run time complexity should be O(log (m+n)).

Example 1:

Input: nums1 = \[1,3\], nums2 = \[2\]
Output: 2.00000
Explanation: merged array = \[1,2,3\] and median is 2.
Example 2:

Input: nums1 = \[1,2\], nums2 = \[3,4\]
Output: 2.50000
Explanation: merged array = \[1,2,3,4\] and median is (2 + 3) / 2 = 2.5.

Constraints:

nums1.length == m
nums2.length == n
0 &lt;= m &lt;= 1000
0 &lt;= n &lt;= 1000
1 &lt;= m + n &lt;= 2000
-106 &lt;= nums1\[i\], nums2\[i\] &lt;= 106

## Solution

````python
from typing import List


class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        total = m + n
        half = (total + 1) // 2
        lo, hi = 0, m
        while lo <= hi:
            px = (lo + hi) // 2
            py = half - px
            max_left_x = float("-inf") if px == 0 else nums1[px - 1]
            min_right_x = float("inf") if px == m else nums1[px]
            max_left_y = float("-inf") if py == 0 else nums2[py - 1]
            min_right_y = float("inf") if py == n else nums2[py]
            if max_left_x <= min_right_y and max_left_y <= min_right_x:
                if total % 2:
                    return float(max(max_left_x, max_left_y))
                return (max(max_left_x, max_left_y) + min(min_right_x, min_right_y)) / 2.0
            if max_left_x > min_right_y:
                hi = px - 1
            else:
                lo = px + 1
        raise ValueError("arrays must be sorted")
````
