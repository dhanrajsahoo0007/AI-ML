In a party of n people labeled 0..n-1, a celebrity is known by everyone but knows nobody.
You may query knows(a,b) (whether a knows b). Find the celebrity if unique, else -1.

## Examples

````text
Example 1:
Input: n = 3, celebrity = 1 (knows matrix implies person 1 is celebrity)
Output: 1
````

## Constraints

````text
- 2 <= n <= 100
- Exactly one celebrity if exists
````
