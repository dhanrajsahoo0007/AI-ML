Store string values by key and timestamp. set always uses strictly increasing timestamps per key.
get returns the value for the greatest timestamp\_prev &lt;= given timestamp, or empty string.

## Examples

````text
Example 1:
set(foo, bar, 1); get(foo,1)->bar; get(foo,3)->bar; set(foo, bar2, 4); get(foo,4)->bar2
````

## Constraints

````text
- 1 <= timestamp <= 10^7
- At most 2 * 10^5 calls
````
