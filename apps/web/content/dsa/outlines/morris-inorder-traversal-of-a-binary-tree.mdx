Return the inorder traversal of a binary tree using Morris traversal (O(1) extra space, tree temporarily threaded).

## Examples

````text
Example 1:
Input: root = [1,2,3,4,5]
Output: [4,2,5,1,3]
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
````
