Given an undirected graph with V vertices (0..V-1) and a list of edges, determine whether the graph
contains any cycle. The graph may be disconnected.

## Examples

````text
Example 1:
    Input: V = 5, edges = [[0,1],[1,2],[2,3],[3,4],[4,1]]
    Output: True
Example 2:
    Input: V = 4, edges = [[0,1],[1,2],[2,3]]
    Output: False
````

## Constraints

````text
- 1 <= V, number of edges <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** DFS cycle detection (parent tracking)
In an undirected graph, a back edge to a visited vertex that is not the parent implies a cycle.

1. Build adjacency lists.
2. For each unvisited component, DFS from a start node with parent -1.
3. If a neighbor is visited and not the parent, return True; else recurse on unvisited neighbors.

## Complexity

**Time:** O(V + E)

**Space:** O(V + E) for the graph and O(V) for visited / recursion stack.

## Solution

````python
from typing import List


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        return adj

    def has_cycle(self, V: int, adj: List[List[int]]) -> bool:
        visited = [False] * V

        def dfs(u: int, parent: int) -> bool:
            visited[u] = True
            for v in adj[u]:
                if v == parent:
                    continue
                if visited[v]:
                    return True
                if dfs(v, u):
                    return True
            return False

        for i in range(V):
            if not visited[i] and dfs(i, -1):
                return True
        return False
````
