Given an array of meeting intervals \[start\_i, end\_i\] with start\_i &lt; end\_i, determine
whether one person can attend all meetings without overlap. Meetings that touch at an
endpoint (end of one equals start of another) are not conflicts.

## Examples

````text
Example 1:
    Input: intervals = [[0,30],[5,10],[15,20]]
    Output: false

Example 2:
    Input: intervals = [[5,8],[9,15]]
    Output: true
````

## Constraints

````text
- 0 <= len(intervals) <= 500
- 0 <= start_i < end_i <= 10^6
````
