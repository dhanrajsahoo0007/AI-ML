Books have page counts in order. Assign contiguous books to m students so each gets at least one
book and the maximum total pages assigned to any student is minimized. Return that minimum, or -1
if m &gt; number of books.

## Examples

````text
Example 1:
Input: arr = [12, 34, 67, 90], m = 2
Output: 113
````

## Constraints

````text
- 1 <= m, len(arr) <= 10^3 (typical competitive bounds)
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Answer (minimize maximum load)
Feasible if m or fewer students suffice when each is capped at mid pages (greedy partition).

1. If m &gt; n return -1. Search cap in \[max(arr), sum(arr)\].
2. Count students needed with greedy linear scan; compare to m.

## Complexity

**Time:** O(n log S) - S = total pages.

**Space:** O(1) - Greedy only.

## Solution

````python
from typing import List


class Solution:
    def findPages(self, arr: List[int], n: int, m: int) -> int:
        if m > n:
            return -1

        def students_needed(cap: int) -> int:
            s = 1
            load = 0
            for pages in arr:
                if pages > cap:
                    return m + 1
                if load + pages > cap:
                    s += 1
                    load = pages
                else:
                    load += pages
                if s > m:
                    return s
            return s

        lo, hi = max(arr), sum(arr)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if students_needed(mid) <= m:
                hi = mid
            else:
                lo = mid + 1
        return lo
````
