Given a binary tree and two nodes p and q, return their lowest common ancestor (LCA).
A node may be a descendant of itself.

## Examples

````text
Example 1:
    Tree [3,5,1,6,2,0,8,None,None,7,4], p=5, q=1 -> LCA 3
Example 2:
    Same tree, p=5, q=4 -> LCA 5
````

## Constraints

````text
- All values unique; p and q exist and differ.
````
