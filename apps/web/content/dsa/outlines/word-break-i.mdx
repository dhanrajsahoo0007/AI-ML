Given a string s and a list of words wordDict, determine if s can be segmented
into a sequence of one or more dictionary words separated without extra letters.
Words may be reused.

## Examples

````text
Example 1:
    Input: s = "leetcode", wordDict = ["leet", "code"]
    Output: True
Example 2:
    Input: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
    Output: False
````

## Constraints

````text
- 1 <= len(s) <= 300
- 1 <= len(wordDict) <= 1000
- 1 <= len(wordDict[i]) <= 20
````
