Robot starts top-left of an m x n grid, moves only right or down. Count paths
to bottom-right.

## Examples

````text
Example 1: m=3,n=7 -> 28
Example 2: m=3,n=2 -> 3
````

## Constraints

````text
- 1 <= m,n <= 100
````

<PremiumBreak />

## Approach

**Pattern:** 2D grid DP
dp\[i\]\[j\]=dp\[i-1\]\[j\]+dp\[i\]\[j-1\].

1. Initialize first row/col to 1.
2. Fill interior.

## Complexity

**Time:** O(m\*n). Space: O(n) with one row.

## Solution

````python
from typing import List


class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        row = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                row[j] += row[j - 1]
        return row[-1]
````
