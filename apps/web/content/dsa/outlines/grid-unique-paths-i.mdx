Robot starts top-left of an m x n grid, moves only right or down. Count paths
to bottom-right.

## Examples

````text
Example 1: m=3,n=7 -> 28
Example 2: m=3,n=2 -> 3
````

## Constraints

````text
- 1 <= m,n <= 100
````
