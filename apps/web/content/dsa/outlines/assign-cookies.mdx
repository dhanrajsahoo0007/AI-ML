You are the parent with cookies and children. Each child i has a greed factor g\[i\] (minimum
cookie size needed to be happy). Each cookie j has size s\[j\]. If s\[j\] &gt;= g\[i\], assign that
cookie to the child (each child gets at most one cookie). Maximize the number of happy children.

## Examples

````text
Example 1:
    Input: g = [1,2,3], s = [1,1]
    Output: 1

Example 2:
    Input: g = [1,2], s = [1,2,3]
    Output: 2

Example 3:
    Input: g = [10, 11], s = [1, 2, 3]
    Output: 0
````

## Constraints

````text
- 1 <= g.length <= 3 * 10^4
- 0 <= s.length <= 3 * 10^4
- 1 <= g[i], s[j] <= 2^31 - 1
````
