Manage a single conference room. book(start, end) tries to reserve the closed interval
\[start, end\]. Touching at an endpoint is allowed (e.g. \[10, 20\] and \[20, 30\] do not overlap).
Return True if booked, False if the new interval overlaps any existing booking.

## Examples

````text
Example 1:
book(10, 20) -> True; book(20, 30) -> True; book(5, 15) -> False (overlaps [10,20]).
````

## Constraints

````text
- Intervals are on a 1D time axis; treat overlap as max(s1, s2) < min(e1, e2) for [s,e].
````

<PremiumBreak />

## Approach

**Pattern:** Merge / ordered storage
Keep sorted intervals or check overlap against stored bookings in O(n) or tree structure.

1. Store booked intervals in a list (small n) or sorted structure.
2. For each new \[s, e\], if it overlaps any stored \[a, b\], return False.
3. Otherwise append and return True.

## Complexity

**Time:** O(k) per book with k existing bookings; can be O(log k) with interval tree.

**Space:** O(k) for k stored intervals.

## Solution

````python
from typing import List, Tuple


class ConferenceRoom:
    def __init__(self) -> None:
        self._bookings: List[Tuple[int, int]] = []

    @staticmethod
    def _overlaps(a: int, b: int, c: int, d: int) -> bool:
        """True iff closed intervals [a,b] and [c,d] overlap with positive length."""
        return max(a, c) < min(b, d)

    def book(self, start: int, end: int) -> bool:
        for s, e in self._bookings:
            if self._overlaps(start, end, s, e):
                return False
        self._bookings.append((start, end))
        return True
````
