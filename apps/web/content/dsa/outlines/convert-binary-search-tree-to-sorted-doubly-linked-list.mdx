Convert a binary search tree into a sorted circular doubly-linked list in place: left and right
pointers represent predecessor and successor links, and the list wraps head to tail.

## Examples

````text
Example 1:
    Input: BST [4,2,5,1,3]
    Output: circular DLL ordered 1-2-3-4-5

Example 2:
    Input: single node
    Output: node's left and right point to itself
````

## Constraints

````text
- The number of nodes is in the range [0, 1000].
````
