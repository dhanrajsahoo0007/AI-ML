Given sorted distinct letters and a target letter, return the smallest letter strictly larger than
target. Letters are circular: if none is larger, return the first letter.

## Examples

````text
Example 1:
    Input: letters = ['a', 'c', 'f', 'h'], target = 'f'
    Output: 'h'

Example 2:
    Input: letters = ['a', 'c', 'f', 'h'], target = 'h'
    Output: 'a'
````

## Constraints

````text
- 2 <= len(letters) <= 10^4
- letters contains only lowercase English letters and is sorted
````
