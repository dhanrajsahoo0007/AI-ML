Decode strings of the form k\[encoded\_string\], allowing nesting, into the expanded plaintext.

## Examples

````text
Example 1:
Input: "3[a]2[bc]"
Output: "aaabcbc"
````

## Constraints

````text
- 1 <= len(s) <= 30
- k is positive and digits may span multiple characters
````

<PremiumBreak />

## Approach

**Pattern:** Stack Expansion
Push literals and numbers until '\]', then pop the inner string and multiplier to push the repeat.

1. Walk characters; push everything except '\]'.
2. On '\]', pop letters until '\[', pop digits to build k, push k copies back.
3. Join the final stack.

## Complexity

**Time:** O(output length) - Proportional to decoded size.

**Space:** O(n) - Stack holds partial fragments.

## Solution

````python
class Solution:
    def decodeString(self, s: str) -> str:
        stack: list[str] = []
        for ch in s:
            if ch != "]":
                stack.append(ch)
                continue
            fragment: list[str] = []
            while stack[-1] != "[":
                fragment.append(stack.pop())
            stack.pop()
            repeat = ""
            while stack and stack[-1].isdigit():
                repeat = stack.pop() + repeat
            stack.append(int(repeat) * "".join(reversed(fragment)))
        return "".join(stack)
````
