Sort integers with quicksort: partition around a pivot so smaller elements sit
left and larger sit right, then recurse on both sides.

## Examples

````text
Example 1:
Input: [3, 1, 2]
Output: [1, 2, 3]
````

## Constraints

````text
- Elements are orderable; duplicates allowed
````

<PremiumBreak />

## Approach

**Pattern:** Divide and conquer with partitioning
Choose a pivot, partition in linear time, recursively sort subarrays.

1. Base case: length &lt;= 1.
2. Pick pivot (last element), partition into less, equal, greater lists.
3. Return quick\_sort(less) + equal + quick\_sort(greater).

## Complexity

**Time:** O(n log n) average, O(n^2) worst (skewed pivots)

**Space:** O(n) auxiliary for partitions plus O(log n) stack average

## Solution

````python
from typing import List


class Solution:
    def quick_sort(self, nums: List[int]) -> List[int]:
        if len(nums) <= 1:
            return list(nums)
        pivot = nums[-1]
        less = [x for x in nums[:-1] if x < pivot]
        equal = [x for x in nums if x == pivot]
        greater = [x for x in nums[:-1] if x > pivot]
        return self.quick_sort(less) + equal + self.quick_sort(greater)
````
