You have information about recipes (ingredient lists) and a list of supplies you already have.
A recipe can be made if you have all its ingredients (including recipes produced earlier).
Return all recipes you can eventually make.

## Examples

````text
Example 1:
    Input: recipes = ["bread"], ingredients = [["yeast","flour"]],
           supplies = ["yeast","flour","corn"]
    Output: ["bread"]
Example 2:
    Input: recipes = ["bread","sandwich"], ingredients = [["yeast","flour"],["bread","meat"]],
           supplies = ["yeast","flour","meat"]
    Output: ["bread","sandwich"]
````

## Constraints

````text
- 1 <= len(recipes) <= 100
- ingredients[i] lists are non-empty
````

## Approach

**Pattern:** Graph - Topological sort (Kahn) on recipe dependency DAG

1. Map recipe name to index; count missing ingredients per recipe; build adjacency from
ingredient to recipes waiting on it.
2. Start queue with supplies; when an ingredient becomes available, decrement indegree of
waiting recipes; output recipe when indegree hits 0.

## Complexity

**Time:** O(total string lengths + edges).

**Space:** O(total sizes).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def findAllRecipes(self, recipes: List[str], ingredients: List[List[str]], supplies: List[str]) -> List[str]:
        need = defaultdict(list)
        indeg = {}
        for r, ing in zip(recipes, ingredients):
            indeg[r] = len(ing)
            for x in ing:
                need[x].append(r)

        q = deque(supplies)
        recipes_set = set(recipes)
        made = []

        while q:
            x = q.popleft()
            for r in need[x]:
                indeg[r] -= 1
                if indeg[r] == 0:
                    made.append(r)
                    q.append(r)
        return made
````
