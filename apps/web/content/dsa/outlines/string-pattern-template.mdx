Given an alphabet list and a length n, return all strings of length n formed by choosing
one character at each position (Cartesian product / telephone-style enumeration).

## Examples

````text
Example 1:
Input: chars = ["a", "b"], n = 2
Output: ["aa","ab","ba","bb"] (order may vary)
````

## Constraints

````text
- 1 <= len(chars) <= 5
- 0 <= n <= 4
````

<PremiumBreak />

## Approach

**Pattern:** String building by index backtracking
Fix position by position; at each depth try every allowed character, then backtrack.

1. If index == n, append the built string and return.
2. For each character in chars, recurse with index + 1 and extended string.

## Complexity

**Time:** O(len(chars)^n \* n) - strings counted, each length n.

**Space:** O(n) - recursion depth and active string excluding output.

## Solution

````python
from typing import List


class Solution:
    def buildStrings(self, chars: List[str], n: int) -> List[str]:
        if n == 0:
            return [""]
        result: List[str] = []

        def backtrack(i: int, cur: List[str]) -> None:
            if i == n:
                result.append("".join(cur))
                return
            for ch in chars:
                cur.append(ch)
                backtrack(i + 1, cur)
                cur.pop()

        backtrack(0, [])
        return result
````
