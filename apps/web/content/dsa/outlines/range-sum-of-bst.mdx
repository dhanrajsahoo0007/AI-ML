Given the root of a binary search tree and integers low and high, return the sum of values
of every node whose value lies in the inclusive range \[low, high\].

## Examples

````text
Example 1:
    Input: root = [10,5,15,3,7,null,18], low = 7, high = 15
    Output: 32

Example 2:
    Input: empty tree, low = 1, high = 10
    Output: 0
````

## Constraints

````text
- The number of nodes is in the range [0, 2 * 10^4].
- 1 <= Node.val <= 10^5 (typical LeetCode bounds); low and high fit in the same range.
````
