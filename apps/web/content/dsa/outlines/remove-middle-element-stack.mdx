Remove the middle element from a stack represented as a list (top at the end)
using recursion only—no index-based middle removal without recursion.

## Examples

````text
Example 1:
    Input: [1, 2, 3, 4, 5] (bottom to top)
    Output: [1, 2, 4, 5] (3 removed)

Example 2:
    Input: [1, 2, 3, 4, 5, 6]
    Output: [1, 2, 4, 5, 6] (element 3 removed)
````

## Constraints

````text
- Stack non-empty for meaningful removal; empty stack is a no-op
````

<PremiumBreak />

## Approach

**Pattern:** Recursion with stack unwinding
Pop elements until the middle depth is reached, drop that element, then push
stored elements back to preserve order.

1. Fix n = initial size and mid = n // 2 (index of removed element counting from the top pops).
2. Pop top, recurse until current reaches n (stack empty), then unwind.
3. While unwinding, skip re-pushing the element popped when current == mid.

## Complexity

**Time:** O(n) - each element pushed/popped a constant number of times

**Space:** O(n) - recursion depth

## Solution

````python
from typing import List


class Solution:
    def delete_middle(self, stack: List[int]) -> None:
        if not stack:
            return
        n = len(stack)
        mid = n // 2

        def recurse(current: int) -> None:
            if not stack or current == n:
                return
            temp = stack.pop()
            recurse(current + 1)
            if current != mid:
                stack.append(temp)

        recurse(0)
````
