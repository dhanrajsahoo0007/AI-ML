Swap two integers without using a third temporary variable and return them in
(a, b) order after swapping.

## Examples

````text
Example 1:
Input: a = 2, b = 3
Output: (3, 2)
````

## Constraints

````text
- Values fit in Python arbitrary-precision integers
````

<PremiumBreak />

## Approach

**Pattern:** XOR swap
Three XORs exchange values when a and b refer to distinct storage locations.

1. a ^= b; b ^= a; a ^= b.
2. Return (a, b).

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
from typing import Tuple


class Solution:
    def swap(self, a: int, b: int) -> Tuple[int, int]:
        a ^= b
        b ^= a
        a ^= b
        return a, b
````
