Given a circular integer array nums, return the next greater element for every index, searching
forward in the circular sense. Use -1 when no greater element exists.

## Examples

````text
Example 1:
Input: [1, 2, 1]
Output: [2, -1, 2]
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -10^9 <= nums[i] <= 10^9
````
