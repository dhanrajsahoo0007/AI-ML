Given the root of a binary search tree and an integer key, delete the node with value key
if it exists, and return the root of the possibly updated tree.

## Examples

````text
Example 1:
    Input: root = [5,3,6,2,4,null,7], key = 3
    Output: valid BST without the node 3 (any valid restructuring is allowed).

Example 2:
    Input: root = [5,3,6,2,4,null,7], key = 0
    Output: unchanged tree (key not present).
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
- Each node has a distinct value in typical formulations; here deletion follows standard BST rules.
````
