For each query value, reset nums to its original multiset and compute the minimum total increment or
decrement operations (cost 1 per unit) to make every element equal to that query.

## Examples

````text
Example 1:
Input: nums = [3, 1, 6, 8], queries = [1, 5]
Output: [14, 10]
````

## Constraints

````text
- 1 <= len(nums), len(queries) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Sort + Prefix Sum + Binary Search
Sort nums; for query q, split into elements &lt; q and &gt; q; costs use prefix sums and index counts.

1. Sort nums and build prefix sums.
2. For each q, bisect\_left for split index; left cost = q \* i - pref\[i\], right cost = (pref\[n\]-pref\[i\]) - q \* (n-i).

## Complexity

**Time:** O((n + m) log n) - Sort once, each query O(log n).

**Space:** O(n) - Prefix array.

## Solution

````python
from bisect import bisect_left
from typing import List


class Solution:
    def minOperations(self, nums: List[int], queries: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + nums[i]
        out: List[int] = []
        for q in queries:
            i = bisect_left(nums, q)
            left_ops = q * i - pref[i]
            right_ops = (pref[n] - pref[i]) - q * (n - i)
            out.append(left_ops + right_ops)
        return out
````
