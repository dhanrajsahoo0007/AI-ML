For each query value, reset nums to its original multiset and compute the minimum total increment or
decrement operations (cost 1 per unit) to make every element equal to that query.

## Examples

````text
Example 1:
Input: nums = [3, 1, 6, 8], queries = [1, 5]
Output: [14, 10]
````

## Constraints

````text
- 1 <= len(nums), len(queries) <= 10^5
````
