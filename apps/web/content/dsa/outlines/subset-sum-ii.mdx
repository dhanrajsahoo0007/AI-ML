Given nums that may contain duplicates, return all subsets without duplicate subsets.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 2]
    Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]

Example 2:
    Input: nums = [0]
    Output: [[],[0]]
````

## Constraints

````text
- 1 <= len(nums) <= 10
- -10 <= nums[i] <= 10
````

<PremiumBreak />

## Approach

**Pattern:** Subset backtracking with duplicate skipping
Sort nums; skip nums\[i\] when it equals nums\[i-1\] at the same recursion depth.

1. Sort the array so equal values are adjacent.
2. At each level, skip index i if i &gt; start and nums\[i\] == nums\[i - 1\].
3. Otherwise include nums\[i\] and recurse with start = i + 1.

## Complexity

**Time:** O(n \* 2^n) worst case; duplicate skipping reduces work.

**Space:** O(n) - recursion depth.

## Solution

````python
from typing import List


class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        result: List[List[int]] = []

        def backtrack(start: int, path: List[int]) -> None:
            result.append(path[:])
            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])
                backtrack(i + 1, path)
                path.pop()

        backtrack(0, [])
        return result
````
