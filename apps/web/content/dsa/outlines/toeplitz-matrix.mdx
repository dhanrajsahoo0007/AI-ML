Given an m x n integer matrix, return True if the matrix is Toeplitz.
A matrix is Toeplitz if every diagonal from top-left to bottom-right has the same value.

## Examples

````text
Example 1:
    Input: matrix = [[1,2,3,4],[5,1,2,3],[9,5,1,2]]
    Output: True
    Explanation: Each top-left-to-bottom-right diagonal is constant.

Example 2:
    Input: matrix = [[1,2],[2,2]]
    Output: False
    Explanation: The main diagonal [1,2] is not constant.
````

## Constraints

````text
- 1 <= m, n <= 20
- 0 <= matrix[i][j] <= 99
````

## Approach

**Pattern:** Constant diagonals
Compare each cell to its neighbor one step up-left; all matches imply Toeplitz.

1. For each cell (i, j) with i &gt; 0 and j &gt; 0, require matrix\[i\]\[j\] == matrix\[i-1\]\[j-1\].
2. If any comparison fails, return False; otherwise return True.

## Complexity

**Time:** O(m \* n) - Each interior cell is checked once.

**Space:** O(1) - Only index variables are used.

## Solution

````python
from typing import List


class Solution:
    def isToeplitzMatrix(self, matrix: List[List[int]]) -> bool:
        m = len(matrix)
        n = len(matrix[0])
        # Start from (1,1): compare each cell to the element diagonally up-left.
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] != matrix[i - 1][j - 1]:
                    return False  # broken diagonal
        return True
````
