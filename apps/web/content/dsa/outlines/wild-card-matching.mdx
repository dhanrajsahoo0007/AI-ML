Given text s and pattern p where '?' matches any single character and '\*'
matches any sequence (including empty), return whether the full pattern matches
the full string.

## Examples

````text
Example 1:
    Input: s = "aa", p = "a"
    Output: False
Example 2:
    Input: s = "cb", p = "?a"
    Output: False
````

## Constraints

````text
- 0 <= len(s), len(p) <= 2000
````

<PremiumBreak />

## Approach

**Pattern:** 2D DP on string vs pattern
dp\[i\]\[j\] means s\[:i\] matches p\[:j\]; star can consume 0..remaining chars.

1. Initialize dp\[0\]\[j\] for leading stars in pattern.
2. Fill using equality, '?', or '\*' branch taking OR of skip star or consume char.

## Complexity

**Time:** O(m \* n).

**Space:** O(m \* n).

## Solution

````python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True
        for j in range(1, n + 1):
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 1]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == "*":
                    dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
                elif p[j - 1] == "?" or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
        return dp[m][n]
````
