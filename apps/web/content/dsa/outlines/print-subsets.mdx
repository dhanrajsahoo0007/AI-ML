Given a string, generate all non-empty subsequences (same relative order, any
subset of characters). Distinct positions count separately (e.g. "aa" yields two
single-letter subsequences).

## Examples

````text
Example 1:
    Input: "abc"
    Output: sorted multiset of 7 non-empty strings

Example 2:
    Input: "aa"
    Output: ["a", "a", "aa"]
````

## Constraints

````text
- Length modest for exponential output (tests use n <= 4)
````
