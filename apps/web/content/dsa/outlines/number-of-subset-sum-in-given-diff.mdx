Given an array of non-negative integers and integer diff, count partitions into
two subsets S1 and S2 (using every element exactly once) such that
sum(S1) - sum(S2) = diff.

## Examples

````text
Example 1:
    Input: nums = [1, 1, 2, 3], diff = 1
    Output: 3
Example 2:
    Input: nums = [2, 2, 2, 2], diff = 0
    Output: 6
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 0 <= nums[i] <= 1000
- -1000 <= diff <= 1000
````
