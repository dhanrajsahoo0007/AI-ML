Given a bitonic array (strictly increasing then strictly decreasing) and a target, return its index
or -1.

## Examples

````text
Example 1:
    Input: mountain = [1, 3, 8, 12, 4, 2], target = 4
    Output: 4

Example 2:
    Input: mountain = [1, 3, 8, 12, 9, 5, 2], target = 7
    Output: -1
````

## Constraints

````text
- 3 <= len(mountain) <= 10^4
- -10^9 <= mountain[i] <= 10^9
````
