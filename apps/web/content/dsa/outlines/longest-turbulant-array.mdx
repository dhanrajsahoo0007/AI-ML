Given an integer array arr, return the length of the longest turbulent subarray, where comparisons
between adjacent elements strictly alternate between &gt; and &lt; (equality breaks turbulence).

## Examples

````text
Example 1:
    Input: arr = [9,4,2,10,7,8,8,1,9]
    Output: 5

Example 2:
    Input: arr = [4,8,12,16]
    Output: 2

Example 3:
    Input: arr = [100]
    Output: 1
````

## Constraints

````text
- 1 <= arr.length <= 4 * 10^4
- 0 <= arr[i] <= 10^9
````
