You are given an integer array nums where nums\[i\] is the maximum jump length from index i.
Starting at index 0, determine whether you can reach the last index.

## Examples

````text
Example 1:
    Input: nums = [2,3,1,1,4]
    Output: True

Example 2:
    Input: nums = [3,2,1,0,4]
    Output: False

Example 3:
    Input: nums = [0]
    Output: True
````

## Constraints

````text
- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 10^5
````
