Given a digit string num and integer target, insert +, -, or \* between digits (no reordering)
so the expression evaluates to target; return all such expressions without leading zeros on
multi-digit operands.

## Examples

````text
Example 1:
Input: num = "123", target = 6
Output: ["1*2*3","1+2+3"]
````

## Constraints

````text
- 1 <= len(num) <= 10
- Operands fit in 64-bit evaluation for tests below
````

<PremiumBreak />

## Approach

**Pattern:** DFS with multiplication tail
Track running sum and last operand so \* can replace the previous additive contribution.

1. DFS chooses the next number span and operator (none for first number).
2. For \* update sum as sum - last + last \* cur; set last to last \* cur.
3. Prune leading-zero multi-digit spans.

## Complexity

**Time:** O(4^n \* n) branching across splits and operators.

**Space:** O(n) recursion depth.

## Solution

````python
from typing import List


class Solution:
    def addOperators(self, num: str, target: int) -> List[str]:
        result: List[str] = []

        def dfs(index: int, path: List[str], total: int, last: int) -> None:
            if index == len(num):
                if total == target:
                    result.append("".join(path))
                return
            for j in range(index, len(num)):
                if j > index and num[index] == "0":
                    break
                cur_str = num[index : j + 1]
                cur = int(cur_str)
                if not path:
                    dfs(j + 1, [cur_str], cur, cur)
                else:
                    dfs(j + 1, path + ["+", cur_str], total + cur, cur)
                    dfs(j + 1, path + ["-", cur_str], total - cur, -cur)
                    dfs(
                        j + 1,
                        path + ["*", cur_str],
                        total - last + last * cur,
                        last * cur,
                    )

        dfs(0, [], 0, 0)
        return result
````
