You are given a string word and an integer k. Each second you must remove the first
k characters of word and append any k characters to the end. Return the minimum
positive number of seconds after which the string can equal its initial value again.

## Examples

````text
Example 1:
    Input: word = "abacaba", k = 2
    Output: 2

Example 2:
    Input: word = "abcd", k = 2
    Output: 2

Example 3:
    Input: word = "aa", k = 2
    Output: 1
````

## Constraints

````text
- 1 <= len(word) <= 10^5
- 1 <= k <= len(word)
````
