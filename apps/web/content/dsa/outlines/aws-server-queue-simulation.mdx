AWS has a server processing requests in FIFO order. Each request has a maximum
waiting time. If not served within that time, the request expires and is removed.
At each second, the first request is processed. Find the queue size at every second.

## Examples

````text
Example 1:
    Input: wait = [2, 2, 3, 1]
    Output: [4, 2, 1, 0]

Example 2:
    Input: wait = [3, 1, 2, 1]
    Output: [4, 1, 0]

Example 3:
    Input: wait = [4, 4, 4]
    Output: [3, 2, 1, 0]
````

## Constraints

````text
- 1 <= n <= 10^5
- 1 <= wait[i] <= 10^5
````
