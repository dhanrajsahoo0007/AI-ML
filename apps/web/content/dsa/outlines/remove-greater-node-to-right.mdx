Remove every node that has a strictly larger value somewhere to its right.

## Examples

````text
Example 1:
    Input: head = [5,2,13,3,8]
    Output: [13,8]

Example 2:
    Input: head = [1,1,1,1]
    Output: [1,1,1,1]
````

## Constraints

````text
- 1 <= n <= 10^5
- 1 <= Node.val <= 10^5
````
