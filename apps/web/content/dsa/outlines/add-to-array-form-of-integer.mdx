Given a non-negative integer represented as a list of digits (most significant
first) and an integer k, return the array-form of their sum.

## Examples

````text
Example 1:
    Input: num = [1,2,0,0], k = 34
    Output: [1,2,3,4]
Example 2:
    Input: num = [2,7,4], k = 181
    Output: [4,5,5]
````

## Constraints

````text
- 1 <= len(num) <= 10^4
- 0 <= num[i] <= 9
- 0 <= k <= 10^4
````
