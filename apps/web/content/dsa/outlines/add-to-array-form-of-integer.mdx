Given a non-negative integer represented as a list of digits (most significant
first) and an integer k, return the array-form of their sum.

## Examples

````text
Example 1:
    Input: num = [1,2,0,0], k = 34
    Output: [1,2,3,4]
Example 2:
    Input: num = [2,7,4], k = 181
    Output: [4,5,5]
````

## Constraints

````text
- 1 <= len(num) <= 10^4
- 0 <= num[i] <= 9
- 0 <= k <= 10^4
````

## Approach

**Pattern:** School addition from the least significant digit
Process k with the tail of num while carrying.

1. Walk from the end of num, adding k % 10 and carry, then k //= 10.
2. After digits, fold remaining k with carry.
3. Reverse the collected digits.

## Complexity

**Time:** O(max(len(num), log10(k)))

**Space:** O(1) extra besides output

## Solution

````python
from typing import List


class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        i = len(num) - 1
        carry = 0
        out: List[int] = []
        while i >= 0 or k > 0 or carry:
            if i >= 0:
                carry += num[i]
                i -= 1
            carry += k % 10
            k //= 10
            out.append(carry % 10)
            carry //= 10
        return out[::-1]
````
