In a directed graph with n vertices labeled 0..n-1, a mother vertex is a vertex v such that
every other vertex is reachable from v. Given edges as \[u, v\] directed u -&gt; v, return any
mother vertex or -1 if none exists.

## Examples

````text
Example 1:
    Input: n = 5, edges = [[0,1],[1,2],[2,0],[2,3],[3,4]]
    Output: 2 (or any valid mother vertex)
Example 2:
    Input: n = 3, edges = [[0,1],[1,2]]
    Output: 0
````

## Constraints

````text
- 1 <= n <= 10^4
- 0 <= len(edges) <= 10^5
````
