You are given an integer array nums and an integer k. In one operation you may
increment any element by 1, at most k total increments across all operations. Return
the maximum achievable frequency of any single value after the operations.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 4], k = 5
    Output: 3
Example 2:
    Input: nums = [1, 4, 8, 13], k = 5
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- 1 <= nums[i], k <= 10^5
````

## Approach

**Pattern:** Sorted sliding window with operation budget
After sorting, a window is feasible if you can raise every element to nums\[right\] within k increments.

1. Sort a copy of nums so all values in a window are non-decreasing.
2. Expand the right edge while maintaining the sum of the current window.
3. If making every element in the window equal to the right endpoint costs more than k, shrink from the left.

The frequency of an element is the number of times it occurs in an array.

You are given an integer array nums and an integer k. In one operation, you can choose an index of nums and increment the element at that index by 1.

Return the maximum possible frequency of an element after performing at most k operations.

Example 1:

Input: nums = \[1,2,4\], k = 5
Output: 3
Explanation: Increment the first element three times and the second element two times to make nums = \[4,4,4\].
4 has a frequency of 3.
Example 2:

Input: nums = \[1,4,8,13\], k = 5
Output: 2
Explanation: There are multiple optimal solutions:
- Increment the first element three times to make nums = \[4,4,8,13\]. 4 has a frequency of 2.
- Increment the second element four times to make nums = \[1,8,8,13\]. 8 has a frequency of 2.
- Increment the third element five times to make nums = \[1,4,13,13\]. 13 has a frequency of 2.
Example 3:

Input: nums = \[3,9,6\], k = 2
Output: 1

Constraints:

1 &lt;= nums.length &lt;= 105
1 &lt;= nums\[i\] &lt;= 105
1 &lt;= k &lt;= 105

## Complexity

**Time:** O(n log n) - Sorting dominates; the scan across the sorted array is linear.

**Space:** O(n) - A sorted copy of the input is stored.

## Solution

````python
from typing import List


class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        nums_sorted = sorted(nums)
        left = 0
        total = 0
        best = 0

        for right in range(len(nums_sorted)):
            total += nums_sorted[right]

            while nums_sorted[right] * (right - left + 1) > total + k:
                total -= nums_sorted[left]
                left += 1

            best = max(best, right - left + 1)

        return best
````

### Approach

**Pattern:** Sliding Window + Sorting
Sort nums; for window \[L..R\], cost to raise all to nums\[R\] is nums\[R\]\*(R-L+1) - sum(window) &lt;= k.

1. Sort nums.
2. Expand R, add nums\[R\] to running sum; shrink L while cost exceeds k.
3. Track max window length.

### Complexity

**Time:** O(n log n) - Sort dominates; window scan is O(n).

**Space:** O(1) - Aside from sort in place.
