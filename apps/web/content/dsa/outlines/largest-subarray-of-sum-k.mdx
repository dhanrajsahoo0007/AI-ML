Given an integer array nums (which may contain negative values) and an integer k,
return the length of the longest contiguous subarray whose sum equals k.

## Examples

````text
Example 1:
    Input: nums = [10, 5, 2, -8, 8, 7, -2, 9], k = 7
    Output: 5
Example 2:
    Input: nums = [1, -1, 5, -2, 3], k = 3
    Output: 4
````

## Constraints

````text
- Negative numbers are allowed; a pure two-pointer positive-only approach is insufficient.
````
