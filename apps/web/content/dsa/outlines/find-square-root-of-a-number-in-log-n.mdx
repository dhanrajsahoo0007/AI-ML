Given a non-negative integer x, return the integer part of its square root (truncate toward zero)
without using library pow/sqrt.

## Examples

````text
Example 1:
    Input: x = 8
    Output: 2

Example 2:
    Input: x = 16
    Output: 4
````

## Constraints

````text
- 0 <= x <= 2^31 - 1
````
