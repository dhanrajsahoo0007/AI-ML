Given an integer array nums and an integer k, count the number of non-empty
subarrays whose sum is divisible by k.

## Examples

````text
Example 1:
Input: nums = [4, 5, 0, -2, -3, 1], k = 5
Output: 7
````

## Constraints

````text
- 1 <= len(nums) <= 3 * 10^4
- -10^4 <= nums[i] <= 10^4
- 2 <= k <= 10^4
````
