Given a string s, remove all adjacent duplicate letters repeatedly until no more
adjacent duplicates remain. Return the final string.

## Examples

````text
Example 1:
    Input: s = "abbaca"
    Output: "ca"
    Explanation: "abbaca" -> "aaca" -> "ca"

Example 2:
    Input: s = "azxxzy"
    Output: "ay"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s consists of lowercase English letters.
````
