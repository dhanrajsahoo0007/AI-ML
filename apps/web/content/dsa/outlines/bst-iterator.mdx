Design an iterator over a binary search tree that is initialized with the root. Implement
next() to return the next smallest element in ascending order, and hasNext() to indicate
whether another element exists.

## Examples

````text
Example 1:
Input: BST [7,3,15,null,null,9,20], call next/hasNext in order
Output values from next(): 3, 7, 9, 15, 20 then hasNext() is False
````

## Constraints

````text
- The number of nodes is in the range [0, 10^5].
- next() and hasNext() run in amortized O(1) time with a stack-based inorder simulation.
````
