Students queue for sandwiches stacked with types 0 or 1. The front student takes the top sandwich
if it matches preference; otherwise they rotate to the back. Return how many students remain hungry.

## Examples

````text
Example 1:
Input: students = [1, 1, 0, 0], sandwiches = [0, 1, 0, 1]
Output: 0
````

## Constraints

````text
- len(students) == len(sandwiches) <= 100
````
