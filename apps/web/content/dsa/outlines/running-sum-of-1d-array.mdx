Given an array nums, return the running sum of nums, where runningSum\[i\] =
sum(nums\[0\]..nums\[i\]) inclusive.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 4]
    Output: [1, 3, 6, 10]

Example 2:
    Input: nums = [1, 1, 1, 1, 1]
    Output: [1, 2, 3, 4, 5]
````

## Constraints

````text
- 1 <= len(nums) <= 1000
- -10^6 <= nums[i] <= 10^6
````
