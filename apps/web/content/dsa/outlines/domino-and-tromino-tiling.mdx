Given a 2 x n board, count ways to tile it with dominoes (2x1 or 1x2) and
trominoes (L-shaped triominoes), modulo 10^9 + 7.

## Examples

````text
Example 1:
    Input: n = 3
    Output: 5
Example 2:
    Input: n = 1
    Output: 1
````

## Constraints

````text
- 1 <= n <= 1000
````
