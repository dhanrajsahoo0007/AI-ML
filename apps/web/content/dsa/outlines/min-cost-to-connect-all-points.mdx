You are given an array of integer coordinates points where points\[i\] = \[xi, yi\] represents
the location of the i-th point on a 2D plane. The cost of connecting two points is the
Manhattan distance between them. Return the minimum total cost to connect all points so
that there exists exactly one simple path between every pair of points (a Minimum Spanning
Tree of the complete graph defined by Manhattan distances).

## Examples

````text
Example 1:
    Input: points = [[0,0],[2,2],[3,10],[5,2],[7,0]]
    Output: 20
Example 2:
    Input: points = [[3,12],[-2,5],[-4,1]]
    Output: 18
````

## Constraints

````text
- 1 <= len(points) <= 1000
- -10^6 <= xi, yi <= 10^6
- All pairs are distinct.
````
