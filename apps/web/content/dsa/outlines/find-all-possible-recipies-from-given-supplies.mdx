You are given recipe names, their ingredient lists, and starting supplies (infinite quantities). An
ingredient may itself be a recipe. Return every recipe you can eventually craft.

## Examples

````text
Example 1:
    Input: recipes = ["bread"], ingredients = [["yeast","flour"]], supplies = ["yeast","flour","corn"]
    Output: ["bread"]
Example 2:
    Input: recipes = ["bread","sandwich"], ingredients = [["yeast","flour"],["bread","meat"]],
           supplies = ["yeast","flour","meat"]
    Output: ["bread","sandwich"]
````

## Constraints

````text
- 1 <= len(recipes), len(ingredients), len(supplies) <= 100
- ingredients[i] lists distinct strings
````
