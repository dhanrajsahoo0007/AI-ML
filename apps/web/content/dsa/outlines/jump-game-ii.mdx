Given an array nums where nums\[i\] is the maximum forward jump length from index i, return the
minimum number of jumps to reach the last index starting from index 0. It is guaranteed that the last index is reachable.

## Examples

````text
Example 1:
    Input: nums = [2,3,1,1,4]
    Output: 2

Example 2:
    Input: nums = [2,3,0,1,4]
    Output: 2

Example 3:
    Input: nums = [1]
    Output: 0
````

## Constraints

````text
- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 1000
- It is guaranteed that you can reach nums[n - 1].
````
