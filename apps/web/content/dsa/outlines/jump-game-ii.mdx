Given an array nums where nums\[i\] is the maximum forward jump length from index i, return the
minimum number of jumps to reach the last index starting from index 0. It is guaranteed that the last index is reachable.

## Examples

````text
Example 1:
    Input: nums = [2,3,1,1,4]
    Output: 2

Example 2:
    Input: nums = [2,3,0,1,4]
    Output: 2

Example 3:
    Input: nums = [1]
    Output: 0
````

## Constraints

````text
- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 1000
- It is guaranteed that you can reach nums[n - 1].
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Level BFS
Treat each jump count as a layer: extend the farthest index reachable until the layer boundary hits the end.

1. Maintain the farthest index reachable and the end of the current jump layer.
2. Scan indices before the last; update farthest with i + nums\[i\].
3. When i reaches the layer end, increment jumps and set the next layer end to farthest.

## Complexity

**Time:** O(n) - Single pass.

**Space:** O(1) - Constant extra variables.

## Solution

````python
from typing import List


class Solution:
    def jump(self, nums: List[int]) -> int:
        if len(nums) == 1:
            return 0
        jumps = 0
        cur_end = 0
        farthest = 0
        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])
            if i == cur_end:
                jumps += 1
                cur_end = farthest
        return jumps
````
