Implement a trie that supports insert, counting words equal to a string, counting words
whose prefix matches a string, and erasing one instance of a word.

## Examples

````text
Example 1:
Input: insert "apple", insert "apple", countWordsEqualTo "apple",
       countWordsStartingWith "app", erase "apple", countWordsEqualTo "apple"
Output: 2, 2, 1
````

## Constraints

````text
- 1 <= word.length <= 2000
- 1 <= words.length <= 3 * 10^4
- All strings are lowercase English letters
- erase is only called when the word exists at least once
````
