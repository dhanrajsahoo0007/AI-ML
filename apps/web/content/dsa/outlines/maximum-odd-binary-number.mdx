Given a binary string s containing at least one '1', rearrange its bits to form the largest
odd binary number possible (odd means least significant bit is '1'). Leading zeros are allowed.

## Examples

````text
Example 1:
    Input: s = "010"
    Output: "001"

Example 2:
    Input: s = "0101"
    Output: "1001"

Example 3:
    Input: s = "1"
    Output: "1"
````

## Constraints

````text
- 1 <= len(s) <= 100
- s consists only of '0' and '1'
- s contains at least one '1'
````
