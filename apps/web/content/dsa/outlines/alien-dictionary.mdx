Given sorted words from an alien dictionary using some unknown total order of letters, derive any valid
order of letters consistent with the words. If no valid order exists, return "".

## Examples

````text
Example 1:
    Input: words = ["wrt","wrf","er","ett","rftt"]
    Output: "wertf"
Example 2:
    Input: words = ["z","x"]
    Output: "zx"
Example 3:
    Input: words = ["z","x","z"]
    Output: ""
````

## Constraints

````text
- 1 <= len(words) <= 100
- 1 <= len(words[i]) <= 100
- words[i] contains lowercase English letters
````
