Remove the smallest number of '(' or ')' characters so the remaining parentheses string is valid.
Letters must stay unchanged.

## Examples

````text
Example 1:
Input: "lee(t(c)o)de)"
Output: "lee(t(c)o)de"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s contains lowercase letters and parentheses
````

<PremiumBreak />

## Approach

**Pattern:** Stack + Removal Set
Track unmatched positions with a stack, then filter characters whose indices are not marked.

1. Traverse with a stack of '(' indices; unmatched ')' indices go to a removal set.
2. Push '(' indices; on ')', pop if possible else mark ')'.
3. Remaining stack entries are unmatched '('; merge into the removal set and rebuild the string.

## Complexity

**Time:** O(n) - One forward pass and one filter pass.

**Space:** O(n) - Stack and removal markers.

## Solution

````python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        remove: set[int] = set()
        stack: list[int] = []
        for i, ch in enumerate(s):
            if ch == "(":
                stack.append(i)
            elif ch == ")":
                if stack:
                    stack.pop()
                else:
                    remove.add(i)
        remove.update(stack)
        return "".join(ch for i, ch in enumerate(s) if i not in remove)
````
