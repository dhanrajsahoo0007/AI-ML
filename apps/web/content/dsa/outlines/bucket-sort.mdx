Sort a list of floating-point numbers uniformly distributed in \[0, 1) using
the bucket sort idea and return the sorted list.

## Examples

````text
Example 1:
    Input: nums = [0.78, 0.17, 0.39, 0.26, 0.72, 0.94, 0.21, 0.12, 0.23, 0.68]
    Output: sorted ascending list
Example 2:
    Input: nums = [0.5, 0.1, 0.9]
    Output: [0.1, 0.5, 0.9]
````

## Constraints

````text
- 0 <= nums[i] < 1
- len(nums) <= 10^5
````
