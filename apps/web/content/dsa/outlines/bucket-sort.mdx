Sort a list of floating-point numbers uniformly distributed in \[0, 1) using
the bucket sort idea and return the sorted list.

## Examples

````text
Example 1:
    Input: nums = [0.78, 0.17, 0.39, 0.26, 0.72, 0.94, 0.21, 0.12, 0.23, 0.68]
    Output: sorted ascending list
Example 2:
    Input: nums = [0.5, 0.1, 0.9]
    Output: [0.1, 0.5, 0.9]
````

## Constraints

````text
- 0 <= nums[i] < 1
- len(nums) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Bucket sort
Map each value to floor(x \* n) bucket, sort buckets individually, concatenate.

1. Create n buckets (or n empty lists).
2. Place each number into bucket index min(n-1, int(x \* n)).
3. Sort each bucket and extend the answer.

## Complexity

**Time:** O(n) average when distribution is uniform

**Space:** O(n) for buckets

## Solution

````python
from typing import List


class Solution:
    def bucketSort(self, nums: List[float]) -> List[float]:
        n = len(nums)
        if n <= 1:
            return list(nums)
        buckets: List[List[float]] = [[] for _ in range(n)]
        for x in nums:
            idx = min(n - 1, int(x * n))
            buckets[idx].append(x)
        for b in buckets:
            b.sort()
        out: List[float] = []
        for b in buckets:
            out.extend(b)
        return out
````
