Given a string of digits 2-9, return all letter combinations as on a phone keypad (digit 1 maps to nothing).

## Examples

````text
Example 1:
    Input: digits = "23"
    Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]

Example 2:
    Input: digits = ""
    Output: []
````

## Constraints

````text
- 0 <= len(digits) <= 4
- digits contains only '2'..'9'.
````
