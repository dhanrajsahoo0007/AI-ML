Given an m x n binary grid where '1' is land and '0' is water, count how many islands exist. Cells are
4-directionally adjacent.

## Examples

````text
Example 1:
Input: grid = [["1","1","0"],["1","0","0"],["0","0","1"]]
Output: 2
````

## Constraints

````text
- m == len(grid), n == len(grid[0])
- 1 <= m, n <= 300
````

## Approach

**Pattern:** Connected components on implicit grid graph
Each unseen land cell starts a DFS/BFS that marks its entire island visited.

1. Scan the grid; on finding '1', increment count and DFS-mark the whole island as visited ('0').

## Complexity

**Time:** O(m \* n)

**Space:** O(m \* n) worst-case recursion depth.

## Solution

````python
from typing import List


class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        if not grid:
            return 0
        m, n = len(grid), len(grid[0])
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def dfs(r: int, c: int) -> None:
            grid[r][c] = "0"
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == "1":
                    dfs(nr, nc)

        islands = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == "1":
                    islands += 1
                    dfs(i, j)
        return islands
````

if __name__ == "__main__":
    sol = Solution()

    def clone(g: List[List[str]]) -> List[List[str]]:
        return [row[:] for row in g]

    g1 = [["1", "1", "0"], ["1", "0", "0"], ["0", "0", "1"]]
    assert sol.numIslands(clone(g1)) == 2, "Test 1 Failed"
    print("Test 1 Passed: two islands")

    print("Test 2 Passed: ring island")
    assert sol.numIslands(clone([["0"]])) == 0, "Test 3 Failed"
    print("Test 3 Passed: all water")
