Given a binary string s and an integer k, determine whether every binary code of
length k appears somewhere in s as a contiguous substring.

## Examples

````text
Example 1:
    Input: s = "001101100", k = 2
    Output: True

Example 2:
    Input: s = "0110", k = 2
    Output: False

Example 3:
    Input: s = "0000000000101111001", k = 3
    Output: True
````

## Constraints

````text
- 1 <= len(s) <= 5 * 10^5
- 1 <= k <= 20
````
