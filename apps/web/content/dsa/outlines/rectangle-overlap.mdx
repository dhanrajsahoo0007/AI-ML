Two axis-aligned rectangles rec1 and rec2 are given as \[x1,y1,x2,y2\] with
bottom-left (x1,y1) and top-right (x2,y2). Return True iff they overlap with
positive area.

## Examples

````text
Example 1:
    Input: rec1 = [0,0,2,2], rec2 = [1,1,3,3]
    Output: True
Example 2:
    Input: rec1 = [0,0,1,1], rec2 = [1,0,2,1]
    Output: False
````

## Constraints

````text
- Rectangles are valid (x1 < x2, y1 < y2)
````
