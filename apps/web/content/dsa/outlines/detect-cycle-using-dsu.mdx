Given an undirected graph with V vertices and E edges (adjacency list \`adj\`), detect if there is a cycle
using Union-Find. Return 1 if a cycle exists, else 0.

## Examples

````text
Example 1:
    Input: V = 5, adj = [[1], [0, 2, 4], [1, 3], [2, 4], [1, 3]]
    Output: 1 (cycle present)
Example 2:
    Input: V = 4, adj = [[1, 2], [0, 2], [0, 1], []]  (triangle among 0,1,2)
    Output: 1
````

## Constraints

````text
- 0 <= V, edges reasonable for DSU
````

## Approach

**Pattern:** Union-Find / Disjoint Set Union

1. Initialize parent and rank for each vertex.
2. For each undirected edge (u, v) with u &lt; v to avoid duplicates, if find(u) == find(v), cycle; else union.
3. If no such edge, return 0.

## Complexity

**Time:** O(E \* α(V))
- E is the number of edges
- α is the inverse Ackermann function, which grows very slowly and is effectively constant for all practical values of V
- In the worst case, we might need to perform a find operation for each edge

**Space:** O(V)
- We use two arrays (parent and rank) of size V

## Solution

````python
from typing import List


class Solution:
    def __init__(self) -> None:
        self.parent: List[int] = []
        self.rank: List[int] = []

    def find(self, x: int) -> int:
        if self.parent[x] == x:
            return x

        self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x: int, y: int) -> None:
        x_parent = self.find(x)
        y_parent = self.find(y)

        if x_parent == y_parent:
            return

        if self.rank[x_parent] > self.rank[y_parent]:
            self.parent[y_parent] = x_parent

        elif self.rank[x_parent] < self.rank[y_parent]:
            self.parent[x_parent] = y_parent

        else:
            self.parent[x_parent] = y_parent
            self.rank[y_parent] += 1

    def detectCycle(self, V: int, adj: List[List[int]]) -> int:
        self.parent = list(range(V))  # [0, 1, 2, 3, 4]
        self.rank = [0] * V  # [0, 0, 0, 0, 0]

        for u in range(V):
            for v in adj[u]:
                if u < v:  # Process each edge only once as it is undirected Graph
                    if self.find(u) == self.find(v):
                        return 1  # Cycle detected
                    self.union(u, v)
        return 0  # No cycle detected
````
