Given an undirected graph with V vertices and E edges (adjacency list \`adj\`), detect if there is a cycle
using Union-Find. Return 1 if a cycle exists, else 0.

## Examples

````text
Example 1:
    Input: V = 5, adj = [[1], [0, 2, 4], [1, 3], [2, 4], [1, 3]]
    Output: 1 (cycle present)
Example 2:
    Input: V = 4, adj = [[1, 2], [0, 2], [0, 1], []]  (triangle among 0,1,2)
    Output: 1
````

## Constraints

````text
- 0 <= V, edges reasonable for DSU
````
