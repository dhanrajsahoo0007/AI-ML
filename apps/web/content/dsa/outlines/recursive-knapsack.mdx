0-1 Knapsack: given item weights wt, values val, and capacity W, each item at
most once, maximize total value without exceeding capacity.

## Examples

````text
Example 1:
Input: W=50, wt=[10,20,30], val=[60,100,120]
Output: 220
````

## Constraints

````text
- 1 <= n <= 30 typical for recursion; weights and values positive integers
````
