0-1 Knapsack: given item weights wt, values val, and capacity W, each item at
most once, maximize total value without exceeding capacity.

## Examples

````text
Example 1:
Input: W=50, wt=[10,20,30], val=[60,100,120]
Output: 220
````

## Constraints

````text
- 1 <= n <= 30 typical for recursion; weights and values positive integers
````

<PremiumBreak />

## Approach

**Pattern:** Recursion with choice tree
For each item, branch on take (if fits) or skip.

1. If n==0 or W==0 return 0.
2. If wt\[n-1\] &gt; W return solve(W, n-1).
3. Else return max(val\[n-1\]+solve(W-wt\[n-1\],n-1), solve(W,n-1)).

## Complexity

**Time:** O(2^n) - two branches per item.

**Space:** O(n) - recursion depth.

## Solution

````python
from typing import List


class Solution:
    def knapsack(self, W: int, wt: List[int], val: List[int], n: int) -> int:
        if n == 0 or W == 0:
            return 0
        if wt[n - 1] > W:
            return self.knapsack(W, wt, val, n - 1)
        return max(
            val[n - 1] + self.knapsack(W - wt[n - 1], wt, val, n - 1),
            self.knapsack(W, wt, val, n - 1),
        )
````
