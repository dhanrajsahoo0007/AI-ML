Given a binary tree (not necessarily a BST), return the number of nodes in the largest subtree
that is a binary search tree.

## Examples

````text
Example 1:
    Input: [10,5,15,1,8,6,20]
    Output: 3 (largest BST subtree size)

Example 2:
    Input: full BST on seven nodes
    Output: 7
````

## Constraints

````text
- The number of nodes is in the range [0, 2 * 10^4].
````
