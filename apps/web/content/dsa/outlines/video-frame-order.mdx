Frames arrive out of order with sequence ids or timestamps. Expose SaveFrame(seq, payload)
and GetFrame() that returns the next contiguous frame starting at the expected sequence,
or None if it is not yet available.

## Examples

````text
Example 1:
Save 2, Save 0, Save 1 -> first Get returns frame 0, then 1, then 2.
````

## Constraints

````text
- Sequence numbers are non-negative integers; strictly increasing by one for delivery order.
````
