Given a directed graph with V vertices and an edge list, determine if the graph contains a cycle.
This file uses Kahn's algorithm (topological sort via in-degrees): if fewer than V nodes are processed,
a directed cycle exists.

## Examples

````text
Example 1:
    Input: V = 4, edges = [[0,1],[1,2],[2,3],[3,1]]
    Output: True
Example 2:
    Input: V = 4, edges = [[0,1],[1,2],[2,3]]
    Output: False
````

## Constraints

````text
- 1 <= V, edges <= 10^4
````
