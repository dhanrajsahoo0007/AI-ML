Given a directed graph with V vertices and an edge list, determine if the graph contains a cycle.
This file uses Kahn's algorithm (topological sort via in-degrees): if fewer than V nodes are processed,
a directed cycle exists.

## Examples

````text
Example 1:
    Input: V = 4, edges = [[0,1],[1,2],[2,3],[3,1]]
    Output: True
Example 2:
    Input: V = 4, edges = [[0,1],[1,2],[2,3]]
    Output: False
````

## Constraints

````text
- 1 <= V, edges <= 10^4
````

## Approach

**Pattern:** Kahn's algorithm / BFS topological peel
Repeatedly remove zero in-degree nodes; leftover nodes imply a cycle.

1. Build adjacency list and compute in-degrees.
2. Enqueue all vertices with in-degree 0; count removals.
3. If count &lt; V after processing, return True (cycle); else False.

## Complexity

**Time:** O(V + E)

**Space:** O(V + E)

## Solution

````python
from typing import List
from collections import deque


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
        return adj

    def has_cycle(self, V: int, adj: List[List[int]]) -> bool:
        in_degree = [0] * V
        for u in range(V):
            for v in adj[u]:
                in_degree[v] += 1
        q: deque[int] = deque(i for i in range(V) if in_degree[i] == 0)
        visited_count = 0
        while q:
            u = q.popleft()
            visited_count += 1
            for v in adj[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    q.append(v)
        return visited_count != V
````
