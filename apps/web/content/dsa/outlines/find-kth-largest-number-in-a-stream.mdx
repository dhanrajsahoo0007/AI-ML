Process a stream via getNum() until None; maintain unique values and return the k-th largest
unique number (1 = largest). Duplicates are ignored for ranking.

## Examples

````text
Example 1:
Stream [5,1,5,2,3,2,4], k=3 -> third largest among uniques {1..5} is 3.
````

## Constraints

````text
- At least k distinct values appear in the stream.
````

<PremiumBreak />

## Approach

**Pattern:** Min-heap of size k on distinct largest values
Track seen duplicates; min-heap holds the k largest distinct integers seen so far.

1. Maintain a set of seen numbers and a min-heap of at most k distinct largest values.
2. For each new unique x, push/replace in heap to keep k largest.
3. After stream ends, heap\[0\] is the k-th largest unique.

## Complexity

**Time:** O(N log k) for N stream numbers.

**Space:** O(U) for unique values in worst case plus O(k) heap.

## Solution

````python
import heapq
from typing import Callable, Iterable, List, Optional, Set, Tuple


class KthLargestUniqueStream:
    def __init__(self, stream: Iterable[int], k: int) -> None:
        self._it = iter(stream)
        self._k = k
        self._seen: Set[int] = set()
        self._heap: List[int] = []

    def _process_all(self) -> int:
        while True:
            x = next(self._it, None)
            if x is None:
                break
            if x in self._seen:
                continue
            self._seen.add(x)
            if len(self._heap) < self._k:
                heapq.heappush(self._heap, x)
            elif x > self._heap[0]:
                heapq.heapreplace(self._heap, x)
        if len(self._heap) < self._k:
            raise ValueError("stream did not contain k unique values")
        return self._heap[0]

    @classmethod
    def from_list(cls, values: List[int], k: int) -> int:
        return cls(iter(values), k)._process_all()


def make_stream_api(values: List[int]) -> Tuple[Callable[[], Optional[int]], Callable[[int], bool]]:
    it = iter(values)
    stored: Set[int] = set()

    def getNum() -> Optional[int]:
        try:
            v = next(it)
            stored.add(v)
            return v
        except StopIteration:
            return None

    def isNum(value: int) -> bool:
        return value in stored

    return getNum, isNum
````
