Given the head of a linked list that may contain a cycle, return the node where the cycle begins,
or None if there is no cycle.

## Examples

````text
Example 1:
    Input: values [3,2,0,-4], tail connects to index 1
    Output: node with value 2

Example 2:
    Input: values [1,2], tail connects to index 0
    Output: node with value 1
````

## Constraints

````text
- 0 <= n <= 10^4
- -10^5 <= Node.val <= 10^5
````
