Given an m x n matrix, return all elements in diagonal order: traverse diagonals
in alternating directions (up-right, then down-left, repeating) starting from the top-left.

## Examples

````text
Example 1:
    Input: mat = [[1,2,3],[4,5,6],[7,8,9]]
    Output: [1,2,4,7,5,3,6,8,9]

Example 2:
    Input: mat = [[1,2],[3,4]]
    Output: [1,2,3,4]
````

## Constraints

````text
- m == len(mat), n == len(mat[0])
- 1 <= m, n <= 10^4
- 1 <= m * n <= 10^5
- -10^5 <= mat[i][j] <= 10^5
````
