Given an m x n matrix, return all elements in diagonal order: traverse diagonals
in alternating directions (up-right, then down-left, repeating) starting from the top-left.

## Examples

````text
Example 1:
    Input: mat = [[1,2,3],[4,5,6],[7,8,9]]
    Output: [1,2,4,7,5,3,6,8,9]

Example 2:
    Input: mat = [[1,2],[3,4]]
    Output: [1,2,3,4]
````

## Constraints

````text
- m == len(mat), n == len(mat[0])
- 1 <= m, n <= 10^4
- 1 <= m * n <= 10^5
- -10^5 <= mat[i][j] <= 10^5
````

## Approach

**Pattern:** Simulation with direction toggle
Move along diagonals and flip direction when hitting a boundary of the grid.

1. Track current row, column, and whether we are moving up-right or down-left.
2. Append the current cell, then advance: on up-right, prefer hitting the top or right edge;
on down-left, prefer hitting the bottom or left edge.
3. Stop after m \* n elements are collected.

## Complexity

**Time:** O(m \* n) - Each cell is visited exactly once.

**Space:** O(1) extra besides the output list - Only a few indices and a flag.

## Solution

````python
from typing import List


class Solution:
    def findDiagonalOrder(self, mat: List[List[int]]) -> List[int]:
        if not mat or not mat[0]:
            return []
        m = len(mat)
        n = len(mat[0])
        res: List[int] = []
        row = col = 0
        going_up = True
        while len(res) < m * n:
            res.append(mat[row][col])
            if going_up:
                if col == n - 1:
                    row += 1
                    going_up = False
                elif row == 0:
                    col += 1
                    going_up = False
                else:
                    row -= 1
                    col += 1
            else:
                if row == m - 1:
                    col += 1
                    going_up = True
                elif col == 0:
                    row += 1
                    going_up = True
                else:
                    row += 1
                    col -= 1
        return res
````
