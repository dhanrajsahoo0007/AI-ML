For an even-length linked list, the twin of the i-th node (0-indexed) is the (n-1-i)-th node.
Return the maximum sum of values over all twin pairs.

## Examples

````text
Example 1:
Input: head = [5,4,2,1]
Output: 6 (pairs (5,1) and (4,2))
````

## Constraints

````text
- 2 <= n <= 10^5, n is even
- 1 <= Node.val <= 10^5
````
