Given the root of a binary tree, collect nodes in rounds: repeatedly remove all current leaves until the tree is empty.
Return a list of lists where each inner list is one round of removed leaf values (left-to-right within a round).

## Examples

````text
Example 1:
    Input: root = [1,2,3,4,5]
    Output: [[4,5,3],[2],[1]]
Example 2:
    Input: root = [1]
    Output: [[1]]
````

## Constraints

````text
- The number of nodes is in the range [1, 100].
- Node values in [-100, 100].
````
