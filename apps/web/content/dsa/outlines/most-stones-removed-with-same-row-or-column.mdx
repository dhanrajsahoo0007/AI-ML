On a 2D plane, we place n stones at some integer coordinate points. Each coordinate point may have at most one stone.
A stone can be removed if it shares either the same row or the same column as another stone that has not been removed.
Given an array stones of length n where stones\[i\] = \[xi, yi\] represents the location of the ith stone,
return the largest possible number of stones that can be removed.

## Examples

````text
Example 1:
Input: stones = [[0,0],[0,1],[1,0],[1,2],[2,1],[2,2]]
Output: 5
````

## Constraints

````text
- 1 <= stones.length <= 1000
````

## Approach

**Pattern:** Union-Find / Disjoint Set Union (row/column connectivity)

1. Union stones that share a row or column (naive O(n^2) acceptable for n &lt;= 1000 here).
2. Count connected components as distinct DSU roots using find with path compression.
3. Answer is n - (#components) because one stone per component must remain.

## Complexity

**Time:** O(n^2 \* α(n)), where α(n) is the inverse Ackermann function

**Space:** O(n)

Note: The time complexity could be optimized to O(n \* α(n)) by mapping rows/columns to DSU nodes,
but this implementation preserves the original union loop structure.

## Solution

````python
from typing import List


class Solution:
    def __init__(self) -> None:
        self.parent: List[int] = []
        self.rank: List[int] = []
        self.n = 0

    def find(self, i: int) -> int:
        if self.parent[i] != i:
            self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i: int, j: int) -> None:
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            if self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            elif self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            else:
                self.parent[root_j] = root_i
                self.rank[root_i] += 1

    def removeStones(self, stones: List[List[int]]) -> int:
        self.n = len(stones)
        self.parent = list(range(self.n))
        self.rank = [0] * self.n

        for i in range(self.n):
            for j in range(i + 1, self.n):
                if stones[i][0] == stones[j][0] or stones[i][1] == stones[j][1]:
                    self.union(i, j)

        groups = len({self.find(i) for i in range(self.n)})

        return self.n - groups
````
