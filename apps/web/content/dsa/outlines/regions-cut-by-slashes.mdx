An n x n grid contains characters ' ', '/', or '\\'. These slashes partition the square into regions.
Return the number of resulting regions.

## Examples

````text
Example 1:
    Input: grid = [" /"]
    Output: 2
Example 2:
    Input: grid = ["/"]
    Output: 2
````

## Constraints

````text
- 1 <= n <= 30
````
