A robot sits on an unknown empty cell in a hidden grid of 0 (wall) and 1 (open). Using
move, turnLeft, turnRight, and clean, visit and clean every reachable open cell.

## Examples

````text
Example 1:
Input: a mocked room grid (see tests)
Output: every open cell is cleaned exactly once
````

## Constraints

````text
- The hidden grid is rectangular; the robot starts on an open cell.
````
