An array original becomes changed by appending twice every element of original, then shuffling.
Given changed, reconstruct any valid original, or return \[\] if none exists.

## Examples

````text
Example 1:
    Input: changed = [1, 3, 4, 2, 6, 8]
    Output: [1, 3, 4] (any order of that multiset is acceptable)
Example 2:
    Input: changed = [6, 3, 0, 1]
    Output: []
````

## Constraints

````text
- 1 <= len(changed) <= 10^5
- 0 <= changed[i] <= 10^5
````

## Approach

**Pattern:** Greedy with frequency map
Process sorted distinct keys; repeatedly pair x with 2x using remaining counts.

1. If len(changed) is odd, return \[\].
2. Count values with a multiset.
3. For x in sorted keys, repeatedly consume x with 2x while counts allow; otherwise return \[\].
4. Return collected originals.

## Complexity

**Time:** O(n log n) - Sorting keys dominates.

**Space:** O(n) - Counter and output list.

## Solution

````python
import collections
from typing import List


class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2 == 1:
            return []
        freq = collections.Counter(changed)
        result: List[int] = []
        for x in sorted(freq.keys()):
            while freq[x] > 0:
                if freq[x * 2] <= 0:
                    return []
                freq[x] -= 1
                freq[x * 2] -= 1
                result.append(x)
        return result


def _multiset_equal(a: List[int], b: List[int]) -> bool:
    return collections.Counter(a) == collections.Counter(b)
````
