nums contains n + 1 integers where each integer is in \[1, n\] inclusive. Exactly
one value appears at least twice; return that duplicate.

## Examples

````text
Example 1:
    Input: nums = [1,3,4,2,2]
    Output: 2
Example 2:
    Input: nums = [3,1,3,4,2]
    Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- Values are in [1, len(nums) - 1]
````
