Given an m x n grid of characters and a list of distinct words, return every word that
can be built by moving up/down/left/right to adjacent cells without reusing a cell in the same word.

## Examples

````text
Example 1:
    Input: board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]],
           words = ["oath","pea","eat","rain"]
    Output: ["eat","oath"] (order may vary)

Example 2:
    Input: board = [["a","b"],["c","d"]], words = ["abcb"]
    Output: []
````

## Constraints

````text
- m == len(board), n == len(board[0]), 1 <= m, n <= 12
- 1 <= len(words) <= 3 * 10^4, 1 <= len(words[i]) <= 10
- Letters are lowercase English; all words are unique
````

## Approach

**Pattern:** Trie + DFS backtracking
Put words in a trie so each step only follows valid next letters; mark found words in the trie to prune.

1. Build a trie from words; store the full word at terminal nodes for collection.
2. DFS from each cell with the root; match board letters to trie children.
3. Temporarily mark visited cells; restore after exploring four directions.
4. When a terminal node is hit, add the word and clear the terminal flag to avoid duplicates.

## Complexity

**Time:** O(M \* N \* 4^L) worst-case DFS exploration; trie pruning and removing found words improve typical performance — L is max word length.

**Space:** O(S) for the trie — S is total characters in all words — plus O(L) recursion depth.

Given an m x n board of characters and a list of strings words, return all words on the board.
Each word must be constructed from letters of sequentially adjacent cells, where adjacent cells

Space Complexity: O(K), where K is the total number of characters in all words.

Approach:

2. Perform DFS on the board, simultaneously traversing the Trie.
3. When a word is found, add it to the result set.
4. Use a set to store results to automatically handle duplicates.

## Solution

````python
from __future__ import annotations

from typing import List


class TrieNode:
    def __init__(self) -> None:
        self.children: dict[str, TrieNode] = {}
        self.is_word: bool = False
        self.word: str = ""

    def insert(self, word: str) -> None:
        node = self
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_word = True
        node.word = word


class Solution:
    def find_words(self, board: List[List[str]], words: List[str]) -> List[str]:
        root = TrieNode()
        for w in words:
            root.insert(w)

        rows, cols = len(board), len(board[0])
        result: set[str] = set()

        def dfs(i: int, j: int, node: TrieNode) -> None:
            if node.is_word:
                result.add(node.word)
                node.is_word = False

            if i < 0 or i >= rows or j < 0 or j >= cols:
                return
            ch = board[i][j]
            if ch not in node.children:
                return

            board[i][j] = "#"
            nxt = node.children[ch]
            for di, dj in ((0, 1), (1, 0), (0, -1), (-1, 0)):
                dfs(i + di, j + dj, nxt)
            board[i][j] = ch

        for r in range(rows):
            for c in range(cols):
                dfs(r, c, root)

        return list(result)
````
