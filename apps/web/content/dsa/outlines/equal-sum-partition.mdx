## Examples

````text
Example 1:
    Input: nums = [1, 5, 11, 5]
    Output: True
Example 2:
    Input: nums = [1, 2, 3, 5]
    Output: False
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 1 <= nums[i] <= 100
````
