You must take n trains in order; dist\[i\] is distance of train i. Each train except the last must
finish at an integer hour boundary before the next departs. The last train may end on a fractional hour.
Return the minimum integer speed (km/h) to arrive within hour, or -1 if impossible.

## Examples

````text
Example 1:
    Input: dist = [1, 3, 2], hour = 6.0
    Output: 1

Example 2:
    Input: dist = [1, 3, 2], hour = 2.7
    Output: 3
````

## Constraints

````text
- 1 <= len(dist) <= 10^5
- 1 <= dist[i] <= 10^5
- 1 <= hour <= 10^9
````
