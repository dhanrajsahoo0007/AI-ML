You must take n trains in order; dist\[i\] is distance of train i. Each train except the last must
finish at an integer hour boundary before the next departs. The last train may end on a fractional hour.
Return the minimum integer speed (km/h) to arrive within hour, or -1 if impossible.

## Examples

````text
Example 1:
    Input: dist = [1, 3, 2], hour = 6.0
    Output: 1

Example 2:
    Input: dist = [1, 3, 2], hour = 2.7
    Output: 3
````

## Constraints

````text
- 1 <= len(dist) <= 10^5
- 1 <= dist[i] <= 10^5
- 1 <= hour <= 10^9
````

## Approach

**Pattern:** Binary Search on Answer
Time decreases as speed increases; check feasibility with ceil for all but the last segment.

1. If hour &lt;= n - 1, return -1 (not enough time slots for n trains).
2. Binary search speed in \[1, 10^7\]; feasible if sum ceil(dist\[i\]/s) for i &lt; n-1 plus dist\[-1\]/s &lt;= hour.

## Complexity

**Time:** O(n log U) - U = 10^7 upper bound on speed.

**Space:** O(1) - Only arithmetic state.

## Solution

````python
import math
from typing import List


class Solution:
    def minSpeedOnTime(self, dist: List[int], hour: float) -> int:
        if hour <= len(dist) - 1:
            return -1

        def ok(speed: int) -> bool:
            t = 0.0
            for i in range(len(dist) - 1):
                t += math.ceil(dist[i] / speed)
            t += dist[-1] / speed
            return t <= hour

        lo, hi = 1, 10**7
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if ok(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
````
