Given the root of a binary search tree and a key, delete the node with that key while keeping
the BST property. When the node has two children, replace its value with the inorder successor
(minimum of the right subtree) and delete that successor node.

## Examples

````text
Example 1:
    Input: BST built from [5,3,7,1,4,6,8], delete 3
    Output: inorder traversal missing 3 but still sorted

Example 2:
    Input: BST, delete a missing key
    Output: unchanged structure
````

## Constraints

````text
- Distinct values are typical; algorithm supports standard BST deletion cases.
````

## Approach

**Pattern:** Classic BST deletion
Three cases: zero children, one child, or two children with successor promotion on the right subtree.

1. Recursively locate the key by comparing with the current root.
2. When found: if missing a child, return the other child; else copy successor value and delete successor in the right subtree.
3. Return the (possibly new) subtree root after rewiring.

## Complexity

**Time:** O(h) - Search height plus possibly one extra path to the successor.

**Space:** O(h) - Recursion depth.

Binary Search Tree (BST) Deletion Implementation

Problem Statement:
Implement a function to delete a given element from a Binary Search Tree.

Time Complexity: O(h), where h is the height of the tree.
- In a balanced BST, h = log(n), where n is the number of nodes.
- In the worst case (skewed tree), h = n.

Space Complexity: O(h) due to the recursive call stack.

Explanation:
The deletion algorithm needs to handle three main cases:
1. Node to be deleted is a leaf (has no children).
2. Node to be deleted has only one child.
3. Node to be deleted has two children.

For case 3, we find the inorder successor (smallest value in the right subtree)
to replace the node we're deleting.

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_bst_insert(values: List[int]) -> Optional[TreeNode]:
    root: Optional[TreeNode] = None
    for v in values:
        if root is None:
            root = TreeNode(v)
            continue
        cur = root
        while True:
            if v < cur.val:
                if cur.left is None:
                    cur.left = TreeNode(v)
                    break
                cur = cur.left
            else:
                if cur.right is None:
                    cur.right = TreeNode(v)
                    break
                cur = cur.right
    return root


def inorder_values(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    return inorder_values(root.left) + [root.val] + inorder_values(root.right)


class Solution:
    def deleteNode(self, root: Optional[TreeNode], key: int) -> Optional[TreeNode]:
        if root is None:
            return None
        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        else:
            if root.left is None:
                return root.right
            if root.right is None:
                return root.left
            succ = root.right
            while succ.left:
                succ = succ.left
            root.val = succ.val
            root.right = self.deleteNode(root.right, succ.val)
        return root
````
