Given an array of integers nums and a non-negative integer limit, return the length
of the longest contiguous subarray such that the absolute difference between any two
elements in the subarray is at most limit.

## Examples

````text
Example 1:
    Input: nums = [8, 2, 4, 7], limit = 4
    Output: 2
Example 2:
    Input: nums = [10, 1, 2, 4, 7, 2], limit = 5
    Output: 4
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- 0 <= nums[i] <= 10^9
- 0 <= limit <= 10^9
````
