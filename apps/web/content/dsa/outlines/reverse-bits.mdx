Reverse bits of a given 32-bit unsigned integer.

## Examples

````text
Example 1:
    Input: n = 43261596 (00000010100101000001111010011100)
    Output: 964176192
Example 2:
    Input: n = 4294967293
    Output: 3221225471
````

## Constraints

````text
- The input must be a binary string of length 32 (interpreted as unsigned int)
````
