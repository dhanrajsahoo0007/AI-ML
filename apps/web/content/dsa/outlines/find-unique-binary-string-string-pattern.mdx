Given an array nums of n distinct binary strings, each of length n, return any length-n binary
string that does not appear in nums.

## Examples

````text
Example 1:
Input: nums = ["01","10"]
Output: "11" or "00" (either is acceptable if absent from nums)
````

## Constraints

````text
- nums.length == n
- Each string in nums has length n
````

## Approach

**Pattern:** Cantor / diagonal construction
Greedy diagonal: at position i choose the bit opposite nums\[i\]\[i\] so the candidate differs from nums\[i\].

1. For each index i from 0 to n-1, set answer bit to complement of nums\[i\]\[i\].
2. Join bits into a string; diagonal argument guarantees it differs from every nums\[i\].

## Complexity

**Time:** O(n^2) to read inputs when building character by character.

**Space:** O(n) for the output string.

## Solution

````python
from typing import List


class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        return "".join("1" if nums[i][i] == "0" else "0" for i in range(len(nums)))
````
