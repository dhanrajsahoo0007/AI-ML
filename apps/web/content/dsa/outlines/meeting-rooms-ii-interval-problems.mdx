Given an array of meeting time intervals \[start, end\], return the minimum number
of conference rooms required so no overlapping meetings share a room.

## Examples

````text
Example 1:
Input: intervals = [[0, 30], [5, 10], [15, 20]]
Output: 2
````

## Constraints

````text
- 1 <= len(intervals) <= 10^4
- 0 <= start < end <= 10^6
````

**Also in the notes under:** [19. Interval/03. Interval Scheduling](/dsa/problems/meeting-rooms-ii).

## Approach

**Pattern:** Chronological Ordering / Prefix Events
Sort starts and ends; sweep time increasing rooms in use when a start precedes the next end.

1. Sort all start times and all end times.
2. Two-pointer: if next start is before next end, occupy a room; otherwise release one.
3. Track the peak simultaneous meetings.

## Complexity

**Time:** O(n log n) for sorting.

**Space:** O(n) for the sorted copies.

## Solution

````python
from typing import List


class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        starts = sorted(s for s, _ in intervals)
        ends = sorted(e for _, e in intervals)
        n = len(intervals)
        i = j = 0
        cur = 0
        best = 0
        while i < n:
            if starts[i] < ends[j]:
                cur += 1
                best = max(best, cur)
                i += 1
            else:
                cur -= 1
                j += 1
        return best
````
