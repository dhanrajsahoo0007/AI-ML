Given a string s and an integer k, remove duplicates such that every k consecutive
identical characters are removed. Repeat until the string no longer changes.

## Examples

````text
Example 1:
    Input: s = "deeedbbcccbdaa", k = 3
    Output: "aa"
    Explanation: Remove "eee" and "bbb", then "ccc", leaving "daa" -> remove "aaa" -> "aa".

Example 2:
    Input: s = "pbbcggttciiippooaais", k = 2
    Output: "ps"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- 2 <= k <= 10^4
- s consists of lowercase English letters.
````
