Given axis-aligned integer coordinate points, return the minimum area of any
rectangle formed from four distinct points, or 0 if none exists.

## Examples

````text
Example 1:
    Input: points = [[1,1],[1,3],[3,1],[3,3],[2,2]]
    Output: 4
Example 2:
    Input: points = [[1,1],[1,3],[3,3],[3,1],[4,1],[4,3]]
    Output: 2
````

## Constraints

````text
- 1 <= len(points) <= 500
- 0 <= points[i][0], points[i][1] <= 4 * 10^4
- All points are unique
````
