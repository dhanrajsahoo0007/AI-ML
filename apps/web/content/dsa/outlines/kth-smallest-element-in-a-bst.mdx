Given the root of a binary search tree and an integer k, return the kth smallest element
in the tree (1-indexed) using the sorted order induced by an inorder traversal.

## Examples

````text
Example 1:
    Input: BST [5,3,6,2,4,null,null,1], k = 3
    Output: 3

Example 2:
    Input: single node [42], k = 1
    Output: 42
````

## Constraints

````text
- 1 <= k <= number of nodes <= 10^4.
````
