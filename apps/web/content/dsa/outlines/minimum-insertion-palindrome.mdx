Given string s, return the minimum insertions needed to make s a palindrome.

## Examples

````text
Example 1:
    Input: s = "zzazz"
    Output: 0
Example 2:
    Input: s = "mbadm"
    Output: 2
````

## Constraints

````text
- 1 <= len(s) <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Same as minimum deletions
Insertions to palindrome equal deletions to palindrome: n - LPS(s).

1. Compute LPS length.
2. Return n - LPS.

## Complexity

**Time:** O(n^2).

**Space:** O(n^2).

## Solution

````python
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    inner = dp[i + 1][j - 1] if i + 1 <= j - 1 else 0
                    dp[i][j] = 2 + inner
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        return n - dp[0][n - 1]
````
