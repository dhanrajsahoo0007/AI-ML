Given string s, return the minimum insertions needed to make s a palindrome.

## Examples

````text
Example 1:
    Input: s = "zzazz"
    Output: 0
Example 2:
    Input: s = "mbadm"
    Output: 2
````

## Constraints

````text
- 1 <= len(s) <= 1000
````
