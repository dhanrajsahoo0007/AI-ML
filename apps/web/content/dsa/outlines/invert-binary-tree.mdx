Given the root of a binary tree, invert it (mirror every subtree) and return the new root.

## Examples

````text
Example 1:
    Input: root = [4,2,7,1,3,6,9]
    Output: [4,7,2,9,6,3,1]
Example 2:
    Input: root = [2,1,3]
    Output: [2,3,1]
````

## Constraints

````text
- The number of nodes is in the range [0, 100].
- Node values in [-100, 100].
````
