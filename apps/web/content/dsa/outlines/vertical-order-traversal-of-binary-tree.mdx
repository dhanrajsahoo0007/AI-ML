Given the root of a binary tree, return the vertical order traversal of node values.
Columns are ordered left to right; within the same column and row, sort by value.

## Examples

````text
Example 1:
    Input: root = [3,9,20,None,None,15,7]
    Output: [[9],[3,15],[20],[7]]
Example 2:
    Input: root = [1,2,3,4,5,6,7]
    Output: [[4],[2],[1,5,6],[3],[7]]
````

## Constraints

````text
- The number of nodes is in the range [0, 1000].
- Node values fit in 32-bit signed integers.
````
