Given a list used as a stack (top at the end), sort it in ascending order using only
recursive calls and stack operations (pop / append); no explicit sort built-ins.

## Examples

````text
Example 1:
Input: stack bottom -> top as [34, 3, 31, 98, 92, 23]
Output: [3, 23, 31, 34, 92, 98]
````

## Constraints

````text
- Elements are comparable (e.g. integers)
- Stack is represented as a list with the top at index -1
````
