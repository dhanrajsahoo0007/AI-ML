Given integer bags cookies\[i\] and k children, assign each whole bag to exactly one child.
Minimize unfairness: the maximum total cookies held by any child.

## Examples

````text
Example 1:
    Input: cookies = [8,15,10,20,8], k = 2
    Output: 31

Example 2:
    Input: cookies = [6,1,3,2,2,4,1,2], k = 3
    Output: 7
````

## Constraints

````text
- 2 <= k <= len(cookies) <= 8
- 1 <= cookies[i] <= 10^5
````

## Approach

**Pattern:** Assignment backtracking with symmetry pruning
Try placing each bag on each child; prune when empty children exceed remaining bags.

1. DFS over bag index; maintain totals per child.
2. Prune if more empty children than remaining bags (symmetry break).
3. Track minimum of max totals at leaves.

## Complexity

**Time:** O(k^n) worst case.

**Space:** O(k) for totals and recursion.

## Solution

````python
from typing import List


class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        totals = [0] * k
        best = [10**18]

        def dfs(idx: int) -> None:
            if idx == len(cookies):
                best[0] = min(best[0], max(totals))
                return
            if totals.count(0) > len(cookies) - idx:
                return
            for i in range(k):
                totals[i] += cookies[idx]
                dfs(idx + 1)
                totals[i] -= cookies[idx]

        dfs(0)
        return best[0]
````
