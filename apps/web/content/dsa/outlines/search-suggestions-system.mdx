Given products and searchWord, after each typed character suggest up to three product
names sharing that prefix; if more than three match, return the three lexicographically smallest.

## Examples

````text
Example 1:
Input: products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"
Output: [["mobile","moneypot","monitor"],["mobile","moneypot","monitor"],
         ["mouse","mousepad"],["mouse","mousepad"],["mouse","mousepad"]]
````

## Constraints

````text
- 1 <= len(products) <= 1000; unique lowercase strings; searchWord lowercase.
````

<PremiumBreak />

## Approach

**Pattern:** Sort + two-pointer / Trie
Sort products once; for each prefix, advance pointers to the first and matching range, take three.

1. Sort products lexicographically.
2. For each i in range(len(searchWord)), filter or scan from the range that matched i-1.
3. Collect up to three strings that start with searchWord\[: i + 1\].

## Complexity

**Time:** O(P log P + S \* P) worst case; with two-pointer O(P log P + S + matches).

**Space:** O(P) for output aside from input; tries use O(total characters) if used.

## Solution

````python
import bisect
from typing import List


class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        products.sort()
        res: List[List[str]] = []
        left, right = 0, len(products)
        prefix = ""
        for c in searchWord:
            prefix += c
            left = bisect.bisect_left(products, prefix, left, right)
            right = bisect.bisect_right(products, prefix + "{", left, right)
            res.append(products[left : min(left + 3, right)])
        return res
````
