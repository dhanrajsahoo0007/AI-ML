Convert an absolute Unix-style path with '.', '..', repeated slashes, and literal names into its
canonical form starting with '/' and without redundant segments.

## Examples

````text
Example 1:
Input: "/home/"
Output: "/home"
````

## Constraints

````text
- 1 <= len(path) <= 3000
- path contains '/', '.', '..', or names built from English letters, digits, or '_'
````

<PremiumBreak />

## Approach

**Pattern:** Token Stack
Split on '/', ignore empties and '.', pop on '..', otherwise push directory tokens.

1. Split the string on '/'.
2. Push non-empty names; pop when encountering '..' if possible.
3. Join stack with '/' and prefix with '/'.

## Complexity

**Time:** O(n) - Single traversal of the string plus joining.

**Space:** O(n) - Stack of path components.

## Solution

````python
from typing import List


class Solution:
    def simplifyPath(self, path: str) -> str:
        stack: List[str] = []
        for part in path.split("/"):
            if not part or part == ".":
                continue
            if part == "..":
                if stack:
                    stack.pop()
            else:
                stack.append(part)
        return "/" + "/".join(stack)
````
