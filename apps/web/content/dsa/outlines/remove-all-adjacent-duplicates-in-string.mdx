Repeatedly remove pairs of adjacent equal letters until stable; return the final string.

## Examples

````text
Example 1:
Input: "abbaca"
Output: "ca"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s contains lowercase English letters
````

<PremiumBreak />

## Approach

**Pattern:** Stack Cancellation
Push letters while popping when the new letter matches the top.

1. Iterate characters, popping when stack top equals current.
2. Otherwise push the character.
3. Join the stack into the result.

## Complexity

**Time:** O(n) - Each character is pushed and popped at most once.

**Space:** O(n) - Stack holds surviving characters.

## Solution

````python
from typing import List


class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack: List[str] = []
        for ch in s:
            if stack and stack[-1] == ch:
                stack.pop()
            else:
                stack.append(ch)
        return "".join(stack)
````
