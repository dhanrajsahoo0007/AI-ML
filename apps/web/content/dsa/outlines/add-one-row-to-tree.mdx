Given the root of a binary tree, integers val and depth, add a full row of nodes with value val at depth
(root depth is 1). Original children attach under the new nodes.

## Examples

````text
Example 1:
    Input: root = [4,2,6,3,1,5], val = 1, depth = 2
    Output: root values level-order reflect new row under 4.
Example 2:
    Input: depth = 1: new root val with old tree as left child.
````

## Constraints

````text
- The number of nodes is in the range [1, 10^4].
- Node values and val in [-100, 100].
- 2 <= depth <= depth of tree + 1
````
