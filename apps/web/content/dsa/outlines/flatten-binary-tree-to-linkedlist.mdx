Flatten a binary tree to a linked list in-place using TreeNode: right pointer is next preorder node, left is always null.

## Examples

````text
Example 1:
Input: root = [1,2,5,3,4,None,6]
Output: preorder chain 1->2->3->4->5->6 with left pointers null.
````

## Constraints

````text
- The number of nodes is in the range [0, 2000].
- Node values in [-100, 100].
````
