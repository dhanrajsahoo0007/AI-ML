Given an integer array nums and a positive integer k, return the maximum value in
each sliding window of size k as the window moves from left to right.

## Examples

````text
Example 1:
    Input: nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
    Output: [3, 3, 5, 5, 6, 7]
Example 2:
    Input: nums = [1], k = 1
    Output: [1]
````

## Constraints

````text
- 1 <= k <= len(nums) <= 10^5
````

## Approach

**Pattern:** Monotonic deque on indices
Keep deque indices in decreasing value order so the front always points to the current maximum.

1. Pop from the back while the new value is greater than or equal to values at those indices.
2. Push the current index; drop front indices that left the window.
3. Once the window is full, append nums\[deque\[0\]\] to the answer.

## Complexity

**Time:** O(n) - Each index is pushed and popped at most once from the deque.

**Space:** O(k) - The deque holds at most k indices.

## Solution

````python
from collections import deque
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq: deque[int] = deque()
        out: List[int] = []

        for i in range(len(nums)):
            while dq and nums[dq[-1]] <= nums[i]:
                dq.pop()
            dq.append(i)

            if dq[0] <= i - k:
                dq.popleft()

            if i >= k - 1:
                out.append(nums[dq[0]])

        return out
````
