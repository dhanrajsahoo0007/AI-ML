Given an integer array nums and a positive integer k, return the maximum value in
each sliding window of size k as the window moves from left to right.

## Examples

````text
Example 1:
    Input: nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
    Output: [3, 3, 5, 5, 6, 7]
Example 2:
    Input: nums = [1], k = 1
    Output: [1]
````

## Constraints

````text
- 1 <= k <= len(nums) <= 10^5
````
