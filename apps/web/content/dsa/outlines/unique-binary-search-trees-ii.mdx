Given n, generate every structurally unique BST that stores values 1..n. Return
the list of roots (order among trees is not specified by the problem).

## Examples

````text
Example 1:
    Input: n = 1
    Output: a single tree with node 1
Example 2:
    Input: n = 3
    Output: 5 distinct trees (Catalan number C_3)
````

## Constraints

````text
- 1 <= n <= 8
````
