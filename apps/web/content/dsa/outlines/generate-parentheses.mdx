Given n pairs of parentheses, generate every well-formed parentheses string of length 2n.

## Examples

````text
Example 1:
Input: n = 3
Output: five strings (Catalan number C3)
````

## Constraints

````text
- 1 <= n <= 4 in exhaustive tests
````
