Return the preorder traversal of a binary tree using Morris traversal without stack or recursion.

## Examples

````text
Example 1:
Input: root = [1,2,3,4,5]
Output: [1,2,4,5,3]
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
````
