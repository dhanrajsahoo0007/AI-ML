Given n non-negative integers representing bar heights, compute how much water
can be trapped after raining between the bars.

## Examples

````text
Example 1:
    Input: height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
    Output: 6
Example 2:
    Input: height = [4, 2, 0, 3, 2, 5]
    Output: 9
````

## Constraints

````text
- n == len(height)
- 1 <= n <= 2 * 10^4
- 0 <= height[i] <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Prefix/suffix DP (two-pass)
Water above i is min(max left, max right) minus height\[i\], using precomputed arrays.

1. left\_max\[i\] = max(height\[0..i\]); right\_max\[i\] = max(height\[i..n-1\]).
2. Sum max(0, min(left\_max\[i\], right\_max\[i\]) - height\[i\]).

## Complexity

**Time:** O(n) - three linear passes.

**Space:** O(n) - two auxiliary arrays.

## Solution

````python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        if not height:
            return 0
        n = len(height)
        left_max = [0] * n
        right_max = [0] * n
        left_max[0] = height[0]
        for i in range(1, n):
            left_max[i] = max(left_max[i - 1], height[i])
        right_max[n - 1] = height[n - 1]
        for i in range(n - 2, -1, -1):
            right_max[i] = max(right_max[i + 1], height[i])
        return sum(max(0, min(left_max[i], right_max[i]) - height[i]) for i in range(n))
````
