An m x n binary matrix grid indicates which boys can invite which girls (1 means allowed).
Each boy invites at most one girl and each girl accepts at most one invitation. Return the
maximum number of invitations that can be accepted.

## Examples

````text
Example 1:
    Input: grid = [[1,1,1],[1,0,1],[0,0,1]]
    Output: 3
Example 2:
    Input: grid = [[1,0,1,0],[1,0,0,0],[0,0,1,0],[1,1,1,0]]
    Output: 3
````

## Constraints

````text
- 1 <= m, n <= 200
- grid[i][j] is 0 or 1
````

## Approach

**Pattern:** Graph - Bipartite maximum matching (DFS augmenting paths)

1. Maintain matchG\[girl\] = boy matched or -1.
2. For each boy, DFS try to match to an allowed girl, stealing from another boy if needed.

## Complexity

**Time:** O(m \* n \* min(m,n)) in typical assignment problems.

**Space:** O(n + m) for match arrays and recursion.

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def maximumInvitations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        match_g = [-1] * n

        def dfs(b: int, seen: List[bool]) -> bool:
            for g in range(n):
                if grid[b][g] == 0 or seen[g]:
                    continue
                seen[g] = True
                if match_g[g] == -1 or dfs(match_g[g], seen):
                    match_g[g] = b
                    return True
            return False

        ans = 0
        for b in range(m):
            if dfs(b, [False] * n):
                ans += 1
        return ans
````
