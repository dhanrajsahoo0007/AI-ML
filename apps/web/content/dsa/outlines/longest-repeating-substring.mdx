Given a string s, return the length of the longest substring that appears at
least twice (the two occurrences may overlap).

## Examples

````text
Example 1:
    Input: s = "abcd"
    Output: 0
Example 2:
    Input: s = "aababa"
    Output: 3
````

## Constraints

````text
- 2 <= len(s) <= 1500
- s contains lowercase English letters
````
