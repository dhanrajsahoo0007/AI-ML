In a party of n people labeled 0..n-1, a celebrity is someone who is known by everyone
but knows nobody (including themselves: mat\[i\]\[i\] == 0). Given an n x n matrix mat where
mat\[i\]\[j\] == 1 means person i knows person j, return the celebrity's index or -1 if none exists.

## Examples

````text
Example 1:
    Input: mat = [[0,1,0],[0,0,0],[0,1,0]]
    Output: 1
    Explanation: Person 1 is known by 0 and 2 and knows no one.

Example 2:
    Input: mat = [[0,1],[1,0]]
    Output: -1
    Explanation: Each person knows the other; there is no celebrity.
````

## Constraints

````text
- 1 <= n <= 3000
- mat[i][j] is 0 or 1
- mat[i][i] == 0
````

## Approach

**Pattern:** Candidate elimination (greedy)
If i knows j, i cannot be the celebrity; otherwise j cannot be the celebrity. One pass narrows to one candidate, then verify.

1. Let candidate be 0; for each i from 1 to n-1, if mat\[candidate\]\[i\] == 1 then candidate = i else keep candidate.
2. Confirm: for all i != candidate, mat\[candidate\]\[i\] must be 0 and mat\[i\]\[candidate\] must be 1.
3. If confirmation fails, return -1; else return candidate.

## Complexity

**Time:** O(n) - One elimination pass and one verification pass over n people (matrix lookups O(1)).

**Space:** O(1) - Only the candidate index is stored.

## Solution

````python
from typing import List


class Solution:
    def findCelebrity(self, mat: List[List[int]]) -> int:
        n = len(mat)
        candidate = 0
        for i in range(1, n):
            if mat[candidate][i] == 1:
                candidate = i
        for i in range(n):
            if i == candidate:
                continue
            if mat[candidate][i] == 1 or mat[i][candidate] == 0:
                return -1
        return candidate


class SolutionRowScan:
    """
    Alternate approach from original notes: a celebrity row is all zeros (knows nobody),
    then verify everyone else has a ``1`` in that column (everyone knows them).
    """

    def findCelebrity(self, mat: List[List[int]]) -> int:
        n = len(mat)
        potential = -1
        for person in range(n):
            if sum(mat[person]) == 0:
                potential = person
                break
        if potential == -1:
            return -1
        for person in range(n):
            if person != potential and mat[person][potential] != 1:
                return -1
        return potential
````
