In a party of n people labeled 0..n-1, a celebrity is someone who is known by everyone
but knows nobody (including themselves: mat\[i\]\[i\] == 0). Given an n x n matrix mat where
mat\[i\]\[j\] == 1 means person i knows person j, return the celebrity's index or -1 if none exists.

## Examples

````text
Example 1:
    Input: mat = [[0,1,0],[0,0,0],[0,1,0]]
    Output: 1
    Explanation: Person 1 is known by 0 and 2 and knows no one.

Example 2:
    Input: mat = [[0,1],[1,0]]
    Output: -1
    Explanation: Each person knows the other; there is no celebrity.
````

## Constraints

````text
- 1 <= n <= 3000
- mat[i][j] is 0 or 1
- mat[i][i] == 0
````
