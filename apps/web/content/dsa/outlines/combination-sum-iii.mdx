Find all unique combinations of k numbers from 1..9 that sum to n; each digit at most once.

## Examples

````text
Example 1:
    Input: k = 3, n = 7
    Output: [[1, 2, 4]]

Example 2:
    Input: k = 3, n = 9
    Output: [[1,2,6],[1,3,5],[2,3,4]]
````

## Constraints

````text
- 2 <= k <= 9
- 1 <= n <= 60
````

<PremiumBreak />

## Approach

**Pattern:** Bounded combination backtracking
Recurse with increasing next digit and track remaining sum and count.

1. DFS(start, remaining, path): if len(path) == k and remaining == 0, record.
2. Prune when remaining &lt; 0 or len(path) &gt; k.
3. Loop digit from start to 9, append, recurse with digit + 1.

## Complexity

**Time:** O(C(9, k)) - choose k distinct digits from nine.

**Space:** O(k) - depth.

## Solution

````python
from typing import List


class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result: List[List[int]] = []

        def dfs(start: int, remaining: int, path: List[int]) -> None:
            if len(path) == k:
                if remaining == 0:
                    result.append(path[:])
                return
            if remaining < 0 or len(path) > k:
                return
            for d in range(start, 10):
                path.append(d)
                dfs(d + 1, remaining - d, path)
                path.pop()

        dfs(1, n, [])
        return result
````
