Given an integer array nums, find the contiguous subarray (at least one element) with the largest sum.

## Examples

````text
Example 1:
    Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
    Output: 6

Example 2:
    Input: nums = [1]
    Output: 1

Example 3:
    Input: nums = [5,4,-1,7,8]
    Output: 23
````

## Constraints

````text
- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
````
