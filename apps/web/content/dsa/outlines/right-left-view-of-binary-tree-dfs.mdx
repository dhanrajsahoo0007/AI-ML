Given the root of a binary tree, return the left boundary view and right boundary view using DFS.
At each depth, the left view records the first node encountered in preorder when visiting left before right;
the right view records the first node when visiting right before left.

## Examples

````text
Example 1:
Tree:
      1
    /              2     3
  / \   /          4  10 9  10
             5
                 6
Output: right view [1,3,10,5,6], left view [1,2,4,5,6]
````

## Constraints

````text
- The number of nodes is in the range [0, 5000].
- Node values fit in 32-bit signed integers.
````
