Given the number of vertices V and a list of undirected edges, build an adjacency list and return
the depth-first traversal order starting from vertex 0. Neighbors may be visited in adjacency-list order.

## Examples

````text
Example 1:
    Input: V = 5, edges = [[0,2],[0,3],[0,1],[2,4]]
    Output: [0, 2, 4, 3, 1] (depends on neighbor order in adjacency lists)
Example 2:
    Input: V = 4, edges = [[0,1],[0,3],[1,2]]
    Output: [0, 1, 2, 3]
````

## Constraints

````text
- 1 <= V <= 10^4
- 0 <= u, v < V
````

<PremiumBreak />

## Approach

**Pattern:** Depth-first search on graph
Recursively visit unvisited neighbors from a start vertex using a visited array.

1. Build undirected adjacency lists from edges.
2. Mark the start vertex visited and append to the result.
3. For each neighbor not yet visited, recurse.

## Complexity

**Time:** O(V + E) — each vertex and edge is touched once in the traversal.

**Space:** O(V + E) — adjacency list plus recursion stack O(V).

## Solution

````python
from typing import List


class Solution:
    def create_graph(self, V: int, edges: List[List[int]]) -> List[List[int]]:
        adj: List[List[int]] = [[] for _ in range(V)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        return adj

    def dfs_of_graph(self, V: int, adj: List[List[int]]) -> List[int]:
        visited = [False] * V
        result: List[int] = []

        def dfs(u: int) -> None:
            visited[u] = True
            result.append(u)
            for v in adj[u]:
                if not visited[v]:
                    dfs(v)

        dfs(0)
        return result
````
