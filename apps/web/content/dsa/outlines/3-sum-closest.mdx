Given an integer array nums and an integer target, choose three distinct integers from nums whose sum is
closest to target and return that sum.

## Examples

````text
Example 1:
    Input: nums = [-1, 2, 1, -4], target = 1
    Output: 2
Example 2:
    Input: nums = [0, 0, 0], target = 1
    Output: 0
````

## Constraints

````text
- 3 <= len(nums) <= 1000
- -1000 <= nums[i] <= 1000
- -10^4 <= target <= 10^4
````
