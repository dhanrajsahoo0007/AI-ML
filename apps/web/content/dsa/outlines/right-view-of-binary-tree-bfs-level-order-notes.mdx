Given the root of a binary tree, return the values of the nodes you can see ordered from top to bottom
when standing on the right side of the tree (rightmost node at each level).

## Examples

````text
Example 1:
    Input: root = [1,2,3,None,5,None,4]
    Output: [1,3,4]
Example 2:
    Input: root = [1,None,3]
    Output: [1,3]
````

## Constraints

````text
- The number of nodes is in the range [0, 100].
- Node values fit in 32-bit signed integers.
````

## Approach

**Pattern:** BFS level order
Process each level; the last node dequeued at each level is the rightmost visible node.

1. If root is None, return \[\].
2. Use a queue for level-order traversal.
3. For each level, pop all nodes at that level; track the last node's value, enqueue children.

## Complexity

**Time:** O(n) - visit each node once.

**Space:** O(w) - queue size up to the widest level (O(n) for a complete last level).
Restored (original notes, diagrams, and walkthrough):
Computes the right side view of a binary tree.

Time Complexity: O(n), where n is the number of nodes in the tree.
- We visit each node exactly once during the level-order traversal.

Space Complexity: O(d), where d is the maximum width of the tree.
- In the worst case (a complete binary tree), the queue will hold
all nodes at the deepest level, which is at most n/2 for a complete tree.
- For a skewed tree, d would be 1, resulting in O(1) space.

## Solution

````python
from collections import deque
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_from_level_order(values: List[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    q: deque[TreeNode] = deque([root])
    i = 1
    while q and i < len(values):
        node = q.popleft()
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            q.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            q.append(node.right)
        i += 1
    return root


class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        result: List[int] = []
        queue: deque[TreeNode] = deque([root])
        while queue:
            level_size = len(queue)
            right_val = 0
            for _ in range(level_size):
                node = queue.popleft()
                right_val = node.val
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            result.append(right_val)
        return result
````
