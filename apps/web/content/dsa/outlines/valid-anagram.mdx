Given two strings s and t, return True if t is an anagram of s, otherwise False.
An anagram uses all original letters exactly once, rearranged.

## Examples

````text
Example 1:
    Input: s = "anagram", t = "nagaram"
    Output: True
Example 2:
    Input: s = "rat", t = "car"
    Output: False
````

## Constraints

````text
- 1 <= len(s), len(t) <= 5 * 10^4
- s and t consist of lowercase English letters.
````

<PremiumBreak />

## Approach

**Pattern:** Hash map / frequency counter
Compare character counts; lengths must match first.

1. If len(s) != len(t), return False.
2. Count occurrences of each character in s and in t.
3. Return whether the two frequency maps are equal.

## Complexity

**Time:** O(n) - n is the length of the strings (single pass each).

**Space:** O(1) - At most 26 buckets for lowercase English letters (O(k) for alphabet size k).

## Solution

````python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        count_s: dict[str, int] = {}
        count_t: dict[str, int] = {}
        for i in range(len(s)):
            count_s[s[i]] = 1 + count_s.get(s[i], 0)
            count_t[t[i]] = 1 + count_t.get(t[i], 0)
        return count_s == count_t  # same frequency maps <=> anagram
````
