Buildings line up east-to-west with the ocean to the right. Return indices whose height exceeds
every building to their right.

## Examples

````text
Example 1:
Input: [4, 2, 3, 1]
Output: [0, 2, 3]
````

## Constraints

````text
- 1 <= len(heights) <= 10^5
````
