For every i in \[0, n\], compute the number of 1 bits in the binary form of i.
Return the list of counts.

## Examples

````text
Example 1:
    Input: n = 2
    Output: [0,1,1]
Example 2:
    Input: n = 5
    Output: [0,1,1,2,1,2]
````

## Constraints

````text
- 0 <= n <= 10^5
````
