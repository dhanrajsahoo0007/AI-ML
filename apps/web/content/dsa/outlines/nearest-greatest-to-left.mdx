Given an integer array, for each index return the nearest element to the left that is strictly
greater than the current value. If none exists, use -1.

## Examples

````text
Example 1:
Input: [4, 5, 2, 25, 7, 8]
Output: [-1, -1, 5, -1, 25, 25]
````

## Constraints

````text
- 1 <= len(arr) <= 10^5
````

<PremiumBreak />

## Approach

**Pattern:** Monotonic Decreasing Stack
Scan left-to-right; the stack preserves candidates for the next greater on the left.

1. Initialize result with -1 and an empty stack.
2. For each index i from 0 to n-1, pop while top &lt;= arr\[i\].
3. If stack is non-empty, result\[i\] is stack\[-1\]; push arr\[i\].
4. Return result.

Problem Statement:
Given an array, find the nearest greater element to the left for each element.
If there is no greater element to the left, use -1.

## Complexity

**Time:** O(n) - Linear amortized stack work per element.

**Space:** O(n) - Stack and output storage.

## Solution

````python
from typing import List


class Solution:
    def nearestGreaterToLeft(self, arr: List[int]) -> List[int]:
        n = len(arr)
        result = [-1] * n
        stack: List[int] = []
        for i in range(n):
            while stack and stack[-1] <= arr[i]:
                stack.pop()
            if stack:
                result[i] = stack[-1]
            stack.append(arr[i])
        return result
````
