Given a directed graph with V vertices and directed edges \[u, v\], return a topological ordering using
Kahn's algorithm. If the graph contains a directed cycle, return an empty list.

## Examples

````text
Example 1:
    Input: V = 6, edges = [[5,2],[5,0],[4,0],[4,1],[2,3],[3,1]]
    Output: A permutation of 0..V-1 satisfying all edge directions (non-empty for a DAG).
Example 2:
    Input: V = 4, edges = [[0,1],[1,2],[2,3],[3,1]]
    Output: [] (cycle present)
````

## Constraints

````text
- 1 <= V, E <= 10^4
````
