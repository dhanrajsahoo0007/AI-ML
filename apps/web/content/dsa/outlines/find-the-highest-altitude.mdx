A trip has n + 1 points at altitudes. You start at altitude 0. gain\[i\] is the
net gain from point i to i + 1. Return the highest altitude reached.

## Examples

````text
Example 1:
Input: gain = [-5, 1, 5, 0, -7]
Output: 1
````

## Constraints

````text
- n == len(gain)
- 1 <= n <= 100
- -100 <= gain[i] <= 100
````
