A trip has n + 1 points at altitudes. You start at altitude 0. gain\[i\] is the
net gain from point i to i + 1. Return the highest altitude reached.

## Examples

````text
Example 1:
Input: gain = [-5, 1, 5, 0, -7]
Output: 1
````

## Constraints

````text
- n == len(gain)
- 1 <= n <= 100
- -100 <= gain[i] <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Prefix Sum
Track cumulative altitude; the maximum of the running sum is the answer.

1. Start current = 0, best = 0.
2. For each g in gain, add to current and update best = max(best, current).
3. Return best.

## Complexity

**Time:** O(n) - one pass.

**Space:** O(1) - only scalars.

## Solution

````python
from typing import List


class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        cur = 0
        best = 0
        for g in gain:
            cur += g
            best = max(best, cur)
        return best
````
