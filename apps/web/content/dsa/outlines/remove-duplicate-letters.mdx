Remove duplicate letters so each letter appears once while keeping the result lexicographically smallest.

## Examples

````text
Example 1:
Input: "bcabc"
Output: "abc"
````

## Constraints

````text
- 1 <= len(s) <= 10^4
- s uses lowercase English letters
````
