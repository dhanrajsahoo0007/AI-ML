Play generalized tic-tac-toe on an n x n board where K consecutive identical marks in any
row, column, or diagonal wins. Process moves in order; return the winner ('X' or 'O') as
soon as someone wins, else None.

## Examples

````text
Example 1:
n=5, K=4, moves leading to four X in row 0 -> 'X'.
````

## Constraints

````text
- 3 <= n, K <= n <= 100; moves are (player, row, col) with zero-based indices.
````

<PremiumBreak />

## Approach

**Pattern:** Incremental win check from last move
After each placement, scan four directions from that cell counting consecutive same player.

1. Maintain a grid; apply moves in order (later move overwrites a cell if the spec allows).
2. After each move, from (r,c) count consecutive marks in four axis directions.
3. If any run reaches K, return that player.

## Complexity

**Time:** O(K) per move after placement.

**Space:** O(n^2) for the board.

## Solution

````python
from typing import List, Optional, Tuple


class TicTacToe:
    def __init__(self, n: int, k: int) -> None:
        self.n = n
        self.k = k
        self._board: List[List[Optional[str]]] = [[None] * n for _ in range(n)]

    def play_moves(self, moves: List[Tuple[str, int, int]]) -> Optional[str]:
        for player, r, c in moves:
            self._board[r][c] = player
            if self._wins_from(r, c, player):
                return player
        return None

    def _wins_from(self, r: int, c: int, p: str) -> bool:
        n, k = self.n, self.k
        dirs = ((1, 0), (0, 1), (1, 1), (1, -1))
        for dr, dc in dirs:
            cnt = 1
            for sign in (-1, 1):
                rr, cc = r + sign * dr, c + sign * dc
                while 0 <= rr < n and 0 <= cc < n and self._board[rr][cc] == p:
                    cnt += 1
                    rr += sign * dr
                    cc += sign * dc
            if cnt >= k:
                return True
        return False
````
