You are given a sorted integer array arr containing 1 and prime numbers.
For every i and j where 0 &lt;= i &lt; j &lt; arr.length, we consider the fraction arr\[i\] / arr\[j\].
Return the kth smallest fraction. Return as \[arr\[i\], arr\[j\]\].

## Examples

````text
Example 1:
    Input: arr = [1,2,3,5], k = 3
    Output: [2,5]
    Explanation: Fractions in order: 1/5, 1/3, 2/5, 1/2, 3/5, 2/3. Third is 2/5.

Example 2:
    Input: arr = [1,7], k = 1
    Output: [1,7]
````

## Constraints

````text
- 2 <= arr.length <= 1000
- 1 <= arr[i] <= 3 * 10^4
- arr[0] == 1
- arr[i] is a prime number for i > 0.
- All numbers are unique and sorted in strictly increasing order.
- 1 <= k <= arr.length * (arr.length - 1) / 2
````

## Approach

**Pattern:** K-Way Merge
Each numerator defines a sorted sequence of fractions (arr\[i\]/arr\[n-1\], arr\[i\]/arr\[n-2\], ...).
We merge these sequences using a min-heap to find the kth smallest.

1. Initialize heap with fractions arr\[i\]/arr\[n-1\] for each i (smallest from each row).
2. Pop the smallest fraction k-1 times.
3. Each time, push the next fraction from the same numerator row.
4. The kth pop gives the answer.

## Complexity

**Time:** O(k log n), where n is the array length

**Space:** O(n) for the heap

## Solution

````python
import heapq
from typing import List


class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        heap = []

        for i in range(n - 1):
            heapq.heappush(heap, (arr[i] / arr[-1], i, n - 1))

        for _ in range(k - 1):
            _, i, j = heapq.heappop(heap)
            if j - 1 > i:
                heapq.heappush(heap, (arr[i] / arr[j - 1], i, j - 1))

        _, i, j = heap[0]
        return [arr[i], arr[j]]


class SolutionBruteForceAllPairs:
    """Original notebook approach: materialize all fractions, keep k smallest with a max-heap."""

    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        pq: list[tuple[float, int, int]] = []
        for i in range(len(arr)):
            for j in range(i + 1, len(arr)):
                frac = arr[i] / arr[j]
                if len(pq) < k:
                    heapq.heappush(pq, (-frac, arr[i], arr[j]))
                elif frac < -pq[0][0]:
                    heapq.heappushpop(pq, (-frac, arr[i], arr[j]))
        _, num, den = pq[0]
        return [num, den]
````
