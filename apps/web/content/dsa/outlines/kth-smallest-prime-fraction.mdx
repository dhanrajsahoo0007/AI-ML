You are given a sorted integer array arr containing 1 and prime numbers.
For every i and j where 0 &lt;= i &lt; j &lt; arr.length, we consider the fraction arr\[i\] / arr\[j\].
Return the kth smallest fraction. Return as \[arr\[i\], arr\[j\]\].

## Examples

````text
Example 1:
    Input: arr = [1,2,3,5], k = 3
    Output: [2,5]
    Explanation: Fractions in order: 1/5, 1/3, 2/5, 1/2, 3/5, 2/3. Third is 2/5.

Example 2:
    Input: arr = [1,7], k = 1
    Output: [1,7]
````

## Constraints

````text
- 2 <= arr.length <= 1000
- 1 <= arr[i] <= 3 * 10^4
- arr[0] == 1
- arr[i] is a prime number for i > 0.
- All numbers are unique and sorted in strictly increasing order.
- 1 <= k <= arr.length * (arr.length - 1) / 2
````
