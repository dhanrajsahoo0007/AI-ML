Maximum path sum between any two leaves in a binary tree (at least two nodes).

## Examples

````text
Example 1:
Tree -10 / 9 \ 20 / 15 7 -> 42
````

## Constraints

````text
- The tree has at least two nodes.
````

<PremiumBreak />

## Approach

**Pattern:** Post-order DFS
At nodes with two children, combine best sums from subtrees that reach leaves.

## Complexity

**Time:** O(n).

**Space:** O(h) recursion depth.

## Solution

````python
from dataclasses import dataclass
from typing import Optional


@dataclass
class TreeNode:
    val: int = 0
    left: Optional["TreeNode"] = None
    right: Optional["TreeNode"] = None


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.ans = -10**15

        def dfs(node: Optional[TreeNode]) -> float:
            if not node:
                return float("-inf")
            if not node.left and not node.right:
                return float(node.val)
            l = dfs(node.left) if node.left else float("-inf")
            r = dfs(node.right) if node.right else float("-inf")
            if node.left and node.right:
                self.ans = max(self.ans, node.val + l + r)
                return float(node.val) + max(l, r)
            return float(node.val) + (l if l != float("-inf") else r)

        dfs(root)
        return int(self.ans)
````
