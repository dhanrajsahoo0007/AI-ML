Given n pairs of parentheses, generate every well-formed parentheses string of length 2n.

## Examples

````text
Example 1:
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"] (order may vary)
````

## Constraints

````text
- 1 <= n <= 4
````

<PremiumBreak />

## Approach

**Pattern:** Decision backtracking with feasibility
Track how many opens and closes remain; only add ')' if it does not exceed '(' count so far.

1. Start with empty string and open = close = n available.
2. If open &gt; 0, append '(' and recurse with open - 1.
3. If close &gt; open (more opens used than closes), append ')' and recurse with close - 1.
4. When both are 0, record the string.

## Complexity

**Time:** O(4^n / sqrt(n)) - Catalan number of valid strings, each built in O(n).

**Space:** O(n) - recursion depth and string builder path.

## Solution

````python
from typing import List


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result: List[str] = []

        def backtrack(open_left: int, close_left: int, path: List[str]) -> None:
            if open_left == 0 and close_left == 0:
                result.append("".join(path))
                return
            if open_left > 0:
                path.append("(")
                backtrack(open_left - 1, close_left, path)
                path.pop()
            if close_left > open_left:
                path.append(")")
                backtrack(open_left, close_left - 1, path)
                path.pop()

        backtrack(n, n, [])
        return result
````
