Given a start gene string, end gene string, and a bank of valid gene strings, a gene string
is eight characters long and each character is 'A','C','G', or 'T'. One mutation changes one
character. Return the minimum number of mutations needed to mutate from start to end such
that each intermediate gene is in the bank. If impossible, return -1.

## Examples

````text
Example 1:
    Input: start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]
    Output: 1
Example 2:
    Input: start = "AACCGGTT", end = "AAACGGTA",
           bank = ["AACCGGTA","AACCGCTA","AAACGGTA"]
    Output: 2
````

## Constraints

````text
- len(start) == len(end) == 8
- 0 <= len(bank) <= 10
- start, end, and bank[i] consist only of ['A','C','G','T']
````

## Approach

**Pattern:** Graph - BFS on implicit mutation graph

1. Treat each valid gene as a node; edges connect strings differing in exactly one position.
2. BFS from start using bank as allowed set (including end if present).
3. Return steps when end is reached, else -1.

## Complexity

**Time:** O(4 \* 8 \* N) per expansion roughly, bank size small.

**Space:** O(N) for visited and queue.

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def minMutation(self, start: str, end: str, bank: List[str]) -> int:
        bank_set = set(bank)
        if end not in bank_set:
            return -1
        chars = "ACGT"
        q = deque([(start, 0)])
        seen = {start}
        while q:
            gene, steps = q.popleft()
            if gene == end:
                return steps
            g = list(gene)
            for i in range(8):
                orig = g[i]
                for ch in chars:
                    if ch == orig:
                        continue
                    g[i] = ch
                    nxt = "".join(g)
                    if nxt in bank_set and nxt not in seen:
                        seen.add(nxt)
                        q.append((nxt, steps + 1))
                g[i] = orig
        return -1
````
