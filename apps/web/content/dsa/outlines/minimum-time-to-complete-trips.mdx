time\[i\] is minutes for bus i to finish one trip. Buses run in parallel. Return the minimum time T
such that the total number of completed trips by all buses is at least totalTrips.

## Examples

````text
Example 1:
Input: time = [1, 2, 3], totalTrips = 5
Output: 3
````

## Constraints

````text
- 1 <= len(time) <= 10^5
- 1 <= time[i], totalTrips <= 10^7
````
