A ZigZag path starts at any node, alternates left/right moves along parent-child edges, and stops when no move exists.
Return the maximum number of edges on such a path.

## Examples

````text
Example 1:
    Tree:
          1
        /              2     3
        \                  4     6
        /
       5
    Longest zigzag 1 -> 2 -> 4 -> 5 uses three edges (left, right, left).
Example 2:
    Single node -> 0 edges.
````

## Constraints

````text
- The number of nodes is in the range [1, 5 * 10^4].
- Node values in [1, 100].
````

## Approach

**Pattern:** DFS with directional streak counts
When moving left, extend a streak that came from the parent's right; otherwise reset the opposite streak.

1. DFS(node, left\_len, right\_len) tracks consecutive edges ending at node from a forced direction.
2. Going left: recurse with (right\_len + 1, 0); going right: recurse with (0, left\_len + 1).
3. Answer is the maximum left\_len or right\_len observed.

## Complexity

**Time:** O(n)

**Space:** O(h) recursion.
Restored (original notes, diagrams, and walkthrough):
Problem Statement:
Given a binary tree root, a ZigZag path for a binary tree is defined as follows:
- Choose any node in the binary tree and a direction (right or left).
- If the current direction is right, move to the right child of the current node; otherwise, move to the left child.
- Change the direction from right to left or from left to right.
- Repeat steps 2 and 3 until you can't move in the tree.
Zigzag length is defined as the number of nodes visited - 1. (A single node has a length of 0).
Return the longest ZigZag path contained in that tree.

Time Complexity for both approaches: O(N), where N is the number of nodes in the tree.
- Each node is visited exactly once in the traversal.

Space Complexity for both approaches: O(H), where H is the height of the tree.
- In the worst case (skewed tree), H can be N.
- This space is used by the recursion stack.
- For a balanced tree, the space complexity would be O(log N).

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_from_level_order(values: List[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    from collections import deque

    root = TreeNode(values[0])
    q: deque[TreeNode] = deque([root])
    i = 1
    while q and i < len(values):
        node = q.popleft()
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            q.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            q.append(node.right)
        i += 1
    return root


def build_sample_zigzag_tree() -> TreeNode:
    root = TreeNode(1)
    root.left = TreeNode(2)
    root.right = TreeNode(3)
    root.left.right = TreeNode(4)
    root.right.right = TreeNode(6)
    root.left.right.left = TreeNode(5)
    return root


class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        self.best = 0

        def dfs(node: Optional[TreeNode], left_len: int, right_len: int) -> None:
            if not node:
                return
            self.best = max(self.best, left_len, right_len)
            dfs(node.left, right_len + 1, 0)
            dfs(node.right, 0, left_len + 1)

        dfs(root, 0, 0)
        return self.best
````
