A ZigZag path starts at any node, alternates left/right moves along parent-child edges, and stops when no move exists.
Return the maximum number of edges on such a path.

## Examples

````text
Example 1:
    Tree:
          1
        /              2     3
        \                  4     6
        /
       5
    Longest zigzag 1 -> 2 -> 4 -> 5 uses three edges (left, right, left).
Example 2:
    Single node -> 0 edges.
````

## Constraints

````text
- The number of nodes is in the range [1, 5 * 10^4].
- Node values in [1, 100].
````
