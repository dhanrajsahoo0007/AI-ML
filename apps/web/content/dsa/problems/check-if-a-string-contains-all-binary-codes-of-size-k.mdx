Given a binary string s and an integer k, determine whether every binary code of
length k appears somewhere in s as a contiguous substring.

## Examples

````text
Example 1:
    Input: s = "001101100", k = 2
    Output: True

Example 2:
    Input: s = "0110", k = 2
    Output: False

Example 3:
    Input: s = "0000000000101111001", k = 3
    Output: True
````

## Constraints

````text
- 1 <= len(s) <= 5 * 10^5
- 1 <= k <= 20
````

## Approach

**Pattern:** Rolling hash / set of seen windows
There are 2^k codes; track which appear using integers of k bits while sliding.

1. If len(s) &lt; 2^k + k - 1 roughly, early check length: need len(s) &gt;= k + 2^k - 1? Actually need at least k + 2^k - 1 for all distinct - standard: len(s) &gt;= k + 2^k - 1 is necessary when all distinct non-overlap... Simpler: collect all length-k substrings in a set and compare size to 2^k.
2. Slide a window, update integer key for the binary substring.
3. Return whether the set size reaches 2^k.

## Complexity

**Time:** O(n) - Each index processed once.

**Space:** O(2^k) - At most one entry per code.

## Solution

````python
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        need = 1 << k
        if len(s) < k + need - 1:
            return False
        cur = 0
        mask = need - 1
        seen: set[int] = set()
        for i, ch in enumerate(s):
            cur = ((cur << 1) | (ch == "1")) & mask
            if i >= k - 1:
                seen.add(cur)
                if len(seen) == need:
                    return True
        return len(seen) == need
````
