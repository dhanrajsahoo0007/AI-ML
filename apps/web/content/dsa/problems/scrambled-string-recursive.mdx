Determine if b is a scrambled string of a (LeetCode 87).

<PremiumBreak />

## Approach

**Pattern:** Divide and conquer with pruning
Same multiset; try every split with straight or swapped children.

## Complexity

**Time:** O(n^4) worst without memo; with memo O(n^3) typical.

## Solution

````python
class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        if s1 == s2:
            return True
        if sorted(s1) != sorted(s2):
            return False
        n = len(s1)
        for i in range(1, n):
            if (self.isScramble(s1[:i], s2[:i]) and self.isScramble(s1[i:], s2[i:])) or (
                self.isScramble(s1[:i], s2[n - i :]) and self.isScramble(s1[i:], s2[: n - i])
            ):
                return True
        return False
````
