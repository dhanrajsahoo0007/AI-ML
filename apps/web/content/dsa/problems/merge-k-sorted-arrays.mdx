You are given an array of k linked-lists, each linked-list is sorted in ascending order.
Merge all the linked-lists into one sorted linked-list and return it.

## Examples

````text
Example 1:
    Input: lists = [[1,4,5],[1,3,4],[2,6]]
    Output: [1,1,2,3,4,4,5,6]

Example 2:
    Input: lists = []
    Output: []

Example 3:
    Input: lists = [[]]
    Output: []
````

## Constraints

````text
- k == lists.length
- 0 <= k <= 10^4
- 0 <= lists[i].length <= 500
- -10^4 <= lists[i][j] <= 10^4
- lists[i] is sorted in ascending order.
- The sum of lists[i].length will not exceed 10^4.
````

## Approach

**Pattern:** K-Way Merge
We use a min-heap to always pick the smallest element across all k lists.
Each element in the heap is a tuple (value, list\_index, element\_index).

1. Push the first element of each list into the min-heap.
2. Pop the smallest element, add it to result.
3. Push the next element from the same list (if available) into the heap.
4. Repeat until the heap is empty.

## Complexity

**Time:** O(N log k), where N is total elements across all lists
- Each push/pop is O(log k) since the heap has at most k elements.

**Space:** O(k) for the heap

## Solution

````python
import heapq
from typing import List


class Solution:
    def mergeKSortedArrays(self, lists: List[List[int]]) -> List[int]:
        min_heap = []
        result = []

        for i, lst in enumerate(lists):
            if lst:
                heapq.heappush(min_heap, (lst[0], i, 0))

        while min_heap:
            val, list_idx, elem_idx = heapq.heappop(min_heap)
            result.append(val)

            # Push successor from the same list (if any) to keep one pointer per list in the heap.
            if elem_idx + 1 < len(lists[list_idx]):
                next_val = lists[list_idx][elem_idx + 1]
                heapq.heappush(min_heap, (next_val, list_idx, elem_idx + 1))

        return result
````
