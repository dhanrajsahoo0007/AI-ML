Given a bitonic array (strictly increasing then strictly decreasing) and a target, return its index
or -1.

## Examples

````text
Example 1:
    Input: mountain = [1, 3, 8, 12, 4, 2], target = 4
    Output: 4

Example 2:
    Input: mountain = [1, 3, 8, 12, 9, 5, 2], target = 7
    Output: -1
````

## Constraints

````text
- 3 <= len(mountain) <= 10^4
- -10^9 <= mountain[i] <= 10^9
````

## Approach

**Pattern:** Peak + Two Binary Searches
Find the peak, compare target to peak value, then search ascending left half and descending right half.

1. Find peak index with binary search on slope.
2. If target equals mountain\[peak\], return peak; if greater than peak value, return -1.
3. Binary search ascending on \[0, peak-1\]; if miss, binary search descending on \[peak+1, n-1\].

## Complexity

**Time:** O(log n) - Three logarithmic phases.

**Space:** O(1) - Iterative only.
Restored (original notes, diagrams, and walkthrough):
Problem Statement:
Given a Bitonic array and a target element, find the index of the target element in the array.
A Bitonic array is an array that is first strictly increasing and then strictly decreasing. If the element is not present, return -1.

Algorithm:
1. Find the peak element (maximum) in the Bitonic array using the previous findPeakElement function.
2. If the target is equal to the peak element, return its index.
3. If the target is greater than the peak element, it's not in the array, return -1.
4. Perform binary search on the left (ascending) part of the array.
5. If not found, perform binary search on the right (descending) part of the array.
6. If still not found, return -1.

Time Complexity: O(log n), where n is the length of the array
Space Complexity: O(1), as we only use a constant amount of extra space

Note: This algorithm assumes that the input array is indeed Bitonic.

## Solution

````python
from typing import List


class Solution:
    def findInMountainArray(self, mountain: List[int], target: int) -> int:
        def peak_index() -> int:
            n = len(mountain)
            if n == 1:
                return 0
            if mountain[0] > mountain[1]:
                return 0
            if mountain[n - 1] > mountain[n - 2]:
                return n - 1
            lo, hi = 1, n - 2
            while lo <= hi:
                mid = (lo + hi) // 2
                if mountain[mid - 1] < mountain[mid] > mountain[mid + 1]:
                    return mid
                if mountain[mid] < mountain[mid + 1]:
                    lo = mid + 1
                else:
                    hi = mid - 1
            return lo

        def bs_asc(lo: int, hi: int) -> int:
            while lo <= hi:
                mid = (lo + hi) // 2
                if mountain[mid] == target:
                    return mid
                if mountain[mid] < target:
                    lo = mid + 1
                else:
                    hi = mid - 1
            return -1

        def bs_desc(lo: int, hi: int) -> int:
            while lo <= hi:
                mid = (lo + hi) // 2
                if mountain[mid] == target:
                    return mid
                if mountain[mid] > target:
                    lo = mid + 1
                else:
                    hi = mid - 1
            return -1

        p = peak_index()
        if mountain[p] == target:
            return p
        if target > mountain[p]:
            return -1
        left = bs_asc(0, p - 1)
        if left != -1:
            return left
        return bs_desc(p + 1, len(mountain) - 1)
````
