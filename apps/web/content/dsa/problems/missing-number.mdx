nums contains n distinct numbers from 0..n inclusive except exactly one missing.
Return the missing value.

## Examples

````text
Example 1:
    Input: nums = [3,0,1]
    Output: 2
Example 2:
    Input: nums = [0,1]
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- Values are unique in [0, n]
````

<PremiumBreak />

## Approach

**Pattern:** XOR / Gauss sum
XOR all indices and values; duplicates cancel leaving the missing index.

1. x = n then XOR every index i and nums\[i\].
2. Return x.

## Complexity

**Time:** O(n)

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        x = len(nums)
        for i, v in enumerate(nums):
            x ^= i ^ v
        return x
````
