Given an array of strings strs, group anagrams together. The answer may be in any order.

## Examples

````text
Example 1:
    Input: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
    Output: [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]] (order of groups and within groups may vary)
Example 2:
    Input: strs = [""]
    Output: [[""]]
````

## Constraints

````text
- 1 <= len(strs) <= 10^4
- 0 <= len(strs[i]) <= 100
- strs[i] consists of lowercase English letters.
````

**Order.** Any order is accepted: the tests sort your result before comparing it.

<PremiumBreak />

## Approach

**Pattern:** Hash map keyed by canonical form
Use a 26-length frequency tuple (or sorted string) as key so anagrams share one bucket.

1. For each string, build a length-26 count vector for a-z.
2. Use tuple(counts) as key in a map from key to list of strings.
3. Return all groups as a list of lists.

## Complexity

**Time:** O(n \* k) - n strings, each of length up to k for counting.

**Space:** O(n \* k) - Store every character in grouped buckets plus keys.

## Original notes

````text
Worked trace (original debug notes):
For ``["act","pots","tops","cat","stop","hat"]``, the 26-length count tuple is the key:
``(1,0,...,1,...,1)`` groups ``act`` and ``cat``; another tuple groups ``pots``, ``tops``,
``stop``; ``hat`` sits alone. Same multiset of letters always yields the same tuple key.
````

## Solution

````python
from collections import defaultdict
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        buckets: dict[tuple[int, ...], List[str]] = defaultdict(list)
        for word in strs:
            counts = [0] * 26
            for ch in word:
                counts[ord(ch) - ord("a")] += 1  # frequency signature for this word
            buckets[tuple(counts)].append(word)  # all anagrams share the same tuple key
        return list(buckets.values())


def _normalize(groups: List[List[str]]) -> List[List[str]]:
    return sorted([sorted(g) for g in groups])
````
