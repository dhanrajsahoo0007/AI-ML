Given strictly increasing stone positions stones\[0..n-1\] (stones\[0\]=0), a frog
starts on the first stone. From stone i it may jump back by 1..k earlier stones
(to any index i-j for 1&lt;=j&lt;=min(i,k)). Each jump costs abs(stones\[i\]-stones\[i-j\]).
Return the minimum total cost to reach the last stone.

## Examples

````text
Example 1:
    Input: stones = [0, 1, 3, 5, 6, 8, 12, 17], k = 5
    Output: 17
Example 2:
    Input: stones = [0, 2, 5], k = 2
    Output: 5
````

## Constraints

````text
- 1 <= n <= 10^4
- stones is strictly increasing, stones[0] == 0
- 1 <= k <= 100
````

## Approach

**Pattern:** 1D Dynamic Programming with bounded transitions
dp\[i\] = minimum cost to stand on stone i using up to k-step jumps backward.

1. dp\[0\]=0; for i&gt;=1, dp\[i\] = min over j in 1..min(i,k) of dp\[i-j\]+\|stones\[i\]-stones\[i-j\]\|.
2. Return dp\[n-1\].

## Complexity

**Time:** O(n \* k).

**Space:** O(n) for dp (can optimize with deque for special cases, not needed here).

## Solution

````python
from typing import List


class Solution:
    def minJumpCost(self, stones: List[int], k: int) -> int:
        n = len(stones)
        dp = [float("inf")] * n
        dp[0] = 0
        for i in range(1, n):
            for j in range(1, min(i, k) + 1):
                dp[i] = min(dp[i], dp[i - j] + abs(stones[i] - stones[i - j]))
        return int(dp[n - 1])
````
