Given an array of intervals intervals\[i\] = \[start\_i, end\_i\], merge every pair of
overlapping intervals and return a list of disjoint intervals that covers the same
union as the input.

## Examples

````text
Example 1:
    Input: intervals = [[1,3],[2,6],[8,10],[15,18]]
    Output: [[1,6],[8,10],[15,18]]

Example 2:
    Input: intervals = [[1,4],[4,5]]
    Output: [[1,5]]
````

## Constraints

````text
- 1 <= len(intervals) <= 10^4
- Each interval has length 2 with 0 <= start_i <= end_i <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Sort + linear merge
Sorting by start time lets overlaps appear only against the last merged interval,
so each interval is merged or appended in constant time.

1. Sort intervals by their start coordinate.
2. Seed the answer with the first interval.
3. For each next interval, merge into the last answer interval if it overlaps;
otherwise push it as a new interval.
4. Return the merged list.

## Complexity

**Time:** O(n log n) - dominated by sorting n intervals.

**Space:** O(n) - output holds up to n merged intervals (sort may use O(n) extra).

## Original notes

````text
Detailed breakdown (from original notes):
1. Sorting guarantees that any overlap must involve the most recently appended interval,
   so a single linear scan suffices after the sort.
2. Keep `output[-1]` as the interval we are actively extending.
3. If `start <= last_end`, extend `last_end` with `max(last_end, end)` even when the
   incoming interval is completely nested — the right endpoint still might stretch.
4. Otherwise push `[start, end]` as a brand-new disjoint segment.
````

## Solution

````python
from typing import List


class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda pair: pair[0])
        output: List[List[int]] = [intervals[0][:]]

        for start, end in intervals[1:]:
            last_end = output[-1][1]
            if start <= last_end:
                # Overlap or touching endpoints ([1,4] + [4,5] → [1,5]).
                output[-1][1] = max(last_end, end)
            else:
                output.append([start, end])

        return output
````
