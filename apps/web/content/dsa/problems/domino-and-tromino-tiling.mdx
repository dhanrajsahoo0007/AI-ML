Given a 2 x n board, count ways to tile it with dominoes (2x1 or 1x2) and
trominoes (L-shaped triominoes), modulo 10^9 + 7.

## Examples

````text
Example 1:
    Input: n = 3
    Output: 5
Example 2:
    Input: n = 1
    Output: 1
````

## Constraints

````text
- 1 <= n <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Linear recurrence / 1D DP
Let full\[i\] be tilings of 2xi with no overhang; relate to smaller widths via recurrence.

1. Use recurrence f(n) = 2\*f(n-1) + f(n-3) with base f(0)=1, f(1)=1, f(2)=2 (standard for this problem).
2. Take results modulo MOD = 10\*\*9 + 7.

## Complexity

**Time:** O(n).

**Space:** O(1) with three rolling states.

## Solution

````python
class Solution:
    def numTilings(self, n: int) -> int:
        mod = 10**9 + 7
        if n == 1:
            return 1
        if n == 2:
            return 2
        a, b, c = 1, 1, 2
        for _ in range(3, n + 1):
            a, b, c = b, c, (2 * c + a) % mod
        return c
````
