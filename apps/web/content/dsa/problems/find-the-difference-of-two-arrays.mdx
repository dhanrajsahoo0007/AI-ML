Given two 0-indexed integer arrays nums1 and nums2, return a list of two lists where the first
list contains distinct integers present in nums1 but not nums2, and the second list contains
distinct integers present in nums2 but not nums1. Either list may be returned in any order.

## Examples

````text
Example 1:
    Input: nums1 = [1, 2, 3], nums2 = [2, 4, 6]
    Output: [[1, 3], [4, 6]]
Example 2:
    Input: nums1 = [1, 2, 3, 3], nums2 = [1, 1, 2, 2]
    Output: [[3], []]
````

## Constraints

````text
- 1 <= len(nums1), len(nums2) <= 1000
- -1000 <= nums1[i], nums2[i] <= 1000
````

**Order.** Any order is accepted: the tests sort your result before comparing it.

<PremiumBreak />

## Approach

**Pattern:** Set difference
Distinct values are obtained by casting to sets, then subtract.

1. Build sets s1 and s2 from nums1 and nums2.
2. Return \[list(s1 - s2), list(s2 - s1)\] (order within lists may vary).

## Complexity

**Time:** O(n + m) - Linear scans to build sets.

**Space:** O(n + m) - Two sets of distinct integers.

## Solution

````python
from typing import List, Set, Tuple


class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        s1, s2 = set(nums1), set(nums2)
        return [list(s1 - s2), list(s2 - s1)]


def _normalize_pair(res: List[List[int]]) -> Tuple[Set[int], Set[int]]:
    return set(res[0]), set(res[1])
````
