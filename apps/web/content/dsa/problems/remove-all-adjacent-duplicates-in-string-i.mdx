Given a string s, remove all adjacent duplicate letters repeatedly until no more
adjacent duplicates remain. Return the final string.

## Examples

````text
Example 1:
    Input: s = "abbaca"
    Output: "ca"
    Explanation: "abbaca" -> "aaca" -> "ca"

Example 2:
    Input: s = "azxxzy"
    Output: "ay"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s consists of lowercase English letters.
````

<PremiumBreak />

## Approach

**Pattern:** Stack / Simulation
Treat the result as a stack: push each character; if it matches the top, pop both.

1. Iterate over each character in s.
2. If the result stack is non-empty and its last character equals the current one, pop it.
3. Otherwise append the current character.
4. Join the stack into the answer string.

## Complexity

**Time:** O(n) - Each character is pushed and popped at most once.

**Space:** O(n) - The stack holds up to n characters in the worst case.

## Solution

````python
from typing import List


class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack: List[str] = []
        for ch in s:
            if stack and stack[-1] == ch:
                stack.pop()
            else:
                stack.append(ch)
        return "".join(stack)
````
