Design an in-memory file system that supports creating directories, listing paths,
appending file content, and reading file content. Paths are absolute strings like "/a/b/c".

## Examples

````text
Example 1:
Input: mkdir("/a/b/c"), addContentToFile("/a/b/c/d", "hello"), readContentFromFile("/a/b/c/d"), ls("/")
Output: read returns "hello"; ls("/") lists top-level names (e.g. "a").
````

## Constraints

````text
- Path names are non-empty, start with '/', and contain lowercase letters and '/'.
- File content is appended as strings; same path may receive multiple appends.
````

<PremiumBreak />

## Approach

**Pattern:** Trie (prefix tree on path components)
Each node represents a path component; files store accumulated content at leaf nodes.

1. Split each path into components and walk/create nodes from the root.
2. ls(path): if path is a file, return \[basename\]; else return sorted child names.
3. addContentToFile marks the terminal node as a file and appends content.
4. readContentFromFile returns stored content for a file path.

## Complexity

**Time:** O(p + c) per op - p path length in components, c content size for reads/writes.

**Space:** O(total stored path and content characters).

## Solution

````python
from typing import Dict, List


class _Node:
    __slots__ = ("children", "is_file", "content")

    def __init__(self) -> None:
        self.children: Dict[str, "_Node"] = {}
        self.is_file: bool = False
        self.content: str = ""


class FileSystem:
    def __init__(self) -> None:
        self._root = _Node()

    def _walk(self, path: str, create: bool) -> _Node:
        parts = [p for p in path.split("/") if p]
        cur = self._root
        for part in parts:
            if part not in cur.children:
                if not create:
                    raise KeyError(path)
                cur.children[part] = _Node()
            cur = cur.children[part]
        return cur

    def ls(self, path: str) -> List[str]:
        if path == "/":
            node = self._root
            return sorted(node.children.keys())
        node = self._walk(path, create=False)
        parts = [p for p in path.split("/") if p]
        if node.is_file:
            return [parts[-1]]
        return sorted(node.children.keys())

    def mkdir(self, path: str) -> None:
        self._walk(path, create=True)

    def addContentToFile(self, file_path: str, content: str) -> None:
        node = self._walk(file_path, create=True)
        node.is_file = True
        node.content += content

    def readContentFromFile(self, file_path: str) -> str:
        node = self._walk(file_path, create=False)
        if not node.is_file:
            return ""
        return node.content
````
