Given a string sentence of lowercase English letters, return True if every letter
of the alphabet appears at least once (pangram), otherwise False.

## Examples

````text
Example 1:
    Input: sentence = "thequickbrownfoxjumpsoverthelazydog"
    Output: True

Example 2:
    Input: sentence = "leetcode"
    Output: False
````

## Constraints

````text
- 1 <= len(sentence) <= 1000
- sentence consists of lowercase English letters.
````

<PremiumBreak />

## Approach

**Pattern:** Frequency / set
Track which of the 26 letters appear; a pangram has all 26 present.

1. Use a length-26 counter or a set of seen letters.
2. Iterate characters and mark each letter seen.
3. Return whether all 26 positions are non-zero (or set size is 26).

## Complexity

**Time:** O(n) - Single pass over the sentence.

**Space:** O(1) - Fixed 26 counters regardless of n.

## Solution

````python
class Solution:
    def checkIfPangram(self, sentence: str) -> bool:
        counts = [0] * 26  # one slot per letter a..z
        for ch in sentence:
            counts[ord(ch) - ord("a")] += 1
        return all(c > 0 for c in counts)  # pangram iff every letter seen at least once
````
