Given a valid parentheses string s that may contain digits and operators, return the maximum
nesting depth of parentheses in s (number of '(' opened before a matching ')' at deepest point).

## Examples

````text
Example 1:
    Input: s = "(1+(2*3)+((8)/4))+1"
    Output: 3

Example 2:
    Input: s = "(1)+((2))+(((3)))"
    Output: 3

Example 3:
    Input: s = "()(())((()()))"
    Output: 3
````

## Constraints

````text
- 1 <= len(s) <= 100
- s is a valid parentheses string with only digits, '+', '-', '*', '/', '(', and ')'
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Scan
Treat '(' as depth +1 and ')' as depth -1 while tracking the maximum depth.

1. Walk characters; ignore non-parenthesis symbols.
2. Increment depth on '(' and decrement on ')'.
3. Record the maximum depth after each '('.

## Complexity

**Time:** O(n) - One pass.

**Space:** O(1) - Counters only.

## Solution

````python
class Solution:
    def maxDepth(self, s: str) -> int:
        curr = 0
        max_curr = 0
        for char in s:
            if char == "(":
                curr += 1
                max_curr = max(max_curr, curr)
            elif char == ")":
                curr -= 1
        return max_curr
````
