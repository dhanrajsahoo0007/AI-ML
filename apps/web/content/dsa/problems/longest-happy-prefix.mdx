Given a string s, return its longest proper prefix which is also a suffix (not
counting the full string as a prefix).

## Examples

````text
Example 1:
    Input: s = "level"
    Output: "l"

Example 2:
    Input: s = "ababab"
    Output: "abab"

Example 3:
    Input: s = "leetcodeleet"
    Output: "leet"
````

## Constraints

````text
- 1 <= len(s) <= 10^5
- s contains only lowercase English letters.
````

<PremiumBreak />

## Approach

**Pattern:** KMP prefix function (failure link)
The last pi value for the whole string is the length of the longest border.

1. Build the KMP pi array where pi\[i\] is the length of the longest border of s\[: i + 1\].
2. The answer length is pi\[-1\]; return s\[: pi\[-1\]\].

## Complexity

**Time:** O(n) - Single pass for pi.

**Space:** O(n) - The pi array.

## Solution

````python
from typing import List


class Solution:
    def longestPrefix(self, s: str) -> str:
        n = len(s)
        pi = [0] * n
        for i in range(1, n):
            j = pi[i - 1]
            while j and s[i] != s[j]:
                j = pi[j - 1]
            if s[i] == s[j]:
                j += 1
            pi[i] = j
        return s[: pi[-1]]
````
