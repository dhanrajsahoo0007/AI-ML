Design a data structure for stock price records. Support:
- update(timestamp, price): Update/correct price at timestamp.
- current(): Return the latest price.
- maximum(): Return the maximum price.
- minimum(): Return the minimum price.

## Examples

````text
Example 1:
update(1,10), update(2,5) -> current()=5, maximum()=10
update(1,3) -> maximum()=5 (corrected timestamp 1)
````

## Constraints

````text
- 1 <= timestamp, price <= 10^9
- At most 10^5 total calls.
````

<PremiumBreak />

## Approach

**Pattern:** Heap with Lazy Deletion
Use two heaps (min and max) with lazy deletion. When the top of a heap
has a stale price (doesn't match the current record), discard it.

1. Store timestamp-&gt;price mapping and track the latest timestamp.
2. On update: record price, push to both heaps.
3. On maximum/minimum: pop stale entries (where stored price != current price for that timestamp).

## Complexity

**Time:** O(log n) amortized for all operations

**Space:** O(n) for heaps and hash map

## Solution

````python
import heapq


class StockPrice:
    def __init__(self):
        self.records = {}
        self.latest_time = 0
        self.min_heap = []
        self.max_heap = []

    def update(self, timestamp: int, price: int) -> None:
        self.records[timestamp] = price
        heapq.heappush(self.min_heap, (price, timestamp))
        heapq.heappush(self.max_heap, (-price, timestamp))
        self.latest_time = max(self.latest_time, timestamp)

    def current(self) -> int:
        return self.records[self.latest_time]

    def maximum(self) -> int:
        while self.max_heap:
            price, ts = self.max_heap[0]
            if self.records[ts] == -price:
                return -price
            heapq.heappop(self.max_heap)
        return 0

    def minimum(self) -> int:
        while self.min_heap:
            price, ts = self.min_heap[0]
            if self.records[ts] == price:
                return price
            heapq.heappop(self.min_heap)
        return 0
````
