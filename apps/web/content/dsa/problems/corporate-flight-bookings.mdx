There are n flights labeled 1..n. Each booking bookings\[i\] = \[first, last, seats\]
reserves seats seats for every flight in \[first, last\] inclusive. Return an array
of length n where the i-th value is total seats reserved on flight i + 1.

## Examples

````text
Example 1:
Input: bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]], n = 5
Output: [10, 55, 45, 25, 25]
````

## Constraints

````text
- 1 <= n <= 2 * 10^5
- 1 <= len(bookings) <= 2 * 10^4
- bookings[i].length == 3
````

<PremiumBreak />

## Approach

**Pattern:** Difference Array / Prefix Sum
Mark range starts and ends with +/- seats, then prefix-sum to recover counts.

1. Use diff array of length n+2; for each \[f,l,s\], do diff\[f\] += s and diff\[l+1\] -= s (1-indexed).
2. Prefix sum diff\[1..n\] to get answer per flight.

## Complexity

**Time:** O(n + b) with b = len(bookings).

**Space:** O(n) - difference and result arrays.

## Solution

````python
from typing import List


class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        diff = [0] * (n + 2)
        for first, last, seats in bookings:
            diff[first] += seats
            diff[last + 1] -= seats
        out: List[int] = []
        cur = 0
        for i in range(1, n + 1):
            cur += diff[i]
            out.append(cur)
        return out
````
