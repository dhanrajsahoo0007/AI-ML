Given the roots of two binary trees p and q, return True if they are structurally identical with the same node values.

## Examples

````text
Example 1:
    Input: p = [1,2,3], q = [1,2,3]
    Output: True
Example 2:
    Input: p = [1,2], q = [1,None,2]
    Output: False
````

## Constraints

````text
- The number of nodes in each tree is in the range [0, 200].
- Node values fit in 32-bit signed integers.
````

**How the tests describe the input.** A linked list is written as an array of its values, head first; a binary tree as an array in level order, with `None` for a missing child. The code above the line in the editor turns those arrays into nodes and your answer back into an array: write the function below the line.

## Approach

**Pattern:** Recursion on pairs of nodes
Two trees match if roots match and left subtrees and right subtrees match recursively.

1. If both roots are None, return True.
2. If exactly one is None or values differ, return False.
3. Return isSameTree(left, left) and isSameTree(right, right).

**Time:** O(min(n, m))

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_from_level_order(values: List[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    from collections import deque

    root = TreeNode(values[0])
    q: deque[TreeNode] = deque([root])
    i = 1
    while q and i < len(values):
        node = q.popleft()
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            q.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            q.append(node.right)
        i += 1
    return root


class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        if p is None and q is None:
            return True
        if p is None or q is None or p.val != q.val:
            return False
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
````
