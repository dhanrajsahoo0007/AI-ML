Same as part I: indices i where pattern a occurs in s at i and some occurrence of b
lies within k positions. Constraints are larger, so use the same KMP plus bisect
approach for linear-time matching.

## Examples

````text
Example 1:
    Input: s = "isawsquirrelnearmysquirrelhouseohmy", a = "my", b = "squirrel", k = 15
    Output: [16, 33]

Example 2:
    Input: s = "abcd", a = "a", b = "a", k = 4
    Output: [0]
````

## Constraints

````text
- 1 <= len(s), len(a), len(b) <= 5 * 10^5
- 1 <= k <= len(s)
````

<PremiumBreak />

## Approach

**Pattern:** KMP plus binary search
KMP lists all a- and b-hits in linear time; bisect answers each proximity query in log B.

1. Run KMP for a and for b on s to produce sorted occurrence lists.
2. For each a-index i, binary search b-hits for any value in \[i-k, i+k\].
3. Collect matching indices and return.

## Complexity

**Time:** O(len(s) + len(a) + len(b) + A log B).

**Space:** O(A + B) for hits and prefix tables.

## Solution

````python
import bisect
from typing import List


class Solution:
    def beautifulIndices(self, s: str, a: str, b: str, k: int) -> List[int]:
        hits_a = self._kmp_find(s, a)
        hits_b = self._kmp_find(s, b)
        answer: List[int] = []
        for i in hits_a:
            lo = i - k
            hi = i + k
            idx = bisect.bisect_left(hits_b, lo)
            if idx < len(hits_b) and hits_b[idx] <= hi:
                answer.append(i)
        return answer

    def _kmp_find(self, text: str, pattern: str) -> List[int]:
        if not pattern:
            return []
        m = len(pattern)
        pi = [0] * m
        for i in range(1, m):
            j = pi[i - 1]
            while j and pattern[i] != pattern[j]:
                j = pi[j - 1]
            if pattern[i] == pattern[j]:
                j += 1
            pi[i] = j
        hits: List[int] = []
        j = 0
        for i, ch in enumerate(text):
            while j and ch != pattern[j]:
                j = pi[j - 1]
            if ch == pattern[j]:
                j += 1
            if j == m:
                hits.append(i - m + 1)
                j = pi[j - 1]
        return hits
````
