Given an integer array height of length n, choose two lines together with the x-axis to form a container.
Return the maximum amount of water the container can store. You may not slant the container.

## Examples

````text
Example 1:
    Input: height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
    Output: 49
Example 2:
    Input: height = [1, 1]
    Output: 1
````

## Constraints

````text
- n == len(height)
- 2 <= n <= 10^5
- 0 <= height[i] <= 10^4
````

## Approach

**Pattern:** Shrinking two pointers
Always discard the shorter side because keeping it cannot increase the limiting height while width only shrinks.

1. Initialize pointers at the leftmost and rightmost indices and track best area.
2. Compute area as the minimum of the two heights times the width between them.
3. Move the pointer at the shorter line inward to search for a potentially taller boundary.
4. Repeat while the pointers stay apart, updating the maximum area seen.

## Complexity

**Time:** O(n) - Each pointer traverses the array at most once.

**Space:** O(1) - Only a constant number of variables are used.

## Solution

````python
from typing import List


class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        best = 0
        while left < right:
            h = min(height[left], height[right])
            best = max(best, h * (right - left))
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return best
````
