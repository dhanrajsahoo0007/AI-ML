Given a digit string num\_str and an integer k, repeatedly swap any two positions at most k
times to obtain the largest possible numeric string (lexicographic maximum among digit strings).

## Examples

````text
Example 1:
    Input: num_str = "1234567", k = 4
    Output: "7654321"

Example 2:
    Input: num_str = "1234", k = 2
    Output: "4321"

Example 3:
    Input: num_str = "3435335", k = 3
    Output: "5543333"
````

## Constraints

````text
- len(num_str) between 1 and 15 typically for backtracking
- Digits are '0'..'9'
````

## Approach

**Pattern:** Backtracking with greedy digit choice
At each index, optionally swap a larger digit from the right into place, consuming one swap,
or skip swapping and move on.

1. Keep the best string seen in a mutable maximum.
2. DFS on (index, remaining\_swaps): optionally swap index with each later position holding the max digit rightward.
3. Always try advancing without swapping to cover cases where saving swaps helps later.

## Complexity

**Time:** Exponential in n and k in worst case; practical for small n.

**Space:** O(n) - recursion depth and digit list copy path.

## Solution

````python
from typing import List


class Solution:
    def findMaximumNum(self, num_str: str, k: int) -> str:
        digits: List[str] = list(num_str)
        best = [num_str]

        def swap(i: int, j: int) -> None:
            digits[i], digits[j] = digits[j], digits[i]

        def dfs(index: int, swaps: int) -> None:
            cur = "".join(digits)
            if cur > best[0]:
                best[0] = cur
            if swaps == 0 or index == len(digits):
                return
            max_digit = max(digits[index:])
            if digits[index] != max_digit:
                for j in range(index + 1, len(digits)):
                    if digits[j] == max_digit:
                        swap(index, j)
                        dfs(index + 1, swaps - 1)
                        swap(index, j)
            dfs(index + 1, swaps)

        dfs(0, k)
        return best[0]
````
