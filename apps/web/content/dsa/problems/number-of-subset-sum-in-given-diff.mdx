Given an array of non-negative integers and integer diff, count partitions into
two subsets S1 and S2 (using every element exactly once) such that
sum(S1) - sum(S2) = diff.

## Examples

````text
Example 1:
    Input: nums = [1, 1, 2, 3], diff = 1
    Output: 3
Example 2:
    Input: nums = [2, 2, 2, 2], diff = 0
    Output: 6
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 0 <= nums[i] <= 1000
- -1000 <= diff <= 1000
````

## Approach

**Pattern:** Transform to subset-sum count
Let T = sum(nums). Need S1 = (T + diff) / 2; require T + diff even and nonnegative target.

1. If (T + diff) % 2 != 0 or T + diff &lt; 0 return 0.
2. target = (T + diff) // 2; count 0-1 subsets summing to target.

## Complexity

**Time:** O(n \* target).

**Space:** O(n \* target).

## Solution

````python
from typing import List


class Solution:
    def countSubsetsWithDiff(self, nums: List[int], diff: int) -> int:
        total = sum(nums)
        if (total + diff) % 2 != 0 or total + diff < 0:
            return 0
        target = (total + diff) // 2
        n = len(nums)
        dp = [[0] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = 1
        for i in range(1, n + 1):
            for j in range(target + 1):
                dp[i][j] = dp[i - 1][j]
                if nums[i - 1] <= j:
                    dp[i][j] += dp[i - 1][j - nums[i - 1]]
        return dp[n][target]
````
