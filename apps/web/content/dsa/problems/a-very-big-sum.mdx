Given an array of integers ar, return the sum of its elements. Values may be large, so the result
must be computed with arbitrary-precision integer arithmetic (Python int is unbounded).

## Examples

````text
Example 1:
    Input: ar = [1000000001, 1000000002, 1000000003, 1000000004, 1000000005]
    Output: 5000000015
Example 2:
    Input: ar = [1, 2, 3]
    Output: 6
````

## Constraints

````text
- 1 <= len(ar) <= 10
- 0 <= ar[i] <= 10^10
````

<PremiumBreak />

## Approach

**Pattern:** Reduction / aggregation
Accumulate all elements into one sum with a simple loop or built-in.

1. Initialize total to 0.
2. Add each element of ar to total.
3. Return total.

## Complexity

**Time:** O(n) - n is the length of ar.

**Space:** O(1) - Aside from the input, only the running sum is stored.

## Solution

````python
from typing import List


class Solution:
    def aVeryBigSum(self, ar: List[int]) -> int:
        return sum(ar)
````
