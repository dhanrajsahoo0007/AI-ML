Given an array people where people\[i\] is the weight of the ith person, and an integer limit
such that each boat carries at most two people and their combined weight is at most limit,
return the minimum number of boats needed to rescue everyone.

## Examples

````text
Example 1:
    Input: people = [1,2], limit = 3
    Output: 1

Example 2:
    Input: people = [3,2,2,1], limit = 3
    Output: 3

Example 3:
    Input: people = [3,5,3,4], limit = 5
    Output: 4
````

## Constraints

````text
- 1 <= people.length <= 5 * 10^4
- 1 <= people[i] <= limit <= 3 * 10^4
````

## Approach

**Pattern:** Greedy Two Pointers
After sorting, repeatedly pair the heaviest remaining person with the lightest if they fit.

1. Sort people ascending.
2. Use pointers left (lightest) and right (heaviest).
3. While left &lt;= right: if people\[left\] + people\[right\] &lt;= limit, move left; always move right; count a boat.

## Complexity

**Time:** O(n log n) - Sorting dominates.

**Space:** O(1) extra beyond the input array for pointers and counters.

## Original notes

````text
Intuition (from original write-up):
Think of the heaviest person still waiting: you might as well try to "fill" their boat
with the lightest person available, because using a heavier partner can only make it
harder to stay under `limit`. If the pair still exceeds `limit`, the heavy person must
sail alone — no one else can compensate enough.
````

## Solution

````python
from typing import List


class Solution:
    def numRescueBoats(self, people: List[int], limit: int) -> int:
        people.sort()
        left, right = 0, len(people) - 1
        boats = 0
        while left <= right:
            if people[left] + people[right] <= limit:
                # Light + heavy share a boat; advance the light pointer.
                left += 1
            # Heavy always boards (either alone or paired).
            right -= 1
            boats += 1
        return boats
````
