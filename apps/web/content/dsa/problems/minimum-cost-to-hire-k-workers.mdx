Given n workers with quality and wage arrays, hire k workers such that:
- Every worker is paid at least their minimum wage expectation.
- Pay is proportional to quality within the group.
Return the minimum total cost.

## Examples

````text
Example 1:
    Input: quality = [10,20,5], wage = [70,50,30], k = 2
    Output: 105.0

Example 2:
    Input: quality = [3,1,10,10,1], wage = [4,8,2,2,7], k = 3
    Output: 30.66667
````

## Constraints

````text
- n == quality.length == wage.length
- 1 <= k <= n <= 10^4
- 1 <= quality[i], wage[i] <= 10^4
````

**Precision.** The tests round your result to 5 decimal places before comparing it.

## Approach

**Pattern:** Scheduling and Simulation
The key insight is the wage/quality ratio. Sort by ratio; for each worker
as the ratio-setter, maintain a max-heap of k smallest qualities.

1. Calculate wage/quality ratio for each worker. Sort by ratio.
2. Use a max-heap of qualities (size k). Track quality sum.
3. For each worker: add quality, remove highest if &gt; k workers.
4. When we have k workers, compute cost = ratio \* quality\_sum. Track minimum.

## Complexity

**Time:** O(n log n)

**Space:** O(n)

## Solution

````python
import heapq
from typing import List


class Solution:
    def mincostToHireWorkers(self, quality: List[int], wage: List[int], k: int) -> float:
        workers = sorted((w / q, q) for w, q in zip(wage, quality))
        qual_heap = []
        qual_sum = 0
        min_cost = float('inf')

        for ratio, q in workers:
            heapq.heappush(qual_heap, -q)
            qual_sum += q

            if len(qual_heap) > k:
                qual_sum += heapq.heappop(qual_heap)

            if len(qual_heap) == k:
                min_cost = min(min_cost, ratio * qual_sum)

        return min_cost
````
