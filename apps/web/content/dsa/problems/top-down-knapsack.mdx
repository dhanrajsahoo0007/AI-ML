0-1 Knapsack bottom-up: fill table K\[i\]\[w\] = max value using first i items with capacity w.

## Examples

````text
Example 1:
Input: W=50, wt=[10,20,30], val=[60,100,120]
Output: 220
````

## Constraints

````text
- Same as standard knapsack
````

<PremiumBreak />

## Approach

**Pattern:** 2D Tabulation
Row i considers item i-1; transition max(include, exclude).

1. Initialize (n+1)x(W+1) with zeros.
2. For each i,w: if wt\[i-1\]&lt;=w take max(val\[i-1\]+K\[i-1\]\[w-wt\[i-1\]\], K\[i-1\]\[w\]); else K\[i-1\]\[w\].
3. Return K\[n\]\[W\].

## Complexity

**Time:** O(n \* W).

**Space:** O(n \* W) table (can optimize to O(W)).

## Solution

````python
from typing import List


class Solution:
    def knapsack(self, W: int, wt: List[int], val: List[int], n: int) -> int:
        k = [[0] * (W + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for w in range(1, W + 1):
                if wt[i - 1] <= w:
                    k[i][w] = max(val[i - 1] + k[i - 1][w - wt[i - 1]], k[i - 1][w])
                else:
                    k[i][w] = k[i - 1][w]
        return k[n][W]
````
