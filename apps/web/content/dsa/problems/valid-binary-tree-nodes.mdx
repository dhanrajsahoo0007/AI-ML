You have n binary tree nodes numbered from 0 to n - 1 where node i has two children leftChild\[i\] and rightChild\[i\],
return true if and only if all the given nodes form exactly one valid binary tree.
If node i has no left child then leftChild\[i\] will equal -1, similarly for the right child.

Note that the nodes have no values and that we only use the node numbers in this problem.

## Examples

````text
Example 1:
Input: n = 4, leftChild = [1,-1,3,-1], rightChild = [2,-1,-1,-1]
Output: True
````

## Constraints

````text
- 1 <= n <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Union-Find / Disjoint Set Union (custom union enforcing single parent)

1. Each node starts as its own DSU parent; track component count.
2. For each directed parent-&gt;child edge, fail if the child already has a parent (second parent) or would create a parallel issue.
3. Exactly one component remains if the structure is one valid tree.

## Complexity

**Time:** O(n \* α(n)), where n is the number of nodes and α is the inverse Ackermann function

**Space:** O(n) for the parent array

This solution uses a Disjoint Set Union (DSU) data structure with path compression.

## Solution

````python
from typing import List


class Solution:
    def __init__(self) -> None:
        self.parent: List[int] = []
        self.components = 0

    def find(self, x: int) -> int:
        if self.parent[x] == x:
            return x
        self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, par: int, child: int) -> bool:
        child_ka_parent = self.find(child)

        # Child already has a parent
        if child_ka_parent != child:
            return False

        parent_ka_parent = self.find(par)
        # Parallel edge (already connected by another edge)
        if parent_ka_parent == child_ka_parent:
            return False

        self.parent[child] = par
        self.components -= 1
        return True

    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        self.components = n
        self.parent = list(range(n))

        for i in range(n):
            if leftChild[i] >= 0 and not self.union(i, leftChild[i]):
                return False
            if rightChild[i] >= 0 and not self.union(i, rightChild[i]):
                return False

        return self.components == 1
````
