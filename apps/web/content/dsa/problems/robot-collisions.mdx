Robots occupy unique positions with health and move either right or left. When a right-moving robot
meets a left-moving one they collide: lower health disappears, ties destroy both, otherwise the
stronger survives with health reduced by one. Return surviving healths sorted by original index.

## Examples

````text
Example 1:
Input: positions=[5,4,3,2,1], healths=[2,17,9,15,10], directions="RRRRR"
Output: [2,17,9,15,10]
````

## Constraints

````text
- 1 <= len(positions) <= 10^5
- directions matches positions length and uses only 'L' or 'R'
````

<PremiumBreak />

## Approach

**Pattern:** Sorted Sweep with Collision Stack
Sort by coordinate then simulate like asteroids while decrementing health on partial wins.

1. Zip robots with indices, sort by position, and encode left movers as negative health on the stack.
2. Resolve collisions until directions no longer oppose; decrement winners when needed.
3. Map survivors back to original indices and filter zeros.

## Complexity

**Time:** O(n log n) - Sorting plus linear stack processing.

**Space:** O(n) - Auxiliary lists for survivors.

## Solution

````python
from typing import List, Tuple


class Solution:
    def survivedRobotsHealths(self, positions: List[int], healths: List[int], directions: str) -> List[int]:
        robots: List[Tuple[int, int, str, int]] = sorted(
            zip(positions, healths, directions, range(len(positions))), key=lambda item: item[0]
        )
        stack: List[Tuple[int, int]] = []

        for _, health, direction, idx in robots:
            signed = health if direction == "R" else -health
            while stack and signed < 0 < stack[-1][0]:
                if abs(stack[-1][0]) < abs(signed):
                    stack.pop()
                    continue
                if abs(stack[-1][0]) == abs(signed):
                    stack.pop()
                    signed = 0
                    break
                top_health, top_idx = stack.pop()
                new_health = abs(top_health) - 1
                if new_health > 0:
                    stack.append((new_health if top_health > 0 else -new_health, top_idx))
                signed = 0
                break
            if signed != 0:
                stack.append((signed, idx))

        survivors = [0] * len(positions)
        for health, idx in stack:
            survivors[idx] = abs(health)
        return [h for h in survivors if h > 0]
````
