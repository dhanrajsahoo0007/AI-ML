Given non-negative integers and a target sum, decide if some subset sums exactly
to the target.

## Examples

````text
Example 1:
    Input: nums = [3, 34, 4, 12, 5, 2], target = 9
    Output: True
Example 2:
    Input: nums = [1, 2, 5], target = 4
    Output: False
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 0 <= nums[i] <= 1000
- 0 <= target <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** 0-1 Knapsack boolean
dp\[i\]\[j\] = achievable sum j with first i elements.

1. dp\[i\]\[0\] = True for all i; for j&gt;0 dp\[0\]\[j\] = False.
2. Transition: dp\[i\]\[j\] = dp\[i-1\]\[j\] or (j&gt;=nums\[i-1\] and dp\[i-1\]\[j-nums\[i-1\]\]).
3. Return dp\[n\]\[target\].

## Complexity

**Time:** O(n \* target).

**Space:** O(n \* target); can compress to O(target).

## Solution

````python
from typing import List


class Solution:
    def isSubsetSum(self, nums: List[int], target: int) -> bool:
        n = len(nums)
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True
        for i in range(1, n + 1):
            for j in range(1, target + 1):
                if nums[i - 1] <= j:
                    dp[i][j] = dp[i - 1][j - nums[i - 1]] or dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]
        return dp[n][target]
````
