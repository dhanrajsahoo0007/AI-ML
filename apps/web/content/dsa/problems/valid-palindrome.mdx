Given a string s, return true if it is a palindrome after considering only alphanumeric
characters and ignoring case.

## Examples

````text
Example 1:
    Input: s = "A man, a plan, a canal: Panama"
    Output: true
Example 2:
    Input: s = "race a car"
    Output: false
````

## Constraints

````text
- 1 <= len(s) <= 2 * 10^5
- s consists only of printable ASCII characters.
````

## Approach

**Pattern:** Two pointers
Walk inward from both ends, skipping non-alphanumeric characters and comparing letters case-insensitively.

1. Place pointers at the start and end of the string.
2. Advance each pointer inward until it lands on an alphanumeric character.
3. Compare the two characters in lowercase; on mismatch return false.
4. Move both pointers toward the center and repeat until they cross.

Problem: Valid Palindrome

Given a string s, return true if the s can be palindrome after deleting at most one character from it.

A palindrome is a word, phrase, number, or other sequence of characters that reads the same backward as forward.

Example 1:
Input: s = "aba"
Output: true

Example 2:
Input: s = "abca"
Output: true
Explanation: You could delete the character 'c'.

Time Complexity: O(n), where n is the length of the string.
Space Complexity: O(1), as we're using constant extra space.

## Complexity

**Time:** O(n) - Each index is moved at most once across the string.

**Space:** O(1) - Only a constant number of indices and comparisons are stored.

## Solution

````python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        while left < right:
            while left < right and not s[left].isalnum():
                left += 1
            while left < right and not s[right].isalnum():
                right -= 1
            if s[left].lower() != s[right].lower():
                return False
            left += 1
            right -= 1
        return True
````
