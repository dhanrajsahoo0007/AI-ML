Given a string queryIP, return "IPv4" if it is a valid IPv4 address, "IPv6" if it
is a valid IPv6 address, or "Neither" otherwise.
IPv4: four decimal numbers from 0 to 255 separated by '.', with no leading zeros.
IPv6: eight groups of 1 to 4 hexadecimal digits separated by ':'; a single '::' may
stand for one or more groups, and no other group may be empty.

## Examples

````text
Example 1:
    Input: queryIP = "172.16.254.1"
    Output: "IPv4"

Example 2:
    Input: queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
    Output: "IPv6"

Example 3:
    Input: queryIP = "256.256.256.256"
    Output: "Neither"
````

## Constraints

````text
- queryIP consists only of digits, letters, and the characters '.' and ':'.
````

## Approach

**Pattern:** String parsing / validation
Apply disjoint IPv4 and IPv6 grammars: dotted decimal with strict digit rules, or
colon-hex groups optionally using a single :: compression.

1. Prefer IPv4 when the string contains a dot: split into four segments by '.'.
2. Validate each IPv4 segment for non-empty digits, no illegal leading zeros, and 0..255.
3. For IPv6, if '::' appears at most once, split left/right; otherwise split into eight groups.
4. Each IPv6 piece must be 1-4 hexadecimal characters; compressed form must expand to eight groups.

## Complexity

**Time:** O(n) - Linear time in the length of queryIP.

**Space:** O(n) - Storing split segments.

Given a string queryIP, return "IPv4" if IP is a valid IPv4 address, "IPv6" if IP is a valid IPv6 address or "Neither" if IP is not a correct IP of any type.

A valid IPv4 address is an IP in the form "x1.x2.x3.x4" where 0 <= xi <= 255 and xi cannot contain leading zeros. For example, "192.168.1.1" and "192.168.1.0" are valid IPv4 addresses while "192.168.01.1", "192.168.1.00", and "192.168@1.1" are invalid IPv4 addresses.

A valid IPv6 address is an IP in the form "x1:x2:x3:x4:x5:x6:x7:x8" where:

1 <= xi.length <= 4
xi is a hexadecimal string which may contain digits, lowercase English letter ('a' to 'f') and upper-case English letters ('A' to 'F').
Leading zeros are allowed in xi.
For example, "2001:0db8:85a3:0000:0000:8a2e:0370:7334" and "2001:db8:85a3:0:0:8A2E:0370:7334" are valid IPv6 addresses, while "2001:0db8:85a3::8A2E:037j:7334" and "02001:0db8:85a3:0000:0000:8a2e:0370:7334" are invalid IPv6 addresses.

 

Example 1:

Input: queryIP = "172.16.254.1"
Output: "IPv4"
Explanation: This is a valid IPv4 address, return "IPv4".
Example 2:

Input: queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
Output: "IPv6"
Explanation: This is a valid IPv6 address, return "IPv6".
Example 3:

Input: queryIP = "256.256.256.256"
Output: "Neither"
Explanation: This is neither a IPv4 address nor a IPv6 address.

## Solution

````python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        if "." in queryIP:
            parts = queryIP.split(".")
            if len(parts) != 4:
                return "Neither"
            for p in parts:
                if not p or not p.isdigit():
                    return "Neither"
                if len(p) > 1 and p[0] == "0":
                    return "Neither"
                val = int(p)
                if val > 255:
                    return "Neither"
            return "IPv4"
        if ":" not in queryIP:
            return "Neither"

        def is_hex_block(block: str) -> bool:
            if not (1 <= len(block) <= 4):
                return False
            hex_digits = set("0123456789abcdefABCDEF")
            return all(c in hex_digits for c in block)

        if "::" in queryIP:
            if queryIP.count("::") != 1:
                return "Neither"
            left, right = queryIP.split("::", 1)
            left_parts = left.split(":") if left else []
            right_parts = right.split(":") if right else []
            if "" in left_parts or "" in right_parts:  # ":::" or a stray ":" next to "::"
                return "Neither"
            if len(left_parts) + len(right_parts) > 7:
                return "Neither"
            for block in left_parts + right_parts:
                if not is_hex_block(block):
                    return "Neither"
            return "IPv6"

        parts = queryIP.split(":")
        if len(parts) != 8:
            return "Neither"
        for block in parts:
            if not is_hex_block(block):
                return "Neither"
        return "IPv6"
````
