Given an integer array nums and an integer target, choose three distinct integers from nums whose sum is
closest to target and return that sum.

## Examples

````text
Example 1:
    Input: nums = [-1, 2, 1, -4], target = 1
    Output: 2
Example 2:
    Input: nums = [0, 0, 0], target = 1
    Output: 0
````

## Constraints

````text
- 3 <= len(nums) <= 1000
- -1000 <= nums[i] <= 1000
- -10^4 <= target <= 10^4
````

## Approach

**Pattern:** Sort + two pointers
For each anchor, shrink or expand a two-pointer window to approach the remaining two-sum goal.

1. Sort nums to use monotonic two pointers.
2. Track closest\_sum initialized to a large sentinel.
3. For each anchor i, set left = i + 1 and right = n - 1, updating closest\_sum whenever a triplet is nearer to target.
4. Move left or right depending on whether the current triplet sum is below or above target; stop early if an exact hit occurs.

## Complexity

**Time:** O(n^2) - Anchors with linear two-pointer scans dominate sorting.

**Space:** O(1) auxiliary excluding the sort stack or temporary space used by the sort implementation.

## Solution

````python
from typing import List


class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        closest = nums[0] + nums[1] + nums[2]
        for i in range(n - 2):
            left, right = i + 1, n - 1
            while left < right:
                current = nums[i] + nums[left] + nums[right]
                if abs(target - current) < abs(target - closest):
                    closest = current
                if current == target:
                    return current
                if current > target:
                    right -= 1
                else:
                    left += 1
        return closest
````
