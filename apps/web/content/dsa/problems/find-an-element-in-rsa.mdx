Search a target in a sorted array that has been rotated at an unknown pivot. Return the index or -1.

## Examples

````text
Example 1:
    Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 0
    Output: 4

Example 2:
    Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 3
    Output: -1
````

## Constraints

````text
- 1 <= len(nums) <= 5000
- nums values distinct, originally sorted ascending
````

<PremiumBreak />

## Approach

**Pattern:** Binary Search on Rotated Sorted Array
One half is always sorted; compare target to that half's endpoints to shrink the interval.

1. While left &lt;= right, if nums\[mid\] == target return mid.
2. If nums\[left..mid\] is sorted and target lies in \[nums\[left\], nums\[mid\]), go left; else go right.
3. Else the right half is sorted; if target in (nums\[mid\], nums\[right\]\], go right; else left.

## Complexity

**Time:** O(log n) - Each step discards half the range.

**Space:** O(1) - Iterative search only.

## Solution

````python
from typing import List


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            if nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
        return -1
````
