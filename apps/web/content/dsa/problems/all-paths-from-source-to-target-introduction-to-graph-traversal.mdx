Given a directed acyclic graph (DAG) with n nodes labeled 0..n-1, graph\[i\] lists nodes reachable by a
directed edge from i. Return all paths from node 0 to node n-1 (in any order).

## Examples

````text
Example 1:
    Input: graph = [[1,2],[3],[3],[]]
    Output: [[0,1,3],[0,2,3]]
Example 2:
    Input: graph = [[1],[]]
    Output: [[0,1]]
````

## Constraints

````text
- n == len(graph)
- 2 <= n <= 15
- 0 <= graph[i][j] < n
- graph[i][j] != i (no self-loops)
- All edges are unique; the graph is a DAG
````

**Order.** Any order is accepted: the tests sort your result before comparing it.

**Also in the notes under:** [17. Graphs/04. BFS Story Based/01. Introduction to Graph Traversal with BFS](/dsa/problems/all-paths-from-source-to-target).

## Approach

**Pattern:** Backtracking / DFS on DAG
Explore every extension of the current path from 0; when the last node is n-1, record a copy of the path.

1. Start path \[0\] and DFS from node 0 toward target n-1.
2. For each neighbor, push, recurse, pop (backtrack).
3. When u == n-1, append path copy to results.

## Complexity

**Time:** O(2^n \* n) in worst-case exponential path count; each path length O(n).

**Space:** O(n) for recursion stack and current path (excluding output).

## Solution

````python
from typing import List


class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        target = len(graph) - 1
        result: List[List[int]] = []
        path: List[int] = [0]

        def dfs(u: int) -> None:
            if u == target:
                result.append(path.copy())
                return
            for v in graph[u]:
                path.append(v)
                dfs(v)
                path.pop()

        dfs(0)
        return result
````
