Given a circle (radius r centered at xCenter, yCenter) and an axis-aligned
rectangle \[x1,y1\] bottom-left to \[x2,y2\] top-right, return True iff they have
a non-empty intersection (including touching).

## Examples

````text
Example 1:
    Input: radius=1, xCenter=0, yCenter=0, x1=1, y1=-1, x2=3, y2=1
    Output: True
Example 2:
    Input: radius=1, xCenter=0, yCenter=0, x1=5, y1=5, x2=8, y2=8
    Output: False
````

## Constraints

````text
- 1 <= r, coordinates <= 10^6
````

<PremiumBreak />

## Approach

**Pattern:** Closest point on rectangle to circle center
Clamp the center to the rectangle bounds; compare squared distance to r^2.

1. Find closest point (cx, cy) on the rectangle to the circle center.
2. Return whether squared distance from center to (cx, cy) is &lt;= r^2.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
class Solution:
    def checkOverlap(
        self,
        radius: int,
        xCenter: int,
        yCenter: int,
        x1: int,
        y1: int,
        x2: int,
        y2: int,
    ) -> bool:
        cx = min(max(xCenter, x1), x2)
        cy = min(max(yCenter, y1), y2)
        dx, dy = xCenter - cx, yCenter - cy
        return dx * dx + dy * dy <= radius * radius
````
