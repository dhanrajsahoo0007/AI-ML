Given an integer array nums, find the contiguous subarray (at least one element) with the largest sum.

## Examples

````text
Example 1:
    Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
    Output: 6

Example 2:
    Input: nums = [1]
    Output: 1

Example 3:
    Input: nums = [5,4,-1,7,8]
    Output: 23
````

## Constraints

````text
- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Kadane's Algorithm
Extend the current sum while it helps; reset when the running sum goes negative.

1. Initialize max\_sub to nums\[0\] and cur\_sum to 0.
2. For each n, reset cur\_sum to 0 if negative, add n, update max\_sub.

## Complexity

**Time:** O(n) - One pass.

**Space:** O(1) - Two variables.

## Solution

````python
from typing import List


class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_sub = nums[0]
        cur_sum = 0
        for n in nums:
            if cur_sum < 0:
                cur_sum = 0
            cur_sum += n
            max_sub = max(max_sub, cur_sum)
        return max_sub
````
