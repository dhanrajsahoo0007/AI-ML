Given n non-negative integers representing an elevation map where the width of each bar is 1,
compute how much water can be trapped after raining.

## Examples

````text
Example 1:
    Input: height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
    Output: 6
Example 2:
    Input: height = [4, 2, 0, 3, 2, 5]
    Output: 9
````

## Constraints

````text
- n == len(height)
- 1 <= n <= 2 * 10^4
- 0 <= height[i] <= 10^5
````

## Approach

**Pattern:** Two pointers with running maxima
Process the shorter side first because its supported water level is limited by the shorter maximum so far.

1. Initialize left and right pointers with left\_max and right\_max at zero.
2. While left &lt; right, compare height\[left\] and height\[right\].
3. On the shorter side, update that side's max; if the current bar is lower than the max, add the difference to water.
4. Advance the pointer on the processed side inward.

## Complexity

**Time:** O(n) - Each index is visited once.

**Space:** O(1) - Only a handful of counters are stored.

## Solution

````python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        if not height:
            return 0
        left, right = 0, len(height) - 1
        left_max = right_max = 0
        water = 0
        while left < right:
            if height[left] < height[right]:
                if height[left] >= left_max:
                    left_max = height[left]
                else:
                    water += left_max - height[left]
                left += 1
            else:
                if height[right] >= right_max:
                    right_max = height[right]
                else:
                    water += right_max - height[right]
                right -= 1
        return water
````
