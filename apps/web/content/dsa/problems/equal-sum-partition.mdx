Partition nums into two non-empty subsets with equal sum if possible.

## Examples

````text
Example 1:
    Input: nums = [1, 5, 11, 5]
    Output: True
Example 2:
    Input: nums = [1, 2, 3, 5]
    Output: False
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 1 <= nums[i] <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Subset sum on half total
Total must be even; find subset with sum total//2.

1. If sum(nums) odd return False.
2. Run subset-sum DP to target = sum//2 with correct base: dp\[i\]\[0\]=True.

## Complexity

**Time:** O(n \* sum).

**Space:** O(n \* sum).

## Solution

````python
from typing import List


class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        s = sum(nums)
        if s % 2:
            return False
        target = s // 2
        n = len(nums)
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True
        for i in range(1, n + 1):
            for j in range(1, target + 1):
                if nums[i - 1] <= j:
                    dp[i][j] = dp[i - 1][j - nums[i - 1]] or dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]
        return dp[n][target]
````
