Given an unsorted array of integers, find the kth smallest element in the array.

## Examples

````text
Example 1:
    Input: nums = [7, 10, 4, 3, 20, 15], k = 3
    Output: 7

Example 2:
    Input: nums = [7, 10, 4, 3, 20, 15], k = 4
    Output: 10
````

## Constraints

````text
- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Top-K
We maintain a max-heap of size k (using negated values). The root is always the kth
smallest element. Any element larger than the root is ignored.

1. Build a max-heap (negated min-heap) from the first k elements.
2. For each remaining element, if it is smaller than the root (largest in heap),
replace the root with the current element.
3. After processing all elements, the root is the kth smallest element.

## Complexity

**Time:** O(n log k), where n is the length of the array
- Each heap operation takes O(log k) time.

**Space:** O(k) - We maintain a heap of at most k elements.

## Solution

````python
import heapq
from typing import List


class Solution:
    def findKthSmallest(self, nums: List[int], k: int) -> int:
        max_heap = [-x for x in nums[:k]]
        heapq.heapify(max_heap)

        for i in range(k, len(nums)):
            # Discard values larger than our current k-th smallest candidate.
            if nums[i] < -max_heap[0]:
                heapq.heapreplace(max_heap, -nums[i])

        return -max_heap[0]
````
