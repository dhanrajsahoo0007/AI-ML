Given triangle list of lists, return minimum path sum from top to adjacent row below.

## Examples

````text
Example 1: triangle=[[2],[3,4],[6,5,7],[4,1,8,3]] -> 11
````

## Constraints

````text
- 1 <= len(triangle) <= 200
````

<PremiumBreak />

## Approach

**Pattern:** Bottom-up DP on triangle
next\_row\[j\]=tri\[i\]\[j\]+min(cur\[j\],cur\[j+1\]).

## Complexity

**Time:** O(n^2). Space: O(n).

## Solution

````python
from typing import List


class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        cur = triangle[-1][:]
        for i in range(len(triangle) - 2, -1, -1):
            nxt = []
            for j in range(len(triangle[i])):
                nxt.append(triangle[i][j] + min(cur[j], cur[j + 1]))
            cur = nxt
        return cur[0]
````
