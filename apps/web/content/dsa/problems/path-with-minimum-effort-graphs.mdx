Given a 2D grid of heights, travel from the top-left to the bottom-right moving only
up, down, left, or right. The effort of a route is the maximum absolute height difference
between two consecutive cells on the route. Return the minimum effort among all routes.

## Examples

````text
Example 1:
    Input: heights = [[1,2,2],[3,8,2],[5,3,5]]
    Output: 2
Example 2:
    Input: heights = [[1,2,3],[3,8,4],[5,3,5]]
    Output: 1
````

## Constraints

````text
- rows == len(heights), columns == len(heights[0])
- 1 <= rows, columns <= 100
- 1 <= heights[i][j] <= 10^6
````

## Approach

**Pattern:** Graph - Shortest Path (Dijkstra / minimax edge relaxation)

1. Model each cell as a node; moving to a neighbor relaxes effort with max(current, edge diff).
2. Run Dijkstra from (0,0) using a min-heap keyed by effort so far.
3. Return effort when (m-1, n-1) is first finalized (or equivalent best value at destination).

## Complexity

**Time:** O(m \* n \* log(m \* n)) - each cell pushed/popped from heap at most a few times.

**Space:** O(m \* n) - distance grid and heap.

## Solution

````python
from typing import List
from collections import defaultdict, deque
import heapq


class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        m, n = len(heights), len(heights[0])
        dist = [[float("inf")] * n for _ in range(m)]
        dist[0][0] = 0
        pq = [(0, 0, 0)]
        dirs = ((-1, 0), (1, 0), (0, -1), (0, 1))

        while pq:
            d, r, c = heapq.heappop(pq)
            if d > dist[r][c]:
                continue
            if r == m - 1 and c == n - 1:
                return d
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    nd = max(d, abs(heights[r][c] - heights[nr][nc]))
                    if nd < dist[nr][nc]:
                        dist[nr][nc] = nd
                        heapq.heappush(pq, (nd, nr, nc))
        return dist[m - 1][n - 1]
````
