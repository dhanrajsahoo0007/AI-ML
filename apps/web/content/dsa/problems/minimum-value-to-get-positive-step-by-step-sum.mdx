Given nums, choose a positive start value such that the running sum is always
strictly positive after each step. Return the minimum such start value.

## Examples

````text
Example 1:
Input: nums = [-3, 2, -3, 4, 2]
Output: 5
````

## Constraints

````text
- 1 <= len(nums) <= 100
- -100 <= nums[i] <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Prefix Sum
Track the minimum prefix sum; start must be at least 1 - min\_prefix.

1. Walk nums, maintaining running sum and minimum prefix seen.
2. Return max(1, 1 - min\_prefix).

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
from typing import List


class Solution:
    def minStartValue(self, nums: List[int]) -> int:
        s = 0
        min_pre = 0
        for x in nums:
            s += x
            min_pre = min(min_pre, s)
        return max(1, 1 - min_pre)
````
