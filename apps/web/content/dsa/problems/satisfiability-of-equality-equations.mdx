You are given an array of strings 'equations' that represent relationships between variables
where each string equations\[i\] is of length 4 and takes one of two different forms: "xi==yi" or "xi!=yi".

Here, xi and yi are lowercase letters (not necessarily different) that represent one-letter variable names.
Return true if it is possible to assign integers to variable names so as to satisfy all the given equations,
or false otherwise.

## Examples

````text
Example 1:
    Input: equations = ["a==b", "b!=a"]
    Output: False
Example 2:
    Input: equations = ["b==a", "a==b"]
    Output: True
````

## Constraints

````text
- 1 <= equations.length <= 500
- equations[i].length == 4
````

<PremiumBreak />

## Approach

**Pattern:** Union-Find / Disjoint Set Union on 26 letters

1. Initialize DSU for 26 letters.
2. Union all "==" pairs.
3. For each "!=", if both letters share a root, return False.

## Complexity

**Time:** O(n \* α(n)), nearly linear in practice.

**Space:** O(1) — fixed 26 nodes.

## Solution

````python
from typing import List


class Solution:
    def __init__(self) -> None:
        self.parent: List[int] = []
        self.rank: List[int] = []

    def find(self, x: int) -> int:
        if self.parent[x] == x:
            return x

        self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x: int, y: int) -> None:
        x_parent = self.find(x)
        y_parent = self.find(y)

        if x_parent == y_parent:
            return

        if self.rank[x_parent] > self.rank[y_parent]:
            self.parent[y_parent] = x_parent

        elif self.rank[x_parent] < self.rank[y_parent]:
            self.parent[x_parent] = y_parent

        else:
            self.parent[x_parent] = y_parent
            self.rank[y_parent] += 1

    def equationsPossible(self, equations: List[str]) -> bool:
        self.parent = list(range(26))
        self.rank = [0] * 26

        for eq in equations:
            if eq[1] == "=":
                x = ord(eq[0]) - ord("a")
                y = ord(eq[3]) - ord("a")
                self.union(x, y)

        for eq in equations:
            if eq[1] == "!":
                x = ord(eq[0]) - ord("a")
                y = ord(eq[3]) - ord("a")
                if self.find(x) == self.find(y):
                    return False

        return True
````
