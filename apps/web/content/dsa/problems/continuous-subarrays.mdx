Given an unsorted array of integers nums, return the length of the longest contiguous
strictly increasing subarray (a run where each next element is larger than the previous).

## Examples

````text
Example 1:
    Input: nums = [1, 3, 5, 4, 7]
    Output: 3
Example 2:
    Input: nums = [2, 2, 2, 2, 2]
    Output: 1
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -10^9 <= nums[i] <= 10^9
````

<PremiumBreak />

## Approach

**Pattern:** Linear scan with running streak length
Extend a streak while the sequence stays strictly increasing; reset when it breaks.

1. Track the current streak length starting from each new increasing segment.
2. When nums\[i\] &gt; nums\[i - 1\], increment the streak; otherwise reset to 1.
3. Keep the maximum streak observed.

## Complexity

**Time:** O(n) - Single pass through the array.

**Space:** O(1) - Only counters are stored.

## Solution

````python
from typing import List


class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        best = 1
        cur = 1

        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                cur += 1
            else:
                cur = 1
            best = max(best, cur)

        return best
````
