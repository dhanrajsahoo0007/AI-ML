nums contains n + 1 integers where each integer is in \[1, n\] inclusive. Exactly
one value appears at least twice; return that duplicate.

## Examples

````text
Example 1:
    Input: nums = [1,3,4,2,2]
    Output: 2
Example 2:
    Input: nums = [3,1,3,4,2]
    Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- Values are in [1, len(nums) - 1]
````

<PremiumBreak />

## Approach

**Pattern:** Floyd cycle detection (tortoise and hare)
Treat nums as a linked list from index i to nums\[i\]; duplicate creates a cycle.

1. Phase 1: advance slow by one step and fast by two until they meet.
2. Phase 2: reset one pointer to start; advance both one step until they meet.

## Complexity

**Time:** O(n)

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = fast = nums[0]
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        slow = nums[0]
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
````
