Houses are in a line; each house has cash nums\[i\]. You cannot rob two adjacent
houses. Return the maximum cash you can rob.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 1]
    Output: 4
Example 2:
    Input: nums = [2, 7, 9, 3, 1]
    Output: 12
````

## Constraints

````text
- 1 <= nums.length <= 100
- 0 <= nums[i] <= 400
````

<PremiumBreak />

## Approach

**Pattern:** 1D Dynamic Programming
Same recurrence as maximum non-adjacent sum on a path.

1. dp\[i\] = max(dp\[i-1\], dp\[i-2\] + nums\[i\]) with base cases for i=0,1.
2. Compress to two variables for space O(1).

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0
        if len(nums) == 1:
            return nums[0]
        prev2, prev1 = nums[0], max(nums[0], nums[1])
        for i in range(2, len(nums)):
            prev2, prev1 = prev1, max(prev1, prev2 + nums[i])
        return prev1
````
