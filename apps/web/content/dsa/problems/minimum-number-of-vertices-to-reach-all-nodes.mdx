Given a directed acyclic graph with n nodes 0..n-1 and edges\[i\] = \[from\_i, to\_i\], return the
smallest list of vertices from which every node is reachable (any order).

## Examples

````text
Example 1:
    Input: n = 6, edges = [[0,1],[0,2],[2,5],[3,4],[4,2]]
    Output: [0,3] (in any order)
Example 2:
    Input: n = 5, edges = [[0,1],[2,1],[3,1],[1,4],[2,4]]
    Output: [0,2,3]
````

## Constraints

````text
- 2 <= n <= 10^5
- 1 <= len(edges) <= 5 * 10^5
````

**Order.** Any order is accepted: the tests sort your result before comparing it.

<PremiumBreak />

## Approach

**Pattern:** Graph - DAG sources (indegree zero)

1. Mark every node that appears as a destination of some edge.
2. All unmarked nodes are sources and form a minimum dominating set of start vertices.

## Complexity

**Time:** O(n + m).

**Space:** O(n).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def findSmallestSetOfVertices(self, n: int, edges: List[List[int]]) -> List[int]:
        incoming = [False] * n
        for u, v in edges:
            incoming[v] = True
        return [i for i in range(n) if not incoming[i]]
````
