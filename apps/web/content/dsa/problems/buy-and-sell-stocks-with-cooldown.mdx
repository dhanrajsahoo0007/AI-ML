Sell then must cooldown one day before buying again.

<PremiumBreak />

## Approach

**Pattern:** Three-state DP: hold, sold, rest.

## Complexity

**Time:** O(n).

## Solution

````python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        hold = -10**9
        sold = 0
        rest = 0
        for p in prices:
            prev_hold = hold
            hold = max(hold, rest - p)
            rest = max(rest, sold)
            sold = prev_hold + p
        return max(sold, rest)
````
