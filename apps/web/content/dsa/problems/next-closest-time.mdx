Given a valid 24-hour time "HH:MM", form the next closest time using only the digits that
appear in the input (each digit may be reused any number of times). If no strictly later time
exists today, return the earliest valid time on the following day built from those digits.

## Examples

````text
Example 1:
    Input: time = "19:34"
    Output: "19:39"

Example 2:
    Input: time = "23:59"
    Output: "22:22"
````

## Constraints

````text
- time has the form "##:##" with valid hour and minute ranges
````

<PremiumBreak />

## Approach

**Pattern:** Enumerate digit combinations
Try all 4^4 combinations with replacement from the four input digits; keep valid clock times.

1. Convert start time to minutes-from-midnight.
2. Enumerate every length-4 tuple of the four digit characters, form HH and MM, validate.
3. Collect minute values; pick the smallest value strictly greater than start, else the minimum value.

## Complexity

**Time:** O(4^4) with constant pruning.

**Space:** O(1) excluding the small candidate list.

## Solution

````python
class Solution:
    def nextClosestTime(self, time: str) -> str:
        choices = [time[0], time[1], time[3], time[4]]

        def to_minutes(hhmm: str) -> int:
            return int(hhmm[:2]) * 60 + int(hhmm[3:])

        start = to_minutes(time)
        candidates: set[int] = set()

        for a in choices:
            for b in choices:
                for c in choices:
                    for d in choices:
                        hh = int(a + b)
                        mm = int(c + d)
                        if hh < 24 and mm < 60:
                            candidates.add(hh * 60 + mm)

        greater = [t for t in candidates if t > start]
        pick = min(greater) if greater else min(candidates)
        return f"{pick // 60:02d}:{pick % 60:02d}"
````
