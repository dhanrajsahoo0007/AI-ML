Given an array of meeting intervals \[start\_i, end\_i\] with start\_i &lt; end\_i, determine
whether one person can attend all meetings without overlap. Meetings that touch at an
endpoint (end of one equals start of another) are not conflicts.

## Examples

````text
Example 1:
    Input: intervals = [[0,30],[5,10],[15,20]]
    Output: false

Example 2:
    Input: intervals = [[5,8],[9,15]]
    Output: true
````

## Constraints

````text
- 0 <= len(intervals) <= 500
- 0 <= start_i < end_i <= 10^6
````

<PremiumBreak />

## Approach

**Pattern:** Sort + adjacent overlap check
After sorting by start time, a conflict exists exactly when some start is strictly
less than the previous meeting's end.

1. Sort intervals by starting time.
2. Compare each interval with its predecessor.
3. If any start is smaller than the previous end, return False.
4. Otherwise return True.

## Complexity

**Time:** O(n log n) - sorting dominates.

**Space:** O(1) extra beyond the sorted list in place.

## Original notes

````text
Concrete overlaps (from original examples):
- `[[0,30],[5,10],[15,20]]` is impossible because `[0,30]` intersects `[5,10]` with a
  positive-length overlap.
- `[[5,8],[9,15]]` works because `8` touching `9` is **not** a conflict (`start < prev_end`
  is the strict check).
````

## Solution

````python
from typing import List


class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        intervals.sort(key=lambda x: x[0])
        for i in range(1, len(intervals)):
            # Strict `<` allows back-to-back meetings sharing an endpoint.
            if intervals[i][0] < intervals[i - 1][1]:
                return False
        return True
````
