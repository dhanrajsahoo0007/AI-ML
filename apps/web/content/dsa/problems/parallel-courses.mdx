You have n courses labeled 1..n. relations\[i\] = \[prevCourse, nextCourse\] means prevCourse must be taken
before nextCourse. In one semester you can take any number of courses as long as prerequisites are met.
Return the minimum number of semesters needed to finish all courses, or -1 if impossible due to a cycle.

## Examples

````text
Example 1:
    Input: n = 3, relations = [[1,3],[2,3]]
    Output: 2
Example 2:
    Input: n = 3, relations = [[1,2],[2,3],[3,1]]
    Output: -1
````

## Constraints

````text
- 1 <= n <= 5000
- 0 <= len(relations) <= 5000
````

<PremiumBreak />

## Approach

**Pattern:** Longest path in DAG via layered Kahn's BFS
Each BFS layer corresponds to a semester when all indegree-zero nodes available in parallel are taken.

1. Build adjacency list and indegrees for 1-indexed nodes.
2. Repeatedly process all current indegree-zero nodes as one semester; decrement neighbors.
3. If all n nodes processed, return semester count; else -1.

## Complexity

**Time:** O(n + m) for m relations.

**Space:** O(n + m).

## Solution

````python
from typing import List
from collections import defaultdict, deque


class Solution:
    def minimumSemesters(self, n: int, relations: List[List[int]]) -> int:
        g = defaultdict(list)
        indeg = [0] * (n + 1)
        for u, v in relations:
            g[u].append(v)
            indeg[v] += 1
        q: deque[int] = deque(i for i in range(1, n + 1) if indeg[i] == 0)
        semesters = 0
        taken = 0
        while q:
            semesters += 1
            for _ in range(len(q)):
                u = q.popleft()
                taken += 1
                for v in g[u]:
                    indeg[v] -= 1
                    if indeg[v] == 0:
                        q.append(v)
        return semesters if taken == n else -1
````
