The count-and-say sequence starts with "1". Each subsequent term is generated by
reading the previous term aloud: consecutive equal digits are replaced by count
followed by digit. Return the nth term (1-indexed).

## Examples

````text
Example 1:
    Input: n = 1
    Output: "1"

Example 2:
    Input: n = 4
    Output: "1211"
````

## Constraints

````text
- 1 <= n <= 30
````

<PremiumBreak />

## Approach

**Pattern:** Iterative run-length encoding
Build term i from term i-1 by scanning runs of identical characters.

1. Start with cur = "1".
2. Repeat n-1 times: build next by grouping equal characters and appending length then char.
3. Return cur.

## Complexity

**Time:** O(n \* L) - Length grows roughly exponentially; each step is linear in current length.

**Space:** O(L) - Stores the latest term.

## Solution

````python
class Solution:
    def countAndSay(self, n: int) -> str:
        cur = "1"
        for _ in range(n - 1):
            nxt: list[str] = []
            i = 0
            while i < len(cur):
                j = i
                while j < len(cur) and cur[j] == cur[i]:
                    j += 1
                nxt.append(str(j - i))
                nxt.append(cur[i])
                i = j
            cur = "".join(nxt)
        return cur
````
