Given n pairs of parentheses, generate every well-formed parentheses string of length 2n.

## Examples

````text
Example 1:
Input: n = 3
Output: five strings (Catalan number C3)
````

## Constraints

````text
- 1 <= n <= 4 in exhaustive tests
````

<PremiumBreak />

## Approach

**Pattern:** Feasibility-guarded DFS
Track remaining open and close credits; only append ')' when it will not exceed '(' count.

1. DFS with parameters open\_left and close\_left starting at n.
2. Push '(' while open\_left &gt; 0; push ')' only if close\_left &gt; open\_left.
3. Record when both counters reach 0.

## Complexity

**Time:** O(4^n / sqrt(n)) - Catalan number of strings.

**Space:** O(n) for recursion and builder.

## Solution

````python
from typing import List


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result: List[str] = []

        def dfs(open_left: int, close_left: int, path: List[str]) -> None:
            if open_left == 0 and close_left == 0:
                result.append("".join(path))
                return
            if open_left > 0:
                path.append("(")
                dfs(open_left - 1, close_left, path)
                path.pop()
            if close_left > open_left:
                path.append(")")
                dfs(open_left, close_left - 1, path)
                path.pop()

        dfs(n, n, [])
        return result
````
