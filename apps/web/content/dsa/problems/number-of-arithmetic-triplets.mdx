Given a strictly increasing integer array nums and a positive integer diff, count triplets
(i, j, k) with i &lt; j &lt; k such that nums\[j\] - nums\[i\] == diff and nums\[k\] - nums\[j\] == diff.

## Examples

````text
Example 1:
    Input: nums = [0, 1, 4, 6, 7, 10], diff = 3
    Output: 2
Example 2:
    Input: nums = [4, 5, 6, 7, 8, 9], diff = 2
    Output: 2
````

## Constraints

````text
- 3 <= len(nums) <= 200
- 0 <= nums[i] <= 200
- 1 <= diff <= 50
- nums is strictly increasing.
````

## Approach

**Pattern:** Hash set lookups
For each middle value x, check whether x - diff and x + diff exist in the set.

1. Insert all nums into a set for O(1) membership.
2. For each x in nums, if x - diff and x + diff are in the set, increment answer.
3. Return answer.

## Complexity

**Time:** O(n) - One pass with O(1) lookups.

**Space:** O(n) - The set of values.

## Solution

````python
from typing import List


class Solution:
    def arithmeticTriplets(self, nums: List[int], diff: int) -> int:
        values = set(nums)
        return sum((x - diff in values) and (x + diff in values) for x in nums)
````
