Given an integer array nums (which may contain negative values) and an integer k,
return the length of the longest contiguous subarray whose sum equals k.

## Examples

````text
Example 1:
    Input: nums = [10, 5, 2, -8, 8, 7, -2, 9], k = 7
    Output: 5
Example 2:
    Input: nums = [1, -1, 5, -2, 3], k = 3
    Output: 4
````

## Constraints

````text
- Negative numbers are allowed; a pure two-pointer positive-only approach is insufficient.
````

## Approach

**Pattern:** Prefix sum with hash map (subarray sum)
For each prefix sum S, any earlier index with sum S - k defines a subarray summing to k.

1. Iterate through nums while maintaining the running prefix sum.
2. Store the earliest index for each prefix sum in a dictionary (initialize &#123;0: -1&#125;).
3. If current\_sum - k exists in the map, update the maximum length using stored index.

Problem Statement:

with sum of the elements equal to the given value K.

Explanation:
We use a modified sliding window technique with an initial check before shrinking:
1. Initialize two pointers, i and j, both at the start of the array.
2. Maintain a running sum (window\_sum) of the elements in the current window.
3. Expand the window by moving j to the right and adding elements to window\_sum.
4. If window\_sum exceeds K, first check if i &lt;= j, then enter a loop to shrink the window.
5. If window\_sum equals K, update the max\_length.

\*\*\*Note: This approach works for arrays with positive numbers. For arrays with negative
numbers, a more complex approach using a hash map would be more efficient.

## Complexity

**Time:** O(n) - Single pass with O(1) expected map operations per step.

**Space:** O(n) - The map may hold one entry per distinct prefix sum.

## Solution

````python
from typing import List


class Solution:
    def longestSubarraySumK(self, nums: List[int], k: int) -> int:
        index_by_sum = {0: -1}
        prefix = 0
        best = 0

        for i, num in enumerate(nums):
            prefix += num

            if prefix - k in index_by_sum:
                best = max(best, i - index_by_sum[prefix - k])

            if prefix not in index_by_sum:
                index_by_sum[prefix] = i

        return best
````
