Given an integer array nums (positive, negative, or zero) and an integer k, return the length of
the longest contiguous subarray whose sum equals k.

## Examples

````text
Example 1:
    Input: nums = [1, -1, 5, -2, 3], k = 3
    Output: 4  # [1, -1, 5, -2]
Example 2:
    Input: nums = [1, 2, 3], k = 3
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -10^4 <= nums[i] <= 10^4
- -10^9 <= k <= 10^9
````

<PremiumBreak />

## Approach

**Pattern:** Prefix sum with hash map
For each ending index, need earliest start where prefix\[end\] - prefix\[start-1\] == k.

1. Track running prefix sum and a map from prefix value to earliest index achieving it.
2. Seed map with &#123;0: -1&#125;.
3. For each index i, update prefix, if prefix - k exists in map, length is i - map\[prefix - k\].
4. If prefix not in map, record map\[prefix\] = i (keep earliest).
5. Return the maximum length found (or 0).

## Complexity

**Time:** O(n) - One pass with O(1) map ops amortized.

**Space:** O(n) - Map holds up to n prefix sums.

## Solution

````python
from typing import List


class Solution:
    def longestSubarraySumK(self, nums: List[int], k: int) -> int:
        prefix = 0
        first_index: dict[int, int] = {0: -1}
        best = 0
        for i, x in enumerate(nums):
            prefix += x
            need = prefix - k
            if need in first_index:
                best = max(best, i - first_index[need])
            if prefix not in first_index:
                first_index[prefix] = i
        return best
````
