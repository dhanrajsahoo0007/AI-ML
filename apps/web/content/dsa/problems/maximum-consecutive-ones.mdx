Given a binary array nums, return the maximum number of consecutive 1's in the array.

## Examples

````text
Example 1:
    Input: nums = [1, 1, 0, 1, 1, 1]
    Output: 3
Example 2:
    Input: nums = [1, 0, 1, 1, 0, 1]
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^5
- nums[i] is 0 or 1.
````

<PremiumBreak />

## Approach

**Pattern:** Linear scan with running counter
Track current streak of ones and reset on zeros.

1. Initialize best = 0 and cur = 0.
2. For each bit in nums, if 1 increment cur else reset cur to 0; update best = max(best, cur).
3. Return best.

## Complexity

**Time:** O(n) - One pass.

**Space:** O(1) - Two counters.

## Solution

````python
from typing import List


class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        best = 0
        cur = 0
        for x in nums:
            if x == 1:
                cur += 1
                best = max(best, cur)
            else:
                cur = 0
        return best
````
