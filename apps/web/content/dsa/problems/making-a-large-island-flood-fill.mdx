You are given an n x n binary grid. You may change at most one 0 to a 1. Return the size of the largest
island (4-directionally connected group of 1s) achievable.

## Examples

````text
Example 1:
    Input: grid = [[1,0],[0,1]]
    Output: 3
Example 2:
    Input: grid = [[1,1],[1,0]]
    Output: 4
````

## Constraints

````text
- n == len(grid) == len(grid[i])
- 1 <= n <= 500
````

**Also in the notes under:** [17. Graphs/06. Disjoint Union Sets/03. Connected Components and Islands](/dsa/problems/making-a-large-island).

## Approach

**Pattern:** Component coloring + neighbor merge
Label each original island with an id and its area, then evaluate each 0 by summing distinct neighbor ids.

1. DFS paint each island with an id &gt;=2 while recording area sizes.
2. Track the maximum existing island size.
3. For each 0 cell, add 1 plus areas of unique neighboring component ids.

## Complexity

**Time:** O(n^2)

**Space:** O(n^2) for recursion and grid labels.

## Solution

````python
from typing import List


class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        index = 2
        area: dict[int, int] = {}

        def dfs(r: int, c: int, color: int) -> int:
            grid[r][c] = color
            cnt = 1
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1:
                    cnt += dfs(nr, nc, color)
            return cnt

        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    area[index] = dfs(i, j, index)
                    index += 1

        ans = max(area.values(), default=0)
        for i in range(n):
            for j in range(n):
                if grid[i][j] != 0:
                    continue
                seen: set[int] = set()
                cur = 1
                for dr, dc in dirs:
                    ni, nj = i + dr, j + dc
                    if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] >= 2:
                        seen.add(grid[ni][nj])
                for comp in seen:
                    cur += area[comp]
                ans = max(ans, cur)
        return ans
````
