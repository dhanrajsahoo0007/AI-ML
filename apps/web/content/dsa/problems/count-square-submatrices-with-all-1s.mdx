Count square submatrices with all ones (LeetCode 1277).

<PremiumBreak />

## Approach

**Pattern:** DP on square side length.

## Complexity

**Time:** O(m\*n).

## Solution

````python
from typing import List


class Solution:
    def countSquares(self, matrix: List[List[int]]) -> int:
        if not matrix:
            return 0
        m, n = len(matrix), len(matrix[0])
        dp = [[0] * n for _ in range(m)]
        ans = 0
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 0:
                    continue
                if i == 0 or j == 0:
                    dp[i][j] = 1
                else:
                    dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
                ans += dp[i][j]
        return ans
````
