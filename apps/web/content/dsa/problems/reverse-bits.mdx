Reverse bits of a given 32-bit unsigned integer.

## Examples

````text
Example 1:
    Input: n = 43261596 (00000010100101000001111010011100)
    Output: 964176192
Example 2:
    Input: n = 4294967293
    Output: 3221225471
````

## Constraints

````text
- The input must be a binary string of length 32 (interpreted as unsigned int)
````

<PremiumBreak />

## Approach

**Pattern:** Bit extraction and assembly
Build the answer from LSB to MSB of the input across exactly 32 steps.

1. Initialize result to 0.
2. For 32 iterations: shift result left, OR in n &amp; 1, shift n right.

## Complexity

**Time:** O(1) - 32 iterations

**Space:** O(1)

## Solution

````python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0
        for _ in range(32):
            res = (res << 1) | (n & 1)
            n >>= 1
        return res
````
