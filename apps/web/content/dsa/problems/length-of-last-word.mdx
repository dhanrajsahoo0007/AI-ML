Given a string s of words separated by spaces, return the length of the last word.
A word is a maximal substring of non-space characters.

## Examples

````text
Example 1:
    Input: s = "Hello World"
    Output: 5
Example 2:
    Input: s = "   fly me   to   the moon  "
    Output: 4
````

## Constraints

````text
- 1 <= len(s) <= 10^4
- s consists only of English letters and spaces.
- There is at least one word in s.
````

<PremiumBreak />

## Approach

**Pattern:** Single pass from the right
Walk backward counting non-spaces until a space boundary after a word is found.

1. Scan characters of s from right to left.
2. Skip trailing spaces.
3. Count consecutive non-space characters until a space or start of string.
4. Return that count.

## Complexity

**Time:** O(n) - Worst case scans the whole string once.

**Space:** O(1) - Only counters and indices.

## Solution

````python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        c = 0
        for ch in reversed(s):
            if ch == " ":
                if c >= 1:
                    return c
            else:
                c += 1
        return c
````
