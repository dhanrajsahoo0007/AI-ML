Given a binary string s containing at least one '1', rearrange its bits to form the largest
odd binary number possible (odd means least significant bit is '1'). Leading zeros are allowed.

## Examples

````text
Example 1:
    Input: s = "010"
    Output: "001"

Example 2:
    Input: s = "0101"
    Output: "1001"

Example 3:
    Input: s = "1"
    Output: "1"
````

## Constraints

````text
- 1 <= len(s) <= 100
- s consists only of '0' and '1'
- s contains at least one '1'
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Construction
Put all but one '1' at the high end, all '0's in the middle, and a single '1' at the end for odd parity.

1. Count ones and zeros in s.
2. Build (ones-1) copies of '1', then all '0's, then a final '1'.

## Complexity

**Time:** O(n) - Counting and building length n string.

**Space:** O(n) - Output string.

## Solution

````python
class Solution:
    def maximumOddBinaryNumber(self, s: str) -> str:
        count_ones = s.count("1")
        count_zeros = len(s) - count_ones
        return "1" * (count_ones - 1) + "0" * count_zeros + "1"
````
