A parentheses string s of even length is paired with locked of the same length. locked\[i\] is '1'
if s\[i\] cannot change, else s\[i\] may be '(' or ')'. Return whether some assignment of unlocked
positions yields a valid parentheses string.

## Examples

````text
Example 1:
    Input: s = "))()))", locked = "010100"
    Output: True

Example 2:
    Input: s = "()()", locked = "0000"
    Output: True

Example 3:
    Input: s = ")", locked = "0"
    Output: False
````

## Constraints

````text
- 2 <= len(s) == len(locked) <= 10^5
- s[i] is '(' or ')'
- locked[i] is '0' or '1'
````

<PremiumBreak />

## Approach

**Pattern:** Greedy Balance Bounds
Forward pass treats unlocked slots as flexible opens; backward pass treats them as flexible closes.

1. If length is odd, return False.
2. Forward: track balance treating unlocked or '(' as +1 and locked ')' as -1; never let balance go negative.
3. Backward symmetric with roles flipped; if both passes succeed, return True.

## Complexity

**Time:** O(n) - Two linear passes.

**Space:** O(1) - Balance counters.

## Solution

````python
class Solution:
    def canBeValid(self, s: str, locked: str) -> bool:
        n = len(s)
        if n % 2:
            return False
        bal = 0
        for i in range(n):
            if locked[i] == "0" or s[i] == "(":
                bal += 1
            else:
                bal -= 1
            if bal < 0:
                return False
        bal = 0
        for i in range(n - 1, -1, -1):
            if locked[i] == "0" or s[i] == ")":
                bal += 1
            else:
                bal -= 1
            if bal < 0:
                return False
        return True
````
