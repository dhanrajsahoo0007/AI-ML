Given the root of a binary tree, determine whether it satisfies the binary search tree (BST)
property: every node's value is strictly greater than all values in its left subtree and
strictly less than all values in its right subtree.

## Examples

````text
Example 1:
    Input: root = [2,1,3]
    Output: True

Example 2:
    Input: root = [5,1,4,null,null,3,6] (4 is in wrong place relative to 5)
    Output: False
````

## Constraints

````text
- The number of nodes is in the range [0, 10^4].
- Node values may be any 32-bit signed integers (use open bounds for min/max).
````

**How the tests describe the input.** A linked list is written as an array of its values, head first; a binary tree as an array in level order, with `None` for a missing child. The code above the line in the editor turns those arrays into nodes and your answer back into an array: write the function below the line.

## Approach

**Pattern:** Valid range (inorder bounds)
Each node must lie in (low, high) where bounds tighten from parent to children.

1. Define a recursive validator with low and high bounds (initially -inf and +inf).
2. At each node, fail if val is not strictly inside (low, high).
3. Recurse left with high = node.val and right with low = node.val.

## Complexity

**Time:** O(n) - Each node is visited once.

**Space:** O(h) - Recursion stack depth equals tree height.

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_tree_level_order(values: list[Optional[int]]) -> Optional[TreeNode]:
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    queue: list[TreeNode] = [root]
    i = 1
    while queue and i < len(values):
        node = queue.pop(0)
        if i < len(values) and values[i] is not None:
            node.left = TreeNode(values[i])
            queue.append(node.left)
        i += 1
        if i < len(values) and values[i] is not None:
            node.right = TreeNode(values[i])
            queue.append(node.right)
        i += 1
    return root


class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def validate(node: Optional[TreeNode], low: float, high: float) -> bool:
            if node is None:
                return True
            if node.val <= low or node.val >= high:
                return False
            return validate(node.left, low, node.val) and validate(node.right, node.val, high)

        return validate(root, float("-inf"), float("inf"))
````
