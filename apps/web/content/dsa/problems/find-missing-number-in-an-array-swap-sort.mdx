nums has length n containing distinct numbers drawn from &#123;0..n&#125; except exactly
one missing value. Return the missing number.

## Examples

````text
Example 1:
    Input: nums = [3,0,1]
    Output: 2
Example 2:
    Input: nums = [0,1]
    Output: 2
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- All values are unique in the allowed range
````

**Also in the notes under:** [01. Array/02. Array Searching and Counting](/dsa/problems/find-missing-number-in-an-array).

## Approach

**Pattern:** XOR / arithmetic sum
XOR all indices and numbers; the missing index remains.

1. x starts at n (the length), then XOR each index and value.

## Complexity

**Time:** O(n)

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        x = len(nums)
        for i, v in enumerate(nums):
            x ^= i ^ v
        return x
````
