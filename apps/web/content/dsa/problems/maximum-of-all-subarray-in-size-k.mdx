Given an array of integers and a positive integer k, return the maximum value in
each contiguous subarray of length k.

## Examples

````text
Example 1:
    Input: arr = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
    Output: [3, 3, 5, 5, 6, 7]
Example 2:
    Input: arr = [9, 11], k = 2
    Output: [11]
````

## Constraints

````text
- 1 <= k <= len(arr)
````

<PremiumBreak />

## Approach

**Pattern:** Fixed-size sliding window with decreasing deque
Keep indices in decreasing order of values so the front is always the current maximum.

1. For the first window, pop smaller values from the deque tail, then push indices.
2. For each new index, remove indices outside the window from the front.
3. Maintain decreasing order at the tail; append the current window max to the answer.

## Complexity

**Time:** O(n) - Each index is pushed and popped at most once from the deque.

**Space:** O(k) - The deque stores at most k indices.

````text
Problem Statement:
Given an array of integers and a positive integer k, find the maximum element in every contiguous subarray of size k.

Explanation:
We use a simple sliding window technique:
1. Initialize two pointers, i and j, both at the start of the array.
2. Maintain a variable to store the maximum element in the current window.
3. Slide the window through the array:
   - Expand the window by moving j to the right.
   - When the window size reaches k, add the current maximum to the result.
   - Slide the window by moving i to the right and updating the maximum if necessary.

Time Complexity: O(n), where n is the length of the array.
We traverse the array once with the sliding window.

Space Complexity: O(n-k+1) for the result array, O(1) for additional variables.
````

## Solution

````python
from collections import deque
from typing import List


class Solution:
    def maxOfSubarrays(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        if n == 0 or k <= 0 or k > n:
            return []

        dq: deque[int] = deque()
        res: List[int] = []

        for j in range(n):
            while dq and arr[dq[-1]] <= arr[j]:
                dq.pop()
            dq.append(j)

            if dq[0] <= j - k:
                dq.popleft()

            if j >= k - 1:
                res.append(arr[dq[0]])

        return res
````
