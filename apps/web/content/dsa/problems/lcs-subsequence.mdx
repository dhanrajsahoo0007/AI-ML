Given two strings text1 and text2, return the length of their longest common
subsequence (LCS). If there is no common subsequence, return 0.

## Examples

````text
Example 1:
    Input: text1 = "abcde", text2 = "ace"
    Output: 3
Example 2:
    Input: text1 = "abc", text2 = "abc"
    Output: 3
````

## Constraints

````text
- 1 <= len(text1), len(text2) <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** 2D DP on string pairs
Compare last characters; if equal add 1 else max of skipping one side.

1. dp\[i\]\[j\] = LCS length of text1\[:i\] and text2\[:j\].
2. If text1\[i-1\]==text2\[j-1\]: dp\[i\]\[j\]=1+dp\[i-1\]\[j-1\]; else max(dp\[i-1\]\[j\], dp\[i\]\[j-1\]).

## Complexity

**Time:** O(m \* n).

**Space:** O(m \* n); can optimize to O(min(m,n)).

## Solution

````python
from typing import List


class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp: List[List[int]] = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
````
