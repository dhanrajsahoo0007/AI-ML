Given a string s of digits, count how many ways it can be decoded to letters
'A'..'Z' mapped from '1'..'26'. Leading zeros and invalid groups are not allowed.

## Examples

````text
Example 1:
    Input: s = "12"
    Output: 2
Example 2:
    Input: s = "226"
    Output: 3
````

## Constraints

````text
- 1 <= len(s) <= 100
- s contains only digits
````

<PremiumBreak />

## Approach

**Pattern:** 1D Dynamic Programming / DFS with memo
From each index, either take one digit or two if they form 10..26.

1. DFS from index i; if i==n return 1.
2. If s\[i\]=='0', return 0; add ways for one digit.
3. If i+1&lt;n and int(s\[i:i+2\]) in 10..26, add ways for two digits.
4. Memoize on i.

## Complexity

**Time:** O(n) states, O(1) per state.

**Space:** O(n) for memo and recursion stack.

## Solution

````python
class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        memo: dict[int, int] = {}

        def dfs(i: int) -> int:
            if i == n:
                return 1
            if i in memo:
                return memo[i]
            if s[i] == "0":
                memo[i] = 0
                return 0
            ways = dfs(i + 1)
            if i < n - 1 and 10 <= int(s[i : i + 2]) <= 26:
                ways += dfs(i + 2)
            memo[i] = ways
            return ways

        return dfs(0)
````
