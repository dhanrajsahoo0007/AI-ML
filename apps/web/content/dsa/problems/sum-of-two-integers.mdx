Return the sum of two integers a and b without using + or - operators.

## Examples

````text
Example 1:
    Input: a = 1, b = 2
    Output: 3
Example 2:
    Input: a = 2, b = 3
    Output: 5
````

## Constraints

````text
- -1000 <= a, b <= 1000 (LeetCode uses wider 32-bit range)
````

<PremiumBreak />

## Approach

**Pattern:** XOR with carry propagation
XOR gives sum without carry; AND shifted left gives carry bits to add.

1. While b != 0: carry = (a &amp; b) &lt;&lt; 1; a = a ^ b; b = carry.
2. Mask to 32 bits if simulating fixed-width two's complement.

## Complexity

**Time:** O(1) - bounded by bit width

**Space:** O(1)

## Solution

````python
MASK = 0xFFFFFFFF
MAX_INT = 0x7FFFFFFF


class Solution:
    def getSum(self, a: int, b: int) -> int:
        while b & MASK:
            carry = ((a & b) << 1) & MASK
            a = (a ^ b) & MASK
            b = carry
        return a if a <= MAX_INT else ~(a ^ MASK)
````
