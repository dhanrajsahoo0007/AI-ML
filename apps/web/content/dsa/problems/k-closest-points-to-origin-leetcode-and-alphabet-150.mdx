Given an array of integer points on a plane and an integer k, return the k
points closest to the origin (0, 0) by Euclidean distance.

## Examples

````text
Example 1:
    Input: points = [[1,3],[-2,2]], k = 1
    Output: [[-2,2]]
Example 2:
    Input: points = [[3,3],[5,-1],[-2,4]], k = 2
    Output: [[3,3],[-2,4]]
````

## Constraints

````text
- 1 <= len(points) <= 10^4
- -10^4 <= points[i][0], points[i][1] <= 10^4
- 1 <= k <= len(points)
````

**Also in the notes under:** [10. Heap/01. Top-K Pattern](/dsa/problems/k-closest-points-to-origin).

## Approach

**Pattern:** Sorting / heap by squared distance
Compare squared distances to avoid floating sqrt; take k smallest.

1. Sort points by x\*x + y\*y ascending.
2. Return the first k points.

## Complexity

**Time:** O(n log n) - sorting

**Space:** O(n) - sorted copy (or O(k) with heap)

## Solution

````python
import heapq
from typing import List


class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        return heapq.nsmallest(k, points, key=lambda p: p[0] * p[0] + p[1] * p[1])
````
