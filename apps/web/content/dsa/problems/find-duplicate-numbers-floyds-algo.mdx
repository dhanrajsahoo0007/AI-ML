Given an array nums of n + 1 integers in \[1, n\], exactly one value repeats.
Return the repeated number without modifying the array and using only O(1) extra memory.

## Examples

````text
Example 1:
    Input: nums = [1,3,4,2,2]
    Output: 2

Example 2:
    Input: nums = [3,1,3,4,2]
    Output: 3
````

## Constraints

````text
- 1 <= n <= 10^5
- nums.length == n + 1
- 1 <= nums[i] <= n
````

## Approach

**Pattern:** Linked list / cycle detection (Floyd)
Treat indices as edges nums\[i\] -&gt; next index; duplicate creates a cycle; entrance is the duplicate.

1. Phase 1: slow and fast from index 0 until they meet inside the cycle.
2. Phase 2: reset slow to 0; advance slow and fast one step until they meet at duplicate.

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
from __future__ import annotations

from typing import List, Optional


class ListNode:
    def __init__(self, val: int = 0, next: Optional[ListNode] = None):
        self.val = val
        self.next = next


class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = fast = nums[0]
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        slow = nums[0]
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
````
