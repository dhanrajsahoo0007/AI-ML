Return the number of '1' bits in the unsigned 32-bit binary representation of n.

## Examples

````text
Example 1:
    Input: n = 11
    Output: 3
Example 2:
    Input: n = 128
    Output: 1
````

## Constraints

````text
- 0 <= n <= 2^31 - 1
````

<PremiumBreak />

## Approach

**Pattern:** Bit scan / Kernighan trick
Clear lowest set bit repeatedly or test each of 32 positions.

1. Use n &amp;= n - 1 in a loop until n is 0, counting iterations.

## Complexity

**Time:** O(32) worst case

**Space:** O(1)

## Solution

````python
class Solution:
    def hammingWeight(self, n: int) -> int:
        c = 0
        while n:
            n &= n - 1
            c += 1
        return c
````
