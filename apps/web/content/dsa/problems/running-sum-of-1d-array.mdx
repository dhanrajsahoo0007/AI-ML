Given an array nums, return the running sum of nums, where runningSum\[i\] =
sum(nums\[0\]..nums\[i\]) inclusive.

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 4]
    Output: [1, 3, 6, 10]

Example 2:
    Input: nums = [1, 1, 1, 1, 1]
    Output: [1, 2, 3, 4, 5]
````

## Constraints

````text
- 1 <= len(nums) <= 1000
- -10^6 <= nums[i] <= 10^6
````

<PremiumBreak />

## Approach

**Pattern:** Prefix Sum
Reuse the accumulated sum from the previous index instead of rescanning.

1. Initialize an empty result list and running total 0.
2. For each value in nums, add it to the total and append the total to result.
3. Return result.

## Complexity

**Time:** O(n) - single pass over nums, where n is len(nums).

**Space:** O(1) extra if output array is excluded; O(n) including the result list.

## Solution

````python
from typing import List


class Solution:
    def runningSum(self, nums: List[int]) -> List[int]:
        total = 0
        out: List[int] = []
        for x in nums:
            total += x
            out.append(total)
        return out
````
