Given an array of positive integers nums and a positive integer target, return the
minimal length of a contiguous subarray whose sum is greater than or equal to target.
If no such subarray exists, return 0.

## Examples

````text
Example 1:
    Input: target = 7, nums = [2, 3, 1, 2, 4, 3]
    Output: 2
Example 2:
    Input: target = 4, nums = [1, 4, 4]
    Output: 1
````

## Constraints

````text
- 1 <= target <= 10^9
- 1 <= len(nums) <= 10^5
- 1 <= nums[i] <= 10^4 (positive integers)
````

## Approach

**Pattern:** Variable-size sliding window on positives
Expand until the sum reaches the target, then shrink from the left while the sum stays valid to minimize length.

1. Add nums\[right\] to the running sum.
2. While sum &gt;= target, record the window length and subtract nums\[left\], advancing left.
3. Continue until the array is exhausted.

## Complexity

**Time:** O(n) - Each element is added once and removed at most once from the window sum.

**Space:** O(1) - Only running totals and indices are stored.

## Solution

````python
from typing import List


class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left = 0
        cur = 0
        best = 0

        for right in range(len(nums)):
            cur += nums[right]

            while cur >= target:
                width = right - left + 1
                best = width if best == 0 else min(best, width)
                cur -= nums[left]
                left += 1

        return best
````
