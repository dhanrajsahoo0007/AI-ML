Given the root of a binary search tree and a target (floating point), return the node value
whose absolute distance to target is minimum; break ties by choosing the smaller value.

## Examples

````text
Example 1:
    Input: BST [4,2,5,1,3], target = 3.714286
    Output: 4

Example 2:
    Input: BST [1], target = 4.428571
    Output: 1
````

## Approach

**Pattern:** Greedy BST descent
Walk toward the target while tracking the closest value seen so far, refining at each step.

1. Initialize closest to root.val.
2. While current exists, update closest using absolute differences and tie-break with min value.
3. Move left if target is smaller than current.val, else move right.

## Complexity

**Time:** O(h) - One downward path.

**Space:** O(1) - Iterative variables only.

2. At each node, compare its value with the target.
3. Update the closest value if the current node's value is closer to the target.
4. Move left if target is smaller, right if target is larger.

## Solution

````python
from typing import List, Optional


class TreeNode:
    def __init__(self, val: int = 0, left: Optional["TreeNode"] = None, right: Optional["TreeNode"] = None):
        self.val = val
        self.left = left
        self.right = right


def build_bst_insert(values: List[int]) -> Optional[TreeNode]:
    root: Optional[TreeNode] = None
    for v in values:
        if root is None:
            root = TreeNode(v)
            continue
        cur = root
        while True:
            if v < cur.val:
                if cur.left is None:
                    cur.left = TreeNode(v)
                    break
                cur = cur.left
            else:
                if cur.right is None:
                    cur.right = TreeNode(v)
                    break
                cur = cur.right
    return root


class Solution:
    def closestValue(self, root: Optional[TreeNode], target: float) -> int:
        closest = root.val
        cur = root
        while cur:
            if abs(cur.val - target) < abs(closest - target):
                closest = cur.val
            elif abs(cur.val - target) == abs(closest - target):
                closest = min(closest, cur.val)
            cur = cur.left if target < cur.val else cur.right
        return closest
````
