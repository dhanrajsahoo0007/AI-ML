Given an integer n, return how many structurally unique BSTs store values 1..n.

## Examples

````text
Example 1:
    Input: n = 3
    Output: 5
Example 2:
    Input: n = 1
    Output: 1
````

## Constraints

````text
- 1 <= n <= 19
````

<PremiumBreak />

## Approach

**Pattern:** Catalan / 1D DP
Choose each root r; left subtree has r-1 nodes, right has n-r, multiply and sum.

1. Let dp\[0\]=1, dp\[i\] = sum\_&#123;r=1..i&#125; dp\[r-1\]\*dp\[i-r\].
2. Return dp\[n\].

## Complexity

**Time:** O(n^2) for the convolution-style sum.

**Space:** O(n) for dp array.

## Solution

````python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        for i in range(1, n + 1):
            s = 0
            for r in range(1, i + 1):
                s += dp[r - 1] * dp[i - r]
            dp[i] = s
        return dp[n]
````
