Given strings s and t, return true if s is a subsequence of t (delete some
chars from t without reordering to obtain s).

## Examples

````text
Example 1:
    Input: s = "abc", t = "ahbgdc"
    Output: True
Example 2:
    Input: s = "axc", t = "ahbgdc"
    Output: False
````

## Constraints

````text
- 0 <= len(s) <= 100
- 0 <= len(t) <= 10^4
````

<PremiumBreak />

## Approach

**Pattern:** Two pointers / greedy on t
Walk t advancing pointer in s when characters match.

1. i over s, j over t; when t\[j\]==s\[i\] increment i; always increment j.
2. Return i == len(s).

## Complexity

**Time:** O(len(t)).

**Space:** O(1).

## Solution

````python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        if not s:
            return True
        i = 0
        for ch in t:
            if ch == s[i]:
                i += 1
                if i == len(s):
                    return True
        return False
````
