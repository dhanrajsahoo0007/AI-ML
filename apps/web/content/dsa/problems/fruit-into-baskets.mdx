You are picking fruit from trees in a row; each tree has a type label. You have
two baskets and may only collect at most two different types at a time. Return the
maximum number of fruits you can collect in one contiguous stretch.

## Examples

````text
Example 1:
    Input: fruits = [1, 2, 1]
    Output: 3
Example 2:
    Input: fruits = [0, 1, 2, 2]
    Output: 3
````

## Constraints

````text
- 1 <= len(fruits) <= 10^5
- 0 <= fruits[i] < len(fruits) in many statements (integer labels)
````

<PremiumBreak />

## Approach

**Pattern:** Longest substring with at most two distinct values
Sliding window with a frequency map; shrink when more than two types appear.

1. Expand the right pointer and increment the count for fruits\[right\].
2. While more than two keys exist, shrink from the left, deleting zero counts.
3. Track the maximum window length.

## Complexity

**Time:** O(n) - Each tree index enters and leaves the window at most once.

**Space:** O(1) - At most three distinct keys while adjusting the window.

## Solution

````python
from collections import defaultdict
from typing import Dict, List


class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        freq: Dict[int, int] = defaultdict(int)
        left = 0
        best = 0

        for right, label in enumerate(fruits):
            freq[label] += 1

            while len(freq) > 2:
                freq[fruits[left]] -= 1
                if freq[fruits[left]] == 0:
                    del freq[fruits[left]]
                left += 1

            best = max(best, right - left + 1)

        return best
````
