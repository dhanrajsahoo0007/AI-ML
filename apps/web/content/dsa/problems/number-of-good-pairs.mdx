Given an integer array nums, return the number of pairs (i, j) with i &lt; j such that nums\[i\] == nums\[j\].

## Examples

````text
Example 1:
    Input: nums = [1, 2, 3, 1, 1, 3]
    Output: 4
Example 2:
    Input: nums = [1, 1, 1, 1]
    Output: 6
````

## Constraints

````text
- 1 <= len(nums) <= 100
- 1 <= nums[i] <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Counting with combinations
For each value with frequency f, it contributes f choose 2 good pairs.

1. Count frequencies of each number.
2. For each frequency f, add f \* (f - 1) // 2 to the answer.
3. Return the total.

## Complexity

**Time:** O(n) - Counting pass.

**Space:** O(u) - u is number of distinct values (&lt;= 100 here).

## Solution

````python
from collections import Counter
from typing import List


class Solution:
    def numIdenticalPairs(self, nums: List[int]) -> int:
        counts = Counter(nums)
        return sum(f * (f - 1) // 2 for f in counts.values())
````
