Given a 0-indexed integer array nums and an integer k, in one operation:
1. Choose an index i, increase your score by nums\[i\].
2. Replace nums\[i\] with ceil(nums\[i\] / 3).
Return the maximum possible score after exactly k operations.

## Examples

````text
Example 1:
    Input: nums = [10,10,10,10,10], k = 5
    Output: 50

Example 2:
    Input: nums = [1,10,3,3,3], k = 3
    Output: 17
    Explanation: 10 + ceil(10/3)=4 + 3 = 17
````

## Constraints

````text
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^9
- 1 <= k <= 10^5
````

## Approach

**Pattern:** Greedy with Heap
Always pick the largest element (greedy). A max-heap efficiently provides
the largest element and allows replacing it with its reduced value.

1. Build a max-heap (negated values).
2. For k operations: pop the max, add to score, push ceil(max/3) back.
3. Return total score.

## Complexity

**Time:** O(n + k log n)
- O(n) for heapify, O(k log n) for k operations.

**Space:** O(n) for the heap.

## Solution

````python
import heapq
import math
from typing import List


class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        max_heap = [-num for num in nums]
        heapq.heapify(max_heap)

        score = 0
        for _ in range(k):
            max_elem = -heapq.heappop(max_heap)
            score += max_elem
            # Element decays but stays eligible for future greedy picks.
            heapq.heappush(max_heap, -math.ceil(max_elem / 3))

        return score
````
