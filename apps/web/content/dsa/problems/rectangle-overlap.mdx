Two axis-aligned rectangles rec1 and rec2 are given as \[x1,y1,x2,y2\] with
bottom-left (x1,y1) and top-right (x2,y2). Return True iff they overlap with
positive area.

## Examples

````text
Example 1:
    Input: rec1 = [0,0,2,2], rec2 = [1,1,3,3]
    Output: True
Example 2:
    Input: rec1 = [0,0,1,1], rec2 = [1,0,2,1]
    Output: False
````

## Constraints

````text
- Rectangles are valid (x1 < x2, y1 < y2)
````

<PremiumBreak />

## Approach

**Pattern:** Interval intersection
Rectangles overlap with positive area iff both x-intervals and y-intervals
intersect with strictly positive width and height.

1. Check horizontal gap: max(rec1\[0\], rec2\[0\]) &lt; min(rec1\[2\], rec2\[2\]).
2. Check vertical gap similarly on y edges.

## Complexity

**Time:** O(1)

**Space:** O(1)

## Solution

````python
from typing import List


class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        return not (
            rec1[2] <= rec2[0]
            or rec2[2] <= rec1[0]
            or rec1[3] <= rec2[1]
            or rec2[3] <= rec1[1]
        )
````
