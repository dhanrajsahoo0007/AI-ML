Return the pivot index where the sum of elements strictly to the left equals the
sum strictly to the right. If none exists, return -1.

## Examples

````text
Example 1:
Input: nums = [1, 7, 3, 6, 5, 6]
Output: 3
````

## Constraints

````text
- 1 <= len(nums) <= 10^4
- -1000 <= nums[i] <= 1000
````

<PremiumBreak />

## Approach

**Pattern:** Prefix-Suffix Balance
Track left sum while deriving right sum from total minus left minus current.

1. Compute total sum of nums.
2. Walk with left\_sum; for each i, right = total - left - nums\[i\]; if left == right return i.
3. Else return -1.

## Complexity

**Time:** O(n).

**Space:** O(1).

## Solution

````python
from typing import List


class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0
        for i, x in enumerate(nums):
            right = total - left - x
            if left == right:
                return i
            left += x
        return -1
````
