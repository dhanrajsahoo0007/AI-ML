DNA sequences are strings over &#123;A, C, G, T&#125;. Given a string s, return all distinct
10-letter-long sequences that occur more than once in s (in any order).

## Examples

````text
Example 1:
    Input: s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
    Output: ["AAAAACCCCC", "CCCCCAAAAA"]
Example 2:
    Input: s = "AAAAAAAAAAAAA"
    Output: ["AAAAAAAAAA"]
````

## Constraints

````text
- Typical length is up to 10^5; L = 10 is fixed for this classic formulation.
````

**Order.** Any order is accepted: the tests sort your result before comparing it.

<PremiumBreak />

## Approach

**Pattern:** Fixed-size sliding window with rolling hash or hashing
Slide a length-10 window and record hashes or substrings that have been seen before.

1. Track seen 10-mers in a set and duplicates in a second set (or use Counter).
2. Slide the window one character at a time.
3. Return sorted or arbitrary order of duplicates as required.

Restored notes (archived workbook):

Given a string, dna, that represents a DNA subsequence, and a number k, return all the contiguous subsequences (substrings) of length k
that occur more than once in the string.
The order of the returned subsequences does not matter.
If no repeated substring is found, the function should return an empty set.

## Complexity

**Time:** O(n) - Constant work per index when using hashing with O(1) updates.

**Space:** O(n) - Storing seen windows in the worst case.

## Solution

````python
from typing import List


class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        L = 10
        n = len(s)
        if n <= L:
            return []

        seen: set[str] = set()
        dup: set[str] = set()

        for i in range(n - L + 1):
            piece = s[i : i + L]
            if piece in seen:
                dup.add(piece)
            else:
                seen.add(piece)

        return list(dup)
````
