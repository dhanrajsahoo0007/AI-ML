Given an even-length string with n/2 '\[' and n/2 '\]', return the minimum swaps needed so every
prefix has enough '\[' to match closing brackets.

## Examples

````text
Example 1:
Input: "][]["
Output: 1
````

## Constraints

````text
- 2 <= len(s) <= 10^6
- len(s) is even and counts of '[' and ']' match
````

<PremiumBreak />

## Approach

**Pattern:** Prefix Imbalance Tracking
Track how far '\]' runs ahead of available '\['; each swap fixes two imbalance units.

1. Walk the string tracking imbalance when seeing '\]' before '\[' cancels it.
2. Record the maximum imbalance depth.
3. Return ceil(max\_depth / 2) via integer arithmetic.

## Complexity

**Time:** O(n) - Single pass.

**Space:** O(1) - Two integer counters.

## Solution

````python
class Solution:
    def minSwaps(self, s: str) -> int:
        imbalance = 0
        peak = 0
        for ch in s:
            if ch == "]":
                imbalance += 1
                peak = max(peak, imbalance)
            else:
                imbalance -= 1
        return (peak + 1) // 2
````
