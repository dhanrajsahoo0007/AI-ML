Given a list h of 26 integers (heights 0-7 mm for letters 'a' through 'z') and a word
of lowercase letters, compute the area of the rectangle that highlights the word when
each letter is 1 mm wide and the highlight height is the maximum letter height in the word.

## Examples

````text
Example 1:
Input: h = [1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 1, 3, 3, 1, 1, 1, 1, 1, 1, 1], word = "abc"
Output: 9
Explanation: max height among a,b,c is 3; width is 3; area = 9.
````

## Constraints

````text
- len(h) == 26, values in a valid range for the problem (typically 1-7).
- word uses lowercase English letters.
````

## Approach

**Pattern:** Array / Simulation
Scan the word once to find the maximum height among its letters, then multiply by word length.

1. Map each character in word to its index ord(c) - ord('a').
2. Track the maximum h\[i\] for letters appearing in word.
3. Return max\_height \* len(word).

## Complexity

**Time:** O(n) - n is the length of the word.

**Space:** O(1) - only a few scalars besides the fixed-size height list.

## Solution

````python
from typing import List


class Solution:
    def designerPdfViewer(self, h: List[int], word: str) -> int:
        max_h = 0
        for c in word:
            max_h = max(max_h, h[ord(c) - ord("a")])
        return max_h * len(word)
````
