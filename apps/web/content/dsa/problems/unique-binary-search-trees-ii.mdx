Given n, generate every structurally unique BST that stores values 1..n. Return
the list of roots (order among trees is not specified by the problem).

## Examples

````text
Example 1:
    Input: n = 1
    Output: a single tree with node 1
Example 2:
    Input: n = 3
    Output: 5 distinct trees (Catalan number C_3)
````

## Constraints

````text
- 1 <= n <= 8
````

**How the tests describe the input.** A linked list is written as an array of its values, head first; a binary tree as an array in level order, with `None` for a missing child. The code above the line in the editor turns those arrays into nodes and your answer back into an array: write the function below the line.

<PremiumBreak />

## Approach

**Pattern:** Divide and conquer with memoization
For each choice of root, combine any left subtree on smaller keys with any right on larger keys.

1. Define helper build(lo, hi) returning all trees for keys in \[lo, hi\].
2. If lo &gt; hi, return \[None\]; for each root r, combine subtrees from build(lo, r-1) and build(r+1, hi).
3. Memoize build(lo, hi) to avoid recomputing the same intervals.

## Complexity

**Time:** Exponential in n (Catalan number of trees times work per tree).

**Space:** O(n) recursion depth plus space for all generated trees.

## Solution

````python
from __future__ import annotations

from typing import List, Optional


class TreeNode:
    __slots__ = ("val", "left", "right")

    def __init__(self, val: int = 0, left: Optional[TreeNode] = None, right: Optional[TreeNode] = None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        memo: dict[tuple[int, int], List[Optional[TreeNode]]] = {}

        def build(lo: int, hi: int) -> List[Optional[TreeNode]]:
            if lo > hi:
                return [None]
            key = (lo, hi)
            if key in memo:
                return memo[key]
            out: List[Optional[TreeNode]] = []
            for r in range(lo, hi + 1):
                for left in build(lo, r - 1):
                    for right in build(r + 1, hi):
                        out.append(TreeNode(r, left, right))
            memo[key] = out
            return out

        return build(1, n)
````
