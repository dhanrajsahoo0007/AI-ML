Alice starts with 0 points in a game drawing integers uniformly from 1..W
until her total is at least k. She wins if her final total is at most n.
Return the probability of winning.

## Examples

````text
Example 1:
    Input: n = 10, k = 1, maxPts = 10
    Output: 1.0
Example 2:
    Input: n = 6, k = 1, maxPts = 10
    Output: 0.6
````

## Constraints

````text
- 0 <= k <= n <= 10^4
- 1 <= maxPts <= 10^4
````

**Precision.** The tests round your result to 5 decimal places before comparing it.

<PremiumBreak />

## Approach

**Pattern:** Dynamic programming with sliding window
dp\[i\] is probability of being at score i; transitions average the next W scores.

1. Early return 1.0 if k == 0 or even worst-case draws cannot exceed n.
2. Maintain dp\[i\] for i in \[0..n\] with sliding sum over the last W values
contributing to the next positions.
3. Return sum(dp\[i\]) for i in \[k..n\].

## Complexity

**Time:** O(n)

**Space:** O(n)

## Solution

````python
from typing import List


class Solution:
    def new21Game(self, n: int, k: int, maxPts: int) -> float:
        if k == 0 or n >= k + maxPts - 1:
            return 1.0
        dp: List[float] = [0.0] * (n + 1)
        dp[0] = 1.0
        s = 1.0
        W = maxPts
        for i in range(1, n + 1):
            dp[i] = s / W
            if i < k:
                s += dp[i]
            if i - W >= 0 and i - W < k:
                s -= dp[i - W]
        return sum(dp[k:])
````
