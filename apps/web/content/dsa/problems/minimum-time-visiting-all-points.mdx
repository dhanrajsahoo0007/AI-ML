You start at points\[0\]. In one second you may move one unit vertically,
horizontally, or diagonally. Return minimum time to visit all points in order.

## Examples

````text
Example 1:
    Input: points = [[1,1],[3,4],[-1,0]]
    Output: 7
Example 2:
    Input: points = [[3,2],[-2,2]]
    Output: 5
````

## Constraints

````text
- len(points) <= 100
- |coordinates| <= 10^3
````

<PremiumBreak />

## Approach

**Pattern:** Chebyshev distance
Diagonal moves cover min(dx, dy) diagonally; remaining steps are Manhattan
along one axis, so each segment costs max(\|dx\|, \|dy\|).

1. Sum over consecutive pairs max(abs(dx), abs(dy)).

## Complexity

**Time:** O(n)

**Space:** O(1) extra besides input

## Solution

````python
from typing import List


class Solution:
    def minTimeToVisitAllPoints(self, points: List[List[int]]) -> int:
        t = 0
        for i in range(1, len(points)):
            dx = abs(points[i][0] - points[i - 1][0])
            dy = abs(points[i][1] - points[i - 1][1])
            t += max(dx, dy)
        return t
````
