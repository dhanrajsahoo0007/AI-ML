Given strings s and t, return the minimum window substring of s such that every
character in t (including multiplicity) is included in the window. If no such
window exists, return the empty string.

## Examples

````text
Example 1:
    Input: s = "ADOBECODEBANC", t = "ABC"
    Output: "BANC"
Example 2:
    Input: s = "a", t = "a"
    Output: "a"
````

## Constraints

````text
- If t is empty or longer than s with no match, return "".
````

## Approach

**Pattern:** Variable sliding window with need/match counters
Expand until all required characters are satisfied, then shrink from the left while still valid to minimize length.

1. Count characters required from t and track how many required groups are fully satisfied.
2. Expand the right edge, updating satisfaction when counts hit targets.
3. While satisfied, update the best window, then shrink from the left until satisfaction breaks.

Restored notes (archived workbook):

It is the shortest substring of s that includes all of the characters present in t.
It must contain at least the same frequency of each character as in t.
The order of the characters does not matter here.
Time complexity O(nm)

## Complexity

**Time:** O(len(s) + len(t)) - Each pointer moves across s at most once; t is scanned once for counts.

**Space:** O(alphabet) - Frequency maps are bounded by distinct characters.

## Solution

````python
from collections import Counter
from typing import Dict


class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not s or not t:
            return ""

        need: Dict[str, int] = Counter(t)
        window: Dict[str, int] = Counter()
        required = len(need)
        formed = 0

        left = 0
        best_len = float("inf")
        best_l = best_r = 0

        for right in range(len(s)):
            ch = s[right]
            window[ch] += 1

            if ch in need and window[ch] == need[ch]:
                formed += 1

            while formed == required and left <= right:
                if right - left + 1 < best_len:
                    best_len = right - left + 1
                    best_l, best_r = left, right

                left_ch = s[left]
                window[left_ch] -= 1
                if left_ch in need and window[left_ch] < need[left_ch]:
                    formed -= 1
                left += 1

        return "" if best_len == float("inf") else s[best_l : best_r + 1]
````
