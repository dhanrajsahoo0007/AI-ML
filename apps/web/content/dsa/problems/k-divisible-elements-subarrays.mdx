Given an integer array nums and integers k and p, count distinct subarrays (by
value sequence) where at most k elements are divisible by p.

## Examples

````text
Example 1:
    Input: nums = [2, 3, 3, 2, 2], k = 2, p = 2
    Output: 11

Example 2:
    Input: nums = [1, 2, 3, 4], k = 4, p = 1
    Output: 10
````

## Constraints

````text
- 1 <= len(nums) <= 200
- 1 <= k <= len(nums)
- 1 <= p <= 20
````

## Approach

**Pattern:** Enumerate subarrays with divisibility count
Extend each left index while the divisible-by-p count stays within k; store tuples in a set.

1. For each start index i, maintain cnt of positions j where nums\[j\] % p == 0.
2. Extend j from i while cnt &lt;= k, inserting tuple(nums\[i:j+1\]) into a set.
3. Return the set size.

## Complexity

**Time:** O(n^3) in worst case due to tuple copying (constraints keep n small).

**Space:** O(number of distinct subarrays) - Stored tuples.

## Solution

````python
from typing import List


class Solution:
    def countDistinct(self, nums: List[int], k: int, p: int) -> int:
        seen: set[tuple[int, ...]] = set()
        n = len(nums)
        for i in range(n):
            cnt = 0
            for j in range(i, n):
                if nums[j] % p == 0:
                    cnt += 1
                if cnt > k:
                    break
                seen.add(tuple(nums[i : j + 1]))
        return len(seen)
````
