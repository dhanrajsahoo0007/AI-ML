Given the head of a linked list, delete the middle node and return the head of the modified list.
The middle node for n nodes is the node at index floor(n / 2) using 0-based indexing.

## Examples

````text
Example 1:
    Input: head = [1,3,4,7,1,2,6]
    Output: [1,3,4,1,2,6]

Example 2:
    Input: head = [1,2,3,4]
    Output: [1,2,4]
````

## Constraints

````text
- The number of nodes in the list is in the range [1, 10^5].
- 1 <= Node.val <= 10^6
````

**How the tests describe the input.** A linked list is written as an array of its values, head first; a binary tree as an array in level order, with `None` for a missing child. The code above the line in the editor turns those arrays into nodes and your answer back into an array: write the function below the line.

## Approach

**Pattern:** Fast / slow pointers
Advance fast by two steps per slow step so slow lands on the middle; keep previous to unlink.

1. If fewer than two nodes, return None (single node list becomes empty per problem variant).
2. Move slow, fast from head; prev trails slow.
3. When fast exhausts, set prev.next = slow.next.

## Complexity

**Time:** O(n) — one pass.

**Space:** O(1).

## Solution

````python
from __future__ import annotations

from typing import List, Optional


class ListNode:
    def __init__(self, val: int = 0, next: Optional[ListNode] = None):
        self.val = val
        self.next = next


def list_to_linked_list(values: List[int]) -> Optional[ListNode]:
    dummy = ListNode(0)
    cur = dummy
    for v in values:
        cur.next = ListNode(v)
        cur = cur.next
    return dummy.next


def linked_list_to_list(head: Optional[ListNode]) -> List[int]:
    out: List[int] = []
    while head:
        out.append(head.val)
        head = head.next
    return out


class Solution:
    def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return None
        slow = fast = head
        prev: Optional[ListNode] = None
        while fast and fast.next:
            fast = fast.next.next
            prev = slow
            slow = slow.next
        if prev:
            prev.next = slow.next if slow else None
        return head
````
