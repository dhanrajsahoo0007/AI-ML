You are given a directed graph of n nodes labeled 0..n-1 and a string colors where colors\[i\] is a
lowercase letter on node i. For any directed path, its color value is the maximum frequency of any
letter along the path. Return the largest color value among all valid paths, or -1 if the graph contains
a directed cycle.

## Examples

````text
Example 1:
    Input: colors = "abaca", edges = [[0,1],[0,2],[1,3],[2,3],[3,4]]
    Output: 3
Example 2:
    Input: colors = "a", edges = [[0,0]]
    Output: -1
````

## Constraints

````text
- n == len(colors)
- 1 <= n <= 10^5
- 0 <= len(edges) <= 10^5
````

## Approach

**Pattern:** Topological order + dynamic programming on letters
Process nodes in topological order; dp\[node\]\[c\] tracks the best count of letter c on a path ending at node.

1. Build adjacency list and indegrees; initialize dp\[i\]\[letter(colors\[i\])\] = 1.
2. Kahn's BFS: relax each edge u -&gt; v by taking component-wise max of dp\[v\] with dp\[u\] plus the letter at v.
3. If fewer than n nodes processed, return -1; else return the maximum entry in dp.

## Complexity

**Time:** O((n + e) \* 26) — constant alphabet factor.

**Space:** O(n \* 26 + n + e) for dp and graph.

## Solution

````python
from typing import List
from collections import deque


class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        g = [[] for _ in range(n)]
        indeg = [0] * n
        for u, v in edges:
            g[u].append(v)
            indeg[v] += 1
        dp = [[0] * 26 for _ in range(n)]
        for i in range(n):
            dp[i][ord(colors[i]) - ord("a")] = 1
        q: deque[int] = deque(i for i in range(n) if indeg[i] == 0)
        seen = 0
        best = 0
        while q:
            u = q.popleft()
            seen += 1
            for v in g[u]:
                for c in range(26):
                    add = 1 if ord(colors[v]) - ord("a") == c else 0
                    dp[v][c] = max(dp[v][c], dp[u][c] + add)
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
            best = max(best, max(dp[u]))
        return -1 if seen < n else best
````
