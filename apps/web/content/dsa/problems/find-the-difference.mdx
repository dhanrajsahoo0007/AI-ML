String t is formed by shuffling string s and adding exactly one extra letter.
Return that added letter.

## Examples

````text
Example 1:
    Input: s = "abcd", t = "abcde"
    Output: "e"
Example 2:
    Input: s = "", t = "y"
    Output: "y"
````

## Constraints

````text
- 0 <= len(s) <= 1000
- len(t) == len(s) + 1
- Letters are lowercase English
````

<PremiumBreak />

## Approach

**Pattern:** XOR / frequency
XOR all character codes; pairs from s cancel, leaving the extra character.

1. x = 0; XOR every ord in t, then XOR every ord in s.
2. Return chr(x).

## Complexity

**Time:** O(len(s) + len(t))

**Space:** O(1)

## Solution

````python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        x = 0
        for ch in t:
            x ^= ord(ch)
        for ch in s:
            x ^= ord(ch)
        return chr(x)
````
