Same as palindrome partitioning minimum cuts using bottom-up DP.

## Examples

````text
Example 1: s = "leet" -> 2
````

## Constraints

````text
- 1 <= len(s) <= 2000
````

<PremiumBreak />

## Approach

**Pattern:** 1D DP on suffix
cuts\[i\] minimum cuts for prefix s\[:i+1\].

1. Build palindrome table.
2. cuts\[i\] = min over j&lt;=i with pal\[j\]\[i\] of cuts\[j-1\]+1.

## Complexity

**Time:** O(n^2).

**Space:** O(n^2).

## Solution

````python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 2 or pal[i + 1][j - 1]):
                    pal[i][j] = True
        dp = [0] * n
        for i in range(n):
            if pal[0][i]:
                dp[i] = 0
                continue
            best = i
            for j in range(1, i + 1):
                if pal[j][i]:
                    best = min(best, dp[j - 1] + 1)
            dp[i] = best
        return dp[n - 1]
````
