Same as unique paths but grid\[i\]\[j\]==1 means obstacle.

## Examples

````text
Example 1: obstacleGrid=[[0,0,0],[0,1,0],[0,0,0]] -> 2
````

## Constraints

````text
- 1 <= m,n <= 100
````

<PremiumBreak />

## Approach

**Pattern:** Grid DP with blocked cells
Propagate 0 through obstacles.

1. If start or end blocked return 0.
2. dp\[j\] rolling; skip updating blocked cells to 0.

## Complexity

**Time:** O(m\*n). Space: O(n).

## Solution

````python
from typing import List


class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        if obstacleGrid[0][0] == 1 or obstacleGrid[-1][-1] == 1:
            return 0
        n = len(obstacleGrid[0])
        dp = [0] * n
        dp[0] = 1
        for i in range(len(obstacleGrid)):
            for j in range(n):
                if obstacleGrid[i][j] == 1:
                    dp[j] = 0
                elif j > 0:
                    dp[j] += dp[j - 1]
        return dp[-1]
````
