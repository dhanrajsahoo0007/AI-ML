For readers who have finished Start here and Fundamentals and now need to choose where Brightpost's bytes live. This hub teaches only what the cloud adds on top of the database theory in `/system-design/databases/*`: managed replicas and proxies, capacity units, tiers and lifecycle, transfer appliances, migration tooling and the managed queue/stream family. Read it in order: the data map first, then the three storage shapes, then databases and caches, then analytics and events, and finish with migration, which uses everything before it.
