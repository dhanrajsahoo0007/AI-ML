> **Outline.** This topic is planned and will be written up in a future iteration.

**What it will cover:** what managed buys you (patching, backups and failover) and the four building blocks the cloud adds to a relational engine: a synchronous standby for availability, asynchronous read replicas for read scale, a connection proxy for pooling and fast failover, and serverless or autoscaling compute. SQL itself is not taught here.
