Google Cloud's delivery tools are **Cloud Build** for CI, **Cloud Deploy** for promoting releases to GKE and Cloud Run with canaries and approvals, and **Infrastructure Manager** for running Terraform. Terraform is the de facto infrastructure-as-code tool on Google Cloud; Deployment Manager reached end of support on March 31, 2026.

## TL;DR

- **Terraform** (through Infrastructure Manager or your own pipeline) for infrastructure as code.
- **Cloud Build** to test and build images into Artifact Registry.
- **Cloud Deploy** to promote the same release through environments with canary rollouts.
- **Workload Identity Federation** so GitHub Actions or other CI deploy without service account keys.

## Coming from AWS

| On AWS | On Google Cloud | What actually changes |
|---|---|---|
| CloudFormation / CDK | Terraform via Infrastructure Manager | No Google-native template language in active use |
| CodeBuild | Cloud Build | Similar container-step builds |
| CodePipeline + CodeDeploy | Cloud Deploy | Canary and approvals for GKE and Cloud Run |
| CodeCommit | Secure Source Manager | Most teams use GitHub or GitLab instead |
