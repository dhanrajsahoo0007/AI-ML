**Memorystore** is Google Cloud's managed cache, with Valkey, Redis (single node and Cluster) and Memcached engines. **Memorystore for Valkey**, generally available since April 2025, is the default for new caches and supports cross-Region replication.

## TL;DR

- **Memorystore for Valkey** for caches, sessions, counters, leaderboards and presence.
- Pick shard and replica counts; scaling is online.
- No DAX-style integrated cache for Firestore or Bigtable: put Memorystore in front yourself.

## Coming from AWS

| On AWS | On Google Cloud | What actually changes |
|---|---|---|
| ElastiCache for Valkey | Memorystore for Valkey | Very similar; no per-request serverless option |
| MemoryDB | Memorystore with persistence | Snapshots and AOF, not a synchronous multi-zone log |
| DAX | No equivalent | Cache in the application in front of Firestore or Bigtable |
