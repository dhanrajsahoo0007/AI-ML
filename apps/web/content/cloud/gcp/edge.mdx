On Google Cloud the edge is built into the load balancer. The **global external Application Load Balancer** terminates TLS at Google's edge and routes to the nearest healthy backend, **Cloud CDN** is a switch on that load balancer, and **Cloud Armor** attaches to it. **Cloud DNS** handles names and routing policies; **Media CDN** serves large video and downloads.

## TL;DR

- **Global external Application Load Balancer** as the single entry point for HTTP, worldwide.
- **Cloud CDN** enabled per backend for caching; **Media CDN** for streaming-scale video.
- **Cloud DNS** with geolocation, weighted and failover routing policies.
- **Cloud Armor** on the same load balancer for WAF and DDoS protection.

## Coming from AWS

| On AWS | On Google Cloud | What actually changes |
|---|---|---|
| Route 53 | Cloud DNS | Routing policies similar; health checks via the load balancer |
| CloudFront | Cloud CDN on the global load balancer | CDN is a backend setting, not a separate distribution |
| Global Accelerator | Global external load balancer | Anycast IP is built in, no extra service |
| Lambda@Edge | Service Extensions | Plugins on load balancers and Media CDN; narrower than Lambda@Edge |
