Analytics is where Google Cloud is strongest. **BigQuery** is a serverless warehouse with no clusters to size, it queries data lake files through **BigLake**, and it takes streams straight from **Pub/Sub**. **Dataflow** runs Apache Beam pipelines in batch or streaming mode, **Dataproc** runs Spark, and **Looker** sits on top.

## TL;DR

- **BigQuery** for warehousing, ad-hoc SQL and BI, billed per TB scanned or by reserved slots.
- **Dataflow** for streaming and batch ETL with one programming model (Apache Beam).
- **Dataproc** for Spark; **Dataplex** for catalog and governance.
- Partition and cluster large BigQuery tables; select only the columns you need.

## Coming from AWS

| On AWS | On Google Cloud | What actually changes |
|---|---|---|
| Redshift + Athena | BigQuery | One serverless engine for both warehouse tables and lake files |
| Managed Flink | Dataflow | Apache Beam instead of Flink; same code for batch and streaming |
| EMR | Dataproc | Similar; Serverless for Apache Spark for jobs without clusters |
| Glue Data Catalog | Dataplex / BigLake metastore | Catalog and governance across lake and warehouse |
| Quick Sight | Looker | Semantic modelling layer (LookML) |
