Azure serverless centres on **Azure Functions**, with **triggers and bindings** that read and write other services declaratively. **Durable Functions** has long offered workflows written as code, **Logic Apps** offers low-code integration, **Event Grid** routes events, **API Management** fronts APIs, and **Web PubSub** holds WebSocket connections for you.

## TL;DR

- **Functions** (Flex Consumption plan) for event-driven code; **Durable Functions** for long-running orchestrations in code.
- **Logic Apps** for integration workflows across Microsoft 365, SaaS and Azure.
- **Event Grid** for event routing; **Service Bus** when work must be queued reliably.
- **API Management** in front of APIs; **Web PubSub** or **SignalR Service** for real-time connections.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| Lambda | Azure Functions | Bindings read and write other services without SDK code |
| Step Functions | Durable Functions or Logic Apps | Code-first (Durable) or low-code (Logic Apps) |
| EventBridge | Event Grid | Also hosts an MQTT broker for IoT |
| API Gateway WebSocket APIs | Web PubSub | Send to users or groups by id; scale in units of connections |
| API Gateway REST | API Management | Fuller developer portal and policy engine |
