Azure's analytics story is **Microsoft Fabric**, a SaaS platform on one data lake (**OneLake**) that bundles a warehouse, lakehouse, Spark, pipelines, real-time analytics and **Power BI**. **Azure Databricks** is the other common choice for Spark-heavy teams, and **Data Factory** handles data integration.

## TL;DR

- **Fabric** for an all-in-one Microsoft analytics stack, billed by shared capacity.
- **Azure Databricks** for Spark, Delta Lake and ML engineering.
- **Data Factory** pipelines for ingestion from databases, SaaS and on-prem.
- **Power BI** for dashboards, reading directly from OneLake.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| Redshift + Athena + Glue + Quick Sight | Fabric | One SaaS platform with one capacity bill |
| EMR | Azure Databricks or Fabric Spark | Databricks is a first-party Azure service |
| Managed Flink | Stream Analytics / Fabric Real-Time Intelligence | SQL-based stream processing |
| Glue ETL | Data Factory | Hundreds of connectors, including on-prem via self-hosted runtimes |
| S3 data lake | OneLake / Data Lake Storage | Delta tables by default |
