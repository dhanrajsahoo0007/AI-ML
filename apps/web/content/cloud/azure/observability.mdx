**Azure Monitor** is the umbrella for metrics, logs and alerts on Azure. Logs land in **Log Analytics** workspaces and are queried with **KQL**; **Application Insights** adds application performance monitoring and distributed tracing through OpenTelemetry; and **managed Prometheus and Grafana** serve Kubernetes-heavy teams.

## TL;DR

- **One Log Analytics workspace** per environment (or per team) with retention and table plans set deliberately.
- **Application Insights** with the Azure Monitor OpenTelemetry distro for traces and dependencies.
- **Alerts** on symptoms: failed requests, latency, queue length and dead-letter counts.
- **Activity Log** for control-plane changes; export it to a workspace.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| CloudWatch metrics and alarms | Azure Monitor metrics and alerts | Alert rules can query logs with KQL |
| CloudWatch Logs + Logs Insights | Log Analytics + KQL | One workspace across many resources |
| X-Ray | Application Insights | Both use OpenTelemetry |
| CloudTrail | Activity Log | Control-plane events per subscription |
