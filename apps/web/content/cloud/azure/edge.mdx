**Azure Front Door** is Azure's global front door: CDN caching, layer-7 load balancing across Regions and WAF in one service. **Azure DNS** hosts zones, and **Traffic Manager** steers non-HTTP traffic with DNS. The classic tiers are retiring (Front Door classic on March 31, 2027; Azure CDN Standard from Microsoft classic on September 30, 2027), so new designs use **Front Door Standard or Premium**.

## TL;DR

- **Front Door Standard/Premium** in front of every global web app or API: caching, failover across Regions, WAF.
- **Azure DNS** for zones, including private zones for private endpoints.
- **Traffic Manager** for DNS-based failover of non-HTTP endpoints.
- Premium adds Private Link to origins and managed WAF rule sets.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| CloudFront + Global Accelerator | Front Door | One service for CDN and global HTTP load balancing |
| Route 53 hosted zones | Azure DNS | Routing policies live in Traffic Manager instead |
| Route 53 routing policies | Traffic Manager | Priority, weighted, performance and geographic routing |
| Lambda@Edge | Front Door rules engine | Rule-based rewrites and headers; no custom code |
