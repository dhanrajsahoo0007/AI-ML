**Azure Managed Redis** is the cache for new Azure designs. It is built on Redis Enterprise, clustered by default, and supports active geo-replication. The older **Azure Cache for Redis** is closed to new customers and retiring (Enterprise tiers on March 31, 2027; Basic, Standard and Premium on September 30, 2028).

## TL;DR

- **Azure Managed Redis** for caches, sessions, counters and real-time state.
- Clients must support **Redis Cluster** because instances are clustered by default.
- **Cosmos DB integrated cache** caches point reads in front of Cosmos DB, like DAX for DynamoDB.
- Plan migrations off Azure Cache for Redis before its retirement dates.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| ElastiCache for Valkey | Azure Managed Redis | Redis Enterprise based, with modules such as search and JSON |
| ElastiCache Global Datastore | Active geo-replication | Multi-Region writes with conflict resolution |
| DAX | Cosmos DB integrated cache | Through the dedicated gateway |
| ElastiCache for Memcached | No equivalent | Use Azure Managed Redis |
