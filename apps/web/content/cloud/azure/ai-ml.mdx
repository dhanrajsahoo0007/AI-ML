Azure's AI platform is **Microsoft Foundry** (formerly Azure AI Foundry). It deploys OpenAI models, **Claude** and many others, runs agents through **Foundry Agent Service**, and evaluates and filters them. **Azure AI Search** is the usual retrieval layer for RAG, and **Azure Machine Learning** trains and serves your own models.

## TL;DR

- **Microsoft Foundry** for LLM features, with Entra ID auth, private networking and content safety.
- **Foundry Agent Service** to run agents with tools, memory and tracing.
- **Azure AI Search** for hybrid keyword and vector retrieval.
- **Provisioned throughput units** when token quotas on standard deployments are not enough.

## Coming from AWS

| On AWS | On Azure | What actually changes |
|---|---|---|
| Bedrock | Microsoft Foundry | OpenAI models are first-party; Claude available on both |
| Bedrock AgentCore | Foundry Agent Service | Managed agent runtime |
| Bedrock Knowledge Bases | Azure AI Search | Index, vectorise and retrieve with built-in skills |
| SageMaker AI | Azure Machine Learning | Training, registries and managed endpoints |
